> - 数据核对时间：**2026-10**
> - 5A 级景区：**360 家已撰写精编词条**（简介 + 导游词核心稿 + 讲解要点提示）

**重要提醒**

1. 导游词为通用讲解稿，使用前请核对最新门票、开放时间、预约与限流政策。
2. A 级景区名单动态变化（新增、复核、降级、摘牌），建议每年复核一次。
3. 4A 名录为**不完全收录**，各省 4A 实际数量远超索引条数，可按需补写词条。
4. 黄河壶口瀑布旅游区为陕西延安与山西临汾共有，在两省文件中各收录一次；新疆兵团部分景区与新疆自治区重叠统计，已在文件内注明，全库计数时请勿重复。

## 五、已知待核实问题（汇总）

各省文件第三节「待核实与补充事项」均列有明细，全库层面的共性问题如下：

1. **4A 名录缺口大**：全国 4A 约 4,700–6,000 家，本库仅收录 2896 条，各省覆盖率约 30%–80% 不等，需按省文旅厅最新公告续补。
2. **部分景区等级处于变动中**：桂林乐满地度假世界（2025 年被降低质量等级，广西文件暂未撰写词条）、乔家大院（2019 摘牌、2024 重新确定）、西夏陵（现为 4A 非 5A）等。
3. **官方合并口径**：三峡大坝与屈原故里在文旅部统计中合并为一家；部分省份的联合评定景区（如云台山-神农山-青天河）近年名称有变动。
4. **硬数据多版本**：景区面积、海拔、年代等在不同来源中存在多个版本，词条中已回避或加注，讲解时建议用「约」。
5. **涉民族宗教内容**：西藏、青海、新疆、云南、贵州等地词条已按客观、非猎奇口径处理，并区分「史实」与「相传」。
