**【景区简介】**（约240字）

故宫博物院位于北京市东城区景山前街4号，是明清两代的皇家宫殿，旧称紫禁城。明永乐四年（1406年）始建，永乐十八年（1420年）建成，此后至1911年，明代14位、清代10位共24位皇帝在此居住理政。紫禁城南北长961米、东西宽753米，四面城墙高约10米、外绕宽52米的护城河，占地约72万平方米，现存木结构古建筑千余座、房屋8700余间，是世界上现存规模最大、保存最为完整的木结构古建筑群。1961年列为第一批全国重点文物保护单位，1987年列入《世界遗产名录》。1925年10月10日故宫博物院正式成立，现藏文物逾186万件（套）。

**【导游词核心稿】**（约590字）

各位游客朋友们，大家好！欢迎来到北京故宫博物院。我们面前这片红墙黄瓦的建筑群，就是明清两代的皇宫——紫禁城；1925年10月10日起，它又多了一个名字：故宫博物院。

先说一个"大"字。紫禁城南北长961米、东西宽753米，占地约72万平方米，房屋8700余间。它是世界上现存规模最大、保存最完整的木结构古建筑群。1987年，联合国教科文组织把它列入了《世界遗产名录》。

请大家随我沿中轴线往里走。穿过午门、太和门，眼前这座坐落在三层汉白玉须弥座上的大殿，就是太和殿，老百姓叫它"金銮殿"。它面阔11间、进深5间，建筑面积2377平方米，连同台基通高35.05米，是全国现存最大的木结构大殿。明清两代最隆重的典礼——皇帝登基、大婚、命将出征，都在这里举行。

太和殿之后是中和殿、保和殿。据史料记载，自乾隆五十四年（1789年）起，科举最高一级的殿试改在保和殿举行，"金殿传胪"唱名也在这里，此后成为定制。

再往后是乾清宫、交泰殿、坤宁宫，最北端是御花园。相传，宫门上的门钉横九竖九共八十一颗，取"九九归一"之意，九是阳数之极，只有皇家能用。

最后提醒各位：故宫实行单向参观，由午门进入，从神武门或东华门离开，全程步行约需3到4小时。出行前请核实最新的开放时间、预约和限流政策。祝大家在这座六百多岁的紫禁城里，收获一段难忘的中国故事。

**【讲解要点提示】**
- 必讲：明清24位皇帝、中轴线三大殿、1987年列入世界遗产、1925年建院
- 数据锚点：1406年始建／1420年建成；占地约72万平方米、房屋8700余间；太和殿建筑面积2377平方米、通高35.05米；藏品逾186万件（套）
- 常见误区：①"故宫有9999.5间房"只是民间传说，1970年代实测为8700余间；②雍正以后皇帝日常起居与理政在养心殿，并非都住乾清宫；③"金銮殿"是俗称，正式名称是太和殿
- 互动/提问设计：太和殿屋脊上的走兽共有10只，是全国古建筑中唯一的一例，请大家抬头数一数——为什么它能"多"一只？（答案：多出的"行什"为雷神，象征最高等级）

### 2. 天坛公园

| 项目 | 内容 |

| 评定年份 | 2007 |

**【景区简介】**（约230字）

天坛公园位于北京市东城区，是明清两代皇帝祭天、祈谷和祈雨的场所。始建于明永乐十八年（1420年），初名"天地坛"，明嘉靖年间改制后专用于祭天，始称"天坛"。园区占地约273万平方米，约为紫禁城的近四倍，是中国现存规模最大、形制最完备的古代祭祀建筑群。主要建筑有祈年殿、圜丘坛、皇穹宇、斋宫、神乐署等，整体遵循"天圆地方""以南为尊"的礼制思想，主要建筑均作圆形、坐北朝南。祈年殿为三重檐攒尖顶圆形木构大殿，直径32.72米、高38米，全殿不用大梁长檩，以28根楠木柱支撑。1998年，天坛被列入《世界遗产名录》。

**【导游词核心稿】**（约560字）

各位游客朋友们，大家好！欢迎来到天坛。这里是明清两代皇帝祭天、祈谷的地方，1998年被列入《世界遗产名录》。

各位抬头看，天坛的建筑有一个共同点——圆的。古人相信"天圆地方"，所以祭天的坛、殿都建成圆形，围墙则是北圆南方。整个园区占地约273万平方米，差不多是紫禁城的四倍大。

我们现在站的地方是圜丘坛，皇帝冬至祭天的所在。坛分三层，最上层正中是那块圆形的"天心石"。请大家注意脚下的石板：以天心石为中心，第一环9块，第二环18块，第三环27块，一圈一圈按九的倍数往外铺，最外一环81块。为什么用九？因为在古人的数字观念里，九是阳数之极，只有"天"配得上。

往北走，就到了皇穹宇，它是存放祭天神牌的地方。环绕它的这道圆形围墙，就是大名鼎鼎的"回音壁"。相传，两个人分别站在东西两端贴墙低声说话，声音能清晰地传到对方耳朵里——这是因为墙面磨得极光滑，声波沿着圆弧一次次反射。有兴趣的朋友，不妨等会儿亲自试一试。

最后登场的是天坛的标志——祈年殿。它直径32.72米、高38米，三重蓝瓦金顶，全殿不用一根大梁。支撑它的是28根楠木柱：中间4根叫"龙井柱"，象征春夏秋冬四季；中层12根叫"金柱"，象征一年12个月；外层12根叫"檐柱"，象征一天12个时辰。据史料记载，这套数字设计寄托着古人对风调雨顺、五谷丰登的祈愿。

时间有限，请大家跟紧队伍，园内步行与参观约需2小时。出行前请核实最新开放与预约政策。祝各位在天坛，读懂中国人"敬天爱人"的古老智慧。

**【讲解要点提示】**
- 必讲：天圆地方理念、圜丘"九"的倍数、祈年殿28柱、1998年世界遗产
- 数据锚点：占地约273万平方米；祈年殿直径32.72米、高38米；1420年始建；1520年代改名天坛（嘉靖改制）
- 常见误区：①天坛不是"祭祖"的地方，是祭天；②祈年殿不是皇帝住的地方，是祈谷典礼场所；③回音壁并非"隔音墙"，而是声学反射现象
- 互动/提问设计：请游客猜一猜，为什么圜丘坛的石板、台阶数都用"九"的倍数？（答案：九为阳数之极，象征天）

### 3. 颐和园

| 项目 | 内容 |

| 等级 | 5A（2007年评定） |
| 所在地 | 北京市海淀区新建宫门路19号 |

| 评定年份 | 2007 |

**【景区简介】**（约235字）

颐和园位于北京市海淀区，是清代大型皇家园林，前身为清漪园，始建于清乾隆十五年（1750年）。咸丰十年（1860年）遭英法联军焚毁，光绪十四年（1888年）重建并改称"颐和园"。全园占地约290万平方米，其中昆明湖水面约占四分之三，主要由万寿山（原称瓮山，高58.59米）和昆明湖（由瓮山泊拓展而成）构成，现存各式宫殿园林古建3000余间（栋），藏有各类文物4万余件。核心景观有长廊、佛香阁、排云殿、十七孔桥、清晏舫（石舫）、谐趣园、苏州街、西堤等，集中国古典造园艺术之大成。1998年，颐和园被列入《世界遗产名录》，是中国现存最完整的皇家园林之一。

**【导游词核心稿】**（约570字）

各位游客朋友们，大家好！欢迎来到颐和园。这是中国现存最完整的一座皇家园林，1998年列入《世界遗产名录》。

先交代一句来历：它本名清漪园，乾隆十五年（1750年）为庆贺母亲六十大寿而建；咸丰十年（1860年）被英法联军烧毁；光绪十四年（1888年）重建，改名"颐和园"，取"颐养冲和"之意。

全园占地约290万平方米，水面占了将近四分之三。一座万寿山、一片昆明湖，构成了它的骨架——这就是中国造园最讲究的手法："一池三山""山水相依"。

进了东宫门，我们先看仁寿殿，这是慈禧太后和光绪皇帝处理政务的地方，"仁寿"二字出自《论语》"仁者寿"。绕过殿后，眼前豁然开朗，昆明湖到了。

湖的北岸，那条贴山而建的彩色长廊，全长728米，共有273间，梁枋上绘有苏式彩画一万四千余幅，1990年被收入《吉尼斯世界纪录》，是世界上最长的画廊。相传，慈禧太后在园中散步时怕日晒雨淋，才特意修了这条长廊。

抬头看山，万寿山前山正中那座八面三层四重檐的高阁，就是佛香阁，高41米，是全园的构图中心和制高点。它依山而建，八根铁梨木大柱直通顶层，气势不凡。

再看湖上那道长桥——十七孔桥，全长150米，桥洞从中间往两边数都是"九"，正中最大的第九孔正对着南湖岛上的龙王庙。桥栏望柱上雕着544只石狮，形态各不相同。

时间有限，整个园区步行参观约需3小时。出行前请核实最新的开放时间、门票与园内游船政策。祝各位在这座"皇家山水"里，走出一身诗意。

**【讲解要点提示】**
- 必讲：清漪园—颐和园的沿革、山水格局、长廊与佛香阁、1998年世界遗产
- 数据锚点：1750年始建／1888年重建改名；占地约290万平方米；长廊728米、273间、彩画14000余幅；佛香阁高41米；十七孔桥长150米、石狮544只
- 常见误区：①石舫（清晏舫）并非真的能行船，取"水能载舟，亦能覆舟"的警诫之意；②万寿山原名瓮山，昆明湖原名瓮山泊，是乾隆时改的名；③颐和园不是"避暑山庄"
- 互动/提问设计：请游客想一想，为什么十七孔桥的桥洞从两边数都是"九"？（答案：九为阳数之极，且从中间数到两边都是第九孔，暗合"九九"之数）

**【景区简介】**（约240字）

八达岭—慕田峪长城旅游区由延庆区八达岭长城与怀柔区慕田峪长城两片组成，是明长城中保存最完好、最具代表性的地段。八达岭长城位于军都山关沟北口，为居庸关之外口，自古有"居庸之险不在关而在八达岭"之说；现开放游览段约3741米，城墙平均高约7.8米、上宽约5.8米，可容五马并骑、十人并行，敌楼、墩台密集。慕田峪长城西接居庸关、东连古北口，全长5400米，有敌楼22座，植被覆盖率超过96%，以"险、秀、奇、绝"著称，其"正关台"三座敌楼并立、"大角楼"形制独特，在国内均属罕见。长城于1987年被联合国教科文组织列入《世界遗产名录》。

**【导游词核心稿】**（约560字）

各位游客朋友们，大家好！今天我们要登的，是中华民族最著名的地标——长城。1987年，长城被列入《世界遗产名录》。

我们所在的八达岭，位于北京西北的军都山关沟北口，是居庸关的外口。古人说"居庸之险不在关，而在八达岭"，可见它地势之要。八达岭长城现有开放段约3741米，城墙平均高约7.8米，顶面宽约5.8米——什么概念？五匹马并排走、十个人并肩行，都不拥挤。这样的尺度，是为驻兵、运粮、传警设计的。

大家顺着马道往上走，留意脚下的青砖和墙上的射孔、垛口。每隔一段就有一座敌楼，可以屯兵、存粮、放哨。明代隆庆年间，蓟镇总兵戚继光主持加固这一段长城，把城墙加高加厚，还创造性地修建了"空心敌台"——士兵能住进去，战斗力大大提高。这是中国军事工程史上的一项了不起的发明。

如果各位去的是慕田峪段，那是另一番风貌。慕田峪长城全长5400米，有敌楼22座，森林覆盖率超过96%，春看山花、秋赏红叶，被称为"万里长城独秀"。那里的"正关台"由三座敌楼并排矗立，在国内长城中是独一无二的。

相传，民间有"不到长城非好汉"的说法，说的正是登临八达岭的豪情——这句话出自毛泽东1935年所作《清平乐·六盘山》。

最后提醒：长城地势陡峭，请穿防滑鞋、量力而行，不要在未开放的城段攀爬。出行前请核实开放时间、预约与索道运营情况。祝各位登城顺利，做一回"好汉"！

**【讲解要点提示】**
- 必讲：长城1987年世界遗产、八达岭的军事地位、戚继光与空心敌台、慕田峪"秀"的特色
- 数据锚点：八达岭开放段约3741米；城墙高约7.8米、上宽约5.8米；慕田峪全长5400米、敌楼22座；1987年列入世界遗产
- 常见误区：①长城不是秦代一次性修成的，现存多为明代遗存，八达岭、慕田峪均为明长城；②长城不等于"一道墙"，而是由城墙、敌楼、烽燧、关城组成的防御体系；③"孟姜女哭长城"属民间传说，需与史实区分
- 互动/提问设计：请游客观察敌楼上的射孔朝向，想一想为什么都朝外？（答案：防御外敌，兼顾观察与射击）

### 5. 明十三陵景区（神路—定陵—长陵—昭陵）

| 等级 | 5A（2011年评定） |
| 所在地 | 北京市昌平区十三陵镇 |
| 类型 | 陵寝祠庙 · 遗址考古 · 世界文化遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**（约245字）

明十三陵位于北京市昌平区天寿山南麓，是明朝13位皇帝的陵寝群。陵区自明永乐七年（1409年）始建长陵，至明末崇祯帝入葬思陵，营建延续230余年，共葬13位皇帝、23位皇后及众多妃嫔、太子，是中国现存规模最大、帝后陵寝最多的一处皇陵建筑群，陵区面积约40平方公里。各陵共用一条长约7公里的神道，自南向北依次排列石牌坊、大红门、神功圣德碑楼、石像生、龙凤门。长陵为十三陵首陵，其祾恩殿为现存规模最大的楠木大殿，殿内60根金丝楠木柱最大直径达1.124米。定陵是唯一经科学发掘的地下宫殿，1956—1957年发掘，地宫距地面27米、总面积1195平方米，出土文物3000余件。2003年，明十三陵作为"明清皇家陵寝"扩展项目列入《世界遗产名录》。

**【导游词核心稿】**（约580字）

各位游客朋友们，大家好！欢迎来到明十三陵。这片群山环抱的盆地，就是明朝十三位皇帝的长眠之地。

先说规模：陵区从永乐七年（1409年）动工建长陵开始，前后延续了230多年，一共葬着13位皇帝、23位皇后，陵区面积大约40平方公里。2003年，它作为"明清皇家陵寝"的扩展项目，被列入《世界遗产名录》。

各位游客朋友们，大家好！欢迎来到圆明园。这是一座"既美且痛"的园子——它曾经是中国皇家造园艺术的巅峰，如今是留给整个民族的课堂。

1988年，圆明园遗址公园正式开放。我们今天来这里，不是看"园林"，而是读"历史"。

遗址区范围很大，参观西洋楼、福海与园内主要景点约需3到4小时。出行前请核实开放时间、园内交通车与遗址保护规定，请勿攀爬残迹。愿大家在圆明园，记住美，更记住教训。

先问大家一个问题：在没有铁路和公路的年代，南方的粮食怎么运到北京？答案是——走水路，走大运河。而这条水路的北端终点，就是我们脚下的通州。通州自古是京杭大运河北端的漕运码头和仓储重镇，古人称它是"九重肘腋之上流，六国咽喉之雄镇"——意思是说，它是京师的生命线。

各位请看远处那座高塔，那就是燃灯佛舍利塔，通州城的地标。它始建于北周，现存为清代重修，是八角十三级密檐式实心砖塔，高约56米。当年漕船北上，船工远远望见塔影，就知道——通州到了，京城快到了。所以古人写诗说"云光水色潞河秋"，又道"一枝塔影认通州"。

再看塔下这片院落，叫"三庙一塔"——文庙、佑胜教寺、紫清宫三座庙宇，加上这座燃灯塔。儒、释、道三家比邻而居，共处一地近千年，这在全国都属少见。它说明什么？说明运河文化从来就是开放、包容的：南来北往的商人、船工、学子，各自带着信仰在此汇聚、共处。

顺着滨水步道往南走，就是大运河森林公园和运河公园。这一段河道水阔岸绿，春天看柳、夏天观荷，是市民休闲的好去处。园内还有新建的大运河博物馆（首都博物馆东馆），用现代展陈把运河的开凿、漕运、市井生活讲得清清楚楚，非常值得一看。

景区沿河展开，全程参观约需3到4小时。出行前请核实开放时间、游船班次与博物馆预约方式。祝各位沿着这条千年水道，读懂北京"因运而兴"的另一半身世。

**【讲解要点提示】**
- 必讲：通州作为大运河北端漕运码头的地位、"三庙一塔"三教共处、2014年中国大运河列入世界遗产、2024年评为5A
- 数据锚点：燃灯塔八角十三级、高约56米；塔始建北周、现存为清代重修；2024年2月评定为5A
- 常见误区：①通州段属于"北运河"，是京杭大运河的北端，不要与隋唐大运河混为一谈；②"三庙一塔"是三座庙宇加一座塔，不是一座庙；③2014年列入世界遗产的是"中国大运河"整体，并非通州单独申报
- 互动/提问设计：请游客想一想，"三庙一塔"中儒、释、道三教为何能共处一地？（答案：运河码头人口流动大、信仰多元，形成了包容共生的城市性格）
