## 一、5A级景区（精编词条）

### 1. 苏州市苏州园林（拙政园-留园-虎丘）

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 江苏省苏州市姑苏区 |
| 类型 | 古典园林 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 5-6 小时（三处） |

**【景区简介】**

苏州市苏州园林（拙政园-留园-虎丘）位于江苏省苏州市姑苏区，2007年入选首批国家5A级旅游景区，由拙政园、留园、虎丘山风景名胜区三处组成。拙政园始建于明正德四年（1509年），占地约5.2万平方米，为中国四大名园之一，以水为中心、亭榭错落。留园始建于明万历二十一年（1593年），占地约2.3万平方米，以建筑空间的分隔与渗透见长。虎丘相传为春秋吴王阖闾葬地，有"吴中第一名胜"之誉；建于五代后周显德六年（959年）的云岩寺塔（虎丘塔）为八角七层砖塔，塔身倾斜而千年不倒。1997年与2000年，苏州古典园林分两批列入《世界遗产名录》。

**【导游词核心稿】**

各位游客朋友们，大家好！欢迎来到苏州。今天我们要看的是"苏州园林"这个金字招牌里最硬的三个点：拙政园、留园和虎丘。它们在2007年一起进了首批国家5A级景区，而苏州古典园林，1997年和2000年分两批被列入《世界遗产名录》。

先说拙政园。它始建于明正德四年，也就是1509年，占地约5.2万平方米，是中国四大名园之一。据史料记载，园名取自西晋潘岳《闲居赋》里"此亦拙者之为政也"一句——意思是，我这等笨拙之人，就把浇花种菜当作政事吧。一句自谦的话，成就了中国园林史上最风雅的名字。拙政园的看点是"水"，全园以水为中心，远香堂、小飞虹、与谁同坐轩依次展开，走一步换一景，这叫"移步换景"。

再说留园。它建于明万历二十一年（1593年），占地2.3万平方米，比拙政园小一半，但它的厉害之处在"空间"——一条曲廊把园子切成四个性格不同的部分，明明是同一个园子，你却总觉得前面还有没走完的地方。留园的冠云峰，是太湖石里的极品。

最后是虎丘。相传春秋时吴王阖闾葬在这里，剑池之下就是墓门，至今仍是谜。真正镇场的是那座云岩寺塔，建于五代后周显德六年（959年），八角七层，因为地基不均匀沉降，塔身明显倾斜，被称为"中国的比萨斜塔"——但它比比萨斜塔还早了两百多年。

最后提醒：三处相距不远但步行较累，请穿软底鞋；园内地面湿滑、门槛较多，注意脚下；旺季人流大，出行前请核实预约与开放安排。好，我们进园！

**【讲解要点提示】**
- 必讲：1997/2000年苏州古典园林两次列入世界遗产；拙政园以水为中心、留园以空间见长、虎丘塔倾斜千年不倒。
- 数据锚点：拙政园明正德四年（1509年）始建、约5.2万平方米；留园明万历二十一年（1593年）始建、约2.3万平方米；虎丘塔959年建成。
- 常见误区：虎丘塔不是"斜塔"景点而非古迹——它是全国重点文物；不要把"苏州园林"世界遗产说成只含拙政园与留园，实际共九座园林（拙政园、留园、网师园、环秀山庄、沧浪亭、狮子林、艺圃、耦园、退思园）分两批列入，虎丘不在世界遗产范围内。
- 互动/提问设计：请游客在留园找一找漏窗"框景"；在虎丘猜一猜塔身倾斜方向。

### 2. 苏州市周庄古镇景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 江苏省苏州市昆山市 |
| 类型 | 古城古镇 |
| 评定年份 | 2007 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

周庄古镇景区位于江苏省苏州市昆山市西南，地处昆山、吴江与上海青浦三地交界。据史料记载，北宋元祐元年（1086年）因周迪功郎捐地建全福寺，此地始称周庄并设镇。古镇四面环水，因河成街、因水成市，井字形河道上保存元、明、清历代石桥十余座，60%以上的民居仍为明清建筑。沈厅、张厅是江南富宅与官宅的典型代表，双桥（世德桥、永安桥）因旅美画家陈逸飞的油画《故乡的回忆》而闻名海外。周庄2007年入选首批国家5A级旅游景区，素有"中国第一水乡"之誉。

**【导游词核心稿】**

各位游客，欢迎来到周庄——"中国第一水乡"。我们所在的昆山市周庄镇，位置很特别：往东是上海青浦，往南是吴江，往北是昆山城，三条界河在这里交汇，所以周庄自古以来就是个"三不管又谁都管"的水路码头。

据史料记载，北宋元祐元年（1086年），有位周姓的迪功郎在这里捐地建了全福寺，地方因寺得名，就叫"周庄"了。算下来，这座镇子已经快一千年了。

周庄最经典的机位，是双桥。两座桥，一座横的叫世德桥，一座竖的叫永安桥，桥洞一圆一方，拼成一个"钥匙"的形状。1984年，旅美画家陈逸飞以双桥为素材画了油画《故乡的回忆》，第二年这幅画被选作联合国邮政的首日封图案，周庄由此一夜之间走向世界。所以，站在桥上，您看到的不是两座石桥，而是一张中国水乡的名片。

再看宅子。沈厅是江南巨富沈万三后裔所建的七进大宅，一百多间房，走马楼、松茂堂一进深过一进；张厅更妙，它有一条"箸泾"小河从自家屋下穿堂而过，正所谓"轿从门前进，船自家中过"。周庄60%以上的民居还是明清建筑，这不是布景，是生活。

最后提醒：古镇街巷狭窄、临水处无护栏较多，请看管老人与小孩；坐摇橹船请穿好救生衣、不随意站立换座；游览后请把垃圾带走，别让水乡变成"堵乡"。好，我们上桥！

**【讲解要点提示】**
- 必讲：北宋元祐元年（1086年）建镇；双桥与陈逸飞《故乡的回忆》；沈厅、张厅的"船自家中过"。
- 数据锚点：1086年建镇；明清建筑占民居60%以上；元明清石桥十余座；2007年入选首批5A。
- 常见误区：沈厅不是沈万三本人所居（为后裔所建）；不要把周庄与同里、甪直的景点混讲。
- 互动/提问设计：请游客在双桥找"圆洞"与"方洞"；问一问为什么水乡的桥多为一圆一方。

### 3. 南京市钟山风景名胜区—中山陵园风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 江苏省南京市玄武区 |
| 类型 | 陵寝祠庙 · 山岳峰林 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 5-6 小时 |

**【景区简介】**

钟山风景名胜区—中山陵园风景区位于南京市玄武区，2007年入选首批国家5A级旅游景区，为国家级风景名胜区。景区以钟山（紫金山）为主体，主峰头陀岭海拔448.9米，自古有"钟山龙蟠"之称。核心景观包括中山陵、明孝陵与灵谷寺。中山陵是孙中山先生的陵寝，由建筑师吕彦直设计，1926年1月动工，1929年6月1日举行奉安大典，墓道设392级台阶。明孝陵是明太祖朱元璋与马皇后的合葬陵寝，始建于明洪武十四年（1381年），2003年作为"明清皇家陵寝"扩展项目列入《世界遗产名录》。景区还有灵谷寺、音乐台、美龄宫等知名景点。

**【导游词核心稿】**

各位游客朋友们，欢迎来到南京钟山。这座山在南京的地位，用八个字概括：钟山龙蟠，石城虎踞。主峰头陀岭海拔448.9米，不高，却压得住整座城的格局。2007年，钟山风景名胜区—中山陵园风景区入选首批国家5A级景区。

先看中山陵。它是孙中山先生的陵寝，设计者吕彦直，当年只有三十出头。工程1926年1月动工，1929年6月1日举行奉安大典，孙中山先生由北京碧云寺移灵至此。整座陵寝坐北朝南，形如一口"警世钟"。从博爱坊往上，是392级台阶。按景区通行的讲解，这392级，象征当年中国三亿九千二百万同胞。台阶分八段，中间是平台，往上走看不见台阶、只看见平台；回头往下看，只见台阶、不见平台——一上一下之间，是设计者留给后来人的隐喻：革命尚未成功，同志仍须努力。

再看明孝陵。它是朱元璋与马皇后的合葬陵，始建于明洪武十四年（1381年）。最值得慢走的是神道：石象生依次排列，狮、獬豸、骆驼、象、麒麟、马六种，每种两立两跪，共十二对石兽；而神道不走直线，绕着梅花山拐了个弯，据说是为了不破坏孙权墓。2003年，明孝陵作为"明清皇家陵寝"的扩展项目列入《世界遗产名录》。

最后提醒：钟山景区面积大、坡度长，请量力而行并自备饮水；陵园为庄严肃穆场所，请轻声缓行；明孝陵与中山陵之间建议乘坐景区交通车，出行前请核实班次与开放时间。

**【讲解要点提示】**
- 必讲：中山陵392级台阶与吕彦直设计；明孝陵2003年列入世界遗产；钟山"龙蟠"之势。
- 数据锚点：1926年动工、1929年6月1日奉安；392级台阶；明孝陵1381年始建；头陀岭448.9米；2007年入选5A。
- 常见误区：不要把中山陵说成"中山陵园"与"明孝陵"是同一时期建筑；不要把"392级"解释为"392个台阶寓意三月九日二"。
- 互动/提问设计：走上台阶后请游客回头，问"为什么只见平台不见台阶"；在神道请游客辨认石兽种类。

### 4. 无锡市中央电视台无锡影视基地三国水浒城景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 江苏省无锡市滨湖区山水西路128号 |
| 类型 | 主题乐园 |
| 评定年份 | 2007 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

中央电视台无锡影视基地三国水浒城景区位于无锡市滨湖区山水西路，地处太湖之滨，2007年入选首批国家5A级旅游景区。景区始建于1987年，是我国最早建成的大型影视拍摄基地之一，其中三国城于1994年建成开放，水浒城于1997年建成开放。区内按影视拍摄需要复原了汉末三国与宋代市井的建筑群，包括吴王宫、甘露寺、曹营水寨、清明上河街等场景，曾用于拍摄《三国演义》《水浒传》等大型电视剧。景区配套"三英战吕布"马战等实景演出，是集影视拍摄、观光游览与文化体验于一体的主题景区。

**【导游词核心稿】**

各位游客，欢迎来到无锡影视基地——三国城、水浒城。我们脚下的位置，是无锡滨湖区山水西路，三面都是太湖。1987年，中央电视台在这里选址建影视基地，这大概是中国最早的一批"影视＋旅游"的尝试；三国城1994年开门，水浒城1997年开门，2007年它们一起进了首批国家5A级景区。

先看三国城。当年电视剧《三国演义》里的吴王宫、甘露寺、曹营水寨、赤壁栈道，实景就摆在这儿，不是模型。最有意思的是"三英战吕布"的马战演出，真马、真人、真兵器，一天几场——据史料记载，《三国演义》成书于元末明初，罗贯中以《三国志》和民间话本为底本，把那段群雄并起的百年写成了中国最著名的一部小说。今天我们在现场看到的刀光马影，是把文字搬回了地面。

再看水浒城。1997年建成，为拍《水浒传》而建，从紫石街、阳谷县衙到清明上河街，一整套宋代市井。施耐庵笔下一百零八将的故事，很多场景就在这里落地。走在水浒城的街上，您会发现店铺招牌、幌子、酒肆都是照宋代样式做的——这是"服化道"的讲究。

两个城之间有景区交通相连，太湖就在旁边。看完了人造的"历史"，别忘了看看真实的湖：太湖是中国第三大淡水湖，水域约2400平方公里。

最后提醒：演出场次以当日公告为准，请提前到场占位；马战现场有扬尘与声响，请照看好儿童；景区面积大，建议先看导览图规划路线。好，我们进城！

**【讲解要点提示】**
- 必讲：1987年始建、1994年三国城、1997年水浒城；"三英战吕布"马战实景；《三国演义》《水浒传》的成书背景。
- 数据锚点：1987、1994、1997三个年份；2007年入选首批5A；太湖水域约2400平方公里。
- 常见误区：不要把景区说成"古迹遗址"，它是影视拍摄基地与主题景区；不要把三国城、水浒城的建成年代说反。
- 互动/提问设计：请游客辨认三国城里的魏、蜀、吴三处阵营建筑；问一问"三英"指的是哪三位。

### 5. 无锡市灵山大佛景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2009年评定） |
| 所在地 | 江苏省无锡市滨湖区马山灵山路 |
| 类型 | 宗教圣地 |
| 评定年份 | 2009 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

无锡市灵山大佛景区位于无锡市滨湖区马山，南临太湖，2009年获评国家5A级旅游景区。核心景观灵山大佛为青铜释迦牟尼佛立像，1997年建成并举行开光，通高88米，其中佛体高79米、莲花座高9米，由1560块青铜壁板拼装而成，总用铜量700余吨。景区另有2008年建成的灵山梵宫，建筑面积7万余平方米，集佛教文化展示、建筑艺术与大型会议功能于一体；"九龙灌浴"大型动态群雕以九龙吐水为意象，再现佛陀诞生场景；2010年建成的五印坛城为藏传佛教风格建筑。景区是国内规模较大的佛教文化主题景区之一。

**【导游词核心稿】**

各位游客朋友们，欢迎来到灵山。我们在无锡滨湖区的马山，背后是山，前面是太湖。2009年，这里被评为国家5A级景区。

先抬头——这就是灵山大佛。它是一尊释迦牟尼佛的青铜立像，1997年建成开光，通高88米。这个数字怎么来的？佛体79米，下面的莲花座9米，加起来88米。整座像用了1560块青铜壁板拼装，总用铜量700多吨。佛的手势很关键：右手"施无畏印"，表示拔除众生的恐惧；左手"与愿印"，表示满足众生的愿望。很多游客说，站在佛脚下往上看，第一反应不是震撼，是安静。

再看"九龙灌浴"。相传释迦牟尼降生之时，有九条龙吐出净水为其沐浴，太子指天指地，说"天上天下，唯我独尊"。这个传说，被做成了一组铜铸群雕：音乐起时，莲花瓣层层绽开，太子像升起，九龙喷水，水雾在阳光下会有彩虹。这是景区最"出片"的一处，建议提前占位。

第三站是灵山梵宫，2008年建成，建筑面积7万多平方米。它不是寺庙，而是一座集展示、演艺与会议于一体的建筑，内部的东阳木雕、琉璃、敦煌风格的壁画，是让人放慢脚步的地方。

最后提醒：佛国景区为宜静场所，请轻声慢行、不要用手指点佛像；九龙灌浴为定时表演，时间以当日公告为准；景区坡度大、日照强，请备水与遮阳。好，我们上山。

**【讲解要点提示】**
- 必讲：大佛通高88米（佛体79米＋莲座9米）；1997年建成；九龙灌浴的佛教典故；梵宫2008年建成。

同里古镇景区位于江苏省苏州市吴江区，2010年获评国家5A级旅游景区。据史料记载，同里于宋代成镇，因水成街、因水成市，河道纵横，街巷临水，保存有大批明清民居与深宅大院。核心景点退思园建于清光绪十一年至十三年（1885—1887年），占地0.65公顷，亭台楼阁紧贴水面而筑，是苏州古典园林中著名的"贴水园"，2000年作为苏州古典园林扩展项目列入《世界遗产名录》。古镇中心的太平桥、吉利桥、长庆桥"三桥"，是当地"走三桥"民俗的核心空间；另有嘉荫堂、崇本堂、耕乐堂、珍珠塔景园等景点。

各位游客，欢迎来到同里。同里在苏州吴江，是典型的"水做的镇子"——全镇被十五条小河切成七个岛，靠四十九座桥连起来。2010年，它被评为国家5A级景区。

最后提醒：古镇街巷窄、临水无护栏处多，请看管老人与小孩；坐船穿好救生衣；出行前请核实开放与联票政策。好，我们过桥！

**【讲解要点提示】**
- 必讲：退思园2000年列入世界遗产、"贴水园"、《左传》"退思补过"；"走三桥"民俗。
- 数据锚点：1885—1887年建成、0.65公顷；2000年列入世界遗产；2010年获评5A。
- 常见误区：退思园不是同里的"唯一园林"，但与苏州其他园林一并列入遗产；不要把"走三桥"说成只用于婚嫁。
- 互动/提问设计：请游客在退思园找"贴水"的建筑；问一问三桥各取什么寓意。

### 7. 南京市夫子庙-秦淮河风光带

**【导游词核心稿】**

各位游客朋友们，欢迎来到夫子庙秦淮河。一句话概括这里：半部金陵史，十里秦淮灯。2010年，这条风光带被评为国家5A级景区。

- 常见误区：不要把"江南贡院"与"南京贡院"混称；不要把秦淮河画舫说成免费项目。

### 9. 扬州市瘦西湖风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2010年评定） |
| 所在地 | 江苏省扬州市邗江区大虹桥路28号 |
| 类型 | 古典园林 |
| 评定年份 | 2010 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

瘦西湖风景区位于扬州市邗江区，2010年获评国家5A级旅游景区，是国家级风景名胜区蜀岗—瘦西湖的核心组成部分。瘦西湖原名保障湖，为历代扬州城北的水上园林带，清代康乾时期因盐商营建而臻于鼎盛，清人汪沆以"也是销金一锅子，故应唤作瘦西湖"的诗句为其定名。湖上自南而北分布长堤春柳、徐园、小金山、钓鱼台、五亭桥、白塔、二十四桥、熙春台等景观。其中五亭桥建于清乾隆二十二年（1757年），桥上五亭相连、桥下十五孔相通，是瘦西湖的标志性建筑。2014年，中国大运河列入《世界遗产名录》，扬州为重要遗产城市。

**【导游词核心稿】**

各位游客朋友们，欢迎来到扬州瘦西湖。2010年，它被评为国家5A级景区；而在扬州人心里，它就是这座城的名片。

瘦西湖这个名字，其实是一个"外号"。它原名叫保障湖，清代康乾年间，扬州盐商沿着湖两岸一处处修园子，把一条普通的河道修成了一条园林带。清朝有位诗人汪沆来游，写了一句"也是销金一锅子，故应唤作瘦西湖"——意思是这里和杭州西湖一样费钱，但清瘦得多。这一"瘦"字，从此就叫开了。

湖上第一主角，是五亭桥。它建于清乾隆二十二年，1757年。桥上有五座亭子，桥下有十五个桥洞，洞洞相通。老扬州人说，中秋夜月圆时，十五个桥洞里各映一个月亮，加上天上和水中的倒影，能看出三十三个月亮——这是扬州人最得意的一景。

五亭桥不远，是白塔。相传乾隆皇帝南巡时说此处像北海，只差一座白塔，盐商们一夜之间用盐包堆出一座白塔，第二天再改建成砖塔——这故事虽然带点传奇色彩，但扬州盐商的阔绰是真事。

往北是二十四桥。这三个字，来自唐代杜牧的名句："二十四桥明月夜，玉人何处教吹箫。"据史料记载，二十四桥究竟是一座桥还是二十四座桥，历来有争论，今天我们看到的是后来复建的。但杜牧的诗，让这条瘦瘦的湖水有了声音。

最后提醒：湖上游船另计，班次出行前请核实；园内步道临水，注意脚下；春季为旺季，人流密集。好，我们上五亭桥。

**【讲解要点提示】**
- 必讲：五亭桥1757年建成、五亭十五孔；汪沆诗定名"瘦西湖"；杜牧"二十四桥明月夜"。
- 数据锚点：1757年建桥；五亭、十五孔；2010年获评5A；2014年大运河申遗成功。
- 常见误区：不要把"一夜造白塔"当史实（须说明为相传）；不要把瘦西湖当作天然湖泊，它是历代人工整治的园林水道。
- 互动/提问设计：请游客数一数五亭桥的桥洞；问一问"二十四桥"是一座还是二十四座。

### 10. 南通市濠河风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 江苏省南通市崇川区 |
| 类型 | 水域湖泊 · 城市地标 |
| 评定年份 | 2012 |
| 建议游览时长 | 2-3 小时（环河） |

**【景区简介】**

濠河风景区位于南通市崇川区，2012年获评国家5A级旅游景区。濠河是环绕南通老城的古护城河，据史料记载，其开凿可追溯至后周显德五年（958年）通州筑城之时，河道全长约10公里，是国内保存较为完整、仍处城市中心的古护城河之一。沿河分布南通博物苑、天宁寺、文峰塔、钟楼谯楼、濠南别业等历史建筑与文博场馆。其中南通博物苑由清末状元、实业家张謇于清光绪三十一年（1905年）创办，是中国人自办的第一座公共博物馆。景区以"水抱城、城拥水"的格局与环河夜景著称。

**【导游词核心稿】**

各位游客，欢迎来到南通濠河。我们面前这条河，不是一条普通的景观河——它是一条真正的护城河，而且到现在还完整地绕着南通老城一圈，全长约10公里。据史料记载，后周显德五年（958年）通州筑城时就开了这条河，算下来一千多年了。2012年，濠河风景区被评为国家5A级景区，是国内少见的"城市中心的护城河型"5A景区。

要说濠河的灵魂，绕不开一个人：张謇。他是清末状元，据史料记载，1895年他在南通创办大生纱厂，此后又办学校、办博物馆、办公园、办气象台，把一个小小的南通城经营成近代中国人自己规划建设的样板，后来被人称作"中国近代第一城"。

张謇留下的最硬的一笔，就在濠河边——南通博物苑，清光绪三十一年（1905年）创办。请注意"第一座公共博物馆"这几个字：在此之前，中国的收藏多是皇家与私人的，张謇第一次把它变成对公众开放的地方。博物苑里既有馆舍也有园林，还养着活体动植物，这种"馆园一体"的做法很超前。

沿河再走，是天宁寺、文峰塔、钟楼谯楼。白天看是历史，晚上看是灯火——濠河夜景是南通的门面，环河一圈的灯光把老城的轮廓勾在水里。所以如果时间允许，建议白天走一半、晚上再走一半。

最后提醒：环河步道较长，建议分段游览或乘坐游船；夜间照明与护栏有限，请看管老人与小孩；游船班次与票价出行前请核实。好，我们沿河走。

**【讲解要点提示】**
- 必讲：958年通州筑城开濠；张謇1905年创办南通博物苑，中国人自办的第一座公共博物馆；水抱城的格局。
- 数据锚点：后周显德五年（958年）；河道全长约10公里；1905年创办博物苑；2012年获评5A。
- 常见误区：不要把濠河说成"人工开挖的景观河"，它是古代城防设施演化而来；不要把南通博物苑说成"江苏最早的博物馆"。
- 互动/提问设计：请游客在河边找一找老城墙遗迹的位置；问一问"中国近代第一城"是谁提出的说法。

### 11. 泰州市溱湖旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 江苏省泰州市姜堰区 |
| 类型 | 水域湖泊 |
| 评定年份 | 2012 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

溱湖旅游景区位于泰州市姜堰区，2012年获评国家5A级旅游景区，以溱湖（喜鹊湖）国家湿地公园为核心。景区地处里下河水网腹地，河港纵横、垛田星罗，湿地生态系统保存完整，是珍稀水鸟与湿地动植物的重要栖息地。最具代表性的活动是每年清明前后举行的溱潼会船节，数百条会船云集溱湖，撑篙竞渡、锣鼓喧天，这一习俗已列入国家级非物质文化遗产代表性项目名录。景区另含溱潼古镇、湿地科普馆与溱湖八鲜等美食体验，是集生态观光、民俗体验与科普研学于一体的湿地型景区。

**【导游词核心稿】**

各位游客朋友们，欢迎来到泰州溱湖。2012年，这里被评为国家5A级景区，是我们江苏第一个以湿地为核心的5A景区。

先说说脚下这片地。我们在里下河的腹地——什么叫里下河？就是地势低洼、河网密布的地方。这里的水不是"一条河"，而是"一张网"：河、港、汊、荡、垛田，层层叠叠。溱湖，又名喜鹊湖，是这张网中间最开阔的一片水面。正因为水多、人少、干扰小，这里成了鸟的天堂，湿地植被也保存得完整。

但溱湖最有名的，不是风景，是船。每年清明前后，溱潼会船节开锣——几百条船从四面八方撑进湖里，篙子一齐下水，锣鼓一齐响，湖面像开了锅。这个习俗已经被列入国家级非物质文化遗产代表性项目名录。相传它的起源说法不一，有的说与南宋抗金的义军祭祀有关，有的说是当地渔民祭祀水神的旧俗，但无论哪一种，都指向同一件事：一群靠水吃饭的人，用船记住自己人。

看完船，别忘了尝一口水。溱湖有"八鲜"之说——簖蟹、鱼饼、虾球、老鹅、甲鱼、螺贝、水禽、茨菇之类，都是湖里长的。一方水土养一方吃食，这八鲜就是湿地给泰州人的回报。

最后提醒：湿地栈道湿滑、临水无护栏处多，请慢行；观鸟请保持距离、不投喂、不用闪光灯；会船节期间人流极大，出行前请核实举办时间与交通管制信息。好，我们上船。

**【讲解要点提示】**
- 必讲：溱湖国家湿地公园；溱潼会船节及其国家级非遗身份；里下河水网地貌。
- 数据锚点：2012年获评5A；会船节每年清明前后举行；列入国家级非物质文化遗产代表性项目名录。
- 常见误区：不要把会船节说成"端午节赛龙舟"，二者节令与形式不同；不要把溱湖与溱潼古镇混为同一景区（古镇是景区组成部分之一）。
- 互动/提问设计：请游客辨认垛田与圩田的差别；问一问"溱湖八鲜"里能说出几种。

### 12. 苏州市金鸡湖旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 江苏省苏州市苏州工业园区 |
| 类型 | 城市地标 · 水域湖泊 |
| 评定年份 | 2012 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

金鸡湖旅游区位于苏州工业园区，2012年获评国家5A级旅游景区，是国内少有的开放式商务旅游示范区。景区总面积11.5平方公里，其中水域面积7.4平方公里。环湖依次分布湖滨大道、李公堤、苏州文化艺术中心、东方之门、圆融时代广场与音乐喷泉等景观，构成现代都市滨水空间。苏州文化艺术中心是中国电影金鸡奖的永久评奖基地。景区集商务、会展、文化、休闲、购物于一体，与古城区的古典园林共同构成苏州"古韵今风"的双面城市形象。

**【导游词核心稿】**

各位游客，欢迎来到苏州金鸡湖。如果说苏州古城是"古韵"，那我们站的地方就是"今风"。2012年，金鸡湖旅游区被评为国家5A级景区，而且它是一个不收大门票、完全开放的城市景区——这在5A里并不常见。

先看一组数字：整个景区总面积11.5平方公里，其中水面7.4平方公里。也就是说，三分之二的地方是水。苏州自古就是水城，但古城区的水是"小桥流水"的窄；金鸡湖是另一回事，一眼望不到边的开阔。

说到苏州的历史，有个数字必须记住：据史料记载，公元前514年，吴王阖闾命伍子胥筑"阖闾大城"，这就是苏州城最初的模样，两千五百多年城址未变。一座两千五百年的古城，边上又长出一座现代化的新城区——这就是苏州最了不起的地方，它被称作"双面绣"：一面是园林，一面是园区。

环湖看几处地标。李公堤是湖中一条长堤，把湖分成内外两片，堤上吃喝玩乐都有，是苏州最有烟火气的滨水街区。苏州文化艺术中心，是中国电影金鸡奖的永久评奖基地，外形像一颗被切开的珍珠。再往那边看，是"东方之门"——本地人管它叫"大秋裤"，两座塔楼在顶部连成一道门。

傍晚和夜里，湖上有音乐喷泉，是这里最热闹的时刻。

最后提醒：景区为开放区域，环湖步行距离长，建议租用共享单车或分段乘车；音乐喷泉与灯光秀时间以当日公告为准；出行前请核实。

**【讲解要点提示】**
- 必讲：11.5平方公里总面积、7.4平方公里水域；苏州城始建于公元前514年；李公堤、苏州文化艺术中心与金鸡奖。
- 数据锚点：11.5平方公里／7.4平方公里；公元前514年筑阖闾大城；2012年获评5A。
- 常见误区：不要把金鸡湖说成"苏州最大的湖"（太湖更大）；不要把"金鸡奖"与"金鸡湖"说成有关联的命名渊源。
- 互动/提问设计：请游客找一找"东方之门"像什么；问一问苏州建城于哪一年。

### 13. 镇江市金山·焦山·北固山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 江苏省镇江市润州区、京口区 |
| 类型 | 宗教圣地 · 山岳峰林 |
| 评定年份 | 2012 |
| 建议游览时长 | 5-6 小时（三山） |

**【景区简介】**

金山·焦山·北固山风景区位于镇江市区，2012年获评国家5A级旅游景区，为国家重点风景名胜区。金山以金山寺（江天禅寺）闻名，寺院依山而建、殿宇层叠，民间传说《白蛇传》中"水漫金山"即出于此。焦山屹立于长江之中、四面环水，山上有定慧寺与焦山碑林，碑林所藏《瘗鹤铭》摩崖石刻在中国书法史上地位极高，被誉为"大字之祖"。北固山临江而立，有甘露寺、"天下第一江山"题刻与多景楼，历代文人登临题咏不绝。三山一寺一江，构成镇江"城市山林"的独特格局。

**【导游词核心稿】**

各位游客朋友们，欢迎来到镇江。镇江有三座山，都姓"水"：金山、焦山、北固山，2012年它们捆绑成为国家5A级景区，是国家级风景名胜区。三座山都不高，但每一座都压着一段中国故事。

先说金山。金山不高，可金山寺厉害——寺依着山往上盖，一层压一层，从山脚一直盖到山顶，远远看去分不清哪是山、哪是寺。这就是"寺裹山"。为什么这么有名？因为一个传说：相传《白蛇传》里白娘子与法海斗法，"水漫金山"就发生在这里。故事是虚构的，但金山寺是真的，法海也确有其人——据史料记载，唐代确有法海禅师在此开山修寺。

再说焦山。它是长江里的一座岛山，四面环水，海拔约70.7米，要坐船才上得去。焦山最值钱的不是风景，是石头——焦山碑林，历代摩崖石刻与碑刻成林。其中最著名的是《瘗鹤铭》。据史料记载，它的书写者历来有王羲之、陶弘景等多种说法，至今没有定论；但它在书法史上的地位无人否认，被称为"大字之祖"。

最后是北固山。它临江而立，形如半岛，山上有甘露寺。相传三国时刘备到东吴招亲，就发生在甘露寺——这段情节出自《三国演义》，正史另有说法。真正让北固山不朽的是词。南宋词人辛弃疾登临此山，写下"何处望神州？满眼风光北固楼"，又写下"想当年，金戈铁马，气吞万里如虎"。

最后提醒：焦山需乘船往返，请留意末班船时间；三山之间距离较远，建议安排一整天；临江风大，请注意保暖与脚下安全。

**【讲解要点提示】**
- 必讲：金山寺"寺裹山"与"水漫金山"传说；焦山碑林与《瘗鹤铭》；北固山与辛弃疾词。
- 数据锚点：2012年获评5A；焦山海拔约70.7米；三山为国家重点风景名胜区。
- 常见误区：不要把"甘露寺招亲"当作正史；不要把《瘗鹤铭》的作者说成定论为王羲之。
- 互动/提问设计：请游客在三山中找"山裹寺"与"寺裹山"的区别；问一问辛弃疾两首北固亭词的篇名。

### 14. 无锡市鼋头渚旅游风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 江苏省无锡市滨湖区鼋渚路1号 |
| 类型 | 水域湖泊 |
| 评定年份 | 2012 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

鼋头渚旅游风景区位于无锡市滨湖区，地处太湖西北岸，2012年获评国家5A级旅游景区。"鼋头渚"因一块巨石突入太湖、形似神鼋昂首而得名。景区始辟于1916年，由无锡实业家杨翰西营建"横云山庄"，后逐步扩建为公园，是太湖沿岸开发最早的风景园林之一。区内主要景观有"太湖佳绝处"牌坊、长春桥、鼋渚春涛、万浪卷雪、鹿顶迎晖与太湖仙岛等，并可乘船游湖。景区内广植樱花，春季长春桥一带樱花临水，为江南著名赏樱地。

**【导游词核心稿】**

各位游客，欢迎来到鼋头渚。先解释这三个字：鼋，是一种大鳖；渚，是水中间的小块陆地。鼋头渚，就是一块像鼋头一样伸进太湖里去的石头。一句话——太湖第一名胜。2012年，它被评为国家5A级景区。

太湖有多大？它是中国第三大淡水湖，水域面积约2400平方公里，横跨江浙两省。这么大的一片水，从哪里看最好？郭沫若来过之后给了答案："太湖佳绝处，毕竟在鼋头。"这十个字，现在就刻在景区门口的牌坊上。

这里的历史不算长。据史料记载，1916年，无锡实业家杨翰西在太湖边买地建"横云山庄"，后来逐步捐出、扩建，才成了今天的鼋头渚公园。所以您在这里看到的，既有江南园林的巧，也有近代私家别墅的趣。

往里走，第一处打卡点是长春桥。它跨在水面上，桥下有堤、堤外是湖，春天的时候，桥两侧的樱花一齐开，粉白的花影落在水里——鼋头渚的樱花是江南最出名的一处，每年三四月，游人如织。再往高处走，是鹿顶山，登"鹿顶迎晖"可以俯瞰整个太湖。时间够的话，请一定坐船去一趟太湖仙岛，站在船上往回看鼋头渚，才明白为什么古人说"太湖佳绝"。

最后提醒：春季樱花季人流极大，出行前请核实预约与限流政策；游船受天气影响，风大时可能停航；临湖栈道湿滑，注意脚下。好，我们去看太湖。

**【讲解要点提示】**
- 必讲："鼋头渚"名称由来；1916年杨翰西营建横云山庄；郭沫若"太湖佳绝处，毕竟在鼋头"；长春桥樱花。
- 数据锚点：始辟于1916年；太湖水域约2400平方公里；2012年获评5A。
- 常见误区：不要把鼋头渚说成"太湖中最大的岛"；不要把樱花花期说成固定日期（每年随气温波动）。
- 互动/提问设计：请游客在长春桥观察"借景"手法的运用；问一问太湖在中国淡水湖中的排位。

### 15. 苏州市太湖旅游区（吴中太湖旅游区）

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 江苏省苏州市吴中区 |
| 类型 | 水域湖泊 · 山岳峰林 · 乡村田园 |
| 评定年份 | 2013 |
| 建议游览时长 | 5-6 小时 |

**【景区简介】**

苏州市太湖旅游区（吴中太湖旅游区）位于苏州市吴中区，2013年获评国家5A级旅游景区，由旺山、穹窿山、东山三大片区组成。穹窿山主峰箬帽峰海拔341.7米，为苏州境内最高峰，山中有孙武苑等纪念性建筑，相传春秋时孙武曾在此隐居并著《孙子兵法》。东山为伸入太湖的半岛，有陆巷古村、雕花楼、启园、杨湾古村等明清村落与园林，是洞庭（山）碧螺春茶的原产地。旺山片区以田园乡村与生态休闲为特色。景区集湖光山色、古村文化、名茶果木与乡村休闲于一体。

**【导游词核心稿】**

各位游客朋友们，欢迎来到苏州太湖旅游区，也叫吴中太湖旅游区。2013年它被评为国家5A级景区。别的景区是一个点，这里是一片——它由三个片区组成：旺山、穹窿山、东山。

先登穹窿山。它的主峰叫箬帽峰，海拔341.7米，是苏州境内最高的山。这个数字放在全国不算什么，但在太湖平原上已经是"屋脊"了。山里有一处孙武苑。相传春秋时期，孙武从齐国来到吴地，在穹窿山中隐居，写出了那部十三篇的《孙子兵法》。据史料记载，孙武以兵法见吴王阖闾，并以此训练吴军，西破强楚——一部五千多字的兵书，影响了两千多年。

再往太湖边走，是东山。它不是一个岛，是一个伸进太湖里的半岛。这里藏着苏州最好的古村：陆巷古村，明清老宅一间挨一间，巷子窄得只能两人错身；雕花楼，顾名思义，木雕砖雕层层叠叠。

东山还有一样宝贝：茶。中国十大名茶里的碧螺春，原产地就在这里。相传"碧螺春"这个名字是清朝康熙皇帝南巡时品尝后赐的，原名"吓煞人香"。据史料记载，碧螺春的采制有讲究：一嫩三鲜，一斤干茶要用六七万个芽头。春天来东山的茶园，站在垄上闻到的那股清香，就是苏州春天的味道。

最后是旺山，以田园与生态为主，适合慢下来吃一顿农家饭。

最后提醒：三个片区相距较远，建议按"一天一区"规划；穹窿山与东山路况有起伏，请穿舒适的鞋；茶园与果园参观请勿随意采摘。好，我们上山。

**【讲解要点提示】**
- 必讲：穹窿山箬帽峰海拔341.7米、苏州最高峰；孙武隐居著《孙子兵法》的传说；东山陆巷古村与碧螺春原产地。

### 20. 盐城市大丰中华麋鹿园景区

| 项目 | 内容 |

| 等级 | 5A（2015年评定） |
| 所在地 | 江苏省盐城市大丰区 |

| 评定年份 | 2015 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

大丰中华麋鹿园景区位于江苏省盐城市大丰区，2015年获评国家5A级旅游景区，依托江苏大丰麋鹿国家级自然保护区建设。麋鹿是中国特有的鹿科动物，因角似鹿、头似马、蹄似牛、尾似驴而俗称"四不像"。20世纪初麋鹿在中国本土绝迹，据史料记载，1986年39头麋鹿从英国重返故土，落户大丰，此后建立起世界上规模较大的麋鹿野生种群与基因库。保护区地处黄海之滨的滨海湿地，滩涂、草甸、水域交错，是麋鹿、丹顶鹤等珍稀动物的重要栖息地，也是开展生态科普与观鸟研学的重要场所。

**【导游词核心稿】**

各位游客，欢迎来到盐城大丰中华麋鹿园。2015年，这里被评为国家5A级景区。我们要看的，是一种命运很特别的动物。

先看它长什么样：角像鹿，头像马，蹄像牛，尾巴像驴——四样都不像自己，所以老百姓叫它"四不像"。它的学名叫麋鹿，是中国特有的物种。

再看它的命运。据史料记载，麋鹿原本广泛分布在长江、黄河中下游的沼泽湿地；到了19世纪末20世纪初，由于战乱与栖息地丧失，麋鹿在中国本土彻底绝迹，仅剩下流落欧洲的少数个体。1986年，39头麋鹿从英国重返故土，落户大丰。今天，保护区里的麋鹿已经繁衍成数千头的种群，并重新回到野外。这不是一个简单的"引进"故事，而是一个物种回家的故事。

请大家记住这个数字：39头。三十多年前，就是这39头麋鹿，替一个在中国消失了近一个世纪的物种，把根接了回来。

保护区的环境本身也值得看。我们在黄海之滨，脚下是滨海湿地：滩涂、草甸、水塘交错，一望无际。这里不只是麋鹿的家，还是候鸟迁徙通道上的重要驿站。运气好的话，能看到成群的雁鸭，运气再好一点，能看到丹顶鹤。

最后提醒：参观请在指定区域与观光车内进行，不下车、不投喂、不大声驱赶动物；保护区为生态敏感区，请勿带走任何动植物；出行前请核实开放时间与游览方式。

**【讲解要点提示】**
- 必讲："四不像"的形态特征；麋鹿在中国本土绝迹与1986年39头回归的史实；滨海湿地生态。
- 数据锚点：1986年、39头麋鹿引回；2015年获评5A；江苏大丰麋鹿国家级自然保护区。
- 常见误区：不要把麋鹿说成"从国外引进的外来物种"，它是中国本土物种的回归；不要把现有种群数量说成固定值（每年变化，讲解时宜用"数千头"并核实当年数据）。
- 互动/提问设计：请游客说出"四不像"的四个"像"；问一问麋鹿为什么适合在湿地生活。

**【景区简介】**

云龙湖景区位于江苏省徐州市泉山区，2016年获评国家5A级旅游景区，为国家级水利风景区。云龙湖三面环山、一面临城，与云龙山相依，湖山相映构成徐州"城中有山、山中有湖"的城市格局。云龙山主峰海拔约142米，山中有兴化寺、大士岩、放鹤亭等古迹，其中放鹤亭与北宋文学家苏轼任徐州知州时期的一段往事相关。环湖分布小南湖、珠山景区、水上世界、音乐厅与滨湖公园等景观，是徐州市民休闲与外地游客游览的核心区域。

**【导游词核心稿】**

各位游客朋友们，欢迎来到徐州云龙湖。2016年，它被评为国家5A级景区，同时也是国家级水利风景区。徐州给人的印象常是"兵家必争之地""汉文化发源地"，但站在云龙湖边，你会发现这座城市也有柔软的一面。

先说格局。云龙湖三面是山、一面是城，湖和山贴在一起，所以叫"云龙"——云是云龙山，龙是蜿蜒的湖岸。这是徐州最好的城市客厅。

山上有故事。云龙山主峰海拔约142米，不高，但山里有兴化寺、大士岩，还有一处放鹤亭。这个亭子，牵着一位大人物：北宋熙宁十年（1077年），苏轼到徐州任知州。据史料记载，那年秋天徐州遭大水，苏轼率民众筑堤抗洪；次年春，云龙山人张天骥在东山之麓筑亭，苏轼应其所请写下《放鹤亭记》，并在文中写下"清远闲放，超然于尘埃之外"的名句。同一年，他还主持修筑了徐州的防洪长堤——徐州人今天仍把那道堤叫作"苏堤"。

山之外，是湖。环湖有小南湖、珠山景区、水上世界、滨湖公园，湖面开阔，傍晚沿着湖边走一圈最舒服。徐州是汉文化的重镇，看完湖，建议顺路去徐州汉文化景区、徐州博物馆看看汉画像石与汉墓——那才是这座城最硬的底子。

最后提醒：环湖步道较长，建议分段游览或骑行；夏季日照强，请备水与遮阳；水上项目另计，出行前请核实开放时间。好，我们上山看亭。

**【讲解要点提示】**
- 必讲：苏轼1077年知徐州、为云龙山人张天骥所建放鹤亭作《放鹤亭记》；云龙山与云龙湖的"山湖相依"格局。
- 数据锚点：云龙山主峰海拔约142米；北宋熙宁十年（1077年）；2016年获评5A。
- 常见误区：不要把徐州"苏堤"与杭州"苏堤"混为一谈（两处各有来历）；不要把云龙湖说成天然湖（其形成与城市水利治理相关）。
- 互动/提问设计：请游客在放鹤亭读一读《放鹤亭记》的片段；问一问苏轼在徐州还做过什么。

### 22. 连云港市花果山景区

| 类型 | 山岳峰林 · 宗教圣地 |
| 评定年份 | 2016 |
| 建议游览时长 | 5-6 小时 |

**【景区简介】**

花果山景区位于江苏省连云港市海州区，2016年获评国家5A级旅游景区，属连云港云台山国家级风景名胜区，并为国家地质公园。景区主峰玉女峰海拔624.4米，是江苏省境内最高峰。山中主要景观有水帘洞、三元宫、娲遗石、七十二洞、花果山石等，林木葱郁、怪石嶙峋，兼具山海景观与人文古迹。相传《西游记》作者吴承恩以云台山一带的山形水势与民间传说为素材塑造了"花果山""水帘洞"等形象，景区因此成为《西游记》文化的重要实景载体。

**【导游词核心稿】**

各位游客，欢迎来到连云港花果山——孙悟空的"老家"。2016年，它被评为国家5A级景区。

先报一个数字：花果山的主峰叫玉女峰，海拔624.4米。这是江苏全省的第一高峰。江苏以平原为主，能有一座六百多米的山，很不容易。它属于云台山，是国家级风景名胜区，也是国家地质公园。

为什么叫"花果山"？相传《西游记》的作者吴承恩，是明代淮安府人。据史料记载，他一生仕途坎坷，晚年归乡著书；连云港的云台山就在淮安东北不远处，山中有水帘洞、娲遗石、七十二洞这些奇特的地貌与名字，民间又流传着许多猴王的故事。很多人相信，吴承恩正是从这里取水帘之名、取猴王之形，写出了那部《西游记》。需要说明的是，这是"相传"——学术研究尚有不同看法，但一点也不影响我们在这里做一场"西游梦"。

上山有几处必看：水帘洞，一挂瀑布从洞口垂下，进洞要穿过水帘，是孩子们的乐园；三元宫，依山而建的道观建筑群，香火延续多年；娲遗石，一块巨大的、中间有缝的石头，民间说孙猴子就是从这缝里蹦出来的；还有七十二洞，大大小小的岩洞连成一片，钻来钻去很有意思。

体力好的朋友可以徒步上山，也可以乘景区交通与索道，山上有猴群出没，请勿挑逗、不要拿着食物在手上晃。

最后提醒：山路台阶多、里程长，请量力而行；猴子会抢食，请把食物收进包里；索道遇大风可能停运，出行前请核实。

**【讲解要点提示】**
- 必讲：玉女峰624.4米、江苏最高峰；水帘洞、娲遗石、三元宫；吴承恩与《西游记》的"相传"关系。
- 数据锚点：海拔624.4米；2016年获评5A；国家级风景名胜区、国家地质公园。
- 常见误区：不要把"孙悟空老家"讲成定论，须说明是文学形象与民间传说的结合；不要把花果山与云台山说成两座不同的山（花果山属云台山）。
- 互动/提问设计：请游客在水帘洞背一两句《西游记》原文；问一问江苏最高峰是哪座。

### 23. 常州市中国春秋淹城旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2017年评定） |
| 所在地 | 江苏省常州市武进区 |
| 类型 | 遗址考古 · 主题乐园 |
| 评定年份 | 2017 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

中国春秋淹城旅游区位于江苏省常州市武进区，2017年获评国家5A级旅游景区，由淹城遗址、淹城春秋乐园、淹城野生动物世界等部分组成。淹城是中国现存最为完整的春秋时期地面城池遗址之一，1988年公布为全国重点文物保护单位。遗址采用罕见的"三城三河"形制——子城、内城、外城三重城垣，各由一道护城河环绕，城河相依、层层相套。据考古与文献研究，淹城的营建年代约在西周晚期至春秋时期，距今两千五百余年。淹城春秋乐园是以春秋文化为主题的大型游乐园，复原宫殿、市井等场景并配有多项游乐设施。

**【导游词核心稿】**

各位游客朋友们，欢迎来到常州淹城。2017年，中国春秋淹城旅游区被评为国家5A级景区。这里最值钱的，不是游乐设施，是脚下这片土。

请大家看平面图。淹城的形状非常特别：它不是一圈城墙，而是三圈——子城、内城、外城，三重城垣层层相套；城墙外面还各有一道护城河，三城三河，一共三道水。这种形制在中国古代城址里极为罕见，因此1988年淹城被公布为全国重点文物保护单位。

它有多老？据考古与文献研究，淹城的营建年代大约在西周晚期到春秋时期，距今两千五百多年。换句话说，当我们站在这里，脚下踩的是一个与孔子同时代的城。而这座城是谁建的、为什么叫"淹"，至今没有定论——有说是吴国的城邑，有说是奄国之遗，学界仍无定论。也正因为没有答案，它才迷人。

淹城最动人的地方在于"没挖"：它是中国保存最完整的春秋地面城址之一，我们没有把它掘开重建，而是让它以原样留在原地。土城墙、护城河，两千五百年，还是当年的轮廓。

看完遗址，再去淹城春秋乐园。那是以春秋文化为主题的主题乐园，有复原的宫殿、市井与诸子百家场景，也有过山车、水世界这些现代项目。历史和游乐放在一起，是这里最特别的处理方式。

最后提醒：遗址区为文物保护单位，请勿攀爬城墙、请勿离开步道；乐园项目有身高与健康限制，请阅读乘坐须知；出行前请核实演出与设备检修信息。

**【讲解要点提示】**
- 必讲："三城三河"形制；1988年公布为全国重点文物保护单位；营建年代约西周晚期至春秋时期。
- 数据锚点：三重城垣、三道护城河；距今约2500余年；1988年全国重点文物；2017年获评5A。
- 常见误区：不要把淹城的归属（吴国／奄国）讲成定论；不要把淹城春秋乐园的复原建筑说成"春秋原物"。
- 互动/提问设计：请游客在沙盘上指出三城三河的位置；问一问为什么淹城"只保护不开挖"。

### 24. 无锡市惠山古镇景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2019年评定／2020年1月授牌） |

| 评定年份 | 2019 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

惠山古镇景区位于无锡市梁溪区，2019年获评国家5A级旅游景区（2020年1月正式授牌），以惠山古祠堂群、寄畅园、天下第二泉与惠山寺为核心。古镇保存着百余座明清以来的祠堂建筑，涉及数十个姓氏，是国内规模较大、保存较完整的祠堂建筑群落，素有"露天历史博物馆"之誉。寄畅园始建于明正德十五年（1520年），是江南著名的山麓别墅式园林，1988年公布为全国重点文物保护单位。天下第二泉相传开凿于唐代大历年间，因茶圣陆羽品评而得名；民间音乐家阿炳（华彦钧）的二胡名曲《二泉映月》即由此得名。

**【导游词核心稿】**

各位游客，欢迎来到无锡惠山古镇。2019年，它被评为国家5A级景区。别的地方看风景，这里看的是"人"——几百年来，谁在这片山脚下被记住。

第一看，祠堂群。惠山古镇保存着百余座明清以来的祠堂建筑。祠堂是什么？是一个家族在此地立住脚跟的证据。一座祠堂一个姓，几十个姓氏排在一条街上，就说清楚了一件事：无锡这座城，是四面八方的人一起建起来的。所以这里被称作"露天历史博物馆"。

第二看，寄畅园。它始建于明正德十五年（1520年），是一座"山麓别墅式"园林——借惠山的山势、引二泉的水，把真山真水纳入园中。1988年，它被公布为全国重点文物保护单位。康熙、乾隆各六次南巡，几乎每次都要到寄畅园。园子不大，但站着看山、坐着听泉，格局极妙。

第三看，天下第二泉。相传这口泉开凿于唐代大历年间，茶圣陆羽品评天下名水，把它列为第二。泉名由此而来。而真正让"二泉"二字走进千家万户的，是无锡人阿炳——华彦钧。据史料记载，20世纪50年代初，音乐家为他录制了六首乐曲，其中一首就是《二泉映月》。一个盲艺人，把一生的冷暖拉进了一把二胡里。今天到二泉边上，很多游客会不自觉地放轻脚步。

最后提醒：古镇街巷多青石板，雨后湿滑；祠堂为纪念性场所，请轻声参观；寄畅园与古镇联票政策常调整，出行前请核实。

**【讲解要点提示】**
- 必讲：惠山古祠堂群与"露天历史博物馆"；寄畅园1520年始建、1988年全国重点文物；天下第二泉与《二泉映月》。
- 数据锚点：明正德十五年（1520年）；1988年全国重点文物保护单位；2019年获评5A。
- 常见误区：不要把《二泉映月》的"二泉"说成"两口泉"；不要把评泉者说成陆羽一人定论（文献说法不一，宜用"相传"）。
- 互动/提问设计：请游客在祠堂门额上找自己的姓氏；问一问寄畅园"借山引水"的做法体现在哪里。

### 25. 宿迁市洪泽湖湿地景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2020年评定） |
| 所在地 | 江苏省宿迁市泗洪县 |
| 类型 | 水域湖泊 |
| 评定年份 | 2020 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

洪泽湖湿地景区位于江苏省宿迁市泗洪县，2020年获评国家5A级旅游景区，依托泗洪洪泽湖湿地国家级自然保护区建设。洪泽湖是中国第四大淡水湖，湖面辽阔，是淮河中下游重要的调蓄湖泊与湿地生态系统。景区以湿地生态为核心，拥有大面积的芦苇荡、水泊与浅滩，是众多水鸟的繁殖地与迁徙停歇地。区内主要游览内容包括湿地博物馆、芦苇迷宫水上游线、湿地栈道与科普研学项目，是集湿地观光、生态科普、鸟类观察与休闲度假于一体的生态型景区。

**【导游词核心稿】**

各位游客朋友们，欢迎来到泗洪洪泽湖湿地。2020年12月，这里被评为国家5A级景区，是宿迁的第一家5A景区。

先说湖。洪泽湖是中国第四大淡水湖，湖面面积约2000平方公里，是淮河中下游最大的"水袋子"。它承担着一个重要任务：调蓄洪水。每年汛期，上游来的水先在这里缓一缓，再往下游走——所以洪泽湖不只是风景，它关系着下游几千万人的安危。也正因为水来水去，湖边形成了大片大片的湿地。

湿地是什么？简单说，就是水与陆地之间那层过渡的地方。它看着不起眼，却是地球上生物多样性最丰富的生态系统之一，被称作"地球之肾"。它能蓄水、净水、养鱼、养鸟。

我们景区里最值得做的，是坐船进芦苇荡。芦苇一人多高，船在水道里穿行，两侧的苇墙把天空割成一条带子。水道弯弯绕绕，像个迷宫，所以叫"芦苇迷宫"。运气好的时候，能看到白鹭从苇尖上起飞，能看到水鸟带着雏鸟游过。

看完水，建议去湿地博物馆走一趟。那里会讲清楚三件事：洪泽湖怎么形成的、湿地为什么重要、我们能为它做什么。

最后提醒：湿地栈道湿滑、临水处护栏有限，请慢行；观鸟请保持距离、不用闪光灯、不投喂；游船受水位与天气影响，出行前请核实班次与开放安排。

**【讲解要点提示】**
- 必讲：洪泽湖为中国第四大淡水湖；湿地"地球之肾"的生态功能；芦苇迷宫水上游线。
- 数据锚点：湖面面积约2000平方公里；2020年获评5A；泗洪洪泽湖湿地国家级自然保护区。
- 常见误区：不要把洪泽湖的面积说成固定值（随水位季节变化明显）；不要把湿地与"滩涂荒地"等同。
- 互动/提问设计：请游客说一说湿地的三大功能；问一问中国四大淡水湖分别是哪几个。

**【景区简介】**

连岛景区位于江苏省连云港市连云区，2024年2月被文化和旅游部确定为国家5A级旅游景区。连岛古称鹰游山，面积7.6平方公里，是江苏省最大的海岛，通过全长约6.7公里的拦海大堤与陆地相连，与连云港港隔海相望。景区集青山、碧海、茂林、海蚀地貌与天然沙滩于一体，拥有大沙湾、苏马湾两处海水浴场，是江苏省知名的健康型海水浴场。岛上保存有全国重点文物保护单位——汉代界域刻石，并建有"邓小平和人民在一起"雕塑公园等红色与人文景观。连岛为中国十大美丽海岛之一。

**【导游词核心稿】**

各位游客，欢迎来到连云港连岛。2024年2月，它被确定为国家5A级景区，也是江苏第26家5A景区。

先说这座岛。连岛古时候叫"鹰游山"，面积7.6平方公里——它是江苏最大的海岛。请注意"最大"两个字：江苏的海岸线不算长，海岛也不多，连岛是其中的头一号。它还是"中国十大美丽海岛"之一。

怎么上岛？我们是从一条拦海大堤上过来的。这条大堤全长约6.7公里，是江苏最长的海堤之一，把连岛和陆地连在一起。开车在堤上走，两边都是海，那种感觉很像"在海面上行驶"。

岛上看什么？第一是沙滩。大沙湾和苏马湾两处浴场，沙细、坡缓、水清，是江苏最好的海水浴场之二。第二是海蚀地貌——礁石被海浪啃出各种形状，是天然的地质课堂。第三是人文。岛上有一处全国重点文物保护单位：汉代界域刻石。据史料记载，这是汉代用来划定郡界域的石刻，距今两千多年，是研究汉代行政区划与疆域的实物证据。

岛上还有"邓小平和人民在一起"雕塑公园，是红色教育的一处场所。

最后提醒：海滨紫外线强，请防晒补水；下海游泳请在指定区域内、留意警示旗与救生员；大堤与岛上道路受大风大雾影响，出行前请核实天气与交通安排。好，我们去看海。

**【讲解要点提示】**
- 必讲：连岛面积7.6平方公里、江苏最大海岛；约6.7公里拦海大堤；大沙湾、苏马湾浴场；汉代界域刻石（全国重点文物）。
- 数据锚点：7.6平方公里；6.7公里海堤；2024年2月确定为国家5A。
- 常见误区：不要把连岛说成"群岛"（它是单一海岛）；不要把汉代界域刻石说成"界碑"（它是摩崖石刻，性质与碑不同，讲解前请核实准确表述）。
- 互动/提问设计：请游客在礁石上找海蚀痕迹；问一问汉代界域刻石划的是哪两个郡的界。

## 三、待核实与补充事项

- **江苏5A总数与名单**：截至本文件核对时（2026-10），江苏省5A景区为26家，与《_5A名单核对表.md》底稿一致，且与江苏省文化和旅游厅旅游名录（检索到26条5A记录）、文化和旅游部5A查询系统一致。2024年12月文旅部确定的19家5A名单中无江苏景区，2024年2月新增连云港市连岛景区为最新一家。
- **无锡市惠山古镇景区评定年份**：文化和旅游部政务服务门户"5A级旅游景区"查询显示年份为2019年，景区官网及部分媒体报道为"2020年获评／2020年初授牌"。本文件采用"2019年评定（2020年1月授牌）"，使用时请以文旅部公告为准。
- **苏州市苏州园林（拙政园-留园-虎丘）**：文旅部口径为"苏州市苏州园林（拙政园-留园-虎丘）"；另有资料将虎丘山、留园的5A评定年份标注为2010年，拙政园为2007年。本文件统一采用2007年（首批）。
- **无锡市灵山大佛景区**：文旅部名录作"无锡市灵山大佛景区"，江苏省文旅厅名录作"无锡市灵山景区"，二者指同一景区，本文件采用文旅部名称。
- **常州市天目湖景区**：底稿作"溧阳天目湖景区"，官方名录作"常州市天目湖景区"（溧阳市）。本文件采用官方名录名称。
- **苏州市太湖旅游区**：文旅部作"苏州市太湖旅游区"，江苏省文旅厅作"苏州市吴中太湖旅游区"，为同一景区。
- **泰州市溱湖旅游景区**：文旅部作"泰州市溱湖旅游景区"，底稿作"泰州姜堰溱湖国家湿地公园"，为同一景区。
- **瘦西湖与世界遗产的关系**：2014年"中国大运河"列入《世界遗产名录》，扬州为重要遗产城市；本文件仅在导游词中提及大运河申遗成功，未在表格"类型"栏标注世界文化遗产，如后续确认瘦西湖是否为独立遗产点，再行补充。
- **中华麋鹿园与中国黄（渤）海候鸟栖息地（第一期）的关系**：该世界自然遗产（2019年列入）包含盐城多处候鸟栖息地，景区与遗产地范围的关系需向保护区管理机构核实，本文件未作世界遗产表述。
