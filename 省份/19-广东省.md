### 1. 广州长隆旅游度假区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 广州市番禺区 |
| 类型 | 主题乐园 |
| 评定年份 | 2007 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

广州长隆旅游度假区位于广州市番禺区，是集主题公园、演艺、酒店群于一体的大型综合旅游度假区，2007年被评为首批国家5A级旅游景区。度假区核心板块包括长隆野生动物世界、长隆欢乐世界、长隆水上乐园、长隆飞鸟乐园和长隆国际大马戏。长隆野生动物世界以大规模珍稀野生动物种群展示著称，饲养展出大熊猫、白虎、考拉、亚洲象等物种，其中白虎与考拉的繁育种群规模位居世界同类动物园前列。长隆欢乐世界引进垂直过山车、十环过山车等大型游乐设备。长隆水上乐园据国际主题娱乐协会（TEA）与AECOM联合发布的《主题公园和博物馆报告》，多次位居全球水上乐园游客量排名前列。度假区配套多家主题酒店与演艺场馆，是华南地区规模最大的主题旅游度假目的地之一。

**【导游词核心稿】**

各位游客朋友，大家好！欢迎来到广州长隆旅游度假区。这里是华南地区规模最大的主题旅游度假区之一，早在2007年就跻身首批国家5A级旅游景区。今天我们主要走三个板块：动物王国、机动游乐和水上乐园，请大家跟紧我。

第一站是长隆野生动物世界。它最负盛名的是大熊猫三胞胎的故事：据公开资料记载，2014年7月，大熊猫"菊笑"在这里产下全球首例全部存活的大熊猫三胞胎，这在人工繁育史上极为罕见。园里的白虎和考拉种群规模也位居世界前列，大家可以留意"百虎山"里成群的白虎。

接下来是长隆欢乐世界。垂直下落的过山车、十环过山车都在这里，喜欢刺激的朋友可以挑战；带孩子的家庭建议去看长隆国际大马戏，节目融合了杂技、马术和舞蹈，老少皆宜。

如果正值夏季，长隆水上乐园不可错过。据国际主题娱乐协会与AECOM联合发布的年度报告，它曾多次进入全球水上乐园游客量排名前列。

最后提醒大家：园区面积大，请记牢集合时间和地点；老人、儿童参加机动项目前请留意身高与健康提示，贵重物品随身携带。祝大家在长隆玩得开心！

**【讲解要点提示】**
- 必讲：2007年首批5A身份；野生动物世界、欢乐世界、水上乐园、飞鸟乐园、国际大马戏五大板块；大熊猫三胞胎故事。
- 数据锚点：2014年7月全球首例存活大熊猫三胞胎；2007年首批5A。
- 常见误区：把"广州长隆"与"珠海长隆"混为一谈——两者分属广州番禺与珠海横琴，是两个不同度假区；长隆并非只有野生动物世界。
- 互动/提问设计：先让游客猜考拉一天要睡多久（约20小时），再引出考拉食谱单一、几乎只吃桉树叶的科普点。

### 2. 深圳华侨城旅游度假区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 深圳市南山区 |
| 类型 | 主题乐园 · 城市地标 |
| 评定年份 | 2007 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

深圳华侨城旅游度假区位于深圳市南山区深圳湾畔，是中国最早形成规模的大型主题公园集群之一，2007年被评为首批国家5A级旅游景区。度假区由锦绣中华、中国民俗文化村、世界之窗、欢乐谷四大主题公园及配套酒店、演艺场馆组成。锦绣中华于1989年建成开放，是中国第一座以微缩景观为表现形式的大型主题公园，按中国版图方位布局，集中再现国内著名古建筑与风景名胜；中国民俗文化村于1991年开放，以各民族村寨建筑与民俗歌舞展示为主。世界之窗1994年开业，汇集世界著名景观的微缩再现与文化演艺。欢乐谷1998年开业，是华侨城欢乐谷连锁品牌的首个项目，以大型机动游乐设施与主题节庆活动见长。度假区所在的华侨城片区同时也是深圳重要的城市文化与休闲区域。

**【导游词核心稿】**

各位游客，大家好！欢迎来到深圳华侨城旅游度假区。深圳是一座年轻的城市，但华侨城这片土地，记录了这座城市旅游业的起点。2007年，这里被评为首批国家5A级旅游景区。

我们先走进锦绣中华。1989年，它作为中国第一座大型微缩景观主题公园开门迎客，一句"一步迈进历史，一日游遍中国"的广告语，当年传遍大江南北。园内按中国版图的方位布局，把各地的名楼、古寺、石窟和民居按比例缩小摆放在一起，走一圈就等于翻了一本立体的中国地理课本。旁边的中国民俗文化村1991年开放，是各民族村寨与歌舞的活态展示区。

再看世界之窗，1994年开业，埃菲尔铁塔、凯旋门这些世界名标的微缩景观都集中在这里，很多深圳人的第一张"出国合影"就是在这儿拍的。

最后一站欢乐谷，1998年开业，是欢乐谷连锁品牌的第一座园区，大型过山车和主题节庆是它的招牌。

提醒一下：四个园区面积都很大，建议提前规划路线；观看户外演艺请注意场次时间，随身物品妥善保管。祝大家玩得尽兴！

**【讲解要点提示】**
- 必讲：2007年首批5A；锦绣中华1989年"中国第一座大型微缩景观主题公园"的历史地位；四大园区构成。
- 数据锚点：1989年锦绣中华、1991年民俗文化村、1994年世界之窗、1998年欢乐谷四个年份。
- 常见误区：锦绣中华与民俗文化村常被误认为同一家园区，实为两座公园；华侨城片区是开放式城区，并非封闭景区。
- 互动/提问设计：请游客说出自己家乡在锦绣中华微缩版图中的方位，再引导找一找家乡的名胜微缩景观。

### 3. 广州白云山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 广州市白云区（跨白云、越秀、天河三区） |
| 类型 | 山岳峰林 · 城市地标 |
| 评定年份 | 2011 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**

广州白云山风景区位于广州市北部，由30余座山峰连绵组成，主峰摩星岭海拔382米，是广州城区的最高峰，景区总面积约21.8平方公里。白云山自古被誉为"羊城第一秀"，山中植被茂密、泉涧众多，蒲谷、濂泉、九龙泉等名泉历代题咏不绝，其中"白云晚望""蒲涧濂泉"先后入选不同时期的羊城八景。主要景点包括摩星岭、鸣春谷、能仁寺、桃花涧、云台花园、雕塑公园、明珠楼与山湾竹溪等。白云山是广州城市的"绿肺"与市民登高健身的传统去处，2011年被评为国家5A级旅游景区。景区内开辟有盘山公路与多条登山步道，游览可由南门、西门等不同入口进入，山顶平台可俯瞰广州城区天际线。

**【导游词核心稿】**

朋友们，大家好！欢迎登上广州白云山。白云山自古就有"羊城第一秀"的美称，2011年被评为国家5A级旅游景区。它虽然只有382米高，却是广州城区的最高峰，可以说，白云山是广州人一抬头就能看见的那座山。

我们现在所在的这片山区，总面积约21.8平方公里，由30多座山峰连缀而成。别看它不高，里头的典故可不少。相传秦代方士郑安期——也就是广州人说的"郑仙"——曾在这一带采药修道，后来在此驾鹤飞升，山中的郑仙岩就由此得名。旧时每逢农历七月二十五，广州城里有"郑仙诞"的拜祭习俗，可见这座山与市民生活的渊源之深。

白云山的看点，一半在山、一半在水。蒲谷、濂泉、九龙泉都是历代文人题咏过的名泉，"白云晚望""蒲涧濂泉"都曾是羊城八景之一。夏天来能仁寺一带听蝉，春天去桃花涧看花，各有各的味道。

一会儿登到摩星岭，视野会一下子打开，广州塔、珠江新城的天际线都在脚下。

最后提醒：山道湿滑处请慢行，雷雨天气不要在大树下停留；登山请量力而行，注意集合时间。祝大家步步登高！

**【讲解要点提示】**
- 必讲："羊城第一秀"称号；摩星岭为广州城区最高峰；郑仙采药传说与"郑仙诞"民俗。
- 数据锚点：主峰摩星岭海拔382米；景区总面积约21.8平方公里；30余座山峰。
- 常见误区：白云山不是"广东最高山"，只是广州城区最高峰；白云山风景区与白云机场、白云区并非同一概念。
- 互动/提问设计：请游客猜白云山主峰海拔（382米），再引出"山不在高，在于它守着一座两千万人口的城市"。

### 4. 梅州雁南飞茶田景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 梅州市梅县区雁洋镇 |
| 类型 | 乡村田园 · 民族风情 |
| 评定年份 | 2011 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**

梅州雁南飞茶田景区位于广东省梅州市梅县区雁洋镇，地处粤东名山阴那山麓，2011年被评为国家5A级旅游景区。景区以连绵生态茶田与客家文化为主题，主要包含茶田观光区、制茶与茶艺展示区、客家民居建筑群和度假服务区。茶田依山势层层开垦，从山脚一直铺展到山腰，配套有茶叶加工车间与茶艺表演，游客可了解采青、杀青、揉捻、干燥等工序。景区内的围龙屋大酒店依客家传统"围龙屋"形制建造：围龙屋是客家民居的代表形式，中轴对称、前低后高，前有半月形水塘、后为半圆形围屋，祖堂居于中轴核心，与北京四合院、陕西窑洞、广西干栏式建筑、云南"一颗印"并称为中国传统民居的五大典型样式。梅州是国家历史文化名城，素有"世界客都"之称，景区内可观赏客家歌舞、品尝客家菜与擂茶。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到梅州雁南飞茶田景区。这里是粤东名山阴那山的山麓，2011年被评为国家5A级旅游景区。

先请大家深呼吸一下——这座山里的空气，是带着茶香的。我们眼前这一片层层叠叠的茶田，从山脚一直铺到山腰，是景区最核心的景观。茶园里种的都是适制绿茶的良种茶树，游客可以走进茶垄，看看采青，再到制茶车间看杀青、揉捻、干燥，最后坐下来喝一杯刚泡好的新茶。

雁南飞的另一个主角，是客家文化。梅州被称为"世界客都"，客家人自中原辗转南迁，把语言、饮食、民居和山歌一路带了过来，在这里生根。大家看那边那组半圆形的建筑，叫围龙屋。它中轴对称、前低后高，前面是半月形的水塘，后面是半圆形的围屋，祖堂正居中轴——这种形制与北京的四合院、陕西的窑洞、广西的干栏式建筑、云南的"一颗印"一起，被称为中国传统民居的五大典型样式。

一会儿我们还能看客家歌舞、尝一尝客家菜和擂茶。

提醒一句：茶田步道有坡度，请穿舒适的鞋；采茶体验有季节限制，出行前请核实当期安排。祝大家满袖茶香！

**【讲解要点提示】**
- 必讲：2011年5A身份；茶田—制茶—茶艺的完整体验链；围龙屋形制与"世界客都"背景。
- 数据锚点：2011年获评5A；围龙屋"前塘后围、中轴对称"的形制特征；传统民居五大典型样式的并列关系。
- 常见误区：雁南飞不是单纯的自然茶园，而是茶产业与客家文化结合的度假景区；"雁南飞"是品牌名，不是地名。
- 互动/提问设计：请游客辨认围龙屋前的水塘是圆形还是半月形（半月形），再讲"塘之半"与"围之半"合为圆形的营造观念。

### 5. 深圳观澜湖休闲旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 深圳市龙华区（原宝安区观澜） |
| 类型 | 主题乐园 |
| 评定年份 | 2011 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

深圳观澜湖休闲旅游区位于深圳市龙华区，2011年被评为国家5A级旅游景区。观澜湖高尔夫球会创建于1992年，是中国最早的高尔夫球会之一。球会拥有12个18洞锦标赛级球场，合计216洞，2004年获吉尼斯世界纪录认证为"世界第一大高尔夫球会"。除高尔夫运动外，景区配套有乡村俱乐部、水疗中心、度假酒店、会议中心、运动公园与生态休闲设施，形成以运动休闲为核心的综合度假目的地。观澜湖长期承办多项国际高尔夫赛事，并设有高尔夫学院与青少年培训基地，是中国高尔夫运动的重要推广基地之一。景区所在的观澜片区山水相间、植被良好，是深圳北部重要的生态休闲带。

**【导游词核心稿】**

各位游客，大家好！欢迎来到深圳观澜湖休闲旅游区。这里是2011年评定的国家5A级旅游景区，也是国内少见的以高尔夫运动为核心的国家5A级景区。

先说一组硬数据：观澜湖高尔夫球会创建于1992年，如今拥有12个18洞锦标赛级球场，加起来整整216洞。2004年，它被吉尼斯世界纪录认证为"世界第一大高尔夫球会"——请注意，这个"第一"说的是规模，不是难度。

那么"世界第一大"意味着什么？意味着这里的球场设计出自多位国际知名设计师之手，风格各不相同，有的依山、有的傍水；也意味着这里能同时承接大型国际赛事。观澜湖长期举办国际高尔夫赛事，还设有高尔夫学院和青少年培训基地，很多中国球手是从这里起步的。

当然，不打球的朋友也不会无聊：景区配套了乡村俱乐部、水疗中心、度假酒店、会议中心和运动公园，家庭出行完全可以各取所需。

最后的提醒：球场区域请注意安全，非打球人员不要进入球道；下场打球需提前预约，具体场次与费用出行前请核实。祝大家在这里享受一段从容的时光！

**【讲解要点提示】**
- 必讲：2011年5A身份；1992年创建；12个18洞、共216洞的规模；2004年吉尼斯认证。
- 数据锚点：216洞；2004年吉尼斯世界纪录；1992年创建年份。
- 常见误区："世界第一大高尔夫球会"指规模而非技术难度；观澜湖在深圳龙华，与海口观澜湖是两个不同项目。
- 互动/提问设计：请游客算一算216洞相当于多少个标准18洞球场（12个），再引出球场风格的多样性。

**【景区简介】**

**【讲解要点提示】**

- 常见误区：不要把"丹霞地貌"当成丹霞山独有（全国多地均有分布），丹霞山是命名地而非唯一产地；阳元石是天然形成，非人工雕凿。
- 互动/提问设计：请游客观察山体"顶平、身陡、麓缓"三要素，对照远处石柱判断它处于丹霞地貌发育的哪个阶段。

各位游客，大家好！欢迎来到河源万绿湖。2024年12月，这里被文化和旅游部确定为国家5A级旅游景区，这也是广东省的第16家国家5A级景区。
