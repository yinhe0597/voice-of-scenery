## 一、5A级景区（精编词条）

### 1. 黄山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年首批评定） |
| 所在地 | 安徽省黄山市（黄山区汤口镇为主要进山门户） |
| 类型 | 山岳峰林 · 世界文化与自然双重遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 1.5–2 天 |

**【景区简介】**

黄山风景区位于安徽省黄山市，地跨黄山区、黟县、休宁县、歙县等地，核心景区面积约160.6平方公里。山体为燕山期花岗岩侵入体，经长期风化剥蚀形成典型的花岗岩峰林地貌，千米以上高峰77座，莲花峰海拔1864米为第一高峰，光明顶1860米、天都峰1810米鼎足而立。"奇松、怪石、云海、温泉、冬雪"并称黄山五绝，玉屏楼前的迎客松为标志性景观。1990年，黄山被联合国教科文组织列入《世界遗产名录》，成为中国首批世界文化与自然双重遗产之一；2004年入选世界地质公园。山间现存历代摩崖石刻200余处，并保存有登山古道、古建遗址多处，历代文人留有诗文画作数以万计。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到黄山风景区。黄山秦代称"黟山"；据史书记载，唐玄宗于天宝六年（747年）下诏改称黄山。1990年，黄山列入《世界遗产名录》，成为我国最早的世界文化与自然双遗产之一；2004年又入选世界地质公园。今天我们要走进的，就是这样一座"双料"的大山。

先看自然。黄山的山体是一整块巨大的花岗岩，经过亿万年的抬升与风化，形成了今天这种"千峰竞列"的峰林景观。在核心景区160.6平方公里范围内，海拔1000米以上的高峰有77座——最高的莲花峰1864米，往西边看是1860米的光明顶，东边是1810米的天都峰。天都峰与莲花峰实行轮休开放，五年一换，所以今天能登上哪一座，一半靠安排，一半靠运气。

第二要看的是黄山松。黄山松的根能分泌有机酸，把花岗岩慢慢溶蚀出缝隙，于是能在海拔800米以上的悬崖石缝里扎稳脚跟。最有名的玉屏楼迎客松，据测算树龄已逾千年，一侧长枝横向伸展，恰似主人伸臂相迎。朋友们请看——它那一根"手臂"朝向哪边？多数人第一次都猜错，正说明它生在风口、长得很倔。

第三是云海和怪石。海拔1600米以上的高山区，一年中云雾弥漫的日子占到小半年，冬春两季雨雪初晴时最容易出现壮观的云海，看云海的最佳位置是光明顶、排云亭和始信峰。至于怪石，"猴子观海""梦笔生花""飞来石"，每一块都配得上一段名字。

再说人文。明代地理学家徐霞客曾两次游历黄山，赞叹"登黄山，天下无山，观止矣"。需要提醒的是，那句人人会背的"五岳归来不看山，黄山归来不看岳"并不是徐霞客的原话，而是后人对他游记的概括。

上山的路有石阶也有索道，请大家量力而行；山中天气多变，务必备好雨具和外套，雷雨时不要停留在孤峰、大树之下。祝各位在黄山看得到日出，也遇得见云海！

**【讲解要点提示】**
- 必讲：双遗产身份（1990年列入）与世界地质公园（2004年）；三大主峰海拔；迎客松成因与位置。
- 数据锚点：核心景区160.6平方公里；千米以上高峰77座；莲花峰1864米、光明顶1860米、天都峰1810米；摩崖石刻200余处。
- 常见误区："五岳归来不看山，黄山归来不看岳"是后人据《徐霞客游记》概括，非徐霞客原句；黄山不是"皖南山脉"的一部分，而是独立的山体。
- 互动/提问设计：让客人猜迎客松伸出的那一侧朝向何方；让客人估算自己在光明顶看见的第几个"1"字头海拔数；闭目听松涛判断风向。
- 出行提示：门票、索道运营及天都峰/莲花峰轮休安排，出行前请核实官方公告。

### 2. 九华山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年首批评定） |
| 所在地 | 安徽省池州市青阳县 |
| 类型 | 宗教圣地 · 山岳峰林 |
| 评定年份 | 2007 |
| 建议游览时长 | 1.5–2 天 |

**【景区简介】**

九华山位于安徽省池州市青阳县境内，北临长江、南望黄山，是中国佛教四大名山之一、地藏菩萨道场。风景区面积约120平方公里，由九十九座山峰组成，最高峰十王峰海拔1342米，天台峰、莲花峰等千米以上山峰三十余座。据《九华山志》记载，唐开元末年新罗国（今朝鲜半岛）王族金乔觉渡海来此苦修数十年，被后世尊为地藏菩萨应化身，九华山由此成为地藏道场。1982年，九华山被国务院列为首批国家重点风景名胜区；2009年入选世界地质公园。全山现存明清以来寺庙90余座、佛像万余尊，月身宝殿、化城寺、百岁宫、祗园寺等为核心人文景观。

**【导游词核心稿】**

各位朋友，欢迎来到九华山。九华山在汉代称陵阳山，南朝时因山有九座主峰、状如莲华而渐称九子山。唐代大诗人李白游此，写下"昔在九江上，遥望九华峰。天河挂绿水，秀出九芙蓉"的名句，"九华"之名由此广为人知。它坐落在安徽省池州市青阳县，北边是长江，南边是黄山，风景区面积约120平方公里，九十九座山峰连绵起伏，最高峰十王峰海拔1342米。

九华山为什么是地藏菩萨的道场？据《九华山志》等史料记载，唐开元末年，新罗国王族金乔觉渡海来到九华山，在深山岩洞中苦修数十年。相传他圆寂于唐贞元十年（794年），享年九十九岁，遗体经三年不腐，世人以为菩萨示现，遂将其肉身安置于石塔，世称"金地藏"。今天神光岭上的月身宝殿，供奉的正是这座肉身塔，是全山信众心中的圣地。这里请大家留意，史籍记载与民间传说是两回事，"相传"二字我们留在口头上。

再看建筑。九华山现存寺庙九十多座、佛像万余尊，规模之大在国内佛教名山中少见。化城寺是全山的开山祖寺，位于山下九华街正中；百岁宫则建在海拔八百多米的悬崖之上，楼房错落，层层相通，是山地寺庙建筑的典型代表，背山面江，气势不凡。

山门之内是云、石、瀑的自然世界。天台峰海拔一千三百余米，是全山最佳的观日出点，"天台晓日"自古列于九华十景。云雾起时，群峰浮沉，正如古人所言"江上望九华，九华不可见"。

请大家注意，登山路段台阶较多，请缓步慢行；进入殿堂请轻声、勿用闪光灯拍照，尊重宗教礼仪。愿各位在九华山，看山、看寺，也安顿一下自己的心情。

**【讲解要点提示】**
- 必讲：地藏菩萨道场由来与金乔觉；四大名山地位；月身宝殿肉身塔；化城寺。
- 数据锚点：风景区约120平方公里；最高峰十王峰海拔1342米；现存寺庙90余座、佛像万余尊；金乔觉相传圆寂于794年、世寿99岁。
- 常见误区：金乔觉事迹出自地方志与僧传，民间传说成分浓，讲解务必以"相传""据记载"区分；九华山与黄山地理位置相邻但互不相属。
- 互动/提问设计：请客人猜"九十九峰"是不是恰好99座（实为约数，形容山峦众多）；在月身宝殿前讲"绕塔三匝"的民俗含义。
- 出行提示：山门门票、景交车、索道班次及宗教活动日安排，出行前请核实官方公告。

### 3. 天柱山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 安徽省安庆市潜山市 |
| 类型 | 山岳峰林 · 地质地貌 |
| 评定年份 | 2011 |
| 建议游览时长 | 1–1.5 天 |

**【景区简介】**

天柱山位于安徽省安庆市潜山市境内，因主峰如柱擎天而得名"天柱"，古称皖山、皖公山，安徽简称"皖"即源于此。风景名胜区总面积约333平方公里。主峰天柱峰海拔1489.8米，峰体为一整根规模巨大的花岗岩柱状峰；山体所在的秦岭—大别造山带出露有全球罕见的超高压变质岩，记录着两亿多年前大陆板块深俯冲与折返的地质历史。境内峰丛、奇石、怪洞、飞瀑、云海俱全，尤以花岗岩崩塌叠置形成的洞穴群"神秘谷"和海拔1100米的高山人工湖炼丹湖著称。1982年列为首批国家重点风景名胜区，2011年入选联合国教科文组织世界地质公园。

**【导游词核心稿】**

各位朋友，欢迎来到天柱山。先请大家记住一句话："安徽的'皖'字，就是从这座山来的。"天柱山古称皖山，古代皖国就在这片山前的平原之上，因此才有今天安徽省的简称。

天柱山最有名的头衔，是"古南岳"。据《史记·封禅书》记载，汉武帝元封五年（公元前106年）南巡，登上天柱山祭祀，赐封此山为"南岳"；此后数百年，这里一直享受着国家最高等级的祭祀规格。400多年后，到隋文帝开皇九年（公元589年），朝廷把南岳的头衔改封给了湖南衡山，天柱山便退居"古南岳"。这段历史，是天柱山区别于其他名山的最大看点。

再看自然。主峰天柱峰海拔1489.8米，通体是一整根巨大的花岗岩柱，"孤立擎霄、峭拔如柱"，天柱之名由此而来。更有意思的是它的石头：天柱山处在世界上规模最大、出露最好的超高压变质带之一——在这里的岩石里，科学家发现了只有在极深的地幔环境中才能形成的特殊矿物，说明今天高高举向天空的这座山，两亿多年前曾扎到地下上百公里深处，又一路折返回了地面。所谓"曾深埋地下，今高擎于天"，讲的就是它。

山里有三样东西不能错过。第一是神秘谷，那是花岗岩崩塌堆叠形成的洞穴群，巨石交叠、上下盘曲，古人称为"华夏花岗岩第一秘府"，走进去要低头弯腰，别有一番乐趣。第二是炼丹湖，海拔1100米，是国内少见的高山人工湖，湖面开阔，云起时如悬于天上。第三是山上的云海与瀑布群，雨后初晴时最壮观。

请大家登山时注意台阶湿滑，尤其过神秘谷时要躬身慢行。祝各位在天柱山，读懂一根石柱撑起的一座皖西南名山。

**【讲解要点提示】**
- 必讲：古南岳身份与汉武帝封岳、隋代改封衡山；主峰海拔1489.8米；神秘谷成因；超高压变质带地质价值。
- 数据锚点：公元前106年汉武帝赐封南岳；589年隋改封衡山；天柱峰1489.8米；炼丹湖海拔1100米；景区总面积约333平方公里。
- 常见误区：天柱山与安徽简称"皖"同源，但不要把它当作安徽的地理中心；"古南岳"称号属历史称谓，今南岳为衡山。
- 互动/提问设计：请客人猜天柱峰相对高度不过数百米为何视觉如此巍峨（相对高差大、山前为平原）；请客人在神秘谷里闭塞视听只听水滴声。
- 出行提示：索道、景交车及步道开放状况，出行前请核实官方公告。

### 4. 皖南古村落—西递·宏村

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 安徽省黄山市黟县 |
| 类型 | 古城古镇 · 世界文化遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 1 天（两村联游） |

**【景区简介】**

皖南古村落—西递·宏村位于安徽省黄山市黟县，是徽州传统村落的杰出代表。西递始建于北宋皇祐年间，为胡氏聚族而居的血缘村落，保存较完整的明清古民居140余幢；宏村始建于南宋绍兴年间，为汪氏聚族而居，按牛形布局营建：雷岗山为牛首、村口古树为牛角、月沼为牛胃、环绕各家的人工水圳为牛肠、始建于明万历三十五年（1607年）的南湖为牛肚。两村街巷依水而设，马头墙、天井、木雕楼、"堂名为记"的匾额保存完好，承志堂占地约2100平方米，有"民间故宫"之誉。2000年11月，西递、宏村被联合国教科文组织列入《世界遗产名录》；2024年，西递村获评联合国旅游组织"世界最佳旅游乡村"。

**【导游词核心稿】**

各位朋友，欢迎来到黟县。今天我们看的不是一座山、一座庙，而是两个活着的村庄——西递和宏村。2000年11月，它们以"皖南古村落"的名义列入《世界遗产名录》。世界遗产委员会给出的评语是：这两个村庄的传统街道形式、建筑体型和装饰，保持了14世纪以后中国中部农村的面貌。

先说西递。它始建于北宋皇祐年间，距今已有九百多年，全村姓胡，是典型的血缘村落。村里保存完好的明清古民居有140多幢，最抢眼的是门楼上的砖雕、門罩上的雕花、厅堂里的楹联。请大家注意看那副著名的楹联："读书好营商好效好便好，创业难守成难知难不难。"一句话把徽州人"贾而好儒"的人生哲学说透了。

再说宏村。它始建于南宋绍兴年间，全村姓汪。宏村最绝妙的，是一套完整的"牛形"水系：村后有雷岗山当牛头，村口两棵四五百年的古树当牛角，弯弯绕绕的九曲十八弯水圳绕经每家每户，那是牛肠；汇集到村心的半月形池塘月沼，那是牛胃；最后流入村南的大湖。这套水系既是防火、洗涤、灌溉的实用工程，也是古人"引水入村、藏风聚气"的营造智慧。请大家留意脚下：水圳清浅流了六百多年，村规约定每天几点用于饮用、几点用于洗涤，规矩分明。

村里的承志堂是清末徽商汪定贵的宅第，占地约2100平方米，木雕极为繁复，梁枋、槅扇、栏板处处是戏文人物，因此有"民间故宫"之称。2024年，西递村还获评了联合国旅游组织"世界最佳旅游乡村"，这是对古村落活态保护最好的褒奖。

最后一问留给大家：为什么徽州的房子沒有窗？答案就在"天井"二字——外墙高墙小窗是为防盗聚财，采光通风全靠头顶这片天。祝各位在粉墙黛瓦间，看得见古人的生活智慧。

**【讲解要点提示】**
- 必讲：2000年列入世界遗产；宏村牛形水系（牛首、牛肠、牛胃）；承志堂；徽商"贾而好儒"。
- 数据锚点：西递明清古民居140余幢、北宋皇祐年间立村；宏村南宋绍兴年间立村、南湖始建于1607年；承志堂占地约2100平方米；2024年西递获评世界最佳旅游乡村。
- 常见误区：不要将西递、宏村混为一谈（两村相距约十余公里，姓氏、水系、年代均不同）；"牛形村"是后人对布局的概括性归纳，不是建村时的正式图纸。
- 互动/提问设计：请客人踩一踩水圳边缘判断水流方向；请客人在月沼边指出"牛胃"位置；让客人猜为何老宅对外几乎不开窗。
- 出行提示：两村联票、夜游与写生旺季人流情况，出行前请核实官方公告。

### 5. 天堂寨旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 安徽省六安市金寨县（与湖北省罗田县交界） |
| 类型 | 山岳峰林 · 森林草原 |
| 评定年份 | 2012 |
| 建议游览时长 | 1–1.5 天 |

**【景区简介】**

天堂寨旅游景区位于安徽省六安市金寨县西南部，地处皖鄂两省交界的大别山腹地，与湖北省罗田县、英山县接壤。景区主峰天堂寨海拔1729.13米，为大别山第二高峰（最高峰为霍山县境内白马尖，海拔1777米）。这里是秦岭—大别造山带的核心地带，山高谷深、悬崖林立，保存有大面积原生性常绿落叶阔叶混交林，森林覆盖率高，动植物资源丰富，素有"华东最后一片原始森林"之称。景区以瀑布群、峡谷群、奇峰怪石为主要景观，九影瀑、泻玉瀑等多级跌水与白马大峡谷、圣卦峰等共同构成完整的游览体系，是大别山国家地质公园的重要组成部分。2012年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到大别山的深处——天堂寨。先做一个地理交代：大别山横亘在安徽、湖北、河南三省之间，是中国南北气候与植被的分界线之一；我们脚下这座天堂寨，主峰海拔1729.13米，是整条山脉的第二高峰，最高的是邻县霍山的白马尖，海拔1777米。请注意，我们站的这一条山脊，就是安徽和湖北的分界线，一步跨两省，在这里不是夸张的说法。

天堂寨的名字很有意思。"天堂"二字，取自它的高——古时人迹罕至、云雾缭绕，登高如在天上；"寨"则因为它地势险要，自古就是兵家必争之地。山区偏远、山高林深，正是这种特殊的地理，让它保存下了大面积的原始次生林，植被之好在整个华东地区都属少见，因此被誉为"华东最后一片原始森林"。

看水的部分最过瘾。这里的地层被南北方向的断裂切开，落差大、雨水足，于是形成了一连串多级跌落的瀑布群，九影瀑、泻玉瀑、情人瀑层层叠叠。雨后水量最大，晴日到访则清秀如练。与之配套的还有白马大峡谷：谷壁陡直、溪流清澈，两侧岩壁上一串串圆形的凹坑，是冰川融水和急流长期冲刷形成的壶穴，也是地球慢慢打磨石头的证据。

再说"红"。大别山是著名的革命老区，这里是鄂豫皖革命根据地的核心区域之一，山里的村落、山道、旧址散布其间。自然与历史叠加，正是天堂寨区别于一般山地景区的独特之处。

山上气温比山下低数摄氏度，朋友们请带一件外套；雨后石阶湿滑，务必走稳。祝各位在天堂寨，看得见瀑布，也呼吸得上最好的空气。

**【讲解要点提示】**
- 必讲：大别山腹地位置与主峰海拔；皖鄂省界；瀑布群与白马大峡谷；革命老区背景。
- 数据锚点：主峰海拔1729.13米；大别山最高峰白马尖1777米；2012年评定5A；少见于华东的原始森林植被。
- 常见误区：天堂寨常被误认为大别山最高峰，实际第二高；景区跨皖鄂两省，安徽侧的游览入口设在金寨县，不要安排错侧上山。
- 互动/提问设计：让客人在瀑布下估算落差；让客人在峡谷岩壁上寻找并触摸壶穴，猜"它是谁挖出来的"。
- 出行提示：索道、景交车、水量起伏与季节封山，出行前请核实官方公告。

### 6. 龙川景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 安徽省宣城市绩溪县瀛洲镇龙川村 |
| 类型 | 古城古镇 · 陵寝祠庙 |
| 评定年份 | 2012 |
| 建议游览时长 | 2.5–3 小时 |

**【景区简介】**

龙川景区位于安徽省宣城市绩溪县瀛洲镇龙川村（俗称坑口村），是徽州典型的血缘聚落与宗祠文化景区。龙川村地处登源河谷地，村前有龙川溪蜿蜒流过，胡氏族人在此聚族而居已有千余年历史。核心景观龙川胡氏宗祠据研究始建于明代中叶，占地近1300平方米，以数量众多、技艺精湛的木雕著称，梁枋、斗拱、槅扇遍布荷花、戏文题材雕刻，被誉为"江南第一祠""木雕艺术博物馆"，1988年列为第三批全国重点文物保护单位。村内还保存有明代石牌坊奕世尚书坊（建于明嘉靖四十一年，1562年，四柱三间五楼）、胡炳衡宅、乡贤祠、少保府等文物建筑，巷道、水街、古桥格局完整。2012年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到绩溪龙川。龙川是一条山谷里的小村，但它在中国古建筑界的名气极大——全村最了不起的一处，是国家重点文物保护单位：龙川胡氏宗祠。

请大家先站在祠堂门前抬头看。整座宗祠坐北朝南，中轴对称，前有门楼，中为享堂、后为寝楼，占地近1300平方米。它的精华在于木雕——数以千计的构件上几乎没有一块是素面：梁上托着一朵朵木雕莲花，斗拱、雀替、槅扇满布人物戏文与飞禽走兽。为什么会这么"铺张"？因为在徽州，宗祠是一个家族最重的地方，祭祖、议事、惩戒都在其中，财力和手艺都往这里堆，所以才有"江南第一祠""木雕艺术博物馆"的说法。这座建筑1988年被列为全国重点文物保护单位，是全国第一批获此称号的大型宗祠之一。

看完祠堂看牌坊。村口的奕世尚书坊建于明嘉靖四十一年，也就是1562年，四柱三间五楼，通体石构。牌坊在古代是朝廷批准才可以立的"德政标牌"，一座村口能有如此规格的石坊，背后是这个村读书做官的传统。

这里正是徽州文化的关键词——"贾而好儒"。徽州人外出经商，赚了钱回来第一件事是修祠堂、办书院、立牌坊。商与儒，在徽州从来不是对立的两件事，而是同一个人生理想的两个侧面。龙川历史上出过明代兵部尚书胡宗宪这样的重臣，村中的少保府、乡贤祠都是这段历史的注脚。

最后请大家留意脚下这条水街——村中小溪伴街而行，洗衣、淘米、防火都靠它。祠堂、牌坊、水街三样合在一起，才是一个完整的徽州古村。

游览请留意门槛较高，抬脚慢行；祠堂内请勿触摸木雕构件。祝各位在龙川，读懂徽州人敬祖重学的那一颗心。

**【讲解要点提示】**
- 必讲：胡氏宗祠的木雕艺术价值与1988年国保身份；奕世尚书坊年代；徽州"贾而好儒"传统。
- 数据锚点：宗祠占地近1300平方米；奕世尚书坊建于1562年；1988年第三批全国重点文物保护单位；2012年评定5A。
- 常见误区：龙川村俗称"坑口"，但5A景区规范名称为"龙川景区"；村中历史人物的事迹请依据史籍表述，民间故事须注明"相传"。
- 互动/提问设计：请客人在木雕中找出同一朵荷花的不同形态；请客人猜为什么徽州祠堂门前都有泮池或半月塘。
- 出行提示：开放时间、联票政策及祠堂内部限流措施，出行前请核实官方公告。

### 7. 八里河风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 安徽省阜阳市颍上县八里河镇 |
| 类型 | 水域湖泊 · 主题乐园 |
| 评定年份 | 2013 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

八里河风景区位于安徽省阜阳市颍上县八里河镇，地处淮河中游北岸的低洼水网地带。这里原为水患频繁的荒湖洼地，经长期水利治理与生态修复，逐步形成湖泊、岛屿、湿地相间的水域景观，并在此基础上建设了一批休闲游览设施，形成集湖区风光、微缩景观、鸟类观赏、游乐体验于一体的综合性景区，总面积约2.4平方公里。景区由当地群众自筹自建起步，因而在民间有"天下第一农民公园"之称，是淮河流域湿地型、人工营造型景区的代表。2013年评定为国家5A级旅游景区，也是皖北地区重要的生态旅游目的地。

**【导游词核心稿】**

各位朋友，欢迎来到阜阳颍上县的八里河。我先讲一个和别处不一样的故事：这里的风景，不是老天爷留下的，也不是皇家修的，而是当地老百姓自己一锹一锹挖出来的。

八里河一带处在淮河中游，地势低洼，"大雨大灾、小雨小灾、无雨旱灾"是过去这里的常态。水患退去留下的废洼地、旧河道，经过几十年的治理和利用，慢慢变成了今天水网交织、岛屿星罗的湖荡湿地。人们又顺着这份自然本底，开辟出水上游线，栽树种草，逐步建成了今天这个约2.4平方公里的景区。所以八里河最宝贵的一点，不是某一处风景，而是"人把灾地变景区"的这个过程——这也是它在民间被称为"天下第一农民公园"的原因。

景区怎么玩？我建议从三条线走。第一条是水线，坐游船穿行湖面，看两岸的芦苇、水鸟和散落的小岛，这是体验八里河湿地本色的最好方式。第二条是园林线，湖畔排布着成组的风景建筑与植物造景，是典型的现代休闲园林做法，适合慢慢散步。第三条是亲子线，景区内设有动物观赏与游乐区域，带孩子来的朋友可以留出时间。

阜阳地处皖北平原，四周一马平川，所以八里河这一片水显得格外珍贵。每年夏秋，大批水鸟在这里停歇，站在堤上看夕阳落进水面，是本地人最爱的画面。

最后提醒一句：这里是湿地型景区，天气晴热蚊虫较多，请备好防护用品；水上游船请全程穿好救生衣。祝各位在八里河，看到淮北平原上难得的一片碧水。

**【讲解要点提示】**
- 必讲：淮河洼地治理成景的"人工湿地型景区"属性；水面约2.4平方公里；"天下第一农民公园"民间称谓。
- 数据锚点：2013年评定5A；总面积约2.4平方公里；地处淮河中游北岸。
- 常见误区：八里河不是自然名胜古迹，核心看点是水利治理与现代休闲营造，讲解不宜套用"名山大川"话术；个别网络宣传中的获奖名次请以官方资料为准。
- 互动/提问设计：请客人观察湖岸植物判断这是天然湖泊还是人工湿地；让客人对比自己在地图上看颍上的位置，聊聊平原为什么缺水。
- 出行提示：游船班次、动物展区表演时间，出行前请核实官方公告。

### 8. 古徽州文化旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2014年评定） |
| 所在地 | 安徽省黄山市歙县、徽州区 |
| 类型 | 古城古镇 · 陵寝祠庙 |
| 评定年份 | 2014 |
| 建议游览时长 | 1–2 天（五片区分散，需安排分区游） |

**【景区简介】**

古徽州文化旅游区位于安徽省黄山市，跨歙县与徽州区两地，由徽州古城、棠樾牌坊群·鲍家花园、唐模、潜口民宅、呈坎五大片区组成，总面积约9.5平方公里。徽州古城为国家级历史文化名城歙县的核心，自秦置歙县以来长期为郡、州、路、府治所；棠樾牌坊群为明清鲍氏家族所立七座石牌坊，按"忠—孝—节—义"次序排列；鲍家花园为清代盐商园林遗存；唐模以水口园林"檀干园"与同胞翰林坊闻名；潜口民宅集中易地保护了一批明清民居；呈坎按八卦格局营建，明代罗东舒祠（宝纶阁）为其代表建筑。景区整体呈现徽州宗族、科举、商帮、营造技艺等文化面貌，2014年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到古徽州文化旅游区。这一站我们要看的不是一座宅院，而是整整一套"徽州文化的标本"。景区由五个片区组成，横跨歙县与徽州区，总面积9.5平方公里，建议分区安排时间。

第一站，徽州古城。歙县是国家级历史文化名城，秦代设县，自唐以来长期是徽州府的治所。徽州这个名字，始于北宋宣和三年（1121年）改歙州为徽州。城里最值得看的是府衙与街巷格局——一座府城如何把官署、学宫、市井和宗族祠堂安放进同一张图纸，这里是最完整的样本。

第二站，棠樾牌坊群·鲍家花园。请大家站在田埂上，顺着这条线往前看：七座石牌坊一座接一座，明清两代陆续建成，按"忠、孝、节、义"的顺序排列。牌坊不是随便能立的，每一座都要层层上报、皇帝批准，是古代"国家荣誉证书"。旁边的鲍家花园，是清代盐商的私家园林遗存，可以与北方皇家园林、江南文人园林一路对照着看。

第三站和第四站，唐模与潜口民宅。唐模看的是"水口园林"——村口的水口林、亭榭、小西湖一般的檀干园，讲究的是"进门先见水，出门才见村"。潜口民宅走的则是另一条路：把散落各处、难以原址保护的明清老房子整体迁到这里集中保护，这也是文物保护的通行做法之一。

最后一站，呈坎。村名取自八卦中的坎卦，全村按八卦格局布局，街巷宛转如迷宫，明代建筑罗东舒祠（俗称宝纶阁）雕饰精美，是村中最重要的一处文物。古人有诗说"游呈坎一生无坎"，我们边走边体会这句吉祥话。

徽州文化的核心是四句话：以贾代耕、以儒为业、以族为纲、以文传世。五站走完，这十六个字大概就明白了。

**【讲解要点提示】**
- 必讲：五大片区构成；徽州古城作为府治的历史地位；棠樾牌坊群"忠孝节义"序列；呈坎八卦村。
- 数据锚点：总面积约9.5平方公里；七座牌坊；北宋宣和三年（1121年）改歙州为徽州；2014年评定5A。
- 常见误区：不要把这五处与西递·宏村（世界遗产）混为一谈，两者是不同景点、不同批次；鲍家花园为后世重建园林，历史叠压较多，讲解须谨慎使用"原貌"表述。
- 互动/提问设计：请客人数牌坊并说出各自的主题顺序；请客人在呈坎街巷中判断自己是否已经"转回原地"。
- 出行提示：五片区距离较远、门票与开放时间不一，出行前请核实官方公告并合理编排路线。

### 9. 三河古镇景区

**【景区简介】**

三河古镇位于安徽省合肥市肥西县南端，地处肥西、庐江、舒城三县交界地带，因丰乐河、杭埠河、小南河三水交汇、环镇而流而得名，距今已有2500多年历史。历史上这里水运通达，是皖中地区重要的商品集散地，有"皖中商品走廊"之称。古镇保留有水乡格局：古街、古桥、古民居沿小南河两岸铺展，青石板路、马头墙、木构店铺连绵成街，代表建筑有古西街、古南街、三县桥、杨振宁旧居、刘同兴隆庄、鹤庐、大夫第等。清咸丰八年（1858年），太平天国将领陈玉成、李秀成在此围歼湘军李续宾部，史称"三河大捷"，古镇由此留下厚重的近代史印记。2015年评定为国家5A级旅游景区。

各位朋友，欢迎来到合肥三河古镇。先请大家打开手机地图，看看我们的位置：肥西、庐江、舒城三县交界的这一点，丰乐河、杭埠河、小南河三条河在这里交汇，"三河"这个名字，就是这么来的。古镇距今已有2500多年，水运时代它是方圆百里最热闹的码头之一，货物从巢湖进、从这里散向皖中各地，人称"皖中商品走廊"。

古镇怎么逛？记住一句口诀：沿着水走，走到桥为止。小南河穿镇而过，两岸是连绵的青石板古街，前店后坊、下店上宅，典型的江淮水乡做法。请大家留意脚下的石板被独轮车磨出的那一道浅槽，那是几百年商埠的痕迹。

老街上几处名人旧居值得看。一是杨振宁先生少年时的居所，二是"刘同兴隆庄"这样的老铺面，三是深宅"鹤庐"。请不要小看这些宅子——它们共同说明的是，古徽州周边的水乡镇市，既有商业也有文脉。

再讲一段真正改变中国近代史的事。清咸丰八年（1858年）十一月，太平天国将领陈玉成、李秀成率部在三河镇设伏，将湘军名将李续宾所部围歼于镇郊。这场"三河大捷"让曾国藩痛失爱将与精锐，也让他感叹"三河之败，湘军元气大伤"。如今镇上的三河大战风云馆，讲的就是这段往事。一个水乡小镇，为什么能成为决定大势的战场？答案就在地图上的三条河——谁控制了三水交汇的码头，谁就掌握皖中的粮道与兵道。

最后给大家留个小任务：走到古桥"三县桥"中央站定，你会发现一桥连通三县。在这儿拍张照，恭喜你，一步之内到过三个县。

- 必讲：三水交汇得名；水运商埠历史；1858年三河大捷；古街古桥格局。
- 数据锚点：距今2500多年；三条河流交汇、一桥连三县；1858年三河大捷；2015年评定5A。
- 常见误区：三河古镇属合肥市肥西县，不要误认为在巢湖市；"皖中商品走廊"是历史经济地位的表述，非官方等级头衔。
- 互动/提问设计：请客人在三县桥上猜自己站在哪个县；让客人从街面石板的凹槽推测当年运输工具。
- 出行提示：夜游项目、游船班次、故居开放情况，出行前请核实官方公告。

### 11. 万佛湖风景区

| 项目 | 内容 |

**【景区简介】**

万佛湖风景区位于安徽省六安市舒城县境内，地处大别山东北麓、杭埠河上游，原名龙河口水库。水库于1958年动工兴建，是淠史杭灌区的重要水利枢纽之一，承担着灌溉、防洪、供水等功能。库区水面开阔，水域面积约50平方公里，湖中有大小岛屿数十座，岸线曲折，植被覆盖良好，形成湖光山色与洲岛相间的景观格局。近年来依托湖区生态资源发展旅游，建有水上游览、岛屿观光、休闲度假等设施，并保留水库大坝等水利工程作为参观内容。2016年评定为国家5A级旅游景区，是安徽重要的湖泊型旅游目的地。

**【导游词核心稿】**

各位朋友，欢迎来到舒城万佛湖。请先记住一个名字：龙河口水库。万佛湖是它后来的名字，而它的身份，首先是一座1958年动工兴建的人工水库，是举世闻名的淠史杭灌区的重要组成部分。

为什么说人工？因为这一带位于大别山东北麓，历史上岗丘起伏、水源不稳，旱涝交替。上世纪五十年代开始，人们在杭埠河上游筑坝成库，把雨季的水存下来，旱季放出去，灌田、防洪、供水——这三项功能至今依然重要。今天我们看到的这片碧水，水面面积约50平方公里，湖湾曲折、洲岛星罗，是当年那场水利工程的"副产品"，也是人与自然关系的一次重构。

坐船游湖是最值得推荐的方式。船行进在宽阔的水面上，两边是连绵的低山和湖湾，时不时会掠过一个个小岛。晴天时水色清澈，起风时波光万顷，这是典型的库区湖泊风光。

如果只看水，万佛湖就一般了。它的第二个看点是坝上的水利工程。站在大坝上，可以直观理解一座水库是怎样"卡住"一条河流的：坝体、溢洪道、闸门，每一样都有明确的分工。带孩子的朋友，这一站非常适合做一次生动的水利科普。

万佛湖周边的物产也不能错过。舒城一带是安徽名优绿茶产区，此外湖区的鱼鲜、山区的板栗都是本地风味。午饭可以安排湖鲜，配一杯当地好茶。

提醒各位：乘船请全程穿戴救生衣，勿靠近船舷；湖区日照强烈，请备防晒用品。祝各位在万佛湖，看见水，也看见人把水治理好的那一代人的力气。

**【讲解要点提示】**
- 必讲：龙河口水库与1958年建库背景；淠史杭灌区功能；库区水利知识与水上游览。
- 数据锚点：原名龙河口水库；1958年动工；水域面积约50平方公里；2016年评定5A。
- 常见误区：万佛湖是人工水库改造的景区，不是天然湖；不要将其神话传说当成历史事实讲述。
- 互动/提问设计：请客人在坝上指出溢洪道位置并猜其作用；让客人比较库区水位在丰水、枯水期的差别。
- 出行提示：游船班次、岛屿开放情况、泄洪期水位变化，出行前请核实官方公告。

### 12. 长江采石矶文化生态旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2020年评定） |
| 所在地 | 安徽省马鞍山市雨山区采石街道 |

| 评定年份 | 2020 |

**【景区简介】**

长江采石矶文化生态旅游区位于安徽省马鞍山市雨山区，地处长江东岸，矶头兀立江畔，与南京燕子矶、岳阳城陵矶并称"长江三矶"，名列其首。采石矶古称牛渚矶，因扼守长江险要渡口，自古为兵家必争之地与南北津要。南宋绍兴三十一年（1161年），文臣虞允文在此督师抗击金军，取得著名的"采石大捷"，成为中国战争史上以少胜多的经典战例。矶上有纪念李白的太白楼（现存为清代建筑）、李白衣冠冢、三元洞、谪仙园、广济寺等人文景观。相传唐代诗人李白在此醉酒入水捉月而去，采石矶由此成为凭吊李白的重要之地。2020年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到马鞍山采石矶。请大家先站到江边往远处看：这一段是长江下游，江面开阔，水深流急。而在我们脚下，一块岩石突入江中，像一只伸进江心的手臂——这就是"矶"，采石矶正是长江上有名的三座矶头之一，而且号称"三矶之首"。矶头突入江中，水流被逼转，形成天然深水良港，因此在古代，这里是长江最重要的渡口之一，南北往来必经。

第一层看点，是诗。唐代大诗人李白晚年流寓皖南，多次在当涂、采石一带游历。相传他在这里醉酒，见水中月影，纵身入水捉月而去——这个结局当然是传说，但人们宁可相信：配得上这样结局的，只有李白。矶上建有太白楼，现存建筑为清代遗构，历代文人登临题咏不绝；江边的李白衣冠冢，也是后人寄情之地。讲解时请大家记住，这些"捉月"的故事要冠以"相传"二字。

第二层看点，是战场。南宋绍兴三十一年（1161年），金军大举南下，兵临长江。前来劳师的文臣虞允文挺身而出，在采石矶督师整合溃散兵卒，凭借水军优势与地形之利，一举挫败对岸金军，史称"采石大捷"。这一战稳住了南宋半壁江山，也让一个从未带过兵的文官留名史册。站在矶头看这段江面，历史的距离感会忽然消失。

第三层看点，是今天的改造。如今的采石矶已由昔日渡口、港区转变为城市生态与文化景区，江岸植被恢复、生态步道贯通，成为马鞍山人日常休闲的去处。

临江风大，请大家注意保暖与安全，切勿翻越护栏；雨后矶石湿滑，务必走稳。祝各位在采石矶，感受一份长江边的诗与剑气。

**【讲解要点提示】**
- 必讲：长江三矶之首与"矶"的地貌含义；1161年采石大捷；太白楼与李白传说。
- 数据锚点：长江三矶（采石矶、燕子矶、城陵矶）；1161年虞允文督师大捷；2020年评定5A。
- 常见误区："李白捉月骑鲸"是民间传说，须以"相传"表述；太白楼现存建筑为清代遗构，不要说成唐代原物。
- 互动/提问设计：请客人站在矶头判断水流方向与渡口成因；让客人背一句李白的诗，判断他写诗时的年纪。
- 出行提示：直升电梯/索道、游船、夜间项目开放情况，出行前请核实官方公告。

### 13. 琅琊山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年评定） |
| 所在地 | 安徽省滁州市琅琊区 |
| 类型 | 山岳峰林 · 宗教圣地 · 遗址考古 |
| 评定年份 | 2024 |
| 建议游览时长 | 4–6 小时 |

**【景区简介】**

琅琊山景区位于安徽省滁州市琅琊区西南，风景名胜区总面积约115平方公里，主峰海拔三百余米。山中以醉翁亭、琅琊寺为核心人文景观，是欧阳修《醉翁亭记》的发生地。北宋庆历年间欧阳修贬知滁州，山僧智仙建亭于酿泉之上，欧阳修作《醉翁亭记》，一句"醉翁之意不在酒，在乎山水之间也"使此山名扬天下；醉翁亭与北京陶然亭、长沙爱晚亭、杭州湖心亭并称中国四大名亭。琅琊寺始建于唐大历六年（771年），为皖东著名古刹。山中留存历代摩崖石刻与碑刻，其中宋代以后书写的《醉翁亭记》碑最为世人所重。2024年评定为国家5A级旅游景区，是安徽省第13家国家5A级景区。

**【导游词核心稿】**

各位朋友，欢迎来到滁州琅琊山。中国有很多名山靠高度取胜，琅琊山不在此列——它的主峰海拔只有三百多米。但在中国文化地图上，它的分量极重。原因只有一个字：文。

北宋庆历年间，欧阳修因参与革新被贬，出任滁州知州。这段时间他常到城外的琅琊山中游玩，山僧智仙为他在酿泉旁建了一座小亭。亭子落成，欧阳修写下二百多字的短文，开篇五个字——"环滁皆山也"——据说之前改了十几遍才定稿。文章结尾那句"醉翁之意不在酒，在乎山水之间也"，成了中国人讲了一千年的成语。这就是《醉翁亭记》。今天我们要去的醉翁亭，与北京陶然亭、长沙爱晚亭、杭州湖心亭并称"中国四大名亭"。

请大家注意，欧阳修写这篇文章时才三十多岁，正是仕途受挫的当口。开篇一个"环滁皆山也"，把惊慌收敛起来；通篇二十一个"也"字，节奏舒缓，像一个人在山路上漫步，边走边和自己和解。所以读《醉翁亭记》，读的不是风景，是心态。这也是我建议大家上山之前先读一遍原文的原因。

山上第二处必看的是琅琊寺。它始建于唐大历六年（771年），距今已有一千二百多年，比醉翁亭还早两百多年，是皖东一带最有名的古刹之一。山间的摩崖石刻、历代碑刻众多，宋代以后书写《醉翁亭记》的名碑尤为珍贵，是"名篇、名山、名刻"互相成就的典型。

至于自然：琅琊山林木茂盛，让泉、醉翁潭、深秀湖一路串连，尤以"林壑尤美、蔚然而深秀"著称，春天登山看的是"野芳发而幽香"，秋天则是"风霜高洁"。

台阶平缓，适合全家出行；雨后请注意路滑。祝各位在琅琊山，读一遍《醉翁亭记》，也找回自己的一点"在乎山水的闲情"。

**【讲解要点提示】**
- 必讲：《醉翁亭记》与欧阳修贬滁背景；醉翁亭为四大名亭之一；琅琊寺771年始建。
- 数据锚点：风景名胜区总面积约115平方公里；琅琊寺始建于771年；《醉翁亭记》全文二十余个"也"字；2024年评定5A。
- 常见误区："醉翁亭里有汪伦"等张冠李戴说法绝不可用；文中"太守谓谁？庐陵欧阳修也"是自道姓氏籍贯，庐陵在今江西吉安。
- 互动/提问设计：请客人齐声背诵"环滁皆山也"；请客人数一数碑刻上"也"字的数量。
- 出行提示：景区交通车、夜游与碑刻展陈安排，出行前请核实官方公告。
