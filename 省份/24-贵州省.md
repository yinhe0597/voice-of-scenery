### 1. 安顺市黄果树大瀑布景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 贵州省安顺市镇宁布依族苗族自治县黄果树镇 |
| 类型 | 水域湖泊 · 地质地貌 |
| 评定年份 | 2007 |
| 建议游览时长 | 5-7 小时（含陡坡塘、天星桥） |

**【景区简介】**（约250字）

黄果树大瀑布景区位于贵州省安顺市镇宁布依族苗族自治县，距安顺市区约45公里，地处珠江水系白水河上，是以喀斯特瀑布群为核心的国家级风景名胜区。核心景观黄果树大瀑布高77.8米，其中主瀑高约67米，瀑顶宽约83.3米、瀑面宽101米，是中国最大的瀑布，也是世界上著名的大瀑布之一。景区由以黄果树大瀑布为首的18个大小瀑布组成瀑布群，并集溶洞、地下河、石林、峡谷、峰林于一体，主要景点包括水帘洞、陡坡塘瀑布、螺丝滩瀑布、银链坠潭瀑布、天星桥石林与盆景园。瀑布后的水帘洞长134米，可从六个洞窗向内观瀑。1982年，黄果树被国务院公布为首批国家重点风景名胜区；2007年，被评定为国家5A级旅游景区。明代旅行家徐霞客曾亲历此地，留下"捣珠崩玉，飞沫反涌"的生动记载。

**【导游词核心稿】**（约560字）

各位游客朋友们，大家好！欢迎来到安顺黄果树。今天我们要看的，是中国最大的瀑布——黄果树大瀑布。

先给大家两个数字：瀑布高77.8米，瀑面宽101米。什么概念？差不多是二十几层楼高，比一个标准足球场还宽。这么大的水从崖顶砸下来，声音在几百米外就能听见。所以明代那位大旅行家徐霞客走到这儿，写下了八个字——"捣珠崩玉，飞沫反涌"。据史料记载，他是公元1638年沿着古驿道走到这里的，是第一位给黄果树留下系统文字记录的旅行家。

黄果树最妙的还不只是"看"。请各位跟我走进瀑布背后——水帘洞。这条天然溶洞长134米，里面有六个洞窗，从洞口伸出手去，就能摸到飞泻的水流，这叫"摸瀑"。在中国的大瀑布里，能从背后观赏的，黄果树是独一份。

顺着栈道往下走，是陡坡塘瀑布。它顶宽105米，是黄果树瀑布群里最宽的一个，水漫过整片钙化滩坝，平缓铺开，温柔得很。再往前是天星桥，那又是另一副面孔：水在石上走，树在石上长，一块块石头被水打磨成天然盆景，人称"风刀水剑刻就的万倾盆景"。

黄果树所在的这片土地，是典型的喀斯特地貌，地下暗河纵横，所以这里不止有18个地表瀑布，还有若干藏在山腹里的地下瀑布。1982年，它就与桂林、黄山一起，成为国务院公布的首批国家重点风景名胜区。

整个大景区走完大约需要半天到一天。出行前请核实各片区入园时段与观光车安排。祝各位在黄果树，看水，听水，也沾一身清润的水气。

**【讲解要点提示】**
- 必讲：瀑布高77.8米、宽101米；水帘洞134米、六个洞窗；徐霞客"捣珠崩玉，飞沫反涌"；18个瀑布组成的瀑布群；1982年首批国家重点风景名胜区
- 数据锚点：高77.8米；宽101米；水帘洞长134米；陡坡塘瀑顶宽105米；2007年评5A
- 常见误区：①黄果树瀑布在镇宁县境，但景区部分区域跨关岭县，讲解时不必细说行政区划；②"瀑布群"共18个瀑布，不是只有黄果树一个；③水帘洞是天然溶洞，不是人工开凿
- 互动/提问设计：请游客猜，中国能从"瀑布背后"看瀑布的大瀑布有几处？（引出黄果树水帘洞的唯一性）

### 2. 安顺市龙宫景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 贵州省安顺市西秀区龙宫镇 |
| 类型 | 地质地貌 · 水域湖泊 |
| 评定年份 | 2007 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**（约235字）

龙宫景区位于贵州省安顺市西秀区，距安顺市区约27公里，距黄果树大瀑布约30公里，是以喀斯特水溶洞、暗河、洞穴瀑布为主体的国家级风景名胜区，总面积约60平方公里。景区核心是一条全长约15公里的水溶洞，为中国已探明的最长水旱溶洞之一，洞内常年温度稳定、钟乳石形态多样，划分为多个洞厅，泛舟其间可观赏"龙王宫殿""水晶宫"等景段。洞口的龙门飞瀑由地下暗河涌出地表跌落而成，是中国最大的岩溶洞穴瀑布。景区还包含天池、龙宫观音洞、龙门、漩塘、田园风光等区块，集洞、瀑、湖、山、田于一体。1988年，龙宫被国务院公布为第二批国家重点风景名胜区；2007年，被评定为国家5A级旅游景区。当地有"吞石为洞，吐石为花，神宫赖水造"的形象概括。

**【导游词核心稿】**（约540字）

各位游客朋友们，大家好！欢迎来到安顺龙宫。如果说黄果树是"看水从天上来"，那龙宫就是"看水从山里去"。

龙宫的核心是一条水溶洞，全长约15公里。各位现在登上的船，要在这条地下暗河里穿行。请留意头顶和两侧：钟乳石从上往下长，石笋从下往上长，几万年、几十万年，它们才可能接在一起。洞内冬暖夏凉，常年温度稳定，所以当地人才说这儿是"天然空调"。

出洞之前，我们先看一样东西——龙门飞瀑。它可不是一般的瀑布，水是从溶洞里冲出来的：地下暗河蓄满了，从洞口的悬崖上一跃而下，形成中国最大的岩溶洞穴瀑布。各位站在这儿，能同时听见水声在洞里回响、看见水花在洞外飞溅，这种"洞中有瀑、瀑下有洞"的组合，在全国都不多见。

整个龙宫景区面积约60平方公里，除了水洞，还有天池、观音洞、漩塘和田园区。漩塘是个很有意思的地方——水塘里的水常年缓缓打转，一年四季不紧不慢地旋转，成因至今仍是地质学上津津乐道的话题。

安顺的喀斯特到底有多厉害？有人总结过一句话："吞石为洞，吐石为花，神宫赖水造。"水把石头溶成洞，又把溶解的矿物质重新沉淀成钟乳石花——一吞一吐之间，就有了眼前这座龙宫。1988年，龙宫被列入第二批国家重点风景名胜区；2007年，与黄果树同年被评为国家5A级旅游景区。

游览全程约3到4小时。出行前请核实时段与船票安排。祝各位在水洞里，做一次"地心漫游"。

**【讲解要点提示】**
- 必讲：水溶洞全长约15公里；龙门飞瀑为中国最大岩溶洞穴瀑布；漩塘旋转现象；"吞石为洞，吐石为花"的喀斯特成因概括
- 数据锚点：洞长15公里；景区面积约60平方公里；1988年国家级风景名胜区；2007年评5A
- 常见误区：①龙宫是水洞为主，不是旱洞，行程以乘船为核心；②龙门飞瀑是暗河出露形成的洞穴瀑布，不是地表河流瀑布；③龙宫与黄果树同属安顺但为两个独立景区，需分别购票
- 互动/提问设计：请游客观察钟乳石与石笋，猜一猜一根石笋长高1厘米大约需要多少年？（引出"几十年至上百年"的速率，强调保护）

### 3. 毕节市百里杜鹃景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 贵州省毕节市大方县、黔西市交界（百里杜鹃管理区） |
| 类型 | 山岳峰林 · 森林草原 · 民族风情 |
| 评定年份 | 2013 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**（约245字）

百里杜鹃景区位于贵州省毕节市，横跨大方县与黔西市交界地带，是国家级森林公园，也是世界上面积最大、种类最多、保存最完好的天然原始杜鹃花林带。花带呈东北—西南走向绵延50余公里，宽1至5公里，总面积约125.8平方公里。景区内分布有杜鹃花5个亚属、40余种，占世界杜鹃花属种类的较大比例，其中马缨杜鹃、露珠杜鹃、迷人杜鹃等为优势种，树龄百年以上的古老杜鹃植株随处可见，部分树龄测算逾千年。每年3月下旬至4月底为盛花期，漫山遍野次第开放，形成"地球彩带、世界花园"的景观。景区内聚居彝族、苗族等民族，保留有彝族"祭花神"、苗族跳花坡等民俗活动。2013年，百里杜鹃被评定为国家5A级旅游景区。

**【导游词核心稿】**（约540字）

各位游客朋友们，大家好！欢迎来到毕节百里杜鹃。今天我们来赴一场花开的约。

先说三个数字，请各位记住：花带绵延50余公里，宽1到5公里，总面积125.8平方公里。这不是哪个人种的花园，是天然长成的原始杜鹃林带——全世界范围内，这样规模、这样完整度的，找不到第二处。

第二个数字：这里生长着5个亚属、40多种杜鹃。全世界杜鹃花属大约900多种，百里杜鹃一地就集中了40多种，而且马缨杜鹃、露珠杜鹃、迷人杜鹃都是成片成林地长。更难得的是"老"——这里有大量百年以上的杜鹃古树，个别植株的树龄被测算到千年以上。各位看到那些粗壮扭曲的老桩，它们开花的时候，比人要高出一大截。

花期是每年3月下旬到4月底。因为海拔有落差，山脚开完山腰开，山腰开完山顶开，前后能接续一个多月。所以当地人说这里是"地球彩带"，一点不夸张。

这片花海也不只是风景。这里是彝族、苗族同胞世代居住的地方，相传彝族先民把杜鹃花视为神灵的化身，每年花开时节要举行"祭花神"的仪式，祈求风调雨顺；苗族则有"跳花坡"的传统聚会。花，是他们生活的一部分，不是摆在旁边的布景。

2013年，百里杜鹃被评为国家5A级旅游景区。请各位在栈道上游览、不攀折花枝、不踏入未开放区域——这些古树，一年只开这一季，我们留给下一位游客的，应该还是完整的春天。

游览全程约4到6小时。出行前请核实当年花期预报与开园安排。

**【讲解要点提示】**
- 必讲：花带绵延50余公里、总面积125.8平方公里；5个亚属40余种杜鹃；百年以上古树；3月下旬至4月底花期；彝族"祭花神"与苗族"跳花坡"民俗
- 数据锚点：125.8平方公里；40余种；2013年评5A；花期约一个多月
- 常见误区：①百里杜鹃是天然原始林带，不是人工种植的花海；②花期为3月下旬至4月底，非全年有花；③杜鹃花多数品种不可食用，切勿采食
- 互动/提问设计：请游客找一找，同一株杜鹃上是否同时有深浅不同的花色？（引出多品种共生与古树嫁接现象）

### 4. 黔南州荔波樟江景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2015年评定） |
| 所在地 | 贵州省黔南布依族苗族自治州荔波县 |
| 类型 | 水域湖泊 · 地质地貌 · 世界自然遗产 |
| 评定年份 | 2015 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**（约250字）

荔波樟江景区位于贵州省黔南布依族苗族自治州荔波县，是以喀斯特森林、河谷、湖泊、瀑布为主体的国家级风景名胜区，总面积约118平方公里，由小七孔、大七孔、水春河、樟江风光带等片区组成。景区是"中国南方喀斯特"世界自然遗产的组成部分——2007年6月，在第三十一届世界遗产大会上，荔波与云南石林、重庆武隆共同以"中国南方喀斯特"名义列入《世界遗产名录》，荔波以独特的锥状喀斯特与原始森林生态系统入选。核心景点小七孔古桥建于清道光十五年（1835年），桥长40米、宽2.2米、高5.5米，七孔横跨响水河；另有68级跌水瀑布、水上森林、卧龙潭、鸳鸯湖、拉雅瀑布，以及大七孔的风神洞、恐怖峡、天生桥等。2015年，荔波樟江景区被评定为国家5A级旅游景区。

**【导游词核心稿】**（约570字）

各位游客朋友们，大家好！欢迎来到黔南荔波。这里有一个响亮的名号——"地球腰带上的绿宝石"。

为什么这么说？地球上北纬25度这一圈，大部分地区是沙漠和干草原，唯独在中国贵州南部，还保存着一片郁郁葱葱的喀斯特原始森林。荔波，就是这片绿的核心。2007年6月，在第三十一届世界遗产大会上，荔波和云南石林、重庆武隆一起，以"中国南方喀斯特"的名义列入《世界遗产名录》。这是世界给这片山水盖的一个章。

我们从最有名的那座桥说起——小七孔桥。据史料记载，它建于清道光十五年，也就是1835年，桥长40米、宽2.2米、高5.5米，七个桥孔横跨在响水河上。近两百年了，藤蔓爬满了桥身，桥下的水绿得像一整块翡翠。它是当年黔南通往广西驿道上的一座重要石桥。

再往上走，各位会看到68级跌水瀑布——水在一公里多的河段里，一级一级往下跳，一共跳了68级。然后是水上森林：树直接长在河床的石头上，根扎进水里，水从根间流过，人踩着水中的石墩穿林而过，这在别处几乎看不到。

另一个不能错过的是卧龙潭和鸳鸯湖。鸳鸯湖是两片相通的湖，湖水深不见底，可以划船进去，两边是密不透风的原始林。大七孔那边则更险峻，天生桥、风神洞、恐怖峡，气势更足。

整个景区面积约118平方公里，2015年被评为国家5A级旅游景区。想看得从容些，建议安排一天到两天。出行前请核实各片区开放情况与观光车线路。祝各位在荔波，把"绿"这个词重新认识一遍。

**【讲解要点提示】**
- 必讲：2007年列入世界自然遗产"中国南方喀斯特"；小七孔桥建于1835年；68级跌水瀑布；水上森林；樟江景区总面积约118平方公里
- 数据锚点：桥长40米/宽2.2米/高5.5米；68级；1835年；2007年申遗成功；2015年评5A
- 常见误区：①"中国南方喀斯特"是一个系列遗产，荔波只是其一，不能说"荔波独享"；②小七孔与大七孔是两个相邻片区，不是同一个景点的大小版本；③水上森林路段湿滑，需按指定步道行走
- 互动/提问设计：请游客观察水为什么这么绿？（引出钙化沉积与藻类、水深对光的吸收，以及森林涵养水源的水质）

### 5. 贵阳市花溪青岩古镇景区

| 项目 | 内容 |

| 所在地 | 贵州省贵阳市花溪区青岩镇 |
| 类型 | 古城古镇 · 民族风情 |
| 评定年份 | 2017 |

织金洞位于贵州省毕节市织金县官寨苗族乡，是典型的喀斯特岩溶洞穴，已勘察长度约12.1公里，洞内总面积70余万平方米，洞腔最宽跨度175米，相对高差150米，一般宽高均在60至100米之间，洞内常年温度保持在16℃左右。洞内划分为多个大厅与厅堂，堆积物类型达40余种，涵盖石笋、石柱、石幔、石旗、石盾、卷曲石、边石坝等几乎全部的岩溶沉积形态，规模宏大、类型齐全，被誉为"岩溶博物馆"和"中国最美的旅游洞穴"之一。标志性景观包括"银雨树"（罕见的花瓣状石笋）、"霸王盔""倒挂琵琶""灵霄殿""广寒宫"等。织金洞2004年获批国家地质公园，2015年经联合国教科文组织批准加入世界地质公园网络。2022年7月，织金洞景区被评定为国家5A级旅游景区。民间素有"黄山归来不看岳，织金洞外无洞天"之说。

| 项目 | 内容 |

**【景区简介】**（约240字）

万峰林景区位于贵州省黔西南布依族苗族自治州兴义市，是中国锥状喀斯特峰林规模最大、发育最典型、保存最完整的区域之一，被称为"中国锥状喀斯特大型博物馆"。峰林东起坡岗、西至万峰湖，北起马岭河、南抵南盘江，连绵分布上万座锥状山峰，气势磅礴。景区平均海拔约1200米，气候温和湿润，夏无酷暑、冬无严寒，全年有300天以上适宜户外运动。峰林与山间的纳灰河、田园、布依族村寨相互交织，形成"峰林—田园—村落"共生的独特景观，其中下纳灰村、上纳灰村等布依古村保存完整，八卦田、将军峰、众星捧月等为标志性观景点。明代旅行家徐霞客曾游历至此，留下"天下山峰何其多，惟有此处峰成林"的著名赞叹。2024年12月，万峰林景区被文化和旅游部确定为国家5A级旅游景区，成为贵州第10家国家5A级旅游景区。

**【导游词核心稿】**（约550字）

各位游客朋友们，大家好！欢迎来到兴义万峰林。

请大家先站定，往远处看一眼——上万座锥形的山峰，一座挨着一座，从脚下一直铺到天边。这不是画，是真的。

明代大旅行家徐霞客走到这里，说了一句话，后来成了万峰林的定场诗："天下山峰何其多，惟有此处峰成林。"据史料记载，他是明崇祯年间到访此地的。天下山峰多得是，但像这里一样，成片成林、密密匝匝挤在一起的，他没见过第二处。所以后人把万峰林叫作"中国锥状喀斯特大型博物馆"——喀斯特有好几种长相，桂林是塔状，云南石林是剑状，兴义这种上尖下圆、像一堆倒扣的漏斗的，是典型的锥状。

这片峰林有多大？东起坡岗，西到万峰湖，北起马岭河，南抵南盘江，上万座山峰连绵不断。景区平均海拔约1200米，不高不低，夏无酷暑、冬无严寒，一年里300天以上适合在户外走一走。所以这儿也是国内有名的路跑胜地，有一条经中国田协认证的半程马拉松赛道，跑在峰林和田园之间。

但万峰林最动人的，不只是山，是山和人怎么相处。峰林脚下是纳灰河，河边是一片片稻田和油菜花，再往外是布依族世代居住的村寨——上纳灰、下纳灰。山、水、田、村，四样东西叠在一块儿，谁也没挤走谁。当地还有一块奇特的"八卦田"，田块天然围着落水洞一圈圈铺开，像一枚大地上的印章。

2024年12月，万峰林被文化和旅游部确定为国家5A级旅游景区，是贵州第10家。请各位在村寨里放轻脚步，尊重布依族乡亲的生活。游览约4到6小时，出行前请核实观光车与骑行线路。

- **4A名录为不完全收录**：本索引共98条，主要依据贵州省文化和旅游厅公开的A级景区名录整理，六盘水、毕节、黔西南、黔东南等市州近年新增、调整的4A景区可能未纳入，需以最新公告补充。
