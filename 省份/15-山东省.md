### 1. 泰安泰山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 泰安市泰山区（岱庙、红门、岱顶一带） |
| 类型 | 山岳峰林 · 宗教圣地 · 遗址考古 · 世界文化与自然双重遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

泰山位于山东省泰安市，绵亘于泰安、济南之间，景区总面积约426平方公里，主峰玉皇顶海拔1545米。泰山为"五岳之首"，自古被视为"直通帝座"的神山，据记载历代曾有13位帝王亲登泰山封禅祭祀，另有24位帝王遣官致祭72次，山体上自岱庙至玉皇顶形成完整的祭祀礼制空间，沿途存历代摩崖石刻1800余处。泰山兼具自然与人文价值，1987年被联合国教科文组织列入《世界遗产名录》，成为中国首批世界文化与自然双重遗产。核心景观有岱庙、红门宫、中天门、十八盘、南天门、碧霞祠、玉皇顶、日观峰等，岱庙主殿天贶殿建于北宋大中祥符二年（1009年），殿内壁画《泰山神启跸回銮图》长62米、高3.3米。2007年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到"五岳之首"——泰山。

先看三个数字。第一个，1545米。这是泰山主峰玉皇顶的海拔高度。在中国东部，泰山算不得最高，但它从华北平原上拔地而起，相对高差超过1300米，所以看上去格外雄伟，古人说"泰山之高，非一峰之高"，说的就是这个气势。

第二个，1987年。这一年，泰山被列入《世界遗产名录》，而且是"世界文化与自然双重遗产"——既要自然价值过硬，又要文化价值过硬，能同时拿到这两个身份的，全世界也没有几处。

第三个，1800余处。泰山从山脚到山顶，历代摩崖石刻有1800多处，从秦代李斯的小篆到近现代题刻，几乎是一部刻在石头上的中国书法史。稍后我们经过的路边，您随手一指，可能就是几百年前的字。

说到泰山，绕不开"封禅"。据史料记载，历史上先后有13位帝王亲自登泰山举行封禅或祭祀大典，另有24位帝王派官员前来致祭达72次。帝王为什么要来这里？因为在古人的观念里，泰山是离天最近的山，是"天命"的象征。山下的岱庙，就是历代帝王上山前斋戒、祭祀的场所，它的主殿天贶殿建于北宋大中祥符二年，也就是1009年，殿里那幅《泰山神启跸回銮图》壁画，长62米、高3.3米，是中国现存最长的古代壁画之一。

登泰山，最经典的一段是十八盘。它全长约800米，垂直高差400米，共有石阶1633级，是泰山最陡的一段。杜甫写"会当凌绝顶，一览众山小"，写的就是登顶那一刻的心境。

最后提醒：山上气温比山下低8到10摄氏度，台阶多、风大，请穿防滑鞋、带外套。祝大家登顶顺利，一路平安！

**【讲解要点提示】**
- 必讲：五岳之首、1987年世界文化与自然双重遗产、玉皇顶1545米、帝王封禅（13位亲登、24位遣官72次）、十八盘1633级。
- 数据锚点：1545米；426平方公里；1800余处石刻；1633级台阶；1009年天贶殿；62米壁画。
- 常见误区：①泰山在泰安市，主峰玉皇顶属泰山区，不要把"泰山"与"泰安市区"混为一谈；②"封禅"与"祭祀"是两种不同规格的典礼，讲解时需区分。
- 互动/提问设计：请游客沿路寻找最早的石刻年号；提问"为什么帝王要来泰山祭天"——引出古代山岳崇拜。

### 2. 烟台蓬莱阁-三仙山-八仙过海旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 烟台市蓬莱区 |
| 类型 | 宗教圣地 · 古典园林 · 主题乐园 |
| 评定年份 | 2007 |
| 建议游览时长 | 1 天 |

**【景区简介】**

该旅游区位于山东省烟台市蓬莱区，由蓬莱阁、三仙山、八仙过海三部分及蓬莱水城组成。蓬莱阁始建于北宋嘉祐六年（1061年），与黄鹤楼、岳阳楼、滕王阁并称中国古代四大名楼，阁下即明代抗倭水城——蓬莱水城（备倭城），为民族英雄戚继光操练水师之地；阁区另有天后宫、龙王宫、吕祖殿、弥陀寺等祠庙建筑，形成"阁祠一体"的古建筑群。三仙山与八仙过海为沿海新建的大型文化景区，以"三神山"仙境传说与八仙传说为主题，融仿古园林、海上观光于一体。蓬莱自古有"人间仙境"之称，"八仙过海，各显神通"的传说与海市蜃楼奇观均与此地相关。2007年评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客好！欢迎来到"人间仙境"蓬莱！

蓬莱为什么叫"仙境"？因为它有两样别处难求的东西：传说，和奇观。传说就是"八仙过海"——相传八位神仙从这里渡海，各施法术，于是留下了"八仙过海，各显神通"这句成语。奇观就是"海市蜃楼"，蓬莱海域是中国海市出现最频繁的地方之一，古人看见海面上忽然现出楼台城郭，以为那是仙人居所，于是有了"蓬莱、方丈、瀛洲"三神山的故事。

我们的第一站是蓬莱阁。它始建于北宋嘉祐六年，也就是1061年，与黄鹤楼、岳阳楼、滕王阁并称中国古代四大名楼。请大家注意，蓬莱阁不是单独一座楼，而是一组古建筑群：天后宫供海神妈祖，龙王宫祈风调雨顺，吕祖殿奉吕洞宾，还有弥陀寺、三清殿，儒释道三教共处一山，这正是蓬莱文化的特别之处。

第二站，请大家往下看——那就是蓬莱水城，也叫备倭城。它是明代为防倭寇而建的水军基地，有城墙、码头、炮台和船坞。明代抗倭名将戚继光（1528—1588）就是蓬莱人，他在这里操练水师。所以蓬莱既有仙气，也有骨气。

第三站是三仙山和八仙过海景区，二者为近年新建的文化旅游区，以仿古园林和海上景观再现"仙境"意象，适合拍照与亲子游览。

海边风大、日照强，请注意防晒保暖；乘船项目受天气影响，如遇风浪停航属正常调度。

**【讲解要点提示】**
- 必讲：蓬莱阁1061年始建、中国古代四大名楼、蓬莱水城与戚继光、八仙过海传说、海市蜃楼。
- 数据锚点：1061年；戚继光1528—1588；2007年评为5A。
- 常见误区：①蓬莱阁古建筑群与三仙山、八仙过海景区性质不同，前者为文物古建，后者为现代新建景区，讲解时应区分；②海市蜃楼属自然光学现象，不作"仙人显灵"解释。
- 互动/提问设计：请游客说出八仙的名字；提问"海市蜃楼是怎么形成的"。

### 3. 济宁曲阜明故城三孔旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 济宁市曲阜市 |
| 类型 | 陵寝祠庙 · 遗址考古 · 古城古镇 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 1 天 |

**【景区简介】**

明故城三孔旅游区位于山东省济宁市曲阜市，由孔庙、孔府、孔林三部分组成。孔庙始建于公元前478年（孔子卒后第二年），历代扩建，现存规模形成于明清，南北绵延1000余米，共九进院落，有殿宇堂庑466间，存汉魏以来碑刻1000余块，主殿大成殿为清代重建，前有10根深浮雕蟠龙石柱。孔府为孔子嫡裔"衍圣公"府第，前衙后宅，是延续时间最长的贵族府第之一。孔林为孔氏家族墓地，占地3000余亩，延续使用2400余年，古木参天、碑碣林立，是世界延时最久、规模最大的家族墓地。1994年，"三孔"作为文化遗产列入《世界遗产名录》。2007年评为国家5A级旅游景区，曲阜同时为国家历史文化名城。

**【导游词核心稿】**

各位朋友，大家好！我们现在所在的地方，是孔子的故里——曲阜。今天的行程是"三孔"：孔庙、孔府、孔林。

先说孔庙。它始建于公元前478年，也就是孔子去世后的第二年，鲁哀公把孔子的三间故居改为庙，"以岁时奉祀"。此后的两千多年里，它不断扩建，今天的规模形成于明清。请大家留意三个数字：九进院落，从棂星门一直排到最后；殿宇堂庑466间；汉魏以来的碑刻1000余块，所以孔庙也被称为中国第二大碑林。主殿大成殿前有10根深浮雕蟠龙石柱，龙身盘绕、鳞爪毕现，是全国石雕中的精品。

再说孔府。这是孔子嫡系后裔世代居住的府第，自宋代起，历代朝廷封其嫡裔为"衍圣公"。孔府的格局是"前衙后宅"——前面办公断事，后面居家生活，一座府第，就是一部家族与王朝相处两千年的故事。

最后说孔林。它是孔氏家族的墓地，占地3000多亩，从孔子葬于此地起，延续使用了2400多年，是世界上持续最久、规模最大的家族墓地。走进林中，古柏参天，碑碣林立，人立刻会安静下来。

1994年，孔庙、孔府、孔林被列入《世界遗产名录》。为什么能评为世界遗产？因为它承载了一种延续两千多年、影响整个东亚的思想传统。孔子生于公元前551年，卒于公元前479年，他身后这座城，至今仍在讲述他的话。

参观时请勿触摸碑刻与古建，孔林内请保持肃静。谢谢大家！

**【讲解要点提示】**
- 必讲：公元前478年立庙、九进院落466间、碑刻1000余块、孔府衍圣公、孔林2400余年、1994年世界文化遗产。
- 数据锚点：公元前478年；466间；1000余块碑刻；3000余亩；2400余年；1994年。
- 常见误区：①孔庙是祭祀孔子的庙宇，孔府是后裔府第，孔林是家族墓地，三者功能完全不同，不可混讲；②孔子生卒年（前551—前479）与"孔庙始建于前478年"相隔一年，讲解时须说明是卒后第二年。
- 互动/提问设计：请游客数一数大成殿前的龙柱；提问"为什么家族墓地能延续两千多年"。

### 4. 青岛崂山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 青岛市崂山区 |
| 类型 | 山岳峰林 · 宗教圣地 |
| 评定年份 | 2011 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

崂山景区位于山东省青岛市崂山区，濒临黄海，主峰巨峰（崂顶）海拔1132.7米，是中国大陆海岸线上最高的山峰，故有"海上第一名山"之称。崂山为花岗岩山体，经长期风化形成巨石堆叠的地貌，分巨峰、太清、仰口、北九水、华楼等游览区，其中北九水以"九水十八潭"的溪潭景观著称。崂山是中国道教重要发祥地之一，太清宫据记载始建于西汉建元元年（公元前140年），为全真派重镇，历史上曾有"九宫八观七十二庵"之说，宫内古木参天，存有银杏、汉柏等古树。蒲松龄《聊斋志异》中的《崂山道士》《香玉》即以太清宫一带为背景。崂山矿泉水久负盛名。2011年评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，欢迎来到"海上第一名山"——崂山！

崂山有两个"第一"。第一个，主峰巨峰海拔1132.7米，是中国大陆海岸线上的最高峰。山就在海边拔起，站在山顶看海，海天一色，这种"山海相连"的气势，在中国的名山里独一份。第二个，崂山是中国道教的重要发祥地之一，历史上曾有"九宫八观七十二庵"的说法，道观之多，可见当年香火之盛。

我们的核心一站是太清宫。据记载，它始建于西汉建元元年，也就是公元前140年，至今已有两千一百多年，是崂山历史最久、规模最大的道观。宫内古木成荫，有银杏、汉柏等古树，其中树龄千年以上的并不少见。大家在三官殿、三清殿前稍作停留，看看那些被岁月磨光的石阶——它们才是真正的"老道长"。

再说一段文学。清代蒲松龄写《聊斋志异》，其中《崂山道士》讲的是一个想学法术又不肯吃苦的书生，穿墙术没学成，撞了一头包；另一篇《香玉》，写的就是太清宫里的牡丹花仙。相传蒲松龄曾在此寓居读书，院中那株牡丹，至今仍被游客惦记。

最后一个看点，是北九水。白沙河上游九折成潭，有"九水十八潭"之说，溪水在巨石间跌宕，夏天尤其清凉，是崂山最秀气的一面。

崂山各游览区相距较远，请按既定线路走，不要擅自翻越未开放区域；山区天气多变，注意防滑防雨。

**【讲解要点提示】**
- 必讲：巨峰1132.7米（中国大陆海岸线最高峰）、太清宫（据记载公元前140年始建）、全真派重镇、北九水十八潭、蒲松龄《崂山道士》。
- 数据锚点：1132.7米；公元前140年；九宫八观七十二庵；九水十八潭；2011年评为5A。
- 常见误区：①崂山景区分为多个独立游览区，一次行程通常只能选择一至两个，须提前规划；②太清宫始建年代为文献记载，现存建筑多为后代重修，讲解时用"据记载"。
- 互动/提问设计：请游客找出院内最粗的古树；提问"崂山为什么被称为海上第一名山"。

### 5. 威海刘公岛景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 威海市环翠区 |
| 类型 | 遗址考古 · 博物馆场馆 · 水域湖泊 |
| 评定年份 | 2011 |
| 建议游览时长 | 1 天 |

**【景区简介】**

刘公岛景区位于山东省威海市环翠区威海湾口，岛东西长约4公里，面积3.15平方公里，海岸线长约15公里。刘公岛是北洋海军的诞生地与甲午战争终战地：1888年，北洋海军在此正式成军，岛上建有提督署、水师学堂、炮台等海防设施；1895年2月，中日甲午战争威海卫之战在此结束，北洋舰队全军覆没，提督丁汝昌殉国。岛上现建有中国甲午战争博物院，保存提督署、丁汝昌寓所、水师学堂等旧址，为全国重点文物保护单位。同时，刘公岛为国家森林公园，森林覆盖率约87%，海岛生态与植被良好。2011年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，现在我们乘船前往的，是威海湾口的一座小岛——刘公岛。它只有3.15平方公里，却承载了中国近代史上最沉重的一页。

先说它的"身份"。1888年，清朝的北洋海军在这里正式成军，岛上是它的基地：有提督署，也就是舰队司令部；有水师学堂，培养海军军官；还有炮台、码头、船坞。当年这里军容齐整，是亚洲最受瞩目的一支舰队。

再说它的"结局"。1894年爆发中日甲午战争，1895年1月，日军在荣成登陆，从陆上包抄威海卫；2月，刘公岛被围，北洋舰队腹背受敌，最终全军覆没。提督丁汝昌拒绝投降，在岛上以身殉国。一座岛，从成军到覆没，前后不过七年。这段历史，是我们民族记忆里最痛的一课，也是后来无数人反思自强的起点。

今天岛上有中国甲午战争博物院，完整保留了提督署、丁汝昌寓所等旧址，均为全国重点文物保护单位。请大家在旧址里慢一点走，看一看当年官兵用过的器物，想一想那个年代的抉择。

刘公岛不只有沉重。它同时是国家森林公园，森林覆盖率约87%，岛上林深路静，海边礁石嶙峋，登岛后沿着山路走一圈，海风与松涛是最好的舒缓。

乘船往返请注意听候船班时间；岛上旧址内禁止触摸文物，请保持肃静。谢谢！

**【讲解要点提示】**
- 必讲：1888年北洋海军成军、1895年威海卫之战与北洋舰队覆没、丁汝昌殉国、中国甲午战争博物院与提督署旧址、国家森林公园。
- 数据锚点：3.15平方公里；1888年；1895年2月；森林覆盖率约87%；2011年评为5A。
- 常见误区：①刘公岛战役属甲午战争末期威海卫之战，与黄海海战（1894年9月）不是同一战役，讲解时须区分；②岛上旧址为文物本体，不是复原陈列。
- 互动/提问设计：提问"为什么舰队基地建在岛上"——引出军港选址逻辑；请游客观察炮台与海面的高差关系。

### 6. 烟台龙口南山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 烟台市龙口市 |
| 类型 | 宗教圣地 · 主题乐园 · 古典园林 |
| 评定年份 | 2011 |
| 建议游览时长 | 1 天 |

**【景区简介】**

南山景区位于山东省烟台市龙口市，由南山宗教文化园、中华历史文化园与东海旅游度假区等片区组成，是一处大型文化旅游综合体。宗教文化园以南山大佛为核心，大佛为锡青铜铸造的释迦牟尼坐像，通高38.66米、重约380吨，2004年落成开光；区内还有南山禅寺、玉佛殿、华严世界、南山道院等建筑群，佛道并存为其特色。中华历史文化园按远古、殷商、春秋战国、秦汉、唐宋、明清等历史序列布置仿古园区与展馆，集中展示中华历史文化脉络，具有较强的研学功能。东海旅游度假区依黄海而建，拥有较长海岸线与海滨休闲设施。景区由南山集团投资建设，是村办企业发展旅游业的典型案例。2011年评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客好！欢迎来到龙口南山景区。南山和我们平时爬的山不太一样——它是一座"人造景观与宗教文化相结合"的大型文化园区。

第一看点，是南山大佛。这是一尊锡青铜铸造的释迦牟尼坐像，通高38.66米，重约380吨，2004年落成开光。请您站在佛座下往上看，佛的手掌、衣纹都铸得非常细腻；围绕佛座的是一圈回廊，可以近距离观察铸造工艺。大佛所在的宗教文化园里，还有南山禅寺、玉佛殿、华严世界，以及一座南山道院——佛、道两教的建筑共处一园，这在同类景区里比较少见。

第二看点，是中华历史文化园。它按照历史朝代的顺序，把远古、殷商、春秋战国、秦汉、唐宋、明清串成一条"时间轴"，每到一个朝代就有一组对应的建筑与展陈。带孩子来的家长，这一片很值得细看，基本上就是把中国通史走了一遍。

第三看点，是东海旅游度假区。从山区出来往海边走，是另一番景象：长长的海岸线、沙滩与海滨设施，适合散步、看海。山海同游，是南山行程的一大优势。

最后补充一句背景：南山景区是由龙口南山集团投资兴建的，从村办企业发展而来，这也是山东乡镇经济的一个著名样本。

园区面积大，建议乘坐景区交通车；宗教场所请保持安静，未经许可不要拍摄佛像与法事。祝大家游得顺心！

**【讲解要点提示】**
- 必讲：南山大佛38.66米/约380吨/2004年开光、宗教文化园佛道并存、中华历史文化园朝代序列、东海度假区海滨。
- 数据锚点：38.66米；380吨；2004年；2011年评为5A。
- 常见误区：①南山景区是现代兴建的宗教文化园区，不是千年古刹，讲解时应如实说明建造年代；②宗教文化园与中华历史文化园、东海度假区相距较远，需乘车转场。
- 互动/提问设计：请游客估算大佛高度相当于几层楼；提问"为什么一个村办企业能建起5A景区"。

### 7. 枣庄台儿庄古城景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 枣庄市台儿庄区 |
| 类型 | 古城古镇 · 红色旅游 |
| 评定年份 | 2013 |
| 建议游览时长 | 1 天（夜游更佳） |

**【景区简介】**

台儿庄古城景区位于山东省枣庄市台儿庄区京杭大运河畔，古城因运河而兴，明清时期为南北漕运重镇，曾有"天下第一庄"之称，1938年3月至4月的台儿庄战役中城池基本毁于战火。2008年，枣庄市启动台儿庄古城重建，2010年5月建成开放，重建以历史资料、老照片与考古遗存为依据，恢复明清风貌的街巷、码头、庙宇与会馆建筑。古城保留并利用京杭大运河古河道与古码头，被称作"活着的运河"，现有参将署、天后宫、船形街、万家大院等建筑，以及台儿庄大战纪念馆等纪念设施。台儿庄战役是抗日战争初期中国正面战场的重大胜利，歼敌一万余人。2013年评为国家5A级旅游景区。

**【导游词核心稿】**

朋友们好！欢迎来到"天下第一庄"——台儿庄古城。

这座城有两段历史，一段是"兴"，一段是"毁"。先说"兴"。台儿庄之所以能成为大镇，靠的是一条河——京杭大运河。明清时期，南来北往的漕船从这里经过，商贾云集、会馆林立，最盛时有"天下第一庄"的说法。今天我们在古城里看到的参将署、天后宫、万家大院、船形街，都是当年商埠繁华的见证。特别是那些古码头和仍在通航的古河道，被称为"活着的运河"——大运河沿岸能完整保留古码头的城市，已经非常少了。

再说"毁"。1938年3月下旬到4月上旬，台儿庄爆发了一场极其惨烈的战役。中国军队在这里与日军逐街逐屋争夺，最终取得抗战初期正面战场的一次重大胜利，歼敌一万余人。代价是，这座千年古城基本化为焦土。

所以就有了第三段历史："重生"。2008年，枣庄市决定重建台儿庄古城，依据历史照片、地方文献和考古发现，按明清风貌复建；2010年5月，古城重新开门迎客。今天我们脚下的青石板、两边的店铺，是新的，但城市的格局、运河的走向、老字号的名号，都是旧的。

建议大家留到晚上。夜晚的台儿庄，灯笼映在水面上，船妹子摇着橹唱着歌，是最出片的时候。另外，请安排时间到台儿庄大战纪念馆看一看，那是这座城不能跳过的一页。

**【讲解要点提示】**
- 必讲：京杭大运河与"活着的运河"、1938年台儿庄战役（歼敌一万余人）、2008年重建与2010年开放、参将署/天后宫/船形街。
- 数据锚点：1938年3—4月；一万余人；2008年；2010年5月；2013年评为5A。
- 常见误区：①现存古城为2008年之后依史料重建，讲解时须说明"重建"而非"原样保存"；②台儿庄战役的历史遗址纪念设施与古城游览区是两个相邻但独立的空间。
- 互动/提问设计：提问"为什么大运河边的城市容易繁荣"；请游客在船形街观察街道平面形状。

### 8. 济南天下第一泉景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 济南市历下区、天桥区 |
| 类型 | 水域湖泊 · 古典园林 · 城市地标 |
| 评定年份 | 2013 |
| 建议游览时长 | 1 天 |

**【景区简介】**

天下第一泉景区位于山东省济南市，由趵突泉、大明湖、五龙潭、黑虎泉四大泉群及环城公园组成，是"泉城"济南的核心载体。趵突泉名列济南七十二名泉之首，其名最早见于《春秋》所载之"泺"，泉眼三股并涌，清代乾隆帝南巡时曾御封其为"天下第一泉"；泉畔有泺源堂、观澜亭、李清照纪念堂与万竹园。大明湖由众泉汇流而成，水面约46公顷，以"四面荷花三面柳，一城山色半城湖"著称，湖畔有历下亭、铁公祠、南丰祠等。黑虎泉水自三个石雕虎头喷涌而出，水量在济南众泉中位居前列；五龙潭相传为唐代名将秦琼故宅所在。2013年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到"家家泉水，户户垂杨"的泉城济南！今天我们看的，是济南泉水的精华——天下第一泉景区。

第一站，趵突泉。它的名字很古老，《春秋》里记载的"泺"，指的就是这一带。请大家凑近水池：三股水从池底同时上涌，水涌如轮，声若隐雷。清代乾隆皇帝南巡到这里，据说尝了泉水后御封它为"天下第一泉"，从此这个名字就叫开了。泉边有泺源堂、观澜亭，还有李清照纪念堂——李清照是宋代女词人，她的故里就在济南章丘一带，"知否，知否，应是绿肥红瘦"，很多人都会背。

第二站，大明湖。它由城里的泉水汇流而成，水面约46公顷。夏天来最好，正应了那副名联："四面荷花三面柳，一城山色半城湖"，这是清代刘凤诰咏大明湖的句子，写尽了济南的城湖关系。湖中有历下亭，杜甫当年在此写下"海右此亭古，济南名士多"。

第三站，黑虎泉和五龙潭。黑虎泉的水从三个石雕虎头口中喷出，水量很大，很多济南人每天提着桶来这里打水，这是这座城市最日常的画面。五龙潭则相传是唐代名将秦琼的故宅所在，潭水碧深，泉群密布。

济南有"七十二名泉"之说，我们今天看的这四处是全城的代表。泉边地面湿滑，请照看好老人和孩子；泉水是景观水，请勿取饮。祝大家在泉城玩得清爽！

**【讲解要点提示】**
- 必讲：趵突泉"天下第一泉"（乾隆御封）、《春秋》所载"泺"、大明湖水面约46公顷与名联、黑虎泉虎头喷涌、七十二名泉。
- 数据锚点：约46公顷；七十二名泉；2013年评为5A；李清照（宋代）。
- 常见误区：①"天下第一泉景区"是四大泉群的总称，单独的趵突泉公园只是其中一部分，行程安排上容易只走一处；②泉水虽清澈但不宜直接饮用，须提醒游客。
- 互动/提问设计：请游客找一找池底三股水的位置；提问"为什么济南会有这么多泉"——引出岩溶地下水与南高北低的地形。

### 9. 沂蒙山旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 潍坊市临朐县（沂山）、临沂市平邑县与蒙阴县（龟蒙、云蒙） |
| 类型 | 山岳峰林 · 森林草原 · 宗教圣地 · 红色旅游 |
| 评定年份 | 2013 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

沂蒙山旅游区跨山东省潍坊市临朐县（沂山）与临沂市平邑县、蒙阴县（蒙山龟蒙、云蒙），是沂蒙山世界地质公园的核心区。沂山为中国古代五大镇山之"东镇"，主峰玉皇顶海拔1032米，山中百丈崖瀑布落差较大，东镇庙为历代祭祀沂山之神的庙宇，存有历代碑碣。蒙山主峰龟蒙顶海拔1156米，为山东省第二高峰，森林覆盖率达95%以上，空气负氧离子含量高，山体有巨型长寿文化石雕与鹰窝峰、群龟探海等花岗岩景观；云蒙景区以"中国瀑布"三叠瀑闻名。沂蒙山区是著名革命老区，孟良崮战役等史迹分布于周边。2019年，沂蒙山被列入联合国教科文组织世界地质公园。2013年评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，欢迎来到沂蒙山！这是一座横跨两市三县的大山，我们的行程分"两座山"：临朐的沂山，和临沂的蒙山。

先说沂山。它的头衔很特别——中国古代有"五镇"之说，沂山是"东镇"，而且是五镇之首。古人认为名山大川各有其神，历代朝廷都要遣官致祭，沂山脚下的东镇庙就是为此而建，庙里至今还存着历代碑碣。沂山主峰玉皇顶海拔1032米，山中有百丈崖瀑布，水从高处跌下，气势很足。

再说蒙山。它是沂蒙山的主脉所在，主峰龟蒙顶海拔1156米，是山东省的第二高峰——第一高峰当然是泰山。蒙山最大的宝贝是森林，森林覆盖率达95%以上，山里空气清新，负氧离子含量很高，很多人说"进山就像洗肺"。山上有鹰窝峰、群龟探海等花岗岩景观，还有一处巨型长寿文化石雕，是蒙山"长寿文化"的标志。云蒙景区的"中国瀑布"是三叠跌落，落差大、水量足，在北方山区比较少见。

还有一层身份不能忘：沂蒙山区是著名的革命老区。1947年5月，华东野战军在蒙阴孟良崮一带取得孟良崮战役的胜利，这场战役就发生在这片山区。

2019年，沂蒙山被列入联合国教科文组织世界地质公园名录，地质遗迹与生态价值得到了国际认可。

沂山与蒙山相距较远，建议分两天安排；山区台阶多，请穿登山鞋。祝大家登得高、看得远！

**【讲解要点提示】**
- 必讲：沂山"五镇之首"与东镇庙、玉皇顶1032米、蒙山龟蒙顶1156米（山东第二高峰）、森林覆盖率95%以上、2019年世界地质公园、沂蒙革命老区。
- 数据锚点：1032米；1156米；95%以上；2019年；2013年评为5A。
- 常见误区：①"沂蒙山旅游区"含沂山、龟蒙、云蒙三个彼此分散的片区，分属潍坊与临沂，不要当作一座连续的山；②孟良崮战役纪念地在蒙阴，属周边景点，不在5A景区核心游览线路内。
- 互动/提问设计：提问"五岳和五镇有什么区别"；请游客比较沂山与蒙山的植被差异。

### 10. 潍坊青州古城景区

| 项目 | 内容 |

| 等级 | 5A（2017年评定） |
| 所在地 | 潍坊市青州市 |
| 类型 | 古城古镇 · 博物馆场馆 · 宗教圣地 |

| 建议游览时长 | 1 天 |

**【景区简介】**

青州古城景区位于山东省潍坊市青州市老城区，青州为《尚书·禹贡》所载"九州"之一，是国家历史文化名城。古城片区保留明清街巷格局与阜财门城楼，内有偶园（明代衡王府东花园，清代大学士冯溥改筑，以"福、寿、康、宁"四奇石闻名）、真教寺、天主教堂、基督教堂等多元宗教建筑与大量传统民居。青州博物馆为国家一级博物馆，馆藏1996年龙兴寺遗址窖藏出土的佛教造像400余尊（该发现入选当年全国十大考古新发现之一），并藏有明代赵秉忠状元卷（万历二十六年，1598年）等珍贵文物。城外还有云门山摩崖大"寿"字（高7.5米、宽3.7米）与驼山石窟。2017年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到青州。请先记住一句话："海岱惟青州"——《尚书·禹贡》里把天下分为九州，青州是其中之一，它的名字已经叫了两千多年。今天的青州古城，是一座活着的明清老城。

第一看"城"。我们从阜财门进城，脚下是青石板，两边是保存下来的街巷与老铺面。青州最难得的是，它不是一座"空城"，城里还住着人，还有日常。街边的老字号、非遗铺子，都是活的。

第二看"园"。城里有座偶园，原本是明代衡王府的东花园，清代大学士冯溥买下后加以改造，取名"偶园"。园中"福、寿、康、宁"四块奇石最有名，形态各异，是北方园林叠石的代表。北方园林讲大气，南方园林讲精巧，偶园恰好在两者之间。

第三看"寺"与"馆"。青州城里有真教寺，也有天主教堂和基督教堂，几座不同信仰的建筑相距不远，这在古城里很少见，也说明青州历史上就是一座开放的城市。更要看的是青州博物馆——它是国家一级博物馆。1996年，龙兴寺遗址窖藏一次出土了400多尊佛教造像，造型精美、不少还保留着彩绘贴金，这个发现入选当年全国十大考古新发现之一。馆里还藏着明代赵秉忠的状元卷，是万历二十六年（1598年）的殿试答卷，也是目前存世极少的明代状元卷实物。

如果时间充裕，城外的云门山值得一看，崖壁上那个巨大的"寿"字，高7.5米、宽3.7米，当地人说"人无寸高"。

古城街巷窄、游客多，请跟紧队伍；博物馆内请勿使用闪光灯。

**【讲解要点提示】**
- 必讲：《禹贡》九州之一、阜财门与明清街巷、偶园"福寿康宁"四奇石、龙兴寺窖藏400余尊造像、赵秉忠状元卷（1598年）、云门山"寿"字。
- 数据锚点：400余尊；1996年全国十大考古新发现；1598年；7.5米×3.7米；2017年评为5A。
- 常见误区：①青州古城景区与青州博物馆、云门山等周边景点为相邻关系，行程时间须合理分配；②龙兴寺造像出自遗址窖藏，不是石窟造像。
- 互动/提问设计：请游客在偶园里找出四块奇石；提问"九州指的是哪九个州"——引出《禹贡》地理观。

### 11. 威海华夏城景区

**【景区简介】**

华夏城景区位于山东省威海市环翠区，是在长期采石留下的废弃矿坑与破损山体上实施生态修复后建成的文化旅游区，被视为国内矿山生态修复与旅游再利用的典型案例之一。景区以展示华夏历史文化为主线，建有华夏第一牌楼、夏园、圣水观音音乐喷泉广场、太平禅寺等仿古建筑与景观，并配套大型实景演艺项目。区内破损山体经覆土绿化后植被恢复，水域与瀑布景观串联成线，形成山水与人文相融的游览空间，兼具观光、演艺与休闲功能。2017年评为国家5A级旅游景区。

各位游客好！欢迎来到威海华夏城。这里有一个很不寻常的"前世"——在建成景区之前，它是一片采石场留下的废弃矿坑。

请大家留意山体的轮廓。当年这里长期开山采石，留下了一道道裸露的崖壁和深坑，植被几乎被毁。后来，投资方一边覆土、植树、蓄水，一边在修复后的地形上建景区，把破碎的山体重新连成一个整体。所以今天我们看到的湖、瀑布和成片的林子，其实是生态修复的成果。在山东，把一个废弃矿区改造成国家5A级景区，华夏城是很典型的一例，这也是它最值得讲解的价值：旅游不一定只靠"老天爷"和"老祖宗"，也可以靠修复与再造。

看完了"绿"，再看"文"。景区以华夏历史文化为主线，一进门就是高大的华夏第一牌楼，仿古形制，气势很足；再往里是夏园、圣水观音音乐喷泉广场和太平禅寺等。这些建筑不是文物，而是按中国传统的建筑语言新建的文化景观，把它们连起来，就是一条"从上古到明清"的华夏文化长卷。

最后提醒：景区面积大、坡度多，建议乘坐园内交通车；演艺项目场次随季节调整，出行前请核实当日安排。

**【讲解要点提示】**
- 必讲：废弃采石矿坑生态修复的"前世今生"、华夏第一牌楼、夏园、圣水观音、实景演艺。
- 数据锚点：2017年评为5A；生态修复后建成；景区为大型文化综合体。
- 常见误区：①此处建筑为现代新建的文化景观，不是文物古建，讲解时须明确区分；②实景演艺为季节性、场次性项目，行程安排需预留。
- 互动/提问设计：请游客观察崖壁上植被恢复的痕迹；提问"废弃矿坑还能用来做什么"。

### 12. 东营黄河口生态旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2019年评定） |
| 所在地 | 东营市垦利区 |
| 类型 | 水域湖泊 · 地质地貌 · 森林草原 |
| 评定年份 | 2019 |
| 建议游览时长 | 1 天 |

**【景区简介】**

黄河口生态旅游区位于山东省东营市垦利区黄河入海口，依托山东黄河三角洲国家级自然保护区（1992年建立）建设，是中国暖温带保存最完整、最年轻的湿地生态系统之一。黄河每年在此携带大量泥沙入海淤积造陆，形成"河海交汇"的黄蓝分明景观与广袤的芦苇沼泽；秋季盐地碱蓬连片变红，形成"红地毯"奇观。保护区是东北亚内陆和环西太平洋鸟类迁徙的重要中转站、越冬地与繁殖地，已记录鸟类约370种，其中国家一级保护鸟类有丹顶鹤、东方白鹳、黑鹳等，东营被称为"中国东方白鹳之乡"。区内建有远望楼、鸟类博物馆与湿地木栈道等设施。2019年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到黄河入海的地方——黄河口！

我们脚下这片土地，是全中国最"年轻"的土地之一。为什么？因为黄河每年携带大量泥沙从这里入海，泥沙沉积，海岸线不断向海里推进，新的陆地一年一年长出来。可以说，我们站的地方，几十年前可能还是一片海水。这就是黄河三角洲"生长中"的湿地。

第一看"黄蓝交汇"。在入海口，浑黄的河水与湛蓝的海水相遇，因为密度和流速不同，会形成一条清晰的分界线，黄蓝两色互不混淆，被称为"黄龙入海"。这个景象受潮汐、水量和天气影响很大，能不能看到，一半靠运气。

第二看"红地毯"。秋天，滩涂上的盐地碱蓬会整片变红，从近到远铺开，像给大地铺了一层红地毯，这是黄河口最出名的季节景观。

第三看"鸟"。这里是东北亚鸟类迁徙通道上的重要驿站，已记录鸟类约370种，其中丹顶鹤、东方白鹳、黑鹳等国家一级保护鸟类都在这里出现。东方白鹳尤其值得一提，东营被称为"中国东方白鹳之乡"，每年都有大批东方白鹳在这里筑巢繁殖。带上望远镜，运气好能看到它们在塔架上育雏。

参观时请全程走在栈道上，不要下滩、不要惊扰鸟类；保护区是鸟类栖息地，禁飞无人机。祝大家收获一次"与鸟相遇"的旅程！

**【讲解要点提示】**
- 必讲：黄河入海口与泥沙造陆、"河海交汇"黄蓝分明、秋季盐地碱蓬"红地毯"、约370种鸟类与东方白鹳、1992年国家级自然保护区。
- 数据锚点：约370种鸟类；1992年建立保护区；2019年评为5A。
- 常见误区：①"河海交汇"并非每天可见，受潮汐与水量影响，须提前说明，避免游客误解；②鸟类观赏以不干扰为原则，禁止下滩、追逐与无人机拍摄。
- 互动/提问设计：提问"黄河的水为什么是黄的"；请游客用望远镜数一数远处有多少只水鸟。

**【景区简介】**

该旅游区位于山东省临沂市沂水县，由萤火虫水洞与山东地下大峡谷两大片区组成，沂水县因此被誉为"中国溶洞之乡"。山东地下大峡谷为喀斯特溶洞，全长约6100米，为江北规模较大的溶洞之一，洞内钟乳石、石笋、石幔发育典型，并有一条地下暗河，辟有暗河漂流项目，洞内常年温度较低、湿度较高。萤火虫水洞是一处罕见的萤火虫栖息洞穴，洞内终年黑暗湿润，栖息着大量萤火虫，形成"地下荧光湖"景观，配套有蝴蝶谷、南国风情园等游览区。景区兼具地质研学与生态观光功能，是沂蒙山地区喀斯特地貌的代表性景区。2020年评为国家5A级旅游景区。

各位游客，欢迎来到沂水！我们今天要"下地"——看两个洞：地下大峡谷，和萤火虫水洞。

先说地下大峡谷。它是一条喀斯特溶洞，全长约6100米，在江北的溶洞里属于规模很大的一类。进洞之后，您会看到钟乳石从顶上垂下来，石笋从地上长上去，两者相接就是石柱；洞壁上还有石幔、石花，像凝固的瀑布。这里还有一条地下暗河，景区辟出了暗河漂流，坐上皮艇在幽深的洞中顺流而下，头顶是钟乳，两侧是岩壁，是很特别的体验。洞里常年十几摄氏度，夏天进去清凉，但请注意保暖，地面湿滑要慢走。

再说萤火虫水洞，这是全国少见的一处景观。走进洞中，工作人员会请大家安静、关掉光源。等眼睛适应了黑暗，您会看到岩壁上、头顶上，星星点点的绿光——那是成千上万只萤火虫。它们对环境要求极高，必须黑暗、湿润、无污染，所以这处洞穴能保存萤火虫种群，本身就是生态良好的证明。请大家全程不要拍照闪光、不要大声说话，也不要试图捕捉。

景区还配套蝴蝶谷和南国风情园，适合带孩子一起走。

两个洞之间需要换乘，请留足时间；溶洞内台阶多、光线暗，老人和小孩请注意搀扶。祝大家有一次特别的"地下之旅"！

**【讲解要点提示】**
- 必讲：地下大峡谷约6100米与钟乳石景观、地下暗河漂流、萤火虫水洞的生态条件与"地下荧光湖"、蝴蝶谷。
- 数据锚点：约6100米；2020年评为5A；洞内常年低温。
- 常见误区：①萤火虫水洞严禁闪光拍摄与大声喧哗，这是保护种群的硬要求，须反复提醒游客；②山东地下大峡谷与萤火虫水洞是两个分离的片区，需乘车转场。
- 互动/提问设计：提问"钟乳石一百年能长多少"——引出"百年长一厘米"的常识；请游客观察石笋与石钟乳的区别。

**【景区简介】**

微山湖旅游区位于山东省济宁市微山县，以南四湖为核心。南四湖由微山湖、昭阳湖、独山湖、南阳湖相连组成，总面积约1266平方公里，是中国北方最大的淡水湖群，京杭大运河穿湖而过，湖中微山岛上有殷微子墓、汉代张良墓等古迹，南阳古镇为运河沿岸古村镇。湖区夏季荷花连片，湿地生态良好，是南水北调东线工程的重要调蓄湖泊与湿地保护区。抗战时期，铁道游击队以微山湖与津浦铁路为战场开展游击战，其事迹经小说《铁道游击队》（1954年出版）与歌曲《弹起我心爱的土琵琶》广为流传。2022年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到微山湖！先记一个数字：1266平方公里。这是南四湖——微山湖、昭阳湖、独山湖、南阳湖——加在一起的总面积，它是中国北方最大的淡水湖群。

第一个看点，是"湖与河"。京杭大运河从湖中穿过，这在北方是很少见的景象：一条人工的长河，与一片天然的湖泊并行共处。湖里的南阳古镇，就是因运河而生的老镇，青石街、老码头，还保留着水乡的生活方式。今天的南四湖同时也是南水北调东线工程的重要调蓄湖，北方的水，有一部分就是从这里向北送的。

第二个看点，是"岛"。我们乘船去微山岛。岛上有两座古墓特别值得一提：一座是殷微子墓。微子是商纣王的兄长，周初受封于宋，被尊为宋国始祖，他的墓在这里，说明这片土地的文化脉络可以上溯到三千多年前。另一座是汉代张良墓——张良是辅佐刘邦建立汉朝的谋臣，"运筹帷幄之中，决胜千里之外"说的就是他。

第三个看点，是"红色的湖"。抗战时期，有一支队伍在津浦铁路和微山湖之间神出鬼没，扒火车、夺物资、护送干部过湖，这就是赫赫有名的铁道游击队。小说《铁道游击队》和那首歌大家一定听过——"西边的太阳快要落山了，微山湖上静悄悄"，唱的就是这里。

夏天来最好，湖上荷花连片，可以坐船穿行花间。乘船请穿好救生衣，荷塘深处不要擅自下船。祝大家"荷"气满满！

**【讲解要点提示】**
- 必讲：南四湖四湖相连、约1266平方公里、京杭大运河穿湖、微山岛殷微子墓与张良墓、铁道游击队与《弹起我心爱的土琵琶》。
- 数据锚点：约1266平方公里；1954年小说出版；2022年评为5A。
- 常见误区：①"微山湖"是南四湖中最大的一湖，日常也常被用作南四湖的统称，讲解时须说明二者关系；②铁道游击队活动范围横跨湖区与铁路线，纪念设施分布在微山岛及周边。
- 互动/提问设计：请游客合唱《弹起我心爱的土琵琶》；提问"南四湖是哪四个湖"。

**【景区简介】**

该旅游区位于山东省青岛市市南区，由青岛奥帆中心与青岛海底世界（含水族馆、海产博物馆）等片区组成。奥帆中心为2008年北京奥运会帆船比赛与残奥帆赛的举办场地，建有奥帆博物馆、旗阵广场、情人坝、奥运火炬等设施，是青岛海上运动与滨海休闲的标志性空间，也是市民与游客看海、看帆的公共岸线。青岛水族馆始建于1932年，是中国第一座由中国人自行设计建造的水族馆，由蔡元培等学界人士倡议筹建，其后发展为集海洋生物标本收藏、海洋科普与现代水族展示于一体的海洋主题场馆。2024年评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，欢迎来到青岛奥帆海洋文化旅游区！这里有两张面孔：一张是"现代青岛"，一张是"百年海洋"。

先看"现代青岛"。我们所在的奥帆中心，是2008年北京奥运会帆船比赛的举办场地。当年各国的帆船就从这片海湾出发，海面上千帆竞发。今天，港湾里依然停着成排的帆船，旗阵广场上各国的旗帜迎风招展，情人坝伸入海中，是看海、看日落的最佳位置。旁边的奥帆博物馆里，陈列着当年的赛船、器材和影像资料，可以完整了解那届奥帆赛。

再看"百年海洋"。我们要去的青岛水族馆，始建于1932年，是中国人自己设计建造的第一座水族馆。它由蔡元培等学界人士倡议筹建，当年不仅是个展览场所，更是中国近代海洋科学研究的一处起点。在此基础上发展而来的青岛海底世界，如今是大型海洋主题展馆，有长长的海底隧道，头顶是游过的鲨鱼和鳐鱼，还有水母展区，孩子在里面能待很久。

把这两张面孔连起来，您就理解了青岛这座城市：它既是中国海洋科研与海洋教育的重镇，也是一座把海当成客厅的城市。

海滨风大，注意保暖防滑；海上看帆、乘船项目受潮汐与天气影响，出行前请核实班次。祝大家在青岛看海看帆，玩得痛快！

**【景区简介】**

周村古商城景区位于山东省淄博市周村区，是明清以来形成的传统商业街区，由大街、丝市街、银子市街、绸市街等古街组成，保存有大量明清店铺、票号、会馆与民居建筑，被誉为"中国活着的古商业建筑博物馆群"。周村不临水路而商贾云集，历史上被称为"旱码头"；相传清代周村籍官员李化熙为家乡代缴市税，当地立有"今日无税"碑，这一典故被视为商埠繁盛的重要缘由。周村是北方丝绸重要产地与老字号发祥地之一，瑞蚨祥等绸缎庄自此走向全国，地方特产周村烧饼以薄、香、酥、脆著称。2024年12月评为国家5A级旅游景区，是山东省第16家5A级景区。

**【导游词核心稿】**

各位朋友，欢迎来到"天下第一村"——周村古商城！

周村最特别的一点：它不在水边，却成了大商埠。一般的商业古镇都傍河而兴，靠水运起家，周村没有这条河，全靠陆路，所以历史上叫它"旱码头"。能在没有水路的地方把生意做到全国，靠的是两样东西：丝绸，和规矩。

先说丝绸。周村是北方重要的丝绸产地，街上至今保留着丝市街、绸市街这样的名字——一听就知道当年这里做什么买卖。著名的老字号瑞蚨祥就是从周村一带起家，后来把绸缎庄开到了济南、北京、上海。走进街边的老店铺，您还能看到当年的柜台、账房和票号旧址，银子市街就是当年的"金融街"。

再说规矩。相传清代有位周村籍的官员叫李化熙，他看到家乡商税太重，就自己掏钱替乡亲们代缴市税，于是街上立起了一块"今日无税"碑。故事虽属相传，但它讲的是周村人的生意经：让利于商，才能聚人气、成气候。

最后别忘了尝一尝周村烧饼。它薄得像纸，一面芝麻满满，掰开"咔嚓"一声，特点是四个字：薄、香、酥、脆。相传其做法可追溯到汉代的"胡饼"，是真正的老味道。

逛古商城，建议从大街进、丝市街出，一条条街慢慢走。街巷窄、游客多，请看管好随身物品。祝大家在周村淘到好东西、吃到好味道！

**【讲解要点提示】**
- 必讲：大街/丝市街/银子市街/绸市街的业态格局、"旱码头"、瑞蚨祥等老字号、"今日无税"碑典故（相传）、周村烧饼、2024年12月晋升5A。
- 数据锚点：2024年12月；四条古商业街；"薄、香、酥、脆"四特点。
- 常见误区：①"今日无税"碑的典故属民间相传，讲解时必须加"相传"限定；②周村古商城以商业街市与老字号为主题，与以古民居为主的古城景区定位不同。
- 互动/提问设计：请游客比较丝市街与银子市街的功能差异；提问"没有水运为什么还能成为商埠"。
