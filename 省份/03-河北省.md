### 1. 承德避暑山庄及周围寺庙景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 承德市双桥区 |
| 类型 | 古典园林 · 宗教圣地 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 5-6 小时（含外八庙） |

**【景区简介】**（约250字）

承德避暑山庄及周围寺庙景区位于河北省承德市双桥区，是清代皇帝夏季避暑和处理政务的场所，始建于清康熙四十二年（1703年），经康熙、雍正、乾隆三朝营建，至乾隆五十七年（1792年）基本建成，历时89年。山庄占地约564万平方米，是中国现存占地最大的古代帝王宫苑，由宫殿区、湖泊区、平原区、山峦区四部分组成，取自然山水之本色，融江南塞北之风光。宫墙周长约10公里。周围寺庙俗称"外八庙"，为清代在山庄东北部陆续修建的藏传佛教寺庙群，包括普宁寺、普陀宗乘之庙、须弥福寿之庙、普乐寺、安远庙、殊像寺等，融合汉、满、蒙、藏建筑艺术。1994年，避暑山庄及周围寺庙被列入《世界遗产名录》。

**【导游词核心稿】**（约590字）

各位游客朋友们，大家好！欢迎来到承德避暑山庄。这里是中国现存占地最大的古代帝王宫苑，1994年就被列入了《世界遗产名录》。

先说三个数字。第一，1703年：这一年康熙皇帝开始在此营造山庄，此后经雍正、乾隆两朝续建，到乾隆五十七年（1792年）基本完成，前后整整89年。第二，564万平方米：山庄占地约5.64平方公里，相当于两个颐和园还大。第三，约10公里：那是环绕山庄的宫墙长度。

整座山庄分为四大块——宫殿区、湖泊区、平原区和山峦区。我们现在所在的宫殿区，格调恰恰相反：不施彩绘、不铺琉璃，青砖灰瓦、朴素淡雅。主殿澹泊敬诚殿全部用珍贵的楠木建成，走进去能闻到一股淡淡的木香，因此也叫"楠木殿"。清代皇帝在这里批阅奏章、接见使臣，许多重大的历史决策，就在这座不起眼的大殿里作出。

往北走，是湖泊区。这里仿的是江南——"烟雨楼"取自嘉兴，"金山亭"仿的是镇江金山，一步一景，塞外的山里藏着一整个江南。

再往东，是平原区和山峦区。山峦区占了全园面积的五分之四，峰峦起伏、沟壑纵横，是真正的"野趣"。

最后一站，我们一起看"外八庙"。它们是清代朝廷为团结蒙、藏等少数民族而建的藏传佛教寺庙群。普宁寺的大乘之阁里，立着一尊千手千眼观音，通高22.28米，用松、柏、榆、杉、椴五种木材雕成，重约110吨，是国内现存最高大的木雕佛像之一。普陀宗乘之庙则仿照拉萨布达拉宫而建，因此又叫"小布达拉宫"。

山庄与外八庙全程游览约需5到6小时。出行前请核实开放时间、联票范围与山区观光车安排。祝各位在承德，读懂一座园林背后的大国智慧。

**【讲解要点提示】**
- 必讲：1703—1792年89年营建、四大分区、澹泊敬诚殿楠木、外八庙的民族团结意义、1994年世界遗产
- 数据锚点：占地约564万平方米；宫墙周长约10公里；千手千眼观音高22.28米、重约110吨；营建历时89年
- 常见误区：①避暑山庄不是"行宫"，是清代第二个政治中心，皇帝每年有近半年在此理政；②"外八庙"是俗称，实际修建的寺庙不止8座；③避暑山庄与北京的颐和园、圆明园是不同园林，不可混称
- 互动/提问设计：请游客观察宫殿区的屋顶为什么不用金色琉璃瓦？（答案：山庄追求"朴素淡雅"的山野格调，与紫禁城形成对比）

### 2. 保定安新白洋淀景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 保定市安新县（水域大部分现属雄安新区管辖） |
| 类型 | 水域湖泊 · 红色旅游 · 乡村田园 |
| 评定年份 | 2007 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**（约240字）

白洋淀景区位于河北省保定市安新县，是华北平原最大的淡水湖泊湿地，总面积366平方公里，由143个大小淀泊、3700多条沟壕相连组成，水网纵横、芦苇浩荡，素有"华北明珠""北国江南"之称。淀区物产丰饶，盛产鱼虾、苇席、莲藕、菱角，尤以夏季荷花最负盛名。主要景点有荷花大观园、白洋淀文化苑、鸳鸯岛、元妃荷园、嘎子村、王家寨民俗村等。白洋淀也是著名的革命纪念地：抗日战争时期，"雁翎队"在此依托芦苇荡开展水上游击战；作家孙犁的《荷花淀》、徐光耀的《小兵张嘎》皆取材于此，使其成为中国文学史上的重要地理符号。2007年，白洋淀景区被评定为国家5A级旅游景区。

**【导游词核心稿】**（约570字）

各位游客朋友们，大家好！欢迎来到白洋淀。这里是华北平原最大的一片淡水湿地，人称"华北明珠"。

先说它的体量：总面积366平方公里，由143个淀泊、3700多条沟壕织成一张水网。船是这里唯一的"公交车"，进淀、出村、串景点，全靠它。

我们现在坐船，两边是高过人头的芦苇。请注意，芦苇不只是风景——它是白洋淀人的生计：编席、打箔、盖房；也是抗战时期最好的屏障。

说到抗战，就绕不开"雁翎队"。相传，当年这支水上游击队把雁翎插在船头作标志，队员驾着小船在芦苇荡里神出鬼没，打得敌人摸不着头脑。作家孙犁以此为素材写下了小说《荷花淀》，用诗一样清新的笔调写战争，成为中国文学史上的名篇；另一位作家徐光耀笔下的"小兵张嘎"，原型也出自这片水乡。各位待会儿在嘎子村，就能看到那个机智少年的故事。

再往前是荷花大观园。白洋淀的荷花，品种多、花期长。孙犁写《荷花淀》时，开篇第一句就是"月亮升起来，院子里凉爽得很，干净得很"——接着就是那片"一望无边际的密密层层的大荷叶"。各位不妨在荷花盛开的季节，亲自验证一下这"荷荷荡荡"的气势。

白洋淀还有一样宝贝：水。淀里鱼虾丰美，全鱼宴、熏鱼、荷叶茶、莲子、菱角，都是当地特色。

淀区游览以水路为主，全程约需4到6小时，请穿好救生衣、听从船工安排。出行前请核实码头开放时间、水位与游船航线。祝各位在华北水乡，看得到荷花，也记得住那段烽火岁月。

**【讲解要点提示】**
- 必讲：143个淀泊、3700多条沟壕的水网格局；雁翎队与抗战；《荷花淀》《小兵张嘎》的文学渊源
- 数据锚点：总面积366平方公里；143个淀泊；3700多条沟壕；2007年评为5A
- 常见误区：①白洋淀不是"一个湖"，而是由百余个淀泊组成的湖泊群；②《小兵张嘎》是文学形象，"嘎子"并非特指某一位真实人物；③丰水期与枯水期水位差异大，游览体验差别明显，讲解时应提醒游客核实当时水位
- 互动/提问设计：请游客想一想，为什么抗战时期水上游击队能在这片水乡立足？（答案：芦苇荡便于隐蔽、水网复杂敌人不熟地形、渔民熟悉环境并能提供补给）

### 3. 秦皇岛山海关景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定；2015年摘牌，2018年复牌） |
| 所在地 | 秦皇岛市山海关区 |
| 类型 | 遗址考古 · 水域湖泊 · 世界文化遗产 |
| 评定年份 | 2007（2018年复牌） |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**（约245字）

山海关景区位于河北省秦皇岛市山海关区，是明长城的东北关隘之一，明洪武十四年（1381年）由中山王徐达主持建关设卫，因北依燕山、南襟渤海而得名，素有"天下第一关"之称。景区由天下第一关（镇东楼）、老龙头、角山长城、孟姜女庙、王家大院、闯关东主题文化体验馆等景点组成。镇东楼建于关城东门之上，为两层重檐歇山顶箭楼，城台高约12米、楼高13.7米，楼上悬明代进士萧显所书"天下第一关"匾额。老龙头是明长城唯一的入海段，入海石城长约22.4米，城墙如巨龙探入渤海，为长城与大海交汇的奇观。1987年，长城被列入《世界遗产名录》。景区于2015年被取消5A资质，经整改于2018年恢复。

**【导游词核心稿】**（约580字）

各位游客朋友们，大家好！欢迎来到山海关。这门匾上五个大字——"天下第一关"，是明代进士萧显写的。为什么敢称"第一"？因为它守住了中原通往东北的最后一道门户：北面是燕山，南面是渤海，山海之间仅一线可通，就在这条线上，卡着一座关城。

这座关城，是明洪武十四年，也就是1381年，由大将徐达主持修筑的。从此"山海"成"关"，"关"成"城"，商旅、兵马、驿传，都要从这里过。

请各位抬头看这座箭楼——镇东楼。它建在12米高的城台之上，楼身再高13.7米，两层重檐歇山顶。古人打仗时，士兵在楼上的箭窗后射箭、瞭望，楼下的城门则用千斤闸升降开合。各位走过去，抬头看看那块匾："天下第一关"五个字，每字一米有余，笔画雄健。相传，萧显写完之后，人们发现"下"字少了一点，他提笔蘸墨、搭弓射箭，把笔甩上城楼补了那一点——当然，这只是民间的美谈。

再往南，就到了老龙头。这是整个万里长城唯一一段伸入大海的城墙，入海石城长约22.4米。站在入海石城上，一边是万里长城的砖石，一边是渤海的浪花——两条"龙"，在这里碰头。1987年，长城被列入《世界遗产名录》，老龙头就是其中最具辨识度的一段。

顺便说一句：山海关在2015年曾被取消5A资质，经过两年多的整改，2018年重新挂牌。这段"摘牌—复牌"的经历，本身就是中国景区动态管理的一个鲜活案例，也提醒所有从业者：金字招牌不是终身制。

全程游览约需4到5小时。出行前请核实开放时间与各景点联票范围。祝各位在山海关，看一次"山海相逢"。

**【讲解要点提示】**
- 必讲：1381年徐达建关、镇东楼与"天下第一关"匾、老龙头入海、1987年世界遗产、2015摘牌与2018复牌
- 数据锚点：明洪武十四年（1381年）建关；城台高约12米、楼高13.7米；老龙头入海石城长约22.4米
- 常见误区：①山海关不是"万里长城的东端起点"，明长城东端一般认为是辽宁丹东虎山长城，山海关是"天下第一关"；②孟姜女哭长城是民间传说，庙为纪念性建筑，讲解时须说明"相传"；③老龙头与天下第一关相距数公里，需安排交通
- 互动/提问设计：请游客站在老龙头，想一想为何古人要把城墙一直修到海里？（答案：防止敌人从海上或浅滩绕过关城）

### 4. 保定涞水野三坡景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 保定市涞水县野三坡镇 |
| 类型 | 山岳峰林 · 地质地貌 · 水域湖泊 |
| 评定年份 | 2011 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**（约240字）

野三坡景区位于河北省保定市涞水县西北部，地处太行山与燕山山脉交汇处、拒马河畔，总面积约498.5平方公里，是中国北方极为罕见的融雄山碧水、奇峡怪泉、文物古迹、名树古禅于一体的风景名胜区。主要景点包括百里峡、拒马河、龙门天关、白草畔、鱼谷洞等。百里峡由海棠峪、十悬峡、蝎子沟三条幽峡组成，全长105华里，故名"百里峡"，峡内最窄处不足10米，两侧峭壁摩天，有"一线天""回首观音"等奇景。白草畔森林游览区海拔1983米，为京西太行山主峰之一，以高山草甸与白桦林著称。野三坡于2006年被联合国教科文组织批准为世界地质公园，2011年评定为国家5A级旅游景区。

**【导游词核心稿】**（约570字）

各位游客朋友们，大家好！欢迎来到野三坡。这里位于太行山与燕山的交汇处，总面积约498.5平方公里，2006年被评为世界地质公园，2011年跻身5A。

野三坡最有名的，是"百里峡"。它其实由海棠峪、十悬峡、蝎子沟三条峡谷组成，加起来全长105华里——"百里峡"的名字就是这么来的。走进峡内，两侧的峭壁几乎贴着肩膀，最窄处不足10米，抬头只见一线天光；石壁上常年渗水，夏天走进来，清凉得像开了空调。地质学家告诉我们，这些峡谷是亿万年来水流沿着岩石的裂隙不断下切、冲刷而成，是典型的"嶂谷"地貌。

再往高处走，是白草畔。主峰海拔1983米，山顶是一片开阔的高山草甸，白桦成林，六月里野花铺满山坡，七月平均气温比北京城区低十几度，所以这里是京西著名的避暑地。

除了山，野三坡还有水。拒马河从山中穿过，水流清澈，是漂流、戏水的好去处；龙门天关一带留有古代的摩崖石刻与关隘遗迹；鱼谷洞则是一处溶洞，洞内石笋、石幔发育完整。

相传，"野三坡"这个名字，来自当地的"上坡、中坡、下坡"三个古老村落；也有人说，是因为这里山高谷深、草木繁茂，显得格外"野"。两种说法都流传已久，我们把它们留作谈资就好。

野三坡面积大、景点分散，建议安排1到2天，百里峡一地就需3小时以上。出行前请核实各景点开放时间、漂流季节与山区天气，雨后注意山洪与落石。祝各位在野三坡，走进一条真正的"地质教科书"。

**【讲解要点提示】**
- 必讲：太行山与燕山交汇、百里峡三谷105华里、嶂谷地貌成因、白草畔高山草甸、2006年世界地质公园
- 数据锚点：总面积约498.5平方公里；百里峡全长105华里、最窄不足10米；白草畔海拔1983米
- 常见误区：①野三坡在保定涞水，不在北京，虽然紧邻北京房山，常被误认为北京景区；②"百里峡"是三条峡谷的合称，不是一条谷；③鱼谷洞、龙门天关、白草畔彼此相距较远，一日游需提前规划路线
- 互动/提问设计：请游客在峡内观察岩壁上的水平层理，猜一猜这些岩层是怎么形成的？（答案：远古河流、湖泊沉积形成的砂岩、页岩，后被地壳抬升与流水切割成谷）

### 5. 石家庄平山西柏坡景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 石家庄市平山县西柏坡镇 |
| 类型 | 红色旅游 · 博物馆场馆 |
| 评定年份 | 2011 |

- 常见误区：①广府古城在邯郸永年，不是山西或江南的同名古镇；②杨式太极源自陈式太极并经杨露禅改编，讲解时应说明源流；③弘济桥与赵州桥形制相近但规模、年代不同，不可称"同一座桥"

衡水湖旅游景区位于河北省衡水市，景区面积26.4平方公里。衡水湖是华北平原单体水域面积最大的内陆淡水湖，也是华北平原上唯一保持沼泽、水域、滩涂、草甸、林地等完整湿地生态系统的湖泊，享有"京南第一湖""东亚蓝宝石"的美誉。据观测记录，湖区鸟类达336种，占河北省鸟类记录的68.7%。景区由享有"双金赛事"之称的衡水湖马拉松环湖赛道串联，形成衡水湖生态体验区、冀州古城历史文化区、闾里古镇传统文化研学区、鸭鸭乐园亲子度假区四大板块拥湖发展的格局。主要景点有鸭鸭乐园、衡水历史文化生态研学馆、梅花岛、三生岛、樱花岛、闾里古镇、孙敬学堂、冀州古城遗址公园等。2024年12月，景区被文化和旅游部确定为国家5A级旅游景区，成为河北省第13家、衡水市首家5A级景区。

**【导游词核心稿】**（约580字）

各位游客朋友们，大家好！欢迎来到衡水湖。2024年12月，文化和旅游部公布新一批国家5A级旅游景区名单，衡水湖名列其中——这是衡水第一家5A级景区，也是河北省的第13家。

先说这片水。衡水湖是华北平原单体水域面积最大的内陆淡水湖。更难得的是，它是华北平原上唯一还完整保留着沼泽、水域、滩涂、草甸、林地这几种湿地生态系统的湖泊。什么叫"完整"？就是鸟来了，有地方吃、有地方歇、有地方藏、有地方繁殖。所以这里成了候鸟的天堂。截至目前，湖区观测记录到的鸟类有336种，占了河北省鸟类记录的68.7%。这个数字意味着：河北十种鸟里，将近七种能在衡水湖见到。每年迁徙季，湖面上鸟浪翻滚，是摄影爱好者的节日。当地也因此赢得了"京南第一湖""东亚蓝宝石"的美誉。

我们脚下这片区域，古属冀州。相传，大禹治水后分天下为九州，冀州列在首位，所以河北简称"冀"，衡水湖畔的这座古城遗址，承载着这段记忆。
