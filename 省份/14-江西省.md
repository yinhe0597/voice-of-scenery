### 1. 庐山风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 九江市庐山市（牯岭镇一带） |
| 类型 | 山岳峰林 · 古城古镇 · 世界文化景观遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 2 天 |

**【景区简介】**

庐山位于江西省九江市，北濒长江、东临鄱阳湖，风景区面积约302平方公里，主峰汉阳峰海拔1474米。山体以"雄、奇、险、秀"著称，集瀑布、云海、峡谷、别墅群与书院、宗教文化于一体，主要景点有三叠泉、含鄱口、五老峰、锦绣谷、仙人洞、花径、如琴湖等。1996年，庐山以"世界文化景观"列入《世界遗产名录》，是中国首批世界文化景观遗产；2004年入选首批世界地质公园。庐山自古为文化名山，晋代慧远大师创东林寺、陶渊明故里在此，宋代朱熹复兴白鹿洞书院，历代诗人留有诗词数千首。近代牯岭镇形成中外别墅群600余栋，庐山会议旧址、美庐别墅等保存了近现代史迹。

**【导游词核心稿】**

各位游客朋友，大家好！欢迎来到"匡庐奇秀甲天下"的庐山。我们现在所在的位置是海拔一千多米的牯岭镇，这是一座建在山顶上的小城，也是庐山游览的集散地。

先说庐山的"高度"。庐山主峰汉阳峰海拔1474米，虽然在全国的名山里不算最高，但它平地拔起于长江与鄱阳湖之间，相对高差极大，所以一路上来，您会明显感到气温下降、云雾升腾，这正是庐山成为避暑胜地的原因。

再说庐山的"厚度"。庐山不只有风景，更是一部中国文化史。晋代高僧慧远在东林寺创立净土宗，陶渊明在庐山脚下写下田园诗；宋代大儒朱熹重修白鹿洞书院，使它成为中国古代四大书院之一；1996年，庐山正是以"文化景观"的身份被列入《世界遗产名录》——这在中国的名山中是非常特殊的荣誉。

说到诗词，几乎每个中国人都背过两句庐山的诗。"飞流直下三千尺，疑是银河落九天"是李白写的，他写的是庐山瀑布，今天我们去看的三叠泉，落差就有155米，分三叠跌落后才汇入深潭。而苏东坡那句"不识庐山真面目，只缘身在此山中"，据史料记载写于元丰七年他游庐山之后，说的既是看山，也是看人生。

待会儿我们还会经过花径、锦绣谷、仙人洞，下午去含鄱口看鄱阳湖。山上天气多变，请大家带好外套和雨具，台阶湿滑处慢一点走。祝大家在庐山看得开心、走得安全！

**【讲解要点提示】**
- 必讲：世界文化景观遗产身份（1996）、汉阳峰1474米、三叠泉155米落差、白鹿洞书院与朱熹、牯岭别墅群。
- 数据锚点：1474米；155米；302平方公里；1996年申遗；2004年世界地质公园。
- 常见误区：①"庐山"与"庐山西海"是两处不同景区，相距约百公里；②李白诗中的瀑布不能与三叠泉一一对应，讲解时用"相传""历来认为"限定。
- 互动/提问设计：请游客背一句庐山诗词；问"为什么山顶能建一座镇"——引出牯岭近代别墅群避暑文化。

### 2. 井冈山风景旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 吉安市井冈山市 |
| 类型 | 山岳峰林 · 红色旅游 · 森林草原 |
| 评定年份 | 2007 |
| 建议游览时长 | 2 天 |

**【景区简介】**

井冈山位于江西省吉安市井冈山市，地处湘赣边界罗霄山脉中段，风景区面积约333平方公里，主峰五指峰海拔1586米，山体属花岗岩穹隆地貌，森林覆盖率86%以上。1927年10月，毛泽东率秋收起义部队上井冈山，创建了中国第一个农村革命根据地；1928年4月，朱德、陈毅所部与毛泽东所部在宁冈砻市会师，合编为工农革命军第四军。境内保存有茨坪、大井、黄洋界等革命旧址群与井冈山革命烈士陵园、井冈山革命博物馆，多为全国重点文物保护单位。自然景观有龙潭瀑布群、杜鹃山、五指峰等，其中主峰五指峰是第四套人民币100元券背面图案的取景地。2007年评为国家5A级旅游景区，素有"中国革命摇篮"之称。

**【导游词核心稿】**

朋友们好！我们现在踏上的，是被称为"中国革命摇篮"的井冈山。

先交代三个数字。第一，井冈山风景区面积333平方公里，主峰五指峰海拔1586米，山高林密、易守难攻，这正是当年选择在这里建立根据地的地理原因。第二，1927年10月，毛泽东率领秋收起义部队抵达井冈山；次年4月，朱德、陈毅率部在宁冈砻市与毛泽东会师，这就是著名的"朱毛会师"，两军合编为工农革命军第四军。第三，从1927年10月到1930年初，井冈山根据地坚持了两年零四个月。

井冈山的看，分两条线。一条是"红色线"：茨坪革命旧址群、大井毛泽东同志旧居、黄洋界哨口、井冈山革命烈士陵园和井冈山革命博物馆。1928年8月的黄洋界保卫战，红军以不足一个营的兵力击退敌军进攻，毛泽东后来在《西江月·井冈山》里写"黄洋界上炮声隆，报道敌军宵遁"，写的就是这一仗。

另一条是"绿色线"：龙潭瀑布群五级跌水，杜鹃山春季山花如海，主峰五指峰五座石峰并立——您掏出一百元人民币看看背面，第四套人民币100元券上的图案，正是取自这座山峰。这也是井冈山最容易被游客记住的一个细节。

井冈山山高路弯，上下山请注意保暖和防滑；在烈士陵园和旧址内请保持安静。谢谢！

**【讲解要点提示】**
- 必讲：第一个农村革命根据地（1927年10月）、朱毛会师（1928年4月）、黄洋界保卫战、五指峰与人民币图案。
- 数据锚点：1586米；333平方公里；1927/1928年；森林覆盖率86%以上。
- 常见误区：①井冈山市与井冈山景区范围不同，景区含茨坪、龙潭、黄洋界等多个分散片区，需换乘观光车；②"两年零四个月"指根据地存续时间，不是单次行程时间。
- 互动/提问设计：请游客找出百元钞背面图案与眼前五指峰的对应关系；提问"山上为什么适合打游击"。

### 3. 三清山风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 上饶市玉山县（与德兴市交界） |
| 类型 | 山岳峰林 · 宗教圣地 · 世界自然遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 1.5–2 天 |

**【景区简介】**

三清山位于江西省上饶市玉山县与德兴市交界处，属怀玉山脉，风景区面积229.5平方公里，主峰玉京峰海拔1819.9米。三清山是世界著名的花岗岩峰林地貌区，峰柱林立、石景万千，"东方女神""巨蟒出山""观音赏曲"等象形石为标志性景观，其中"巨蟒出山"石柱高约128米。山中保存高等植物1600余种，是华东重要的生物多样性区域。三清山因玉京、玉虚、玉华三峰象征道教"三清"尊神而得名，自唐代起营建宫观，现存明代三清宫及一批古建、石刻。2008年，三清山以"三清山国家公园"名义列入《世界自然遗产名录》；2012年入选世界地质公园。2011年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到"天下第一仙山"三清山！

先给大家一个"高度"的概念：三清山主峰玉京峰海拔1819.9米，站在山顶往下看，是连绵的花岗岩石林——这些石柱是经过亿万年风化崩塌留下的"骨架"，2008年，三清山正是因为这种独特的花岗岩峰林景观被列入《世界自然遗产名录》。

三清山有两条经典线路。第一条是南清园，这是石景最集中的地方。您一定要看"东方女神"和"巨蟒出山"。"巨蟒出山"是一根高约128米的巨型石柱，像一条巨蟒破山而出，头部微抬，是全国乃至世界都罕见的花岗岩象形石；"东方女神"则像一位端坐的少女，被当地人视为三清山的守护神。相传，她是在此修道的女神化身，世代守护山中百姓。

第二条是西海岸。这是一条悬挂在海拔约1600米绝壁上的高空栈道，全长约4公里，脚下是万丈深渊，身旁是云海翻涌。运气好时，云从脚下过，峰在云中浮，这就是三清山最著名的"云海"体验。

为什么叫"三清"？因为玉京、玉虚、玉华三座主峰，恰好对应道教最高神"玉清、上清、太清"。自唐代起这里就修宫建观，现存的三清宫是明代遗构，是研究道教名山建筑的重要实物。

山上气温比山下低8到10摄氏度，栈道风大，请注意保暖和防滑。祝大家一路好运气，看得到云海！

**【讲解要点提示】**
- 必讲：2008年世界自然遗产、主峰1819.9米、巨蟒出山128米、西海岸栈道、三清与道教渊源。
- 数据锚点：1819.9米；128米；海拔约1600米栈道；约4公里。
- 常见误区：①三清山主体在上饶市玉山县，部分在德兴市，不是上饶市区；②"东方女神""巨蟒出山"是天然风化石柱，不是人工雕刻。
- 互动/提问设计：让游客猜眼前石像的名字；问"为什么山上比山下凉"——引出垂直气候带。

### 4. 龙虎山风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 鹰潭市贵溪市 |
| 类型 | 地质地貌 · 宗教圣地 · 遗址考古 · 世界自然遗产 |
| 评定年份 | 2012 |
| 建议游览时长 | 1.5–2 天 |

**【景区简介】**

龙虎山位于江西省鹰潭市贵溪市境内，属武夷山脉余脉，风景区面积约220平方公里，主峰天门山海拔1300余米。龙虎山是中国典型的丹霞地貌区，赤壁丹崖连绵，泸溪河蜿蜒穿行，仙水岩一带崖壁上分布着距今2600余年的春秋战国崖墓群。龙虎山是道教正一道祖庭，相传东汉张道陵曾在此炼丹，"丹成而龙虎现"，山因此得名；上清镇嗣汉天师府始建于北宋崇宁四年（1105年），为历代天师起居与教务中心。2010年，龙虎山作为"中国丹霞"组成部分列入《世界自然遗产名录》；2008年入选世界地质公园。2012年评为国家5A级旅游景区。

**【导游词核心稿】**

朋友们好！欢迎来到道教祖庭、丹霞胜地——龙虎山。

龙虎山有三样东西，别处看不到。第一是"丹霞"。这里的山体是红色的砂砾岩，经过千万年流水侵蚀，形成顶平、身陡、麓缓的赤壁丹崖。2010年，龙虎山作为"中国丹霞"的一员被列入《世界自然遗产名录》——请注意，"中国丹霞"是六处遗产地捆申报的，龙虎山是其中之一。

第二是"古越崖墓"。请大家抬头看仙水岩的悬崖，那些洞口就是崖墓。据考古研究，这些墓葬距今已有2600多年，属于春秋战国时期古越人的葬俗。古人如何把棺木送上几十米高的绝壁？至今没有定论，景区每天有悬棺升棺表演，就是根据学者推测复原的，大家可以带着疑问去看。

第三是"道教祖庭"。相传东汉时期，张道陵在此炼丹，"丹成而龙虎现"，龙虎山因此得名。自宋代起，历代天师居住在上清镇的嗣汉天师府，这座府第始建于北宋崇宁四年，也就是1105年，规模宏大，被称作"南国无双地，西江第一家"。

接下来的行程，我们先乘竹筏漂泸溪河，从水上看丹霞；再上天师府访道；最后看悬棺表演。泸溪河水路平缓，但上筏请穿好救生衣，注意防晒。祝大家玩得尽兴！

**【讲解要点提示】**
- 必讲：中国丹霞世界自然遗产（2010）、崖墓群距今2600余年、嗣汉天师府（1105年）、泸溪河竹筏。
- 数据锚点：220平方公里；2600余年；1105年；主峰天门山1300余米。
- 常见误区：①龙虎山与龟峰同为"中国丹霞"，但分属鹰潭（贵溪市）与上饶（弋阳县）两个景区，相距约70公里（另有约50公里的宣传口径）；②悬棺表演是"推测复原"，不是史实还原，讲解时须说明。
- 互动/提问设计：请游客猜"古人怎样把棺木送进崖洞"；提问"龙虎山的名字怎么来的"。

### 5. 婺源江湾景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 上饶市婺源县江湾镇 |
| 类型 | 古城古镇 · 乡村田园 · 民族风情 |
| 评定年份 | 2013 |
| 建议游览时长 | 1 天（含周边古村可安排 2 天） |

**【景区简介】**

婺源江湾景区位于江西省上饶市婺源县江湾镇，以江湾古村为核心，涵盖李坑、汪口、晓起等徽派古村落。江湾村相传始建于隋末唐初，为萧江氏族世代聚居地，相传其先祖为避祸改姓，村内保存有萧江宗祠、江氏祖祠及一批明清徽派民居、祠堂与官宅，粉墙黛瓦、马头墙与砖木石"三雕"为其建筑特色。汪口村的俞氏宗祠、东门码头，李坑村的溪流穿村、小桥人家，均为婺源宗族文化与田园风光的代表。区域属亚热带湿润气候，村外茶园、油菜花田与古村相映。江湾村为中国历史文化名村，2013年评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，欢迎来到"中国最美的乡村"——婺源，我们今天的第一站是江湾。

江湾是一座有故事的村。相传这个村子始建于隋末唐初，至今已有一千三百多年；村中大姓为"萧江"，相传其先祖本姓萧，为避祸才改姓江，所以村里的宗祠叫"萧江宗祠"。走进祠堂，您会看到高大的梁柱、精美的木雕，"忠、孝、节、义"四个字，是宗族对子孙最看重的规矩。

婺源的房子怎么看？记住三句话：粉墙、黛瓦、马头墙。白墙黑瓦，轮廓干净；马头墙高高翘起，既是防火的封火墙，也是徽派建筑最醒目的符号。再看细节，徽州有"三雕"——砖雕、木雕、石雕，门楼、梁枋、窗棂上都是，题材多为花鸟、戏文和吉祥图案。江湾现存的一批明清民居，就是最好的样本。

离开江湾，我们去汪口和李坑。汪口有俞氏宗祠，还有当年通航的古码头——婺源的山货、茶叶就是从这些码头上船外运的。李坑则是"小桥流水人家"的模样，溪水穿村，两岸是茶馆和老宅，最适宜慢下来走一走。

三四月油菜花开、七八月绿意浓、十一月晒秋起，婺源四季各有看点。村中巷窄人多，请跟紧队伍，也不要随意进入未开放的民宅。祝大家在婺源拍出好照片！

**【讲解要点提示】**
- 必讲：萧江宗祠与宗族文化、徽派三要素（粉墙黛瓦马头墙）、徽州三雕、汪口码头与婺源水运、李坑水乡格局。

### 6. 景德镇古窑民俗博览区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 景德镇市昌江区（枫树山蟠龙岗） |
| 类型 | 工业遗产 · 博物馆场馆 · 民族风情 |
| 评定年份 | 2013 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

景德镇古窑民俗博览区位于江西省景德镇市昌江区枫树山蟠龙岗，是集中展示景德镇千年制瓷技艺的文化旅游区，规划占地约83公顷。区内保存并复建有宋、元、明、清各代典型瓷窑，包括宋代龙窑、元代馒头窑、明代葫芦窑与清代镇窑（柴窑），其中镇窑为景德镇现存规模最大的柴烧瓷窑之一，一次可装烧瓷器两万余件，2009年成功复烧。博览区设有手工制瓷作坊，现场演示拉坯、利坯、画坯、施釉等传统工序（手工制瓷有"七十二道工序"之说），并集中迁建有明清古建筑群与风火仙师庙，庙中所奉为明代窑工童宾。景德镇制瓷史可上溯至东汉，北宋景德年间以年号赐名"景德镇"，自此成为皇家窑业重镇。2013年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友好！欢迎来到千年瓷都景德镇。今天我们参观的，是一座"活着的窑"——古窑民俗博览区。

为什么说"活着"？因为这里的窑还在烧。请大家看这几座窑：这是宋代的龙窑，顺着山坡向上，像一条长龙；那是元代的馒头窑，圆顶像馒头；这边是明代的葫芦窑，两个窑室相连，形似葫芦；最壮观的是清代的镇窑，它是柴烧瓷窑，一次能装烧两万多件瓷器。2009年，景区重新点燃镇窑，恢复了中断多年的柴烧技艺，这在业界是件大事。

景德镇的瓷器为什么好？关键在于分工。手工制瓷有"七十二道工序"的说法，从采石、制泥到拉坯、利坯、画坯、上釉、烧窑，每一步都有专门的师傅。待会儿在作坊里，您会看到师傅用一双手把一团泥拉成碗——这就是"拉坯"，欢迎大家近距离看，但请不要触碰坯体。

再看这座风火仙师庙，里面供奉的是明代窑工童宾。相传万历年间，为烧成御器大龙缸，窑工屡烧屡败，童宾投身窑火，此后大缸乃成，后人尊他为窑神，立庙祭祀。故事悲壮，但它说的是景德镇匠人对技艺的敬畏。

景德镇的名字来自北宋景德年间，皇帝以年号赐名，从此"景德镇"三字沿用千年。参观结束前，请留意地上的瓷片和窑具——它们才是这座城市真正的年轮。

**【讲解要点提示】**
- 必讲：四代典型瓷窑（龙窑/馒头窑/葫芦窑/镇窑）、镇窑两万余件装烧量、七十二道工序、风火仙师庙与童宾、景德赐名。
- 数据锚点：83公顷；两万余件；2009年复烧；七十二道工序。
- 常见误区：①古窑民俗博览区是展示性文化景区，与明清御窑厂遗址（国家级考古遗址公园）是两回事；②柴窑并非每天都在烧，出行前请核实复烧与演示时间。
- 互动/提问设计：让游客分辨四种窑的造型差异；提问"一团泥如何变成一只碗"。

### 7. 瑞金共和国摇篮景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2015年评定） |
| 所在地 | 赣州市瑞金市 |
| 类型 | 红色旅游 · 博物馆场馆 · 遗址考古 |
| 评定年份 | 2015 |
| 建议游览时长 | 1 天 |

**【景区简介】**

共和国摇篮景区位于江西省赣州市瑞金市，由叶坪、红井（沙洲坝）、二苏大（沙洲坝）、中华苏维埃纪念园四大片区组成，是中华苏维埃共和国诞生地的纪念性景区。1931年11月7日至20日，中华苏维埃第一次全国代表大会在叶坪召开，宣告中华苏维埃共和国临时中央政府成立，瑞金一度改称"瑞京"；1934年1月，第二次全国苏维埃代表大会在沙洲坝召开。境内保存有临时中央政府旧址、红军广场、红军烈士纪念塔、中央革命根据地历史博物馆等旧址与场馆，多为全国重点文物保护单位。沙洲坝红井因小学语文课文《吃水不忘挖井人》广为人知。1934年10月，中央红军主力自瑞金、于都等地出发开始长征。2015年评为国家5A级旅游景区。

**【导游词核心稿】**

朋友们好！我们脚下这片土地，被称为"共和国摇篮"。为什么？因为中华苏维埃共和国就是从这里起步的。

先记住三个时间。第一个，1931年11月7日。这一天，中华苏维埃第一次全国代表大会在叶坪开幕，会期共14天，大会宣告中华苏维埃共和国临时中央政府成立，定都瑞金，瑞金当时改称"瑞京"。叶坪的谢氏宗祠就是当年的会场，一间祠堂，成了新政权的礼堂。

第二个，1933年前后，中央机关迁到沙洲坝。这里有大家熟悉的那口井——红井。小学语文课本里有一篇《吃水不忘挖井人》，讲的就是它。当年沙洲坝缺水，群众饮水困难，红军战士和群众一起挖了这口井，井边那块石碑上的十个字，至今还在："吃水不忘挖井人，时刻想念毛主席"。

第三个，1934年10月。中央红军主力从这里出发，开始了举世闻名的长征。所以瑞金既是"起点"，也是"出发地"。

我们的行程，先在叶坪看旧址群和红军烈士纪念塔，再到沙洲坝看红井、二苏大会址，最后去中华苏维埃纪念园和中央革命根据地历史博物馆，用两个多小时把这段历史串起来。参观旧址时请保持肃静，不要触摸文物。谢谢！

**【讲解要点提示】**
- 必讲：一苏大（1931年11月7日）、中华苏维埃共和国临时中央政府成立、红井与《吃水不忘挖井人》、1934年10月长征出发。
- 数据锚点：1931年11月7日；会期14天；四大片区；1934年10月。
- 常见误区：①叶坪与沙洲坝是两个相距数公里的片区，需乘车转场；②"共和国摇篮景区"与"中央革命根据地历史博物馆"是包含关系，不是并列的两个景区。
- 互动/提问设计：请游客读一遍红井碑文；提问"为什么叫瑞京"——引出定都瑞金的史实。

### 8. 宜春明月山旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2015年评定） |
| 所在地 | 宜春市袁州区（温汤镇一带） |
| 类型 | 山岳峰林 · 水域湖泊 · 宗教圣地 |
| 评定年份 | 2015 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

明月山旅游区位于江西省宜春市中心城区西南，属武功山东延支脉，主峰太平山海拔1735.6米。山体以花岗岩为主，溪谷深切、瀑布成群，云谷飞瀑落差约120米，为赣西著名瀑布之一；海拔1500余米的青云栈道沿绝壁悬空铺设，全长约3100米。山间有星月洞、月亮湖等景观，宜春因此被称为"月亮之都"，并形成以"月亮文化"为主题的节庆活动。山麓温汤镇出露富硒温泉，水温常年保持在68℃至72℃，属可饮可浴的医疗矿泉。宗教方面，仰山栖隐禅寺为禅宗沩仰宗祖庭之一，唐代慧寂禅师曾在此弘法。2015年评为国家5A级旅游景区，同时为国家级风景名胜区与温泉度假地。

**【导游词核心稿】**

各位朋友，欢迎来到"山似明月、泉如温汤"的明月山！

明月山有"三绝"。第一绝是山。主峰太平山海拔1735.6米，山体是花岗岩，经过长期抬升和流水切割，形成了深峡与飞瀑。云谷飞瀑落差约120米，水从崖顶直落，声如雷鸣，是赣西落差最大的瀑布之一。

第二绝是栈道。我们要走的青云栈道，建在海拔1500多米的绝壁上，全长约3100米。它像一条腰带缠在崖壁中间，一侧是石壁，一侧是深谷，云雾来时，人在云中走——这是明月山最刺激也最好看的一段路。害怕的朋友请靠里侧走，不要在栈道上停留太久。

第三绝是温泉。山下的温汤镇，有一口千年不竭的温泉，水温常年保持在68到72摄氏度，含硒等多种微量元素，可饮可浴。相传温汤温泉自宋代就被人用来洗浴治病，今天镇上仍有许多泡脚的老人，这是当地人最日常的生活方式。爬完山下山泡一泡，是明月山最标准的"打开方式"。

另外告诉大家一个文化点：宜春被称为"月亮之都"，山上有星月洞、月亮湖，山下每年举办月亮文化节，"明月山"的名字本身就与月亮有关。下山之后，有兴趣的朋友还可以去仰山栖隐禅寺，它是禅宗沩仰宗的祖庭之一，唐代慧寂禅师曾在此弘法。

**【讲解要点提示】**
- 必讲：太平山1735.6米、云谷飞瀑约120米、青云栈道约3100米、温汤富硒温泉68–72℃、月亮文化。
- 数据锚点：1735.6米；120米；3100米；68–72℃。
- 常见误区：①明月山本身即位于武功山（罗霄山脉北支）的东北段，与以金顶为核心的萍乡武功山景区山体相连，但二者是两个各自独立售票的5A景区——明月山在宜春市袁州区，武功山主景区在萍乡市芦溪县，不可说成"一个地方"或"上下山联通"；②温泉在山下温汤镇，不在山顶，行程安排上先爬山后泡泉。
- 互动/提问设计：请游客在栈道上辨认远处山峰走向；提问"温泉为什么能常年保持高温"。

### 9. 抚州资溪大觉山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2017年评定） |
| 所在地 | 抚州市资溪县 |
| 类型 | 山岳峰林 · 森林草原 · 宗教圣地 |
| 评定年份 | 2017 |
| 建议游览时长 | 1 天 |

**【景区简介】**

大觉山景区位于江西省抚州市资溪县境内，地处武夷山脉西麓，主峰海拔约1370米。区内森林覆盖率高，保存有较大面积的原生性常绿阔叶林，溪谷深切、瀑布成群，空气负氧离子浓度高，是赣东重要的生态旅游与漂流目的地，夏季峡谷漂流为其主打项目，河道落差大、险滩相连。人文方面，山中大觉岩寺依天然岩洞而建，相传始建于东晋，距今1700余年，为赣闽边界著名的佛教场所，历代香火不断。资溪县森林覆盖率约87%，居江西省前列，是国家级生态示范区，盛产白茶，并有"面包之乡"之称。2017年评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，欢迎来到赣东"天然氧吧"——资溪大觉山！

先说大觉山的"绿"。资溪县的森林覆盖率约87%，在江西省名列前茅。走进大觉山，两侧是茂密的常绿阔叶林，溪水常年不断，山谷里负氧离子浓度很高，很多游客说"在这里深呼吸都觉得甜"。建议大家放慢脚步，走一段缓坡，听听水声。

再说大觉山的"高"。景区主峰海拔约1370米，属武夷山脉西麓，山势陡峻，峡谷深切，落差很大。正因为落差大，这里成了漂流的好地方——夏季的峡谷漂流，河道随着山势一路下切，急弯、跌水接连不断，是华东地区颇具名气的一条漂流线。参加漂流请务必穿好救生衣、戴好头盔，听从护漂员指挥，心脏病、高血压患者和儿童不宜参加。

最后说大觉山的"古"。山中有一座大觉岩寺，它是依着一个巨大的天然岩洞建起来的——洞就是殿，殿就是洞，这种"岩寺"形制在南方并不多见。相传这座寺始建于东晋，距今已有1700多年，是赣闽边界一带信众朝拜的佛教场所。站在岩寺前看群山，您会发现"大觉"二字，取的是佛教里"大彻大悟"之意。

大觉山适合安排一整天：上午登山看峡谷，中午素斋或山间简餐，下午漂流或访寺。山区天气多变，请带雨具，注意防滑。

**【讲解要点提示】**
- 必讲：武夷山脉西麓区位、主峰约1370米、资溪县森林覆盖率约87%、大觉岩寺（相传东晋始建，1700余年）、峡谷漂流。
- 数据锚点：约1370米；约87%；1700余年；2017年评为5A。
- 常见误区：①大觉山在抚州资溪，与浙江、福建的同名山体无关；②漂流为季节性项目且受水情限制，出行前务必核实开放情况。
- 互动/提问设计：让游客观察岩寺"以洞为殿"的建筑特点；提问"为什么森林多的地方空气更清新"。

### 10. 上饶弋阳龟峰景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2017年评定） |
| 所在地 | 上饶市弋阳县 |
| 类型 | 地质地貌 · 宗教圣地 · 世界自然遗产 |
| 评定年份 | 2017 |
| 建议游览时长 | 半天–1 天 |

**【景区简介】**

龟峰景区位于江西省上饶市弋阳县境内，又称圭峰，以丹霞地貌为主体，峰石多呈龟形，故有"无山不龟，无石不龟"之说，已命名的龟形石景与峰峦数十处，属老年期丹霞地貌的典型代表。2010年，龟峰与龙虎山以"中国丹霞"名义一并列入《世界自然遗产名录》。区内南岩寺石窟依岩壁开凿，为唐宋时期佛教石窟遗存，是研究江南石窟艺术的重要实物。明代地理学家徐霞客曾游历此地，在《江右游日记》中盛赞龟峰，称其"峦嶂之奇，雁荡所无"。景区林木葱郁，信江支流绕山而过。2017年评为国家5A级旅游景区，同时为国家级风景名胜区。

**【导游词核心稿】**

朋友们好！欢迎来到"无山不龟，无石不龟"的龟峰！

龟峰最奇的，是它的"形"。这里的山体是白垩纪红色砂砾岩，经过千万年风化，形成了一座座圆润的石峰。因为岩层层层剥落，很多峰顶、石块看着就像一只只乌龟——有的像乌龟抬头，有的像群龟下海，所以我们叫它"龟峰"，古代也叫"圭峰"。请各位边走边猜名字，这是游龟峰最有意思的事。

第二个看点，是它的"身份"。2010年，"中国丹霞"被列入《世界自然遗产名录》，龟峰正是其中的一个组成部分，另一处就在不远处的鹰潭龙虎山。两地的丹霞地貌各有特色：龙虎山以泸溪河两岸的崖壁和崖墓取胜，龟峰则以"峰林成林、龟形毕肖"取胜。龟峰属于"老年期"丹霞，峰体被侵蚀得更圆、更独立，这在全国丹霞地貌里是很典型的一类。

第三个看点，是南岩寺石窟。它开凿在红色岩壁之上，为唐宋时期的佛教石窟遗存，是研究江南石窟艺术的重要实物。江南石窟数量本就不多，能与丹霞地貌共生，更显珍贵。

最后讲一段"名人背书"。明代地理学家徐霞客游过龟峰，他在《江右游日记》里称赞这里"峦嶂之奇，雁荡所无"——意思是龟峰峰峦的奇巧，连以奇秀著称的雁荡山都比不了。

龟峰路程不长，但台阶不少，请穿软底鞋、带足饮水。祝大家"数龟愉快"！

**【讲解要点提示】**
- 必讲："无山不龟"的象形石群、2010年中国丹霞世界自然遗产、南岩寺石窟、徐霞客评语。
- 数据锚点：2010年申遗；老年期丹霞；唐宋石窟；数十处象形石景。
- 常见误区：①龟峰与龙虎山是"中国丹霞"系列遗产中相距较远的两处，相距约70公里（另有约50公里的宣传口径），不要说成同一景区；②徐霞客评语是对龟峰与雁荡的比较，引用时须完整。
- 互动/提问设计：请游客给眼前的"龟石"起名；提问"为什么这里的山都是圆的"。

### 11. 南昌滕王阁旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2018年评定） |
| 所在地 | 南昌市东湖区 |
| 类型 | 陵寝祠庙 · 城市地标 |
| 评定年份 | 2018 |
| 建议游览时长 | 2–3 小时 |

**【景区简介】**

滕王阁旅游区位于江西省南昌市东湖区赣江之滨，主体滕王阁临江而立，与湖北黄鹤楼、湖南岳阳楼并称"江南三大名楼"。滕王阁始建于唐永徽四年（653年），为唐高祖李渊之子、滕王李元婴任洪州都督时所建；因初唐诗人王勃于上元二年（675年）在此即席写下《秋日登洪府滕王阁饯别序》（通称《滕王阁序》）而名扬天下，名句"落霞与孤鹜齐飞，秋水共长天一色"即出于此。滕王阁历史上屡毁屡建，现存楼阁为1989年10月落成的第29次重建，系仿宋式钢筋混凝土结构，取"明三暗七"格局（外观三层带回廊、内部七层），主阁高57.5米，建筑面积约1.3万平方米。阁区配套有仿古园区与陈列展示。2018年评为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，大家好！现在我们面前的，就是"江南三大名楼"之一——滕王阁。

先说这座楼的"年纪"。滕王阁始建于唐永徽四年，也就是公元653年，创建者是唐高祖李渊的儿子李元婴，他被封为滕王，任洪州都督，就在赣江边上建了这座楼。楼建成二十多年后，一位二十多岁的年轻人在这里写下一篇序，从此这座楼名满天下——这个人就是王勃。

那是唐上元二年，公元675年。相传王勃当时南下省父，路过洪州，正逢都督在阁上大宴宾客。据记载，主人本想让自家女婿出风头，预先写好了一篇序，谁知王勃毫不推辞，提笔而成，写下了"落霞与孤鹜齐飞，秋水共长天一色"这样的千古名句。一篇序成就一座楼，这在中国的楼阁史上极为少见。

再说这座楼的"身世"。滕王阁历史上屡毁屡建，我们现在看到的，是1989年10月落成的第29次重建。它采用的是仿宋样式，主体高57.5米，建筑格局叫"明三暗七"——从外面看是三层带回廊，里面其实有七层。这个设计是有依据的，宋代《营造法式》和历代滕王阁图都提供了参照。

待会儿我们登阁，一层看台基与陈设，中间各层有历代滕王阁模型与江西人文展陈，顶层可俯瞰赣江。江风较大，请注意安全；楼内为木构装饰，请勿吸烟。祝大家"阁"外有风景，"序"里有文章！

**【讲解要点提示】**
- 必讲：江南三大名楼、653年始建、675年王勃作序、1989年第29次重建、"明三暗七"。
- 数据锚点：57.5米；约1.3万平方米；653年；675年；1989年。
- 常见误区：①现阁为1989年重建的仿宋建筑，不是唐代遗构，讲解时须说明；②"落霞与孤鹜"两句写的是阁上远眺之景，非楼本体。
- 互动/提问设计：请游客接诵《滕王阁序》名句；提问"为什么一座楼能重建29次"——引出战乱与火灾史。

**【景区简介】**

武功山景区位于江西省萍乡市芦溪县境内，地跨萍乡、宜春、吉安三市，主峰白鹤峰（金顶）海拔1918.3米，为江西省境内著名高峰之一。山体顶部保存有约十万亩连绵起伏的高山草甸，海拔1600米以上地带开阔平缓，被称为"云中草原"，罕见于同纬度山地，是国内著名的户外徒步与露营目的地，自2008年起每年举办武功山国际帐篷节。武功山相传自汉晋以来即为道教胜地，山顶分布有历代石砌祭坛遗存，是江南古代山岳祭祀文化的重要实物。山中瀑布、怪石、古松与云海日出构成四季景观。2019年评为国家5A级旅游景区，同时为国家级风景名胜区与世界地质公园网络成员。

朋友们好！欢迎来到"云中草原"武功山！

武功山最大的不同，在于它的"顶"。我们爬到海拔1600米以上，你会发现——树不见了，眼前是一片连绵起伏的草甸，一直铺到天边。这片高山草甸面积约十万亩，是这个纬度上非常罕见的高山植被景观。夏天绿浪翻滚，秋天金黄一片，风一吹，草浪就像海。正因如此，武功山成了全国徒步爱好者心中的"圣地"，每年都有帐篷节，成千上万顶帐篷扎在草甸上看星星。

再报一个数字：武功山主峰白鹤峰，也就是大家说的"金顶"，海拔1918.3米。从山脚到金顶，落差一千多米，常规登山路线要走几个小时，也可以乘索道节省体力。无论怎么上山，都请评估自己的体力，带好防风外套——山顶的风比山下大得多，气温也低十度左右。

武功山还有"老资格"。相传自汉晋以来，这里就是道教活动之地，山顶至今留有历代用石块垒砌的祭坛。古人登山设坛祭天，为的是祈求风调雨顺，这在全国的名山里是很有特色的一处遗存。

最后提醒两句：山上禁止明火，露营请到指定营地；垃圾请全部带下山。武功山的美，靠每一位来的人守护。祝大家看到云海、看到日出、看到满天星斗！

**【讲解要点提示】**
- 必讲：白鹤峰（金顶）1918.3米、约十万亩高山草甸、帐篷节与徒步文化、山顶古祭坛遗存。
- 数据锚点：1918.3米；1600米以上草甸带；约十万亩；2008年起帐篷节。
- 常见误区：①武功山山脉跨萍乡市芦溪县、宜春市袁州区、吉安市安福县三地，主峰金顶（白鹤峰）处芦溪县与安福县交界；明月山位于同一山脉的东北段，主体在宜春市袁州区，与武功山主景区山体相连但各自独立售票、分别进山，不可混为一谈；②高山草甸生态脆弱，严禁碾压与生火。
- 互动/提问设计：提问"为什么山顶没有树"——引出高山草甸成因；请游客辨认古祭坛石构。

### 13. 九江庐山西海景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2020年评定） |
| 所在地 | 九江市永修县、武宁县 |

**【景区简介】**

庐山西海景区位于江西省九江市永修县与武宁县境内，由云居山与柘林湖两大片区组成，因位于庐山之西而得名。柘林湖为柘林水电站拦蓄修河形成的大型人工湖，水域辽阔、水质优良，湖中散布着大量岛屿，其中3亩以上的岛屿达1667个，形成"千岛落珠"的水上景观，是赣北重要的饮用水源地与生态渔业基地。云居山片区以佛教禅宗名刹真如禅寺为核心，该寺始建于唐代，为禅宗曹洞宗重要祖庭之一，历代高僧辈出，近代虚云长老曾在此主持重兴。景区山水相依，兼具湖光山色与禅林文化。2020年评为国家5A级旅游景区，同时为国家级风景名胜区。

**【导游词核心稿】**

各位游客，欢迎来到"江西千岛湖"——庐山西海！

先解释名字。庐山西海在庐山的西边，主体是一片大湖。这片湖是怎么来的？它是修河被柘林水电站拦蓄之后形成的大型人工湖，水域面积广阔，湖里散布着数不清的大小岛屿——其中3亩以上的岛屿就有1667个。坐船穿行其间，一岛一景，水绕山转，这就是"千岛落珠"的由来。

请大家在船上留意两件事。一是水色。柘林湖水质清澈，是赣北重要的饮用水源地，保护区范围内严禁游泳和垂钓，请大家共同守护。二是岛形。有的岛像卧牛，有的像观音，很多岛都有名字，讲解员会一一指给大家。

上岸之后，我们去云居山真如禅寺。这座寺始建于唐代，是禅宗曹洞宗的重要祖庭之一。近代高僧虚云长老曾在这里主持、重兴道场，使它再度成为江南禅林重镇。寺周古木参天，殿堂依山而建，进山门那一刻，城市的喧闹就留在了身后。寺内请轻声慢行，未经许可不要拍摄僧人和法事。

庐山西海适合这样安排：上午游湖，中午尝一尝湖鲜，下午进云居山听禅。水上项目受天气影响，如遇大风停航属正常调度，请听从工作人员安排。

**【讲解要点提示】**
- 必讲：柘林湖成因（柘林水电站拦蓄修河）、1667个岛屿、真如禅寺（唐代始建、曹洞宗祖庭）、虚云长老重兴。
- 数据锚点：1667个岛屿；3亩以上；唐代始建；2020年评为5A。
- 常见误区：①庐山西海与庐山是两处相距约百公里的不同景区，西海并非庐山的组成部分；②湖区是饮用水源地，禁泳禁钓。
- 互动/提问设计：请游客数一数视野中能看到几座岛；提问"人工湖与天然湖的区别在哪里"。

### 14. 赣州三百山景区

| --- | --- |

**【景区简介】**

三百山景区位于江西省赣州市安远县境内，地处武夷山余脉与南岭九连山余脉的交错地带，是长江水系贡江与珠江水系东江的分水岭，主峰十二排海拔约1169米。三百山是东江源头区，山间溪流汇成东江上游水系，经东深供水工程输往东莞、深圳及香港，是粤港地区重要的饮用水源涵养地，区内保存有中亚热带常绿阔叶林与珍稀动植物，生态系统完整。主要景观有东风湖、九曲溪、知音泉、福鳌塘、东江第一瀑等，溪谷深切、瀑布成群，空气中负氧离子浓度高。景区建有源头文化展示与生态科普设施，是集生态保护、科考、研学与观光于一体的山岳型景区。2022年评为国家5A级旅游景区，同时为国家级风景名胜区。

朋友们好！欢迎来到三百山——这里有一个特殊的身份：它是东江的源头。

再说山。三百山主峰十二排海拔约1169米，山不算特别高，但溪谷深切、落差大，所以瀑布特别多。主要景点有东风湖、九曲溪、知音泉、福鳌塘和东江第一瀑。走在溪谷栈道上，两边是常绿阔叶林，水声一路不断；这里空气里负氧离子浓度很高，很多游客形容"像在洗肺"。建议大家走慢一点，多深呼吸几次。

行程上，上午走九曲溪和瀑布群，下午看源头碑刻与科普展馆。山区多雨，请备雨具，栈道湿滑处慢行。

**【讲解要点提示】**
- 必讲：东江源头身份、1965年东深供水工程通水、主峰十二排约1169米、东风湖/九曲溪/东江第一瀑。
- 数据锚点：约1169米；1965年；2022年评为5A。
- 常见误区：①东江源头区的表述涉及流域范围，"源头之一"与"唯一源头"说法不一，讲解时宜用"东江源头区"；②水源保护区内禁止游泳洗涤，须提前告知游客。
- 互动/提问设计：提问"我们喝的水从哪里来"——引出流域保护；请游客辨认常绿阔叶林的常见树种。

**【景区简介】**

篁岭景区位于江西省上饶市婺源县江湾镇，景区面积约7平方公里，是一座"挂在山崖上的"古村落。篁岭村始建于明代中期，距今近600年，数百栋徽派民居依山势错落排布于近百米落差的坡面上，因"地无三尺平"，村民自古在屋顶、窗台晾晒农作物，形成独有的"晒秋"农俗景观。景区由索道空中揽胜、村落天街访古、梯田花海寻芳与晒秋民俗拾趣等游览区域组成，村外千棵古树环绕、万亩梯田簇拥，春看油菜花、秋观晒秋。2023年，篁岭村被联合国旅游组织列入"世界最佳旅游乡村"；2024年12月评为国家5A级旅游景区，是江西省第15家5A级景区。

**【导游词核心稿】**

各位朋友，欢迎来到"挂在山崖上的村庄"——篁岭！

篁岭最特别的一点，是它的地形。这个村子建在山坡上，高低落差近百米，正所谓"地无三尺平"。所以祖辈盖房只能依着山势一层一层往上叠，从对面看过去，几百栋徽派民居像贴在崖壁上，所以我们说它"挂在山崖上"。

第二点，是"晒秋"。因为平地实在太少，村民就把辣椒、稻谷、菊花、笋干摊在屋顶和窗台的圆竹匾里晾晒。红的辣椒、黄的稻谷、白的菊瓣，在黑瓦白墙之间铺开——这就是篁岭最有名的"晒秋"。据当地老人讲，这个习俗已经延续了几百年，最初只是为了干活方便，如今成了中国乡村最著名的一幅画面。每年秋天，这里都会办晒秋节。

第三点，是"古"。篁岭村始建于明代中期，距今近600年。2023年，它被联合国旅游组织评为"世界最佳旅游乡村"；2024年12月，正式评为国家5A级旅游景区，成为江西的第15家5A。村子外面是千棵古树和万亩梯田，春天油菜花开，一层一层从山脚铺到山顶。

我们的路线是：乘索道上山，先走天街访古，再看晒秋观景台，最后到梯田花海。天街窄、人多，请跟紧队伍；晒秋的竹匾是村民的生活用具，请不要挪动。祝大家拍到最美的"秋色"！

**【讲解要点提示】**
- 必讲："挂在山崖上"的地势、晒秋民俗、近600年建村史、2023年世界最佳旅游乡村、2024年12月晋升5A。
- 数据锚点：约7平方公里；近百米落差；近600年；2023年；2024年12月。
- 常见误区：①篁岭与江湾是婺源两个独立的5A级景区，不要混为一个；②"晒秋"是生活习俗的延续，景区有季节性布置，展示时间与作物种类随季变化。
- 互动/提问设计：请游客辨认竹匾里晒的是哪些作物；提问"为什么屋顶也能当晒场"。

## 三、待核实与补充事项

- **江西第15家5A已核实**：为**上饶市婺源篁岭景区**，2024年12月27日文化和旅游部公告确定（同批全国共19家），2023年曾入选联合国旅游组织"世界最佳旅游乡村"。底稿中的"待核实（第15家）"已可确认，无需再存疑。
- **部分5A景区的面积与海拔口径不一**：庐山风景区面积有302平方公里与282平方公里两种口径；三清山有229.5平方公里（景区总面积）与71.68平方公里（核心区）两种口径。本文件采用景区总面积口径，若需对外发布请以景区官方导览图数据为准。
- **三百山"东江源头"表述**：三百山为东江源头区（东江源国家级自然保护区范围），民间亦有"东江源头第一山"之称。讲解时建议使用"东江源头区"，避免"唯一源头"的绝对表述。
- **大觉山景区面积与漂流长度**：公开资料口径差别较大（涉及规划面积、营业面积等不同统计），本文件未给出具体面积与漂流里程数字，待补充权威数据后再写入词条。
- **4A名录索引为不完全收录**：本索引收录62条，其中标注"待核实等级"的18条为名称或等级尚需二次核实的条目，使用前请以江西省文化和旅游厅最新公告为准；全省4A景区实际数量远高于此，后续可持续扩充。
