### 1. 东方明珠广播电视塔

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 上海市浦东新区世纪大道1号（陆家嘴） |
| 类型 | 城市地标 |
| 评定年份 | 2007 |
| 建议游览时长 | 2-3 小时 |

**【景区简介】**

东方明珠广播电视塔坐落于上海市浦东新区陆家嘴世纪大道1号，与外滩万国建筑博览群隔黄浦江相望。塔体于1991年7月动工，1994年11月建成开放，总高468米，由3根直径9米的擎天立柱、11个大小不等的球体与一座球形底座构成。塔内设有259米上球体观光层、263米主观光层、267米旋转餐厅与350米太空舱，底层配套上海城市历史发展陈列馆。作为改革开放后上海建成的第一座超高层地标，东方明珠是首批国家5A级旅游景区之一，也是上海天际线中辨识度最高的符号。

**【导游词核心稿】**

各位游客朋友们，大家好！欢迎来到上海地标——东方明珠广播电视塔。我们现在所在的位置，是浦东新区陆家嘴的世纪大道1号，脚下这条黄浦江，把上海的昨天和今天一分为二：西岸是百年外滩，东岸是而立之年的陆家嘴。

先抬头看塔身。东方明珠总高468米，1994年11月建成，那年它可是中国第一、亚洲第一、世界第三高的广播电视塔。塔的结构很有讲究：3根直径9米的擎天立柱斜撑着整个塔身，中间串起11个球体。据设计者介绍，这组球体的创意，取自白居易《琵琶行》里"大珠小珠落玉盘"的意境——这是唐诗里的句子，被工程师用钢结构译成了现代建筑的诗。

我们乘电梯上行。第一个重点是263米的主观光层，这里是俯瞰上海的最佳高度：往西看，外滩52幢不同风格的历史建筑一字排开；往东看，陆家嘴的摩天楼群层层叠叠。再往上，259米的上球体是室外观光廊，脚下是玻璃，胆大的朋友可以试试。350米的太空舱是整座塔的最高观景点，站在那儿，黄浦江像一条弯曲的银带。还有一个特别的地方——267米的旋转餐厅，转一圈大约一小时，可以边吃边看。

下到地面，别忘了看塔基里的上海城市历史发展陈列馆，从开埠时的沙船、老电车到石库门，上海一百多年的变迁都在里面。

最后提醒各位：高空观光层风大温差大，请带件外套；拍照时注意脚下，贵重物品随身。祝大家在东方明珠看得尽兴，拍得开心！

**【讲解要点提示】**
- 必讲：468米总高、1994年建成、11球"大珠小珠落玉盘"的设计意象、263米主观光层的双向视野（外滩／陆家嘴）。
- 数据锚点：总高468米；1991年动工、1994年11月开放；3根直径9米立柱；259米／263米／267米／350米四个标高。
- 常见误区：东方明珠不是"上海第一高楼"（周边有更高的上海中心、环球金融中心等）；它也不是单纯的电视塔，早期确承担广播电视发射功能，现已以旅游观光为主。
- 互动/提问设计：请游客数一数塔身有几个球体；对照江对岸找外滩海关大楼钟楼。

### 2. 上海野生动物园

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 上海市浦东新区宣桥镇南六公路178号 |
| 类型 | 主题乐园 · 森林草原 |
| 评定年份 | 2007 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

上海野生动物园位于浦东新区宣桥镇南六公路178号，1995年11月18日建成开放，占地面积约153公顷，是中国首座国家级野生动物园，2007年获评国家5A级旅游景区。园区分为车入区与步行区两大板块：车入区模拟非洲草原与亚洲丛林环境，分区放养狮、虎、熊、狼等食肉动物以及长颈鹿、斑马、羚羊等食草动物；步行区设有大熊猫馆、金丝猴馆、狐猴岛、长颈鹿互动区等。园内饲养展出国内外珍稀野生动物200余种、上万头（只），是特大城市近郊重要的野生动物迁地保护、科普教育与休闲游览基地。

**【导游词核心稿】**

各位游客，欢迎来到上海野生动物园！这座园子1995年11月18日开门迎客，占地约153公顷，是中国第一座国家级野生动物园。我们的游程分两段：先坐游览车进"车入区"，再步行逛"步行区"。

车入区是这里的招牌。游览车会依次穿过食草动物放养区和猛兽放养区。在食草区，长颈鹿、斑马、羚羊就在车边散步；进入猛兽区，狮、虎、熊、狼按种群分区放养，各具领地。请大家务必全程关好车窗、不要伸手投喂——这是硬规矩，既为您的安全，也为动物的健康。

步行区是细看的地方。最受欢迎的是大熊猫馆。据史料记载，1869年法国传教士阿尔芒·戴维在四川宝兴发现大熊猫，并把标本带回欧洲，世界才知道这种中国特有的"活化石"；中国古代文献里称它为"貔貅""食铁兽"。今天，大熊猫已是中国的国宝和世界自然保护的旗舰物种。此外，金丝猴、狐猴、火烈鸟、长颈鹿互动平台都很适合亲子家庭。

园区饲养展出的动物超过200种、上万头（只）。大家看的时候可以留意一个细节：每种动物的展区都不是简单的"铁笼"，而是模拟它们原产地的植被、岩石和水源——这叫"丰容"，是现代动物园让动物保持自然行为的重要方法。

最后提醒：园内步行路线较长，建议穿舒适的鞋；投喂、挑逗动物一律禁止；看管好小朋友。祝大家在上海野生动物园度过愉快的一天！

**【讲解要点提示】**
- 必讲：1995年11月18日开园、153公顷、中国首座国家级野生动物园；车入区与步行区的两段式游线。
- 数据锚点：1995年开园；占地约153公顷；展出动物200余种、上万头（只）；2007年获评5A。
- 常见误区：这不是"动物园＋马戏表演"的传统模式，动物行为展示不等同于驯兽表演；车入区严禁开窗投喂。
- 互动/提问设计：让小朋友猜长颈鹿一天睡多久（通常很短、分段打盹）；观察不同动物的"丰容"设施有什么不同。

### 3. 上海科技馆

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2010年评定） |
| 所在地 | 上海市浦东新区世纪大道2000号 |
| 类型 | 博物馆场馆 |
| 评定年份 | 2010 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

上海科技馆位于浦东新区世纪大道2000号，2001年12月18日对外开放，占地面积6.8万平方米，建筑面积9.8万平方米，是上海投资兴建的大型综合性科普场馆，2010年获评国家5A级旅游景区。馆内设有生物万象、地壳探秘、智慧之光、设计师摇篮、机器人世界、信息时代、宇航天地、人与健康、彩虹儿童乐园等常设展区，并建有巨幕、球幕、四维与太空数字等特色影院。上海科技馆以"自然·人·科技"为主题，集展示、教育、研究、交流于一体，是全国科普教育基地，也是上海科技节与各类科普活动的主要举办场所。

**【导游词核心稿】**

各位朋友，欢迎来到上海科技馆。我们的位置在浦东新区世纪大道2000号，正对着世纪广场。这座馆2001年12月18日开馆，占地6.8万平方米、建筑面积9.8万平方米，2010年被评为国家5A级旅游景区——这在科技类场馆里是不多见的。

馆的主题只有六个字："自然·人·科技"。怎么理解？简单说，就是从认识自然开始，认识我们自己，再认识我们造出来的技术。所以最推荐的第一站是"生物万象"：它把热带雨林的植被、水系、动物搬进了室内，一进门就能听见水声、闻到湿土味。第二站"地壳探秘"，可以直观看到地球内部结构和板块运动，还能感受地震模拟。第三站"智慧之光""机器人世界"，是动手的地方，很多展项可以亲自操作——建议大家别急着往前走，在一两个展项上多待五分钟，收获比走马观花大得多。带孩子的朋友别忘了"彩虹儿童乐园"。

还有一个特别的去处：馆里有巨幕、球幕、四维和太空数字影院，球幕影院躺着看星空，是馆内的招牌体验。

说到科技，我们中国人并不陌生。据史料记载，明代科学家宋应星在崇祯十年（1637年）刊行《天工开物》，把当时农业、手工业的各项技术一一记录，被后人称为"中国17世纪的工艺百科全书"——从《天工开物》到今天的机器人，是一条不断续写的线。

最后提醒：馆内展区面积大，建议先看导览图定路线；影院场次固定，请提前确认时间；节假日人多，出行前请核实预约与开放安排。好，我们进馆吧！

**【讲解要点提示】**
- 必讲："自然·人·科技"主题；生物万象、地壳探秘、机器人世界三大展区；四大特色影院。
- 数据锚点：2001年12月18日开馆；占地6.8万平方米、建筑面积9.8万平方米；2010年获评5A。
- 常见误区：不要说成"上海自然博物馆"（那是静安区的另一座场馆）；不要承诺影院场次与票种，出行前请核实。
- 互动/提问设计：在"地壳探秘"问游客地球内部最厚的一层是什么；在"机器人世界"请游客猜机器人如何识别人脸。

### 4. 中国共产党一大·二大·四大纪念馆景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2021年评定） |
| 所在地 | 上海市黄浦区（一大会址）、静安区（二大会址）、虹口区（四大纪念馆） |
| 类型 | 红色旅游 · 博物馆场馆 |
| 评定年份 | 2021 |
| 建议游览时长 | 3-4 小时（三处联游） |

**【景区简介】**

中国共产党一大·二大·四大纪念馆景区由三处革命旧址纪念场馆组成，2021年获评国家5A级旅游景区。中共一大会址纪念馆位于黄浦区兴业路76号（原望志路106号），1921年7月23日，中国共产党第一次全国代表大会在此召开，宣告中国共产党成立；纪念馆新馆于2021年落成开放。中共二大会址纪念馆位于静安区老成都北路7弄30号，1922年7月党的二大在此召开，通过党的第一部党章。中共四大纪念馆位于虹口区四川北路1468号，1925年1月党的四大在此召开。三处会址共同构成上海作为中国共产党诞生地与初心始发地的核心红色地标群。

**【导游词核心稿】**

各位游客朋友们，大家好。我们今天要走的是上海最有分量的一条红色线路——中国共产党一大、二大、四大纪念馆景区。这三处，串联起党诞生最初四年的关键节点。

第一站，黄浦区兴业路76号。这里是一大会址，1921年7月23日，中国共产党第一次全国代表大会就在这幢石库门房子里召开。据史料记载，出席大会的代表共13位，平均年龄28岁，他们代表着当时全国50多名党员。会议在这间十几平方米的客厅里进行，中途因遭到法租界巡捕的搜查而被迫转移，最后一天在嘉兴南湖的游船上闭幕。中国共产党，就这样诞生了。

第二站，静安区老成都北路7弄30号，党的二大会址。1922年7月，二大在这里召开，通过了党的第一部党章，第一次提出了彻底的反帝反封建的民主革命纲领。如果说一大是"立党"，二大就是"立规"。

第三站，虹口区四川北路1468号，党的四大纪念馆。1925年1月，四大在这里召开，明确提出了无产阶级在民主革命中的领导权问题和工农联盟问题，为随后的大革命高潮作了准备。

说到思想的传播，还有一段不能跳过：据史料记载，1920年8月，陈望道翻译的《共产党宣言》第一个中文全译本在上海出版。"一个幽灵，共产主义的幽灵……"——从此，这本书有了中文的声音。

最后提醒各位：纪念馆为庄严肃穆场所，请轻声缓行、不追逐打闹；拍照请遵守馆内指示；三处相距较远，请预留交通时间，出行前请核实开放与预约要求。

**【讲解要点提示】**
- 必讲：一大于1921年7月23日召开、党由此成立；二大通过第一部党章；四大提出革命领导权与工农联盟。
- 数据锚点：1921年7月23日；13位代表、平均年龄28岁、全国50多名党员；1922年二大、1925年四大；2021年获评5A。
- 常见误区：不要把"一大会址"与"一大纪念馆新馆"混为同一建筑（新馆在会址旁）；不要把南湖闭幕说成在南湖召开全程会议。
- 互动/提问设计：请游客算一算13位代表平均年龄对应的今天的自己；请找一找石库门门楣与窗棂的细节。

### 5. 崇明西沙明珠湖景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年评定） |
| 所在地 | 上海市崇明区三华公路333号（崇明岛西南端） |
| 类型 | 水域湖泊 |
| 评定年份 | 2024 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

崇明西沙明珠湖景区位于上海市崇明区崇明岛西南端，由明珠湖与西沙湿地两大片区组成，2024年2月被文化和旅游部确定为国家5A级旅游景区。明珠湖是崇明岛最大的天然淡水湖，湖面开阔，环湖林木成带；西沙湿地位于长江入海口，是长江口典型的潮滩湿地，芦苇荡连片，潮汐沟发育完整。景区地处东亚—澳大利西亚候鸟迁徙通道，记录鸟类百余种，是震旦鸦雀等珍稀鸟类的重要栖息地，周边水域亦可见长江江豚等水生动物。作为崇明世界级生态岛建设的核心展示窗口，景区以"湖、湿地、林、鸟"为特色，是上海重要的生态研学与休闲目的地。

**【导游词核心稿】**

各位游客，欢迎来到崇明西沙明珠湖景区——上海第五家、也是最年轻的国家5A级景区，2024年2月正式获评。我们所在的位置，是崇明岛的西南端，长江入海的地方。

整个景区由两片组成：一片是明珠湖，一片是西沙湿地。先说明珠湖。它是崇明岛上最大的天然淡水湖，湖面开阔、水质清澈，环湖有大片林地，湖光和林色叠在一起，是崇明最耐看的一幅画。

再看西沙湿地。这里是长江口典型的潮滩湿地，大片的芦苇荡随江风起伏，潮水一天两次涨落，把滩面冲刷出密密麻麻的潮汐沟，像大地的血管。请大家留意脚下木栈道两侧的螃蟹和弹涂鱼——它们就是这片湿地的主人。景区处在东亚—澳大利西亚候鸟迁徙通道上，记录鸟类百余种，其中最值得一提的是震旦鸦雀，这种小鸟对芦苇荡的依赖极强，被视作湿地健康的"指示物种"。运气好的话，还能在江面看到长江江豚。

说到崇明岛，还有一段来历可讲。据史料记载，崇明岛是长江泥沙历经千年淤积而成的冲积岛，唐代初期沙洲渐次出水，唐神龙元年（705年）设"崇明镇"，这个名字一直用到今天。换句话说，我们脚下这片土地，是长江用了一千多年一点点堆出来的。

最后提醒：湿地栈道湿滑，请慢行；观鸟请保持距离、不使用闪光灯、不投喂；崇明距市区较远，请预留往返时间，出行前请核实开放时间与交通班次。祝大家在江海交汇处，看得见风，也看得见鸟。

**【讲解要点提示】**
- 必讲：明珠湖（崇明岛最大天然淡水湖）与西沙湿地（长江口潮滩湿地）双片区；2024年2月获评5A；候鸟迁徙通道。
- 数据锚点：2024年2月确定为国家5A；记录鸟类百余种；唐神龙元年（705年）设崇明镇。
- 常见误区：不要把明珠湖说成"人工水库"（表述以"天然淡水湖"为准）；不要把西沙湿地与崇明东滩湿地混为一谈，二者分处崇明岛西、东两端。
- 互动/提问设计：请游客观察潮汐沟的走向，猜潮水一天涨落几次；请找震旦鸦雀的栖息环境（芦苇荡）。

## 三、待核实与补充事项

- **上海是否新增第6家5A**：截至本文件核对时（2026-10），文化与旅游部及上海市文旅部门公开口径均为5家（东方明珠、野生动物园、科技馆、一大·二大·四大纪念馆景区、崇明西沙明珠湖景区）。2024年12月文旅部确定的19家5A名单中无上海景区。若后续有新批次公布，需同步增补词条。
- **中共一大·二大·四大纪念馆景区的"所在地"**：本文件按三处馆址分列黄浦、静安、虹口三区；5A公示口径为上海市级景区，若需单一行政区划表述，以官方公示为准。
- **东方明珠广播电视塔的高度表述**：不同资料分别使用"总高468米"与"塔高468米"，本文件统一采用"总高468米"。建成时间亦有"1994年11月18日落成"与"1995年5月正式启用"两说，本文件采用1994年建成。
- **上海野生动物园占地面积**：公开资料多为"约153公顷"，另有"2300余亩"表述，二者接近；如需精确数字请以景区官方公布为准。
- **上海科技馆展区设置**：常设展区名称与数量近年有调整，本文件所列展区名称为较通行版本，讲解前请核对馆内最新导览图。
- **崇明西沙明珠湖景区的面积与鸟类数据**：明珠湖水面面积、西沙湿地面积、"记录鸟类百余种"等数据来源于公开报道与景区宣传口径，精度不足，正式讲解前建议向景区核实。
- **4A名录第68、69条（上海薰衣草公园、上海笔墨宫坊景区）**：名称来自公开名录，所在区县未能确认，已在表中标注"待核实"。
