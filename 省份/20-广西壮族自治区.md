### 1. 桂林漓江风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 桂林市（灵川县—阳朔县） |
| 类型 | 水域湖泊 · 山岳峰林 |
| 评定年份 | 2007 |
| 建议游览时长 | 1 天 |

**【景区简介】**

桂林漓江风景区位于广西壮族自治区东北部，2007年被评为首批国家5A级旅游景区，是1982年国务院首批公布的国家重点风景名胜区之一。漓江属珠江流域西江水系，发源于华南第一峰猫儿山，猫儿山主峰海拔2141.5米。漓江干流自桂林城区至阳朔段水程约83公里，是漓江风光的精华所在，沿岸喀斯特峰林拔地而起，江流蜿蜒于群峰之间，形成"山青、水秀、洞奇、石美"的典型景观。主要景点包括象鼻山、九马画山、黄布倒影、螺丝山、杨堤、浪石、兴坪等，其中兴坪一带的山水画面被选为第五套人民币20元券背面图案。南宋嘉泰年间，时任提点广西刑狱的王正功在桂林作《劝驾诗》，留下"桂林山水甲天下"之句，这是该名句目前所见最早的出处。

**【导游词核心稿】**

各位游客朋友，大家好！欢迎来到桂林漓江。2007年，漓江被评为首批国家5A级旅游景区；而在1982年，它就是国务院首批公布的国家重点风景名胜区之一。

先请大家看一眼水。漓江的水来自哪里？来自华南第一峰猫儿山——主峰海拔2141.5米，那里的一片森林涵养出这条江。江水一路南下，流到桂林、阳朔这一带，恰恰遇上大片喀斯特峰林，山与水一相逢，才有了我们眼前的画面。

今天我们走的是桂林到阳朔这一段，水程约83公里，这是整条漓江的精华。这一段有几个必看的点：一是九马画山，崖壁上天然纹理形似群马，民间有"看出七匹中榜眼，看出九匹状元郎"的说法；二是黄布倒影，江面平缓如镜，山峰倒影清晰得像是复制了一遍；三是兴坪——大家拿出一张20元人民币看看背面，那幅山水图，取的就是兴坪这一段。

说到"桂林山水甲天下"这句话，很多人不知道它的出处。据史料记载，南宋嘉泰年间，在桂林为官的王正功写了一首《劝驾诗》，诗里就有这句。八个字，为桂林做了八百年的广告。

等船靠岸，请大家带好随身物品，注意脚下湿滑。祝大家一路青山绿水！

**【讲解要点提示】**
- 必讲：2007年首批5A与1982年首批国家重点风景名胜区；猫儿山—漓江—峰林的水系与地貌关系；兴坪与20元人民币图案。
- 数据锚点：猫儿山主峰海拔2141.5米；桂林至阳朔水程约83公里；南宋嘉泰年间王正功《劝驾诗》。
- 常见误区：漓江精华段是桂林至阳朔，不是整条漓江；"桂林山水甲天下"出自南宋王正功诗，而非民间俗语。
- 互动/提问设计：数一数九马画山上有几匹马，再讲"看马"的民间说法；请游客对照20元人民币找一找实景角度。

### 2. 桂林独秀峰·靖江王城景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 桂林市秀峰区 |
| 类型 | 古城古镇 · 遗址考古 |
| 评定年份 | 2012 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

桂林独秀峰·靖江王城景区位于桂林市秀峰区，2012年被评为国家5A级旅游景区。景区以明代靖江王府城垣与独秀峰为主体。靖江王城始建于明洪武五年（1372年），是明朝分封在桂林的靖江王的府第，先后有14位靖江王在此就藩，历时280余年，是明代修建时间较早、保存较为完整的王府城垣之一。王城内原有承运殿、寝宫等建筑，现存城墙、城门、台基与部分明代石构件，靖江王府及王陵为全国重点文物保护单位。王城北面的独秀峰拔地而起，孤峰独立，海拔216米，有"南天一柱"之称，山麓有读书岩、太平岩等岩洞。南宋嘉泰元年（1201年），王正功在读书岩上方题刻《劝驾诗》，"桂林山水甲天下"一句即出于此，题刻今存于独秀峰。

**【导游词核心稿】**

各位游客，大家好！欢迎来到桂林独秀峰·靖江王城景区。2012年，这里被评为国家5A级旅游景区。它有一个很特别之处：这是桂林城里的一座"城中之城"。

先看这座城。靖江王城始建于明洪武五年，也就是1372年，是明朝分封在桂林的靖江王的府第。先后有14位靖江王在这里就藩，前后延续了280余年——一座王府，几乎与一个王朝的半部历史同寿。王城内原有承运殿、寝宫等建筑，今天我们还能看到城墙、城门和大殿台基，靖江王府及王陵已被列为全国重点文物保护单位。

再看这座山。独秀峰孤峰独立，海拔216米，古人称它"南天一柱"。它为什么叫"独秀"？因为周围全是平地，唯独它拔地而起，没有同伴。

而这个景区最值钱的一块石头，就在山脚。南宋嘉泰元年，也就是1201年，在桂林为官的王正功在这里的读书岩上方题了一首诗，诗里有这么一句——"桂林山水甲天下"。这八个字，八百多年来一直挂在桂林的名片上，而它的原刻，就在我们眼前。

提醒大家：登山台阶较陡，请量力而行；摩崖石刻属文物，请勿触摸。祝大家读一段桂林的旧时光！

**【讲解要点提示】**
- 必讲：明洪武五年（1372年）始建；14位靖江王、历时280余年；独秀峰读书岩与"桂林山水甲天下"题刻。
- 数据锚点：1372年始建；14位靖江王、280余年；独秀峰海拔216米；南宋嘉泰元年（1201年）题刻。
- 常见误区：独秀峰海拔216米是相对独立的孤峰，不要与桂林周边喀斯特峰林混谈成因；"桂林山水甲天下"题刻在独秀峰读书岩，不在其他景区。
- 互动/提问设计：请游客找一找"南天一柱"摩崖，再引出独秀峰孤峰地貌与周边峰林的对比。

### 3. 南宁青秀山旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2014年评定） |
| 所在地 | 南宁市青秀区 |
| 类型 | 森林草原 · 山岳峰林 |
| 评定年份 | 2014 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**

南宁青秀山旅游区位于南宁市青秀区邕江畔，2014年被评为国家5A级旅游景区。青秀山古称"青山"，山势起伏、林木葱茏，是南宁城区重要的生态绿地与市民休闲空间，南宁也因此素有"绿城"之称。景区主要景点包括明代龙象塔、苏铁园、兰园、雨林大观、凤凰岭、状元泉、董泉、撷青野崖等。龙象塔为明代万历年间所建的九层八角楼阁式砖塔，历经兴废，现塔为后世重建，是青秀山的标志性建筑。苏铁园收集栽培多种苏铁类珍稀植物，兰园集中展示各类兰花。景区植被以南亚热带常绿阔叶林与人工林为主，四季常青，登高可俯瞰邕江两岸城市景观。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到南宁青秀山。2014年，这里被评为国家5A级旅游景区。

南宁有个外号叫"绿城"，为什么？因为这座城市四季常青、满眼是绿，而青秀山，就是这"绿"里最浓的一笔。

青秀山古称"青山"，紧挨着邕江，山势起伏，林子密得几乎不透阳光。我们今天的路线大致是：先看塔，再看园，最后登高处看江。

先说塔。山上的龙象塔是明代万历年间建的，一座九层八角的楼阁式砖塔。它几经兴废，现在我们看到的塔是后世重建的，但塔的位置和形制延续了老样子。九层八角，在中国古塔里是很经典的形制——八卦方位配九重天数，古人建塔是有讲究的。

再说园。山里有苏铁园和兰园。苏铁是与恐龙同时代的古老植物，今天野生的苏铁已经非常稀少，园里集中栽培了多种苏铁类植物，算是给这些"活化石"安了个家。兰园则是另一番清雅，喜欢兰花的朋友可以在这里慢慢看。

最后我们上山脊，视野一打开，邕江蜿蜒、城市楼群就在脚下——那时候您就会明白，为什么南宁人把这座山当成了自家的后花园。

提醒：山路有坡度，建议穿舒适鞋子；夏季蚊虫较多，可备驱蚊用品。祝大家满目青翠！

**【讲解要点提示】**
- 必讲：2014年5A身份；南宁"绿城"与青秀山的关系；明代龙象塔（九层八角）。
- 数据锚点：龙象塔九层八角形制、明代万历年间始建；2014年获评5A。
- 常见误区：现存龙象塔为后世重建，不能说成"明代原物"；青秀山是城市山地型景区，不是远离市区的原始林区。
- 互动/提问设计：请游客说一说苏铁为什么被称为"活化石"，再引出苏铁的世代与保护等级。

### 4. 桂林两江四湖·象山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2017年评定） |
| 所在地 | 桂林市象山区 |
| 类型 | 水域湖泊 · 城市地标 |
| 评定年份 | 2017 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**

桂林两江四湖·象山景区位于桂林市象山区，2017年被评为国家5A级旅游景区。景区由"两江四湖"环城水系与象山（象鼻山）片区共同构成。"两江四湖"指漓江、桃花江两条江与杉湖、榕湖、桂湖、木龙湖四个湖连通形成的城市环城水系，是桂林市区核心的水上游览线路，游客可乘船穿行于城市腹地，观赏沿岸山体、桥梁、亭台与灯光夜景。象鼻山位于漓江与桃花江汇流处，因山形酷似一头巨象伸长鼻子吸水而得名，是桂林的城市象征与城徽。杉湖中的日月双塔为景区地标：日塔为9层铜塔，高41米；月塔为7层琉璃塔，高35米，两塔一高一低、一金一银，夜间灯火映于湖面，是环城水系上的经典画面。

**【导游词核心稿】**

各位游客，大家好！欢迎来到桂林两江四湖·象山景区。2017年，这里被评为国家5A级旅游景区。

这个景区其实由两部分组成：一部分是"水"，一部分是"山"。

先说"水"——两江四湖。两江指的是漓江和桃花江，四湖指的是杉湖、榕湖、桂湖和木龙湖。桂林把这几片水打通，连成一条环城水系，于是您可以坐着船，从城市的腹地穿过。这在别的地方不常见：多数城市的水是绕城的，而桂林的水是穿心的。白天游一遍是看景、看桥，晚上游一遍是看灯、看倒影，味道完全不同。

再说"山"——象鼻山。它就立在漓江和桃花江汇流的地方，山形像一头巨象把长长的鼻子伸进水里吸水。这座山是桂林的城徽，城市宣传画上出现的，多半就是它。

还有一处务必看：杉湖里的日月双塔。日塔是9层铜塔，高41米；月塔是7层琉璃塔，高35米。一金一银，一高一低，晚上灯光一亮，塔影和湖光叠在一起，是这条水线上最出片的一幕。

提醒：夜游航班受季节与水位影响，出行前请核实班次与开放安排；船上请勿站立走动。祝大家水上看山、山上看城！

**【讲解要点提示】**
- 必讲：两江四湖的构成（漓江、桃花江、杉湖、榕湖、桂湖、木龙湖）；象鼻山为桂林城徽；日月双塔。
- 数据锚点：日塔9层41米、月塔7层35米；2017年获评5A。
- 常见误区：两江四湖是环城水系游览项目，不等于"漓江精华段"的桂林—阳朔航线，两者是不同的游线产品。
- 互动/提问设计：请游客在象鼻山前指认"象鼻"与"象腿"的位置，再讲水月洞与倒影成"象饮水"的成因。

### 5. 崇左德天跨国瀑布景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2018年评定） |
| 所在地 | 崇左市大新县 |
| 类型 | 水域湖泊 |
| 评定年份 | 2018 |
| 建议游览时长 | 5-7 小时 |

**【景区简介】**

崇左德天跨国瀑布景区位于广西壮族自治区崇左市大新县硕龙镇，2018年被评为国家5A级旅游景区。德天瀑布地处中越边境的归春河上，与越南一侧的板约瀑布相连，是亚洲第一大跨国瀑布，也是世界著名的跨国瀑布之一。瀑布宽约200米，落差约70米，分三级跌落，水量丰沛时气势磅礴，水雾弥漫，远在数百米外即可闻其声。景区内可乘竹筏近观瀑布，也可沿栈道登高俯瞰，并设有中越边境53号界碑等边境人文景观。归春河为中越界河，两岸为典型的喀斯特峰丛地貌，峰峦层叠、田园散布，瀑布与田园、界河共同构成边境特有的景观组合。

**【导游词核心稿】**

各位游客，大家好！欢迎来到崇左德天跨国瀑布。2018年，这里被评为国家5A级旅游景区。

请大家先站住，闭上眼听一听——您听到的水声，来自两个国家。德天瀑布就在中越边境的归春河上，河这边是中国的德天瀑布，河那边的越南一侧叫板约瀑布，两股水在丰水期甚至会连成一片。它是亚洲第一大跨国瀑布。

看数据：瀑布宽约200米，落差约70米，而且是分三级跌落。什么叫三级跌落？就是水流不是一口气砸下来的，而是分三段台阶往下跳，所以看起来层次分明，水雾一波接一波地往上翻。

我们的游览有两种方式：一是乘竹筏，从水面上靠近瀑布，那是最震撼的视角，水雾会打在脸上；二是沿栈道往上走，从高处俯瞰整片水域和界河两岸的峰丛。建议大家两种都体验。

这里还有一处特殊的人文景观：中越边境的53号界碑。它立在界河边上，一边是中国，一边是越南。站在这里，您能最直观地理解什么叫"跨国"——一道水，两个国家。

提醒：竹筏游览请全程穿好救生衣；边境地区请随身携带身份证件，遵守边境管理规定，不要越界。祝大家气势磅礴一路同行！

**【讲解要点提示】**
- 必讲：亚洲第一大跨国瀑布；与越南板约瀑布相连；三级跌落的水形特征；53号界碑。
- 数据锚点：宽约200米、落差约70米、三级跌落；2018年获评5A。
- 常见误区：德天瀑布在中越界河归春河上，不要说成"完全在中国境内"；枯水期水量变化大，观感与丰水期差别明显。
- 互动/提问设计：请游客分辨瀑布的三级跌落在哪几个位置，再讨论归春河作为界河的地理意义。

| 类型 | 红色旅游 · 博物馆场馆 |
| 评定年份 | 2019 |

**【景区简介】**

各位游客，大家好！欢迎登上涠洲岛，来到南湾鳄鱼山景区。2020年，这里被评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到柳州三江程阳八寨。2024年，这里被评为国家5A级旅游景区。

"八寨"是哪八寨？马鞍、平寨、岩寨、平坦、懂寨、程阳大寨、平铺、吉昌——八个侗族村寨连成一片，至今仍是活着的村落。

而这片村子的灵魂，是那座桥——程阳永济桥，也叫程阳风雨桥。请大家记住几个数字：始建于1912年，1924年建成；全长64.4米，宽3.4米，高10.6米；5个桥墩、4个桥孔，桥上建了5座亭子和长廊。

但最了不起的不是尺寸，是做法：整座桥不用一根铁钉，全靠榫卯咬合，木料之间互相"别"住，越压越紧。桥面上有廊、有亭，既能过人，又能遮风避雨，还能歇脚、聚会——所以叫"风雨桥"。1982年，它被列为第二批全国重点文物保护单位。

今天我们还会在寨子里看到鼓楼、吊脚木楼和织锦。请大家把脚步放慢，这里值得慢慢看。

### 10. 崇左花山岩画景区

崇左花山岩画景区位于广西壮族自治区崇左市宁明县，2024年被评为国家5A级旅游景区。景区是"左江花山岩画文化景观"的核心组成部分——该文化景观于2016年7月在土耳其伊斯坦布尔召开的第40届世界遗产大会上被列入《世界遗产名录》，是中国第一个岩画类世界文化遗产，也是广西壮族自治区的首项世界文化遗产。整个文化景观由分布在宁明、龙州、江州、扶绥境内的38个岩画点构成，涵盖左江及其支流明江河段长105公里，范围面积达6621.6公顷，由岩画、山崖、河流与台地共同组成带状景观。岩画以赭红色颜料绘制于临江崖壁之上，年代约为战国至东汉时期（约公元前5世纪至公元2世纪），据研究为骆越人所作，图像以双手上举、双腿叉开的蛙形人物为主，另有铜鼓、刀剑、动物等形象，多被认为与当时的大型祭祀活动有关。

**【导游词核心稿】**

各位游客，大家好！欢迎来到崇左花山岩画景区。2024年，这里被评为国家5A级旅游景区；而它更大的身份，来自2016年7月——在土耳其伊斯坦布尔召开的第40届世界遗产大会上，"左江花山岩画文化景观"被列入《世界遗产名录》。

请大家抬头看这片崖壁。两千多年前，有人用赭红色的颜料，在临江的绝壁上画下了这些图案。没有脚手架，没有吊篮，他们是怎么画上去的？至今仍是学界热议的话题。

先看画的是什么。最醒目的是人：双手向上举，两腿叉开，一个个排成队列，形状像青蛙。学者们一般把这些蛙形人物与当时的祭祀活动联系起来。除了人，还有铜鼓、刀剑、动物等图像——铜鼓在今天依然是壮族文化里最重要的符号之一。

再看是谁画的、什么时候画的。据研究，这些岩画的年代大约从战国延续到东汉，也就是公元前5世纪到公元2世纪，前后跨度约七百年；作画者是古代岭南的骆越人。

最后看它的分量：整个"左江花山岩画文化景观"由38个岩画点构成，涵盖105公里的河段，范围面积6621.6公顷。它是中国第一个岩画类世界遗产，也是广西的第一项世界文化遗产。

**【讲解要点提示】**
- 必讲：2016年7月第40届世界遗产大会列入名录；中国首个岩画类世界遗产、广西首项世界文化遗产；骆越人与蛙形人物图像。
- 数据锚点：38个岩画点、105公里河段、6621.6公顷；年代约公元前5世纪—公元2世纪；2024年获评5A。
- 常见误区：花山岩画是崖壁岩画而非洞穴壁画；"花山"在世界遗产名录中的正式名称是"左江花山岩画文化景观"，包含38个岩画点，不限于宁明一处。
- 互动/提问设计：请游客找一找崖壁上的铜鼓图像，讨论铜鼓在壮族文化中的象征意义，再引出岩画绘制方式之谜。

- **桂林乐满地度假世界（2007年评定）等级状态待核实**：该景区为广西早期5A景区之一，另有资料显示其已于近年被降低或取消质量等级（一份公开名录标注为"2025取消"，文化和旅游部2025年7月发布会亦通报"有1家国家5A级旅游景区被降低质量等级"）。**本文件暂未为其撰写词条**，具体状态请以文化和旅游部最新公告为准，待确认后补写。
  - **2026-10-12 复核**：复查文化和旅游部 2026 年 4 月 27 日、7 月 10 日两场例行新闻发布会，均**未公布**新的 5A 降级或摘牌名单（4 月发布会仅点名天门山—武陵源、丽江古城、玉龙雪山、黄河壶口瀑布、桂林漓江、嵩山少林寺、黄果树瀑布、武当山等"问题多发景区"要求限期整改，并称将"挂钩等级复核"）。故乐满地状态维持"待核实"，本期不作改动。
- **程阳八寨评定时间口径**：文旅部公示日期为2024年2月6日，本文件按2024年收录。
- **黄姚古镇评定时间口径**：文旅部公示日期为2022年7月15日，本文件按2022年收录。
