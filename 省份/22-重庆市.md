## 一、5A级景区（精编词条）

### 1. 大足石刻景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 重庆市大足区 |
| 类型 | 遗址考古 · 宗教圣地 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

大足石刻位于重庆市大足区境内，是区内全部摩崖造像的统称，始凿于初唐永徽年间（约公元650年），历晚唐、五代，鼎盛于两宋，延及明清，现存造像141处、5万余尊、铭文10万余字，以宝顶山、北山、南山、石门山、石篆山"五山"最为集中。宝顶山石刻由南宋僧人赵智凤于淳熙至淳祐年间（1174—1252）发愿营建，历时七十余年，规划统一、内容连贯，是中国石窟艺术晚期的巅峰之作。1999年12月，大足石刻被联合国教科文组织列入《世界遗产名录》，与敦煌、云冈、龙门并称中国四大石窟，也是世界上规模最大的石刻造像群之一。

**【导游词核心稿】**

各位游客，大家好！欢迎来到世界文化遗产——大足石刻。我们现在所在的位置，是大足石刻的精华所在：宝顶山大佛湾。

大足石刻不是一座山、一个洞，而是散布在大足境内141处摩崖造像的统称，现存造像5万余尊。它开凿于公元650年前后的初唐，鼎盛于两宋，是中国石窟艺术继云冈、龙门之后的第三次高峰，1999年正式列入《世界遗产名录》，也是重庆目前唯一的世界文化遗产。

请看眼前这道马蹄形的大佛湾，崖壁绵延约500米，高15到30米，造像近万尊，全部由南宋僧人赵智凤统一设计、分期开凿而成，前后历时七十余年，这在中国石窟中绝无仅有。

最重要的看点，是这尊千手观音。据史料记载并经2008年至2015年的抢救性修复工程逐手编号统计，宝顶山千手观音实有1007只手，每只手心都有一只眼睛。历时8年的修复，让它重新金碧辉煌。

再往前，是长达31米的释迦涅槃卧佛。请注意一个细节：佛身只刻出上半身，膝部以下隐入岩体，这种"意到笔不到"的处理，正是东方艺术的高明之处。旁边的六道轮回图直径2.7米，把佛教的因果观念刻成了一幅看得见的图画。

朋友们，大足石刻最动人的地方，在于它的世俗气息——父母恩重经变、牧牛图、地狱变相，讲的都是人间的道理。接下来请大家自由参观，注意不要触摸造像、不要使用闪光灯。

**【讲解要点提示】**

- 必讲：赵智凤与宝顶山统一规划；千手观音1007只手；1999年列入世界遗产。
- 数据锚点：141处造像点、5万余尊；赵智凤营建历时70余年；卧佛31米；六道轮回图直径2.7米。
- 常见误区：宝顶山与北山相距约15公里，不是同一处，团队行程务必分清；大足石刻不等于"乐山大佛"。
- 互动/提问设计：请游客猜千手观音到底有多少只手，再公布1007这个数字；问"卧佛为什么只刻半身"。
- 出行前请核实：门票、开放时间与景区交通车班次。

### 2. 巫山小三峡—小小三峡景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 重庆市巫山县 |
| 类型 | 水域湖泊 · 山岳峰林 |
| 评定年份 | 2007 |
| 建议游览时长 | 4-5 小时（含游船） |

**【景区简介】**

巫山小三峡—小小三峡景区位于重庆市巫山县境内，属长江三峡巫峡西口的大宁河水系，由龙门峡、巴雾峡、滴翠峡组成的"小三峡"与由三撑峡、秦王峡、长滩峡组成的"小小三峡"构成。小三峡为长江一级支流大宁河下游河段，全长约50公里；小小三峡位于大宁河支流马渡河上，全长约15公里，河道更窄、水色更碧，需换乘小艇游览。峡谷两岸峭壁千仞、竹木葱茏，保存有古栈道遗迹、悬棺与船棺，并栖息着野生猕猴群。景区1980年代起开发旅游，2007年成为首批国家5A级旅游景区之一，素有"不是三峡，胜似三峡"之誉。

**【导游词核心稿】**

各位朋友，大家好！欢迎登船游览巫山小三峡。我们现在从巫山古城码头出发，沿大宁河逆流而上。

先交代一下概况：小三峡由龙门峡、巴雾峡、滴翠峡三段峡谷组成，全长约50公里，是大宁河在巫山境内切穿巫山山脉形成的深切河谷。它1980年代对外开放，2007年成为首批国家5A级景区，是长江三峡黄金水道上最经典的支流产品。

第一段是龙门峡，长约3公里，两山对峙如门，是三峡中唯一一段"峡中有峡"的水道。峡口古有龙门桥，形势险要。

第二段是巴雾峡，长约10公里，这里最值得看的是崖壁上的悬棺和成排的方形石孔。据史料记载，这些石孔是秦汉以来大宁河古栈道的遗迹；悬棺则属古代巴人、濮人的崖葬习俗，距今已有两千余年。这一段常有猕猴出没，请大家不要投喂、不要惊扰。

第三段滴翠峡最长也最美，长约20公里，两岸竹木滴翠、飞瀑垂练，有"无限秀美在滴翠"之说。

到大昌古镇附近，还要换乘小舟进入小小三峡。那里是马渡河上的三撑峡、秦王峡、长滩峡，全长约15公里，水浅滩急，全靠船工撑篙前行，可以听见最原始的船工号子。

朋友们，接下来请大家在甲板上留意两侧的悬棺与栈道遗迹，注意安全，不要将身体探出护栏。

**【讲解要点提示】**

- 必讲：三段峡谷名称与顺序；悬棺与古栈道；换乘小艇游小小三峡。
- 数据锚点：小三峡全长约50公里；小小三峡约15公里；龙门峡约3公里、巴雾峡约10公里、滴翠峡约20公里；悬棺距今两千余年。
- 常见误区：小三峡在巫山县，与湖北巴东神农溪、长江主航道三峡不是同一条线路，购票前请确认行程。
- 互动/提问设计：请游客猜古人如何把棺木放到几十米高的崖壁上，再讲"悬棺之谜"。
- 出行前请核实：游船班次、枯水期/丰水期航线差异与是否需要换乘。

### 3. 武隆喀斯特旅游区（天生三桥·仙女山·芙蓉洞）

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 重庆市武隆区 |
| 类型 | 地质地貌 · 山岳峰林 · 森林草原 · 世界自然遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 1.5-2 天 |

**【景区简介】**

武隆喀斯特旅游区位于重庆市武隆区，地处乌江下游、大娄山与武陵山交汇地带，由天生三桥、仙女山、芙蓉洞三大核心片区组成，总面积逾400平方公里。区内喀斯特地貌类型齐全，集天生桥、天坑、地缝、溶洞、峰丛、草场于一体，2007年6月作为"中国南方喀斯特"第一批遗产地列入《世界自然遗产名录》。天生三桥由天龙桥、青龙桥、黑龙桥三座巨型天生石拱桥组成，是亚洲规模最大的天生桥群，其中青龙桥高约281米，为世界已发现最高的天生桥之一。芙蓉洞主洞长约2700米，以"珊瑚瑶池""巨幕飞瀑"等钟乳石景观闻名。仙女山为国家森林公园，平均海拔约1900米，林海与草场相间。

**【导游词核心稿】**

各位游客，大家好！欢迎来到世界自然遗产地——武隆喀斯特。接下来我们要游览的，是三个性格完全不同的地方：天生三桥、仙女山和芙蓉洞。

先说整体：武隆位于重庆东南部的乌江下游，2007年，武隆喀斯特与云南石林、贵州荔波一起，以"中国南方喀斯特"的名义列入《世界遗产名录》。世界遗产委员会的评价里有一句话很关键——这里是"世界上规模最大、最壮观的喀斯特地貌之一"。

第一站天生三桥。三座天生桥依次横跨在同一条峡谷之上，分别是天龙桥、青龙桥、黑龙桥。最高的青龙桥高约281米，跨度超过50米，站在桥下仰望，人渺小得像一粒沙子。这里还是电影《满城尽带黄金甲》和《变形金刚4》的取景地，那座藏在坑底的"天福官驿"，青瓦灰墙，如今成了游客最爱拍照的地方。

第二站仙女山。它平均海拔约1900米，是典型的高山台地，林海、草场、雪原三者兼具，夏天平均气温比主城低10摄氏度左右，冬天可以滑雪，因此有"东方瑞士"的说法。

第三站芙蓉洞。主洞长约2700米，洞内钟乳石种类之齐全，在国内洞穴中罕见。最绝的是"珊瑚瑶池"——一片由方解石晶花铺成的水池，看上去像海底珊瑚。

朋友们，武隆的看点在于"地下看洞、地上看桥、山上看草原"，一天半到两天比较从容。山区天气多变，请随身带一件外套。

**【讲解要点提示】**

- 必讲：2007年"中国南方喀斯特"申遗；三桥名称；天福官驿与影视取景。
- 数据锚点：青龙桥高约281米；芙蓉洞主洞长约2700米；仙女山平均海拔约1900米；总面积逾400平方公里。
- 常见误区：武隆喀斯特是"旅游区"，含三个不相邻的片区，仙女山镇是住宿集散地而非景区本身；不要与"芙蓉江"混为一谈。
- 互动/提问设计：问游客"天生桥是怎么形成的"，再讲地下水溶蚀与洞顶塌陷。
- 出行前请核实：各片区之间交通车时间、电梯与索道是否运营、冬季滑雪场开放期。

### 4. 酉阳桃花源旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 重庆市酉阳土家族苗族自治县 |
| 类型 | 古城古镇 · 地质地貌 · 民族风情 |
| 评定年份 | 2012 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

酉阳桃花源旅游景区位于重庆市酉阳土家族苗族自治县县城北郊，由大酉洞（桃花源）、秦晋农家（酉州古城）、伏羲洞、桃花源国家森林公园等片区组成，规划面积约50平方公里。景区以陶渊明《桃花源记》的意境为文化主题，所在地古属"武陵"，与文中"晋太元中，武陵人捕鱼为业"的地望相契合。大酉洞为天然石灰岩穿洞，洞内幽深狭窄，出洞后豁然开朗，有良田、美池、桑竹与土家吊脚楼人家，与文中"初极狭，才通人，复行数十步，豁然开朗"的描述高度吻合。伏羲洞为大型溶洞，已探明长度约3公里，石笋、石柱密集，被称为"地下桃花源"。景区于2012年获评国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到酉阳桃花源。接下来的这段路，我们要走一遍陶渊明笔下的那篇《桃花源记》。

先说概况：酉阳在重庆东南部，古属武陵郡，而《桃花源记》开篇第一句就是"晋太元中，武陵人捕鱼为业"，这正是本景区文化主题的由来。景区2012年成为国家5A级旅游景区，规划面积约50平方公里，核心是"一洞、一村、一谷"。

现在我们要穿过大酉洞。这是一条天然的石灰岩穿洞，请大家留意洞内的体验——初极狭，才通人。相传当年的渔人就是从这样的洞口进入的。出洞之后，眼前豁然开朗，土地平旷，屋舍俨然，有良田美池桑竹之属，这就是"秦晋农家"。

穿过村子，还有一处伏羲洞。它已探明长度约3公里，洞内石笋、石幔、石柱密布，最粗的石柱要几个人合抱，被称为"地下桃花源"。

酉阳是土家族、苗族聚居地。这里的吊脚楼、西兰卡普织锦、摆手舞和油茶汤，是活着的少数民族生活。据史料记载，酉阳土司制度延续数百年，至今还保留着不少土司文化遗迹。

朋友们，"世外桃源"之所以动人，是因为它寄托了人们对安宁生活的向往。走出桃花源，我们仍要回到现实，但希望这一段路能让你慢下来。请大家注意洞内湿滑，扶好台阶。

**【讲解要点提示】**

- 必讲：《桃花源记》原文与景区实景的对应；大酉洞"豁然开朗"的空间体验。
- 数据锚点：2012年获评5A；规划面积约50平方公里；伏羲洞已探明约3公里。
- 常见误区：全国有多处"桃花源"（湖南常德、江西庐山等），酉阳只是其中之一，讲解时不要断言"唯一正宗"。
- 互动/提问设计：请游客背诵《桃花源记》前两句；问"渔人为什么'不复得路'"。
- 出行前请核实：洞内开放段落与灯光秀场次。

### 5. 万盛黑山谷—石林景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 重庆市万盛经济技术开发区（綦江区） |
| 类型 | 地质地貌 · 森林草原 · 山岳峰林 |
| 评定年份 | 2012 |
| 建议游览时长 | 5-6 小时 |

**【景区简介】**

黑山谷—石林景区位于重庆市万盛经济技术开发区境内，由黑山谷与万盛石林（龙鳞石海）两大片区组成。黑山谷地处大娄山北麓，为典型深切峡谷，全长约13公里，谷深400至1000米，最高峰狮子槽海拔1973米，森林覆盖率达97%，保存银杉、珙桐、红豆杉等珍稀植物，有"渝黔生物基因库"之誉。万盛石林位于景区东部，是中国形成年代最古老的石林之一，其石灰岩形成于约4.6亿年前的奥陶纪，比云南路南石林早约2亿年，石芽、石笋、石峰密集，远望如龙鳞覆盖，故名"龙鳞石海"。景区2012年获评国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到万盛黑山谷和石林。今天我们走的是一条"看峡谷、看石头、看森林"的线路。

黑山谷属于大娄山北麓的深切峡谷，全长约13公里，谷深在400到1000米之间，最深处抬头只见一线天。这里森林覆盖率高达97%，负氧离子含量是主城区的几十倍，被称作"渝黔生物基因库"。区内保存着银杉、珙桐这些和恐龙同时代的孑遗植物，最高峰狮子槽海拔1973米。

走峡谷有个诀窍：看水、看石、看树。水是黑山谷的灵魂，溪流终年不断，落差大的地方形成多级跌水；石是江河亿万年切割的结果，河床上布满壶穴；树则是这里的"底气"，很多是胸径一米以上的原生林。

下午我们去看万盛石林。这里和云南石林不一样——它更老。据地质资料，万盛石林的石灰岩形成于约4.6亿年前的奥陶纪，比云南路南石林早了大约2亿年，是中国最古老的石林之一。远看这些石头像一片片龙鳞铺满山坡，所以叫"龙鳞石海"。

为什么古老反而更矮？因为形成年代早，经历了更长时间的风化剥蚀。这一点，恰恰是它作为地质标本的价值所在。

朋友们，黑山谷步道较长，请大家量力而行，穿防滑鞋，带好饮水和雨具。

**【讲解要点提示】**

- 必讲：黑山谷"一线天"与高森林覆盖率；万盛石林的4.6亿年年龄。
- 数据锚点：峡谷全长约13公里；谷深400—1000米；狮子槽海拔1973米；石林形成于约4.6亿年前。

朋友们，四面山面积约213平方公里，景点分散，建议安排一天半。瀑布区水汽大、石阶湿滑，请大家慢行。

各位朋友，大家好！欢迎来到云阳龙缸。今天我们要看的，是地球上一处很"极端"的景观——一个巨大的天坑。

- 数据锚点：坑口最大直径约550米、深约335米；廊桥悬挑26.68米、海拔约1000米。

- 互动/提问设计：请游客估算天坑能装下多少栋高楼，再给出335米的数字。

白帝城·瞿塘峡景区位于重庆市奉节县东部、长江三峡西端入口处，由白帝城、瞿塘峡、夔门等核心资源组成。白帝城坐落于瞿塘峡口北岸的白帝山上，西汉末年公孙述据蜀时筑城，因传说城中一井常有白气升腾如白龙而得名；三国蜀汉章武三年（223年），刘备伐吴兵败后退守白帝城，在永安宫托孤于诸葛亮，使其名扬天下。瞿塘峡是长江三峡中最短、最险峻的一段，全长约8公里，两岸赤甲山、白盐山夹江对峙，形成气势磅礴的夔门，第五套人民币10元纸币背面即以此为图案。三峡工程蓄水后，白帝城由半岛变为四面环水的孤岛，经廊桥与岸相连。景区2022年获评国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到奉节白帝城·瞿塘峡。在长江三峡所有的景点里，这里的文化分量最重。

先讲一座城。白帝城在瞿塘峡口的白帝山上。据史料记载，西汉末年公孙述据蜀时在此筑城，传说城中一井常有白气升腾，形如白龙，他就自称"白帝"，城因此得名。真正让它家喻户晓的，是三国：公元223年，刘备伐吴兵败，退守白帝城永安宫，病重之际把儿子刘禅和蜀汉的国事托付给诸葛亮，这就是历史上著名的"白帝城托孤"。所以有句话叫"一座白帝城，半部三国史"。

再讲一道门。请大家拿出一张10元人民币，看背面的图案——那就是我们眼前的夔门。瞿塘峡全长只有约8公里，是三峡中最短的一段，却也最险。赤甲山、白盐山隔江对峙，江面最窄处不足百米，水急如箭，古人形容"西控巴渝收万壑，东连荆楚压群山"。

还要提醒一个变化：三峡工程蓄水后，水位抬升，白帝城从一座山间半岛变成了四面环水的小岛，现在靠一座廊桥与岸边相连。

朋友们，李白"朝辞白帝彩云间"、杜甫"无边落木萧萧下"，写的都是这里。接下来请大家自由参观，注意江边风大、台阶湿滑。

**【讲解要点提示】**

- 必讲：223年刘备永安宫托孤；10元人民币背面的夔门；三峡蓄水后白帝城成岛。
- 数据锚点：瞿塘峡全长约8公里；托孤发生于公元223年；西汉末公孙述筑城。
- 常见误区：白帝城不等于"白帝庙"，庙是后人为纪念公孙述、后又供奉刘备而建；李白"朝辞白帝"是顺流东下，方向与部分游客想象相反。
- 互动/提问设计：请游客背一句与白帝城有关的唐诗；问"为什么三峡以奉节为西端"。
- 出行前请核实：游船（瞿塘峡深度游）班次与水位季节变化。

### 12. 涪陵武陵山大裂谷景区

| 项目 | 内容 |

| 等级 | 5A（2024年评定） |

| 评定年份 | 2024 |

**【景区简介】**

武陵山大裂谷景区位于重庆市涪陵区东南约40公里的武陵山乡境内，地处武陵山系西北尾端、乌江下游东岸，2024年2月经文化和旅游部确定为国家5A级旅游景区，是重庆市第12家5A级景区，也是涪陵区第一家。景区创建面积约9平方公里，平均海拔约1300米，属典型的喀斯特地貌与构造裂隙峡谷。景区集山、峡、林、泉、瀑、崖、洞、潭、溪、坑、缝于一体，核心景观为一条狭长的地缝式裂谷，最窄处仅数米、两壁高逾300米，素有"中国第一动感峡谷"之誉。据调查，区内有野生植物2000余种、野生动物200余种，生态环境优良，是夏季避暑与地质科考兼具的目的地。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到涪陵武陵山大裂谷。这里是2024年2月才正式挂牌的重庆第12家5A级景区，也是涪陵的第一家。

"动感峡谷"是什么意思？我们进谷就知道了。武陵山地处武陵山系西北尾端、乌江下游东岸，平均海拔约1300米，创建面积约9平方公里。它的核心，是一条地壳运动撕开的地缝式裂谷。

请大家先抬头——两壁高逾300米，最窄的地方只有几米，抬头只见一线天；再低头——栈道贴着崖壁走，脚下是深不见底的缝隙和暗河，水流声从地底传上来。这种"上下夹击"的空间感，就是"动感"二字的来源。

地质上，这是典型的喀斯特：石灰岩被水溶蚀出裂隙，地壳抬升又把裂隙撕开，于是形成了天坑、地缝、暗河、溶洞这一整套组合。景区里山、峡、林、泉、瀑、崖、洞、潭、溪、坑、缝"十一景"齐全，在国内很少见。

生态也是这里的一张牌。据调查，区内有野生植物2000余种、野生动物200余种，夏天平均气温比主城低十几摄氏度，是川渝一带热门的避暑地。

朋友们，涪陵还有另一张名片——白涛街道的816工程遗址，是"三线建设"时期的巨型地下核工程，如今作为工业遗产开放。它与本景区同在涪陵，行程上可以联动，但属独立景区，出行前请核实联游安排。谷内栈道湿滑，请注意脚下。

**【讲解要点提示】**

- 必讲：地缝式裂谷的成因；"中国第一动感峡谷"；2024年2月获评。
- 数据锚点：平均海拔约1300米；创建面积约9平方公里；两壁高逾300米；植物2000余种、动物200余种。
- 常见误区：本景区与湖南张家界、贵州梵净山同属武陵山区但非同一处；816工程遗址是独立景区，不要说成"在裂谷景区内"。
- 互动/提问设计：让游客在窄处抬头看"一线天"，猜两壁间距与高度。
- 出行前请核实：栈道开放段落、索道与景交车运行情况。
