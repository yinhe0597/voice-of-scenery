## 一、5A级景区（精编词条）

### 1. 厦门鼓浪屿风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年首批评定） |
| 所在地 | 福建省厦门市思明区（鼓浪屿岛） |
| 类型 | 城市地标 · 世界文化遗产 · 古城古镇 |
| 评定年份 | 2007 |
| 建议游览时长 | 5–7 小时（建议住岛一晚） |

**【景区简介】**

鼓浪屿位于福建省厦门市思明区西南隅，与厦门市区隔鹭江相望，面积约1.88平方公里，素有"海上花园"之誉。鸦片战争后，先后有十余个国家在此设立领事馆，各国侨民与归国华侨在此营建住宅、学校、医院与教堂，形成中西合璧的"历史国际社区"风貌。岛上有日光岩、菽庄花园、皓月园、八卦楼等著名景观，并因历史上钢琴密度高、音乐人才辈出而被称为"钢琴之岛"。2017年7月8日，"鼓浪屿：历史国际社区"在第41届世界遗产大会上被联合国教科文组织列入《世界遗产名录》，成为中国第52项世界遗产。2007年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到鼓浪屿。先看一组数字：这座小岛面积只有1.88平方公里，绕岛走一圈不到8公里，但它同时挂着两块牌子——国家5A级旅游景区，以及世界文化遗产。

像鼓浪屿这样小的岛，为什么能成为世界遗产？答案不在某一栋房子，而在"社区"二字。1842年以后，厦门成为通商口岸，先后有十几个国家在这里设立领事馆，洋行、教堂、学校、医院随之而来；同时，大量下南洋谋生的华侨带着积蓄回乡置业。于是，一座小岛上，南洋的柱廊、欧式的拱窗、闽南的红砖和中国的庭院，被砌进了同一堵墙里。这种混血的风格，后来有个专门的名字叫"厦门装饰风格"。2017年7月8日，联合国教科文组织以"鼓浪屿：历史国际社区"的名义把它列入《世界遗产名录》——请注意这四个字：历史国际社区。世界遗产委员会看重的，恰恰是不同文化在同一座小岛上共处的那一段历史。

接下来我们看几处具体的看点。第一是日光岩，它是全岛制高点，海拔92.7米，明末清初郑成功曾在此操练水师，留下寨门、水操台等遗址，登顶可将厦门海峡尽收眼底。第二是菽庄花园，由台湾富商林尔嘉先生于1913年兴建，最妙的手法是"藏海"——进门先不见海，绕过一道矮墙，大海忽然铺面而来，这是中国园林里极高明的障景手法。第三是皓月园里临海的郑成功雕像和八卦楼里的管风琴，一个面向大海，一个藏着乐器。

最后说说音乐。鼓浪屿人家藏着钢琴的传统由来已久，岛上因此被称为"钢琴之岛"，出过殷承宗等一批音乐家。走在巷子里，你随时可能与一段琴声相遇——这是鼓浪屿最动人的部分。

轮渡班次与限流措施会随季节调整，出行前请务必核实官方公告；岛上无机动车，请穿舒适的鞋。祝各位在鼓浪屿，听得见琴声，也看得见历史。

**【讲解要点提示】**
- 必讲：世界遗产身份与"历史国际社区"的核心价值；中西合璧建筑成因；日光岩与郑成功史迹；菽庄花园"藏海"。
- 数据锚点：岛域面积约1.88平方公里；日光岩海拔92.7米；菽庄花园建于1913年；2017年7月8日列入《世界遗产名录》；2007年评定5A。
- 常见误区：不要把鼓浪屿归为"自然遗产"，它列入的是文化遗产；也不要因为世界遗产登录名称叫"历史国际社区"，就说岛上未曾设过租界——1902年《厦门鼓浪屿公共地界章程》签订后，鼓浪屿确曾沦为多国共管的公共租界（公共地界），"历史国际社区"是世遗对其文化价值的定性，二者并不矛盾。
- 互动/提问设计：请客人在街巷立面找一扇欧式窗配闽南红砖；登日光岩前让客人猜岛上最高点有多少米。
- 出行提示：轮渡实名与游客限流政策、景点联票及开放时间，出行前请核实官方公告。

### 2. 南平武夷山风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年首批评定） |
| 所在地 | 福建省南平市武夷山市 |
| 类型 | 山岳峰林 · 地质地貌 · 世界文化与自然双重遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 2–3 天 |

**【景区简介】**

武夷山风景名胜区位于福建省南平市武夷山市（原崇安县）南部，地处闽赣交界。主景区为典型的丹霞地貌，"碧水丹山"为其最大特征，九曲溪萦绕群峰之间，构成"曲曲山回转，峰峰水抱流"的独特景观。主景区著名景观有天游峰、玉女峰、大王峰、虎啸岩、水帘洞及九曲溪竹筏漂流等。武夷山文化积淀深厚：古闽越人在此留下距今3000多年的架壑船棺（悬棺）遗迹；南宋理学大家朱熹于淳熙十年（1183年）在此创建武夷精舍，讲学著书多年；九龙窠峡谷留存有大红袍母树数株，武夷岩茶（大红袍）制作技艺享誉中外。1982年被列为首批国家重点风景名胜区，1999年12月列入《世界遗产名录》，成为世界文化与自然双重遗产。

**【导游词核心稿】**

各位朋友，欢迎来到武夷山。请在心里先放下惯常的登山念头——武夷山不是一个靠高度取胜的地方，它的好，在于一场"水与石的合作"。

先看石。武夷山的山，是丹霞地貌，红色的砂砾岩沉积下来，再被地壳抬升、被流水切开，于是形成了一片顶平、身陡、麓缓的城堡状群峰。因为这些红砂石不易崩塌，才成就了今天我们看到的陡峭赤壁和狭窄的一线天。也正因为岩层中有裂缝，山体才能在雨后挂出一道道白练般的水帘。

再看水。九曲溪像一条碧绿的丝带在群峰之间绕了九个弯，溪水清澈见底。坐竹筏顺流而下，从星村到武夷宫，一路读着两岸的玉女峰、大王峰、架壑船棺缓缓过去——这是武夷山最经典的一段体验。给大家一个小提示：同一座山峰换个角度看，名字就换了。玉女峰从正面看亭亭玉立，绕到另一侧却像一位侧身回首的女子，所以当地人才说武夷山要"看"不要"爬"。

第三，要说说这里的"人文厚度"。三千多年前，古闽越人把船形棺木安放进悬崖缝隙，这就是著名的架壑船棺，是武夷山最神秘的一处历史遗存。八百多年前，南宋理学大家朱熹在五曲隐屏峰下创设武夷精舍，讲学著书，武夷山由此成为理学传播的一处重镇。而我最愿意推荐给大家的，是九龙窠峡谷里那几株大红袍母树——它们长在岩壁上，靠岩缝中的一点点水分和腐殖土存活。武夷岩茶讲究"岩骨花香"，讲的就是这种"石头里长出来的味道"。

山中最著名的一处攀登是天游峰，石阶陡、台阶多，但登顶后的那条九曲全景，十趟也值。请大家登山时穿防滑鞋，量力而行；竹筏漂流请全程穿救生衣。祝各位在武夷山，看得见丹山，也品得懂岩茶。

**【讲解要点提示】**
- 必讲：丹霞地貌与"碧水丹山"；九曲溪竹筏；架壑船棺（3000多年前）；朱熹与武夷精舍（1183年）；大红袍母树。
- 数据锚点：1999年12月列入世界文化与自然双遗产；1982年首批国家重点风景名胜区；朱熹1183年创武夷精舍；2007年评定5A。
- 常见误区：黄岗山（海拔2158米，华东最高峰）在武夷山国家公园范围而非主景区，不要把两者混为一谈；"大红袍是红茶"的说法也不对，它属乌龙茶（青茶）。
- 互动/提问设计：请客人在竹筏上给两岸山峰起名字；让客人闻干茶与冲泡后的盖香，猜辨识率最高的香型。
- 出行提示：竹筏班次需提前预订，天游峰、水帘洞等线路换乘安排，出行前请核实官方公告。

### 3. 三明泰宁风景旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 福建省三明市泰宁县 |
| 类型 | 地质地貌 · 水域湖泊 · 世界自然遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 2 天 |

**【景区简介】**

泰宁风景旅游区位于福建省三明市泰宁县，地处武夷山脉中段东南麓，是以丹霞地貌为主体、以湖泊溪流为骨架的综合性景区。泰宁丹霞是中国东南湿润区青年期丹霞地貌的典型代表，以"水上丹霞、峡谷大观、洞穴博物馆、古建名城"四大特色著称，主要景点包括金湖、寨下大峡谷、上清溪、尚书第明清建筑群、状元岩、猫儿山等。2010年8月1日，"中国丹霞"在第34届世界遗产大会上被列入《世界遗产名录》，泰宁为其中重要的组成部分之一。泰宁早在2005年即入选世界地质公园。2005年以前已被列为国家重点风景名胜区，2011年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到福建三明的泰宁。一句话概括这里的特色："丹霞落在水里。"中国丹霞很多，但像泰宁这样山与水分不开、坐在船上就能看完一整片丹霞群峰的地方，全国少见。

先讲它的世界名片。2010年8月1日，在巴西利亚召开的第34届世界遗产大会上，"中国丹霞"正式列入《世界遗产名录》，泰宁是其中的组成部分之一。为什么要选这一片？因为世界遗产委员会看中的，是湿润地区、青年期丹霞地貌的完整演化序列——简单说，这里的红色岩层正在被流水切割的"青春、壮年、老年"各个阶段，你都能在一县之内看到。这也是泰宁2005年就被联合国教科文组织列入世界地质公园的原因。

第一站推荐金湖。它是上世纪八十年代电站建设形成的人工湖，没想到却成就了最好的丹霞水景。坐船穿行湖面，两岸是赤壁赤壁、峰丛、裂谷，水绕山转，山在水中立。湖畔甘露岩寺是最动人的一幕：它始建于南宋绍兴十六年（1146年），整座寺庙以一根粗柱支撑，藏在一个浅浅的岩穴里，上不着天、下不落地，人称"一柱插地，不施片瓦"，是中国建筑史上因地制宜的经典案例。

第二站推荐寨下大峡谷。这里被称为"世界地质公园样板景区"，一条峡谷里串起通天峡、倚天崖、天穹岩等景观，地质剖面清晰，最适合读懂"石头是被水一点点切开的"这句话。第三站可以安排上清溪漂流，水浅溪窄，两岸藤蔓垂拂，和坐大船游金湖完全是不同的味道。

最后别忘了城里的尚书第——明代天启年间兵部尚书的府第建筑群，规模宏大、工艺讲究，是这座小城历史厚度的证明。

游览请注意：雨后石阶湿滑，峡谷内请勿脱离步道。祝各位在泰宁，坐一趟船，读一部石头写成的教科书。

**【讲解要点提示】**
- 必讲："中国丹霞"世界自然遗产身份（2010年8月1日）；世界地质公园（2005年）；水上丹霞特色；甘露寺"一柱插地"。
- 数据锚点：2010年8月1日列入世界遗产；2005年入选世界地质公园；甘露岩寺始建于1146年；2011年评定5A。
- 常见误区：金湖是人工湖（电站水库）而非天然湖泊；泰宁只是"中国丹霞"六个遗产地之一，不是单独打包的项目。
- 互动/提问设计：请客人在岩壁上寻找水蚀留下的层理；让客人对比峡谷内外的温度差，聊聊"一线天"是怎么形成的。
- 出行提示：游船班次、峡谷开放与泄洪期安排，出行前请核实官方公告。

### 4. 福建土楼（永定·南靖）旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 福建省龙岩市永定区、漳州市南靖县 |
| 类型 | 古城古镇 · 民族风情 · 世界文化遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 2 天（两区各一天） |

**【景区简介】**

福建土楼（永定·南靖）旅游景区主要指分布于龙岩市永定区与漳州市南靖县的客家、闽南土楼群落，其中位于永定的洪坑土楼群、高北土楼群、初溪土楼群、衍香楼、振福楼，以及南靖的田螺坑土楼群、河坑土楼群、和贵楼、怀远楼，与华安大地土楼群一起，于2008年7月6日在第32届世界遗产大会上以"福建土楼"之名列入《世界遗产名录》。土楼多为夯土版筑而成的大型生土民居，或圆或方，高三至五层，集防御、居住、宗族祭祀功能于一体，具有"一楼一世界"的社会结构特点。代表建筑有被誉为"土楼之王"的承启楼、"土楼王子"振成楼、"四菜一汤"田螺坑土楼群与建在沼泽地上的和贵楼。2011年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到福建土楼。在开始看楼之前，请大家先抬头看它的材料：这里的墙，是土。不是简单的泥，而是加了石灰、红糖、糯米浆反复舂捣的"三合土"，再用木板作模层层夯筑——这就是所谓的"版筑"，却能撑起四五层高的大楼。

第一问：为什么要把房子修成这个样子？答案是为了防御。唐宋以来，中原汉人移民南下到此，与原住民争夺资源，山盗、野兽也多，于是整族几百口人缩在同一座堡垒般的楼里：外墙下几层不开窗，唯一的出入口包着铁皮、顶上设防火水槽，楼内还有水井、粮仓。最重要的三点由此而来：墙厚、窗少、内向封闭。

第二问：为什么圆楼居多？请看高北的承启楼：全楼由四道同心圆环套叠，鼎盛时住过的族人以百计。圆形不是审美偏好，而是安全考量：同样周长，圆形围出的面积最大；环形的结构比方形更能抵御地震和不均匀沉降；更重要的是，圆楼没有死角，敌人在环周任何一点，头顶都是同样多双眼睛。

再看人情味。土楼的内部是一个微型的宗法社会：向心的内院安放着祠堂、学堂、水井，每户占一小竖列，从底层灶间到顶层祖堂，垂直分割。清晨开门，全楼人从一个大门进出，谁家来了客人，全楼都知道。

最后，请大家记住两个名字：一个是"振成楼"，建于民国初年，中西合璧，庭院里还用了西式风格的构件，人称"土楼王子"；另一个是南靖的"和贵楼"，它建在沼泽地上，先打下密密麻麻的松木桩再起墙，两百多年依然坚实。

2008年7月6日，福建土楼列入《世界遗产名录》。世界遗产委员会的评价是：它是一种特殊的大型生土夯筑建筑艺术，展现了人与人之间和睦相处的典范。

请各位入楼后脚步放轻，这里的每一栋楼里都还住着人家。祝各位在土楼，读懂客家人如何用一堵土墙，装下整个家族。

**【讲解要点提示】**
- 必讲：2008年7月6日列入《世界遗产名录》；夯土版筑工艺；防御与宗族聚居易居功能；圆楼结构的力学合理性。
- 数据锚点：2008年列为世界遗产；承启楼四环同心布局、鼎盛时居住以百计；和贵楼建在沼泽之上；2011年评定5A。

### 5. 宁德屏南白水洋·鸳鸯溪旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 福建省宁德市屏南县 |
| 类型 | 水域湖泊 · 地质地貌 |
| 评定年份 | 2012 |
| 建议游览时长 | 1–2 天（两片区相距10余公里） |

**【景区简介】**

白水洋·鸳鸯溪旅游景区位于福建省宁德市屏南县境内，由白水洋与鸳鸯溪两大片区组成。白水洋的核心奇观是一片由整块火山岩构成的平坦浅水河床，规模宏大，号称"天下绝景"，这里既是天然的浅水嬉水区，也是火山岩"平台式河床"地貌的典型代表；鸳鸯溪则以深切峡谷、多级瀑布和茂密植被为主要景观，是鸳鸯、猕猴等野生动物的重要栖息地。2010年10月，宁德地质公园（含屏南白水洋、福安白云山、福鼎太姥山三大园区）入选联合国教科文组织世界地质公园网络。2012年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到屏南县白水洋。今天先看一处几乎不可思议的景观：请大家走到水边，最大的疑问一定是——水怎么这么浅、这么平？答案其实很简单：我们脚下不是河滩，而是一整块巨大的火山岩。这里在亿万年前曾是一处岩浆活动的地带，炽热的岩浆冷却后形成了一整片近水平的岩体；后来地表抬升，河流从这里经过，把这整块岩石磨成了一个巨大的"石床"。

于是就有了白水洋的奇观：水面宽展、水层极浅，最深也只到脚踝上下，河床平坦得几乎没有起伏。人可以直接走进水里，用水把自己"印"在这块巨大的岩石上。这种地貌在地质学上叫"平底型冲蚀河床"，是一个非常稀有的样本，也因为这样，宁德地质公园在2010年10月被联合国教科文组织列入世界地质公园网络。

到这里怎么玩？最好的方式是脱了鞋走一趟水面：赤脚踩下去，首先是滑，然后是脚底传来的微热——那是岩石吸收了阳光。请大家务必穿防滑袜、走稳、不要在雨后涨水时下水。

白水洋之外，屏南还有一处完全不同的风景，那就是鸳鸯溪。它是典型的火山岩深切峡谷，两岸是陡峭的岩壁，谷底是清澈的溪水，一路有多个瀑布群。因为人迹罕至、植被完好，这里成为野生鸳鸯的重要越冬栖息地，同时栖息着成群的猕猴。每年秋冬，都会有大批鸳鸯飞来这里过冬，屏南也因此被称为"鸳鸯之乡"。

请记住：这两处片区同在屏南县东北部，鸳鸯溪就在白水洋的下游，彼此相距不过10余公里，但一浅水、一深谷，玩法完全不同，若想两边都从容走完，建议安排两天。祝各位在白水洋，把脚印印在一块亿万年高龄的岩石上。

**【讲解要点提示】**
- 必讲：整块火山岩构成的平底浅水河床成因；2010年宁德地质公园入选世界地质公园；鸳鸯溪的生态价值。
- 数据锚点：2010年10月宁德地质公园入选世界地质公园；白水洋、鸳鸯溪两大片区；2012年评定5A。
- 常见误区：白水洋不是沙滩也不是滩涂，而是岩石河床；鸳鸯为国家二级重点保护野生动物，讲解请以官方保护级别为准。
- 互动/提问设计：请客人赤脚感受岩石温度并猜岩石类型；让客人在鸳鸯溪沿岸寻找哪些是野生猕猴的活动痕迹。
- 出行提示：涉水区开放受水位与季节影响，鸳鸯观鸟季亦有限制，出行前请核实官方公告。

### 6. 泉州清源山风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 福建省泉州市丰泽区 |
| 类型 | 宗教圣地 · 山岳峰林 · 遗址考古 |
| 评定年份 | 2012 |
| 建议游览时长 | 4–6 小时 |

**【景区简介】**

清源山风景名胜区位于福建省泉州市丰泽区北郊，又名齐云山、北山，海拔约六百余米，素有"闽海蓬莱第一山"之称。山中以历代宗教石刻尤其是老君岩造像最为著名——老君岩是我国现存最大的宋代道教石雕老子造像，1988年列为全国重点文物保护单位。山中弥陀岩、千手岩、瑞像岩、赐恩岩等摩崖造像与历代题刻并存，另有弘一法师舍利塔等近现代文化遗存。2021年7月25日，"泉州：宋元中国的世界海洋商贸中心"在第44届世界遗产大会上被列入《世界遗产名录》，共包含22处遗产要素，位于清源山的老君岩造像即为其中之一。1988年被列为国家重点风景名胜区，2012年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到泉州清源山。泉州人常说一句话："站着像东西塔，躺着像洛阳桥"，说的是这两处泉州地标；而我要送给大家的第三句是：走上清源山，一定要去看看"老子天下第一"。

先说这座山为什么重要。泉州在宋元时期是世界级的海洋商贸中心，被称为"东方第一大港"；各种宗教在这座城市并存共生，留下了今天列入《世界遗产名录》的22处遗产要素。而清源山，正是这些要素里最有分量的一处——2021年7月25日列入世界遗产的"泉州：宋元中国的世界海洋商贸中心"，其中就包含我们今天要去看的老君岩造像。

现在请大家顺着我的手指看向这块巨石。这就是老君岩，一整块天然的花岗岩被就地雕成一尊老子坐像。它是我国现存年代较早、体量最大的道教石雕造像之一，成于宋代，1988年被列为全国重点文物保护单位。请注意老人家的姿态：垂耳、含笑、微睁双眼，一副"无为而无不为"的样子。当地人给它取了个通俗的名字——"老子天下第一"，这话既是调侃，也是实至名归：因为论体量，它确实是道教石雕中的第一。

看完老君岩，山间还有几处值得停留：弥陀岩、千手岩等造像与摩崖题布满山道，历代文人踏访留题无数。其中最动人的一处是弘一法师舍利塔。弘一法师晚年多次驻锡闽南，1942年圆寂于泉州，留下"悲欣交集"四字绝笔，他的部分舍利安奉在这里。泉州这座城市的气质，由此可见一斑：做生意做到了全世界，回头却在山里供着一尊老子、送别一位高僧。

山路平缓，适合全家出行；清晨或雨后最宜登山。请留意保留体力，山顶一带视野开阔，可远眺泉州城与泉州湾。祝各位在清源山，读懂一座海港城市的另一面。

**【讲解要点提示】**
- 必讲：老君岩造像的宋代身份与1988年国保地位；2021年泉州世界遗产22处要素之一；弘一法师事迹。
- 数据锚点：2021年7月25日列入世界遗产；22处遗产要素；1988年列为全国重点文物保护单位；2012年评定5A。
- 常见误区：不要把清源山简单说成"道教名山"，它是儒释道多教并存的山地；"闽海蓬莱第一山"是美誉而非评级。
- 互动/提问设计：请客人从老君岩侧面看，判断它是"整石雕成"还是"拼接而成"；让客人猜泉州为何能容纳多种宗教共处。
- 出行提示：登山线路、夜爬规定、部分摩崖石刻封闭保护情况，出行前请核实官方公告。

### 7. 宁德福鼎太姥山旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 福建省宁德市福鼎市 |
| 类型 | 山岳峰林 · 宗教圣地 |
| 评定年份 | 2013 |
| 建议游览时长 | 1 天 |

**【景区简介】**

太姥山旅游区位于福建省宁德市福鼎市东南面，三面临海，一面靠山，主峰覆鼎峰海拔917米，以花岗岩峰丛、嶙峋奇石与转折幽深的裂隙洞穴为主要景观，素有"海上仙都"之誉。其核心特征为"峰险、石奇、洞幽、雾幻"四绝，山上还有大量由巨石堆叠形成的一线天、通天洞类的洞穴景观，被称为"山海大观"。山中人文历史悠久，唐乾符年间已建有大型寺院，历代摩崖石刻与寺观遗址分布于景区各处；民间将山中之神称为"太姥圣母"，太姥娘娘信仰流传至今。2010年10月，宁德地质公园入选联合国教科文组织世界地质公园网络，太姥山即为其三大园区之一。2013年评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到福鼎太姥山。太姥山有个很别致的说法："海上仙都"。这四个字里藏着它的地理密码——它就在海边，三面临海、一面靠山，山上的云雾常年从海上涌来，于是峰顶常常浮在云海里，真像神仙住的地方。

太姥山的山体是花岗岩。请大家注意看那些石头的表面：它们不像普通山体那样只有壁，而是有一道道横向的凹槽和圆滑的凹坑——这是因为花岗岩在地下深处形成时本就有节理，出露地表后被雨水和海风长期侵蚀，棱角被磨成了圆润的形状，地质学上叫"球形风化"。再进一步，岩石沿节理崩塌堆叠，巨石一块压着一块，中间便留出了无数可以钻行的缝隙和洞穴——这就是太姥山"洞幽"的由来。

现在，太姥山最好玩的恰恰是钻洞。这里的洞穴群规模很大，曲折相连，有的要低头，有的要侧身，有的顶端漏下一道阳光、一线青天。请大家跟着指示路牌走，别急于求快，慢一点反而更有趣。

第二要说"雾幻"。太姥山靠海，水汽充足，一日之内天气数变，前一刻还是青峰历历，下一刻雾就涌了上来，此时最能体会"云浮群峰、若隐若现"的意境。若是雨过天晴，站在覆鼎峰一带远眺，晴天可以看到远处的海面与海湾。

最后是人文。太姥山历史悠久，唐代乾符年间就已在此营建大型寺院，香火延续千年。民间称这座山的女神为"太姥圣母"，相传古时候有位罗城人? 那位避居此山的蓝氏贤妇采药治病、救人无数，被尊为"太姥"。这个故事在民间流传很久，讲解时请以"相传"区别。

2010年10月，太姥山作为宁德地质公园的重要组成部分，入选联合国教科文组织世界地质公园网络；2013年又被评定为国家5A级旅游景区。

请各位穿防滑鞋，雨后洞穴湿滑，洞穴内请打开手电。祝各位在太姥山，"进得去也得钻得出"。

**【讲解要点提示】**
- 必讲：花岗岩球状风化与崩塌洞穴成因；主峰覆鼎峰海拔917米；2010年入选宁德世界地质公园；"太姥"民间传说。
- 数据锚点：主峰海拔917米；2010年10月入选世界地质公园；2013年评定5A；唐代乾符年间已建寺。
- 常见误区：太姥山所说"海拔"指主峰覆鼎峰，不要把海岛或观测点数据混入；"太姥娘娘"属民间信仰传说，须注明"相传"。
- 互动/提问设计：请客人用手摸一块风化岩石判断山体是花岗岩还是石灰岩；在洞穴中关闭光源十秒钟，请客人感受方向感的丧失。
- 出行提示：洞穴开放与否随天气与安全情况调整，出行前请核实官方公告。

### 8. 福州三坊七巷景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2015年评定） |
| 所在地 | 福建省福州市鼓楼区 |
| 类型 | 古城古镇 · 城市地标 |
| 评定年份 | 2015 |
| 建议游览时长 | 3–5 小时 |

**【景区简介】**

三坊七巷位于福建省福州市鼓楼区中心的南后街两侧，由衣锦坊、文儒坊、光禄坊三个坊与杨桥巷、郎官巷、塔巷、黄巷、安民巷、宫巷、吉庇巷七条巷组成，是中国现存规模较大、保存较完整的明清城市里坊格局之一。这片街区的格局可上溯至晋唐，明清时期鼎盛，历代名人辈出，林则徐、沈葆桢、严复、林觉民、冰心、萨镇冰、陈宝琛等都曾在此居住或留有故居。街区内保存有大量明清至民国时期的民居建筑，装饰讲究，建筑中的马鞍墙、水榭戏台等极具福州地方特色，并在2009年获评首批中国历史文化名街之一。2015年7月评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到福州三坊七巷。开始之前，先请大家记住一句话：这片街区不大，总占地也就几十公顷，但它被概括为一句话——"一片三坊七巷，半部中国近代史"。这话夸张吗？我们边走边验证。

先看格局。三坊七巷的骨架是"三坊七巷一条街"：三个坊在西侧，七条巷在东侧，中间纵贯的就是南后街。它的由来可以追溯到晋唐时期，成规模在明清。请大家留意一个细节：这里的巷子很窄，两边的墙很高，而且一律是曲线形的"马鞍墙"——墙脊起伏如马鞍，是福州民居最醒目的标志，也有防火隔断的作用。

第二看人物。鸦片战争之后，福州成为最早开放的口岸之一，这里的人得风气之先，读书、留洋、办海军、译西书。林则徐在这里度过早年，"苟利国家生死以，岂因祸福避趋之"的名句为他而传；严复在这里求学成长，后来翻译《天演论》；林觉民的《与妻书》是从广州起义前写下的绝笔，而这封信的主人，正是从这里走出去的；冰心先生的故居也在这条街上，有趣的是，她住的这栋老宅，此前正是林觉民的旧居。

请大家一定要去看水榭戏台。它是福州现存不多的一处水上戏台：舞台建在水池之上，池水既扩音又散热，四周回廊围坐，是当年大户人家看戏的排场。大家在戏台前站一会儿，几乎可以听见当年的弦索声。最后提醒大家南后街上的"味道"：福州鱼丸、肉燕，走进这里才算真正到过福州。

最后说说保护。这片街区经历过两次大规模的修缮改造，现在的三坊七巷既是居民区也是开放的景区，白天热闹、夜里安静，是很适合慢慢走的地方。

祝各位在三坊七巷，走进半部中国近代史，也吃上一碗热气腾腾的福州味。

**【讲解要点提示】**
- 必讲："三坊七巷一条街"格局；马鞍墙特征；林则徐、严复、林觉民、冰心等名人故居；林觉民《与妻书》。
- 数据锚点：2009年获评首批中国历史文化名街之一；2015年7月评定5A；由三坊、七巷与南后街构成。
- 常见误区：不要将"三坊七巷"说成全貌为明清原建，现存建筑历经多次修缮，部分为修复复建；不要把林觉民与冰心故居当成两处不同的宅院。
- 互动/提问设计：请客人在墙头上找"马鞍"形，说说它除了美观还有什么作用；请客人在郎官巷、塔巷等地名中找若干个能对应到历史雅称的线索。

**【景区简介】**

古田旅游区位于福建省龙岩市上杭县古田镇，是中国共产党与人民军队历史上的重要纪念地。1929年12月28日至29日，中国工农红军第四军第九次党的代表大会在古田召开，会议通过了毛泽东同志起草的《中国共产党红军第四军第九次代表大会决议案》，即著名的"古田会议决议"，确立了"思想建党、政治建军"的根本原则。会议旧址原为廖氏宗祠，后曾作为小学使用，现为全国重点文物保护单位并有重要地位。景区还包括红四军政治部旧址、毛泽东《星星之火，可以燎原》写作地旧址等革命旧址群。2014年，全军政治工作会议在古田召开，被称为"新古田会议"。2015年10月评定为国家5A级旅游景区。

各位朋友，欢迎来到上杭县古田镇。今天我们要看的，不是一处风景，而是一次会议所留下的力量。

请大家先看会址本身。它原是一座廖氏宗祠，后来办过小学，所以保留了"曙光小学"的名字。会场的陈设仍然按当年的样子摆放：讲台、课桌、黑板，以及地上炭火留下的痕迹。1961年，它被列为第一批全国重点文物保护单位。

第三部分要说一句"新古田"。2014年，全军政治工作会议同样在古田召开，因此被称为"新古田会议"。历史在同一个小镇上隔了八十五年呼应，这正是此地最深沉的地方。

**【讲解要点提示】**
- 必讲：1929年12月28日至29日红四军第九次党的代表大会；《古田会议决议》；"思想建党、政治建军"；1961年第一批全国重点文物保护单位。
- 数据锚点：1929年12月28—29日；2014年全军政治工作会议；1961年第一批国保；2015年10月评定5A。
- 常见误区：不要把"古田会议"与2014年"全军政治工作会议"混称为同一次会议，二者时代背景不同，后者被称为"新古田会议"。
- 互动/提问设计：请客人在会场数一数当年的座位，估算代表的人数规模；请客人读一段《星星之火，可以燎原》中的名句。

### 10. 莆田湄洲岛妈祖文化旅游区

| 项目 | 内容 |

**【景区简介】**

湄洲岛妈祖文化旅游区位于福建省莆田市秀屿区湄洲镇，湄洲岛是妈祖文化的发源地与妈祖信俗的核心区。妈祖原名林默，相传生于北宋建隆元年（960年），因救助海难而被人尊奉为海神，其信仰随航海者的足迹传播至沿海各地乃至海外。岛上妈祖庙（祖庙）始建于北宋雍熙四年（987年），是世界上最早、也是数以万计妈祖宫庙公认的"祖庙"，现存建筑群依山而建，气势恢宏。2009年9月，"妈祖信俗"被联合国教科文组织列入人类非物质文化遗产代表作名录，是中国首个以信俗类别入选的项目。此外，岛上还有巨型妈祖石雕像、鹅尾神石园等景观。2020年12月评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到妈祖的故乡——莆田湄洲岛。今天我们要讲的，不只是一座庙，而是一种延续了上千年的信俗，以及它背后那一整套"海上人家的世界观"。

先说妈祖其人。相传妈祖姓林名默，生于北宋建隆元年（960年），莆田湄洲人。她自幼熟习水性，通晓天文气象，常常救助遇险的渔船和航海者。相传她在987年因救人而罹难，年仅二十余岁。此后人们把她当作海上的保护神来供奉，越传越远。请注意，"妈祖"这两个字的读音里有个"妈"字——她不是高高在上的神，而是船工渔民心里的"母亲"。

正因为有这样的人格底色，妈祖信仰才随船走遍了天下。从东南沿海到港澳台，再到东南亚，最保守的估计也有上万座妈祖宫庙，信众以亿计。而这些庙，全都尊奉湄洲岛上的这一座为"祖庙"。祖庙始建于北宋雍熙四年（987年），距今已一千多年，现存建筑依山层层而上，登到高处能看到整片海湾。

第三点要说非遗。2009年9月，联合国教科文组织把"妈祖信俗"列入《人类非物质文化遗产代表作名录》，这是中国第一个以信俗类别入选的项目。为什么要保护它？因为它保存的是一整套规矩与仪式：出海前的祭拜、庙会上的巡安、分香回娘家的规矩，以及"立德、行善、大爱"的妈祖精神。

岛上的另一处看点，是临海而立的高大妈祖石雕像——它面向台湾海峡，远远就能望见。每年农历三月廿三的妈祖诞辰和九月初九的妈祖升天纪念日，岛上会举行隆重的祭典，届时海内外分庙都会回来"进香"。

轮渡班次受潮汐与天气影响较大，请务必提前核实船班；海边紫外线强，请做好防晒。祝各位在湄洲岛，听得见海风，也看得懂一种千年信俗。

**【讲解要点提示】**
- 必讲：妈祖传说与宋代文献记载的区分；祖庙（987年始建）的"祖庙"地位；2009年妈祖信俗列入人类非物质文化遗产代表作名录。
- 数据锚点：相传妈祖生于960年、987年因救人罹难；祖庙始建于987年；全球妈祖宫庙数以万计；2009年9月入选人类非遗；2020年12月评定5A。
- 常见误区：妈祖生平来自地方文献与民间传颂，应加"相传"；不要把各地妈祖庙一概说成"分庙"，准确说法是分灵、分香关系的宫庙。
- 互动/提问设计：请客人猜妈祖姓什么；请客人在庙宇布局中找出"分香"的意义。
- 出行提示：轮渡班次、祭典期间交通管制与住宿，出行前请核实官方公告。

厦门园林植物园位于福建省厦门市思明区东侧，俗称"万石岩""万石植物园"，依托万石山山体建设，是厦门市区内规模最大的植物迁地保护与科普游览园地。园区始建于1960年，面积约4.9平方公里，地形起伏、怪石遍布，因而有"万石积翠"之说。园内按照植物类群设置有多个专类园区，涵盖南亚热带季风常绿阔叶林、沙生植物（多肉植物）、棕榈植物、雨林世界、百花厅等代表性景观，广泛收集、保育各类热带亚热带植物，同时承担迁地保护、科普教育与科研功能。园区兼具自然山景与城市休闲功能，是厦门"海上花园"城市形象的重要组成部分。2024年2月评定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到厦门园林植物园。先说一句让大家意外的话：这座园子不在郊区，它在厦门市区的中心地带，从市中心来这里只要十几分钟。而且更意外的是：它不是在平地上造出来的园子，而是"山"就是园、园就在山里。

第一眼看过去，大家可能会以为这是一处天然的山林。其实不然，这是一座建于1960年的植物园，占地约4.9平方公里，厦门人习惯叫它"万石植物园"——名字来自园中遍布的花岗岩巨石，古人称这一带"万石积翠"。石头多、地形起伏，反而成了这里最大的本钱：因为地形高低错落、阴阳有别，这里能同时容纳完全不同的植物群落，这是平地上的公园做不到的。

园子里最值得推荐的三处：第一处是多肉植物区（沙生植物区），成片的仙人掌和巨大的多肉植物列队而立，配上巨石背景，干燥、荒凉、奇异，像到了另一个大洲。第二处是雨林世界，这里利用山间的湿润小气候，营造出层次丰富的雨林景观，藤萝、附生植物、滴水叶尖一应俱全，早上雾森开启的时候最为美丽。第三处是棕榈园和各具特色的专类园，建议大家按地图上的植物"科""属"走，会看到另一种秩序之美。

我认为这座园子最值得尊敬的，其实是它的"后台"。植物园不是简单地把植物种在一起，它承担着收集、保育、研究和科普的功能：许多珍稀濒危植物在这里得到迁地保护，种子、标本、登录信息构成了一座城市对自然的记忆。带孩子来的朋友，这趟行程本身就是一次很好的植物学启蒙。

园区依山而建，坡道较多，请穿舒适的鞋子；夏季日照强，注意防晒补水。祝各位在厦门园林植物园，走一座山，认识成千上万种生命。

**【讲解要点提示】**
- 必讲：万石山地貌与"万石积翠"；1960年建园；多肉植物区、雨林世界、棕榈园等专类园；迁地保护与科普价值。
- 数据锚点：园区建于1960年；面积约4.9平方公里；2024年2月评定5A。
- 常见误区：不要把它当成一般性的城市公园，其核心价值是植物收集、保育与科研；"雨林"为营造性景观，并非原生雨林。
- 互动/提问设计：请客人对比沙生区与雨林区的叶片差异，说说植物怎么节水；让客人找一找附生在树干上的植物。
- 出行提示：园区各部分开放时间、观光车线路与雾森开启时间，出行前请核实官方公告。

### 12. 龙岩市冠豸山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年评定） |

**【景区简介】**

冠豸山景区位于福建省龙岩市连城县东部，与武夷山同属丹霞地貌系统，历来有"北夷南豸，丹霞双绝"之誉。据福建省人民政府网报道，景区面积12.7平方公里，山上保留宋元以来修建的古书院及摩崖石刻40余处，并有"生命之根""生命之门"等奇特景观100余处，主峰因形似古代监察御史所戴"獬豸冠"而得名，被称为"客家第一神山"。冠豸山所在连城县地处闽江、汀江、九龙江三江源头区域，集山、水、岩、泉、寺于一体，历代文人在此读书讲学，留有深厚的客家文化底蕴。2024年12月，文化和旅游部确定龙岩市冠豸山景区为国家5A级旅游景区，至此福建省国家5A级旅游景区达12家。

**【导游词核心稿】**

各位朋友，欢迎来到龙岩连城的冠豸山。请大家先看看主峰的轮廓——像不像一顶帽子？这座山的名字，就是这么来的：它的主峰形似古代监察御史戴的那种"獬豸冠"，因而得名冠豸山。这里请留意"豸"字的读音，常被误读。

先看地质。冠豸山和北边的武夷山同属丹霞地貌，所以民间有一句话："北夷南豸，丹霞双绝"。同样是红色砂砾岩构成的赤壁丹峰，但武夷山有九曲溪的水，而冠豸山的妙处在于山、水、岩、泉、寺兼备。景区面积12.7平方公里，境内保留着宋元以来修建的古书院与摩崖石刻40余处，奇特的景观100余处。请大家留意水——连城处在闽江、汀江、九龙江三条大江的源头区域，山有多高，水就有多清，这一点在石门湖一带最能体会：坐上船，看赤壁倒映水中，这是冠豸山最温柔的一面。

再说人文。这一带是客家聚居地，山上自古就有读书讲学的传统，多座宋元古书院散布山间。古人为什么要在山里办书院？因为山高路远、清净少扰，读书写字最宜。这种"在风景里读书"的传统，正是客家耕读传家的体现。

当然，冠豸山最广为人知的一处景观，是"生命之根"与"生命之门"，它们是流水沿岩石垂直节理长期侵蚀形成的天然石柱与裂隙景观——其俗称出自民间对形态的直观联想，请大家从地貌成因的角度去欣赏。这样的丹霞遗存，正是"天生地造"四字最好的注脚。

2024年12月，文化和旅游部正式确定冠豸山景区为国家5A级旅游景区，这是福建省第12家国家5A级景区。

山路有不少台阶，请穿防滑鞋、备好饮水。祝各位在冠豸山，看得见丹霞，也读得到客家人藏在深山里的那支笔。

**【讲解要点提示】**
- 必讲："北夷南豸，丹霞双绝"与丹霞地貌成因；主峰形似"獬豸冠"的得名；宋元书院与摩崖石刻；2024年12月评定5A。
- 数据锚点：景区面积12.7平方公里（据福建省人民政府网）；宋元以来古书院与摩崖石刻40余处；奇特景观100余处；2024年12月确定。
- 常见误区："生命之根""生命之门"的名称是民间依据形态的俗称，讲解时应回归地质成因的表述（流水沿垂直节理侵蚀形成的石柱与裂隙）；冠豸山不等于整个连城——连城县还有培田古村落、梅花山等景区，其中培田古村同样位于连城县（宣和乡），与冠豸山是同一县域内两个各自独立售票、相距约30公里的景区，行程切勿混排。
- 互动/提问设计：请客人在群峰轮廓中找出"獬豸冠"的形状；让客人在崖壁上找一处方正的摩崖石刻并辨识年代。
- 出行提示：登山线路、石门湖游船与索道运营情况，出行前请核实官方公告。
