## 一、5A级景区（精编词条）

### 1. 嵩山少林寺景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 郑州市登封市 |
| 类型 | 宗教圣地 · 山岳峰林 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 4-5 小时（含武术表演则 5-6 小时） |

**【景区简介】**

嵩山少林景区位于河南省郑州市登封市，坐落在"中岳"嵩山西麓、少室山五乳峰下，规划面积约149平方公里，是嵩山世界地质公园的核心园区。少林寺始建于北魏太和十九年（495年），孝文帝为天竺高僧跋陀敕建，因寺院隐于少室山密林之中而得名。景区由少林寺常住院、初祖庵、塔林、达摩洞与嵩阳书院、中岳庙、观星台、嵩岳寺塔、会善寺等共同构成"天地之中"历史建筑群，2010年该建筑群（8处11项）被联合国教科文组织列入《世界遗产名录》。寺西塔林为唐至清代砖石墓塔群，是中国现存规模最大的古塔群。少林功夫已列入国家级非物质文化遗产名录。

**【导游词核心稿】**

各位游客朋友，大家好！欢迎来到"天下第一名刹"——嵩山少林寺。我们脚下这片山谷，属于中岳嵩山，自古以来被称为"天地之中"；2010年，包括少林寺常住院、初祖庵、塔林在内的8处11项古建筑群，被列入《世界遗产名录》。

先说寺名。据史料记载，北魏太和十九年，即公元495年，孝文帝为来自天竺的僧人跋陀在此建寺，因寺建在少室山的密林深处，便取名"少林寺"。1500多年来，它既是禅宗祖庭，也是少林功夫的发源地。

进山门，穿过天王殿、大雄宝殿、藏经阁，就到了立雪亭。相传二祖慧可为了向达摩求法，在雪地里站了一夜，积雪没膝，最终断臂明志——这便是"立雪断臂"的故事。往前是千佛殿，殿内明代《五百罗汉朝毗卢》壁画色彩依旧，而殿中地面上那些深浅不一的凹坑，是历代武僧长年站桩练功留下的痕迹。

出寺向西，是少林寺塔林。现存唐、宋、金、元、明、清各代砖石墓塔240余座，造型有四角、六角、圆形不等，堪称一座露天古塔博物馆。塔林规模全国罕见，也是少林寺历代高僧的安息之地。

今天行程的最后，请大家留意两件事：一是山路台阶湿滑，上下请扶好栏杆；二是武术表演场次较多，请按我们约定的时间准时集合，别错过了压轴的少林功夫。

**【讲解要点提示】**

- 必讲：495年建寺由来；"天地之中"历史建筑群2010年入遗；常住院—立雪亭—千佛殿—塔林这条主线。
- 数据锚点：495年、240余座墓塔、8处11项遗产点、规划面积约149平方公里、少室山连天峰海拔1512.4米。
- 常见误区：少林寺只是嵩山景区的一部分，嵩山另有太室山、嵩阳书院、中岳庙；"天下武功出少林"是影视与民间说法，不等于历史定论；塔林是历代高僧墓塔，不是供人攀登的佛塔。
- 互动/提问设计：请游客猜一猜千佛殿地面的凹坑是怎么来的；在塔林前问"为什么塔的层数都是奇数"。

### 2. 洛阳龙门石窟景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 洛阳市洛龙区 |
| 类型 | 宗教圣地 · 遗址考古 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 3.5-4.5 小时 |

**【景区简介】**

龙门石窟位于洛阳市洛龙区伊河两岸的龙门山与香山之间，园区面积约31.7平方公里。石窟始凿于北魏太和年间，即公元493年孝文帝迁都洛阳前后，历经东魏、西魏、北齐、隋、唐、五代、北宋等朝代连续营造400余年。现存窟龛2345个、造像10万余尊、碑刻题记2800余品。其中奉先寺卢舍那大佛通高17.14米，耳长1.9米，是唐代石刻艺术的代表作。景区由西山石窟、东山石窟、香山寺、白园四大片区组成，2000年作为"龙门石窟"被列入《世界遗产名录》，与敦煌莫高窟、大同云冈石窟并称中国三大石窟。

**【导游词核心稿】**

朋友们，现在我们站在伊河的西岸。请大家抬头看——两山对峙，伊水中流，形如门阙，所以这里自古叫"伊阙"，隋朝以后才改称"龙门"。

龙门石窟的开凿，要从公元493年说起。据史料记载，北魏孝文帝把都城从平城迁到洛阳，就在迁都前后，第一批石窟在这里动工。此后400多年，历代匠人一锤一錾，把整座山崖雕成了佛国。

我们的路线是：西山石窟—奉先寺—香山寺—白园。先看宾阳中洞，它是北魏宣武帝为父母祈福而开凿的，前后用工80余万，历时二十余年。再看万佛洞，南北两壁密密麻麻刻着上万尊小佛像，最小的只有几厘米高。

重头戏是奉先寺。这组造像始凿于唐高宗咸亨三年，公元672年，历时约三年完成。正中这尊卢舍那大佛通高17.14米，光是一只耳朵就有1.9米长。请留意她的面容：丰颐秀眉，嘴角含着一丝若有若无的笑意，被后人称作"东方的蒙娜丽莎"。相传这尊大佛是以武则天的容貌为参照雕造的——这只是传说，史书上并没有确证，但足以说明唐代工匠追求的那种理想之美。

过桥到东山，香山寺依山而建，白园则是唐代诗人白居易的墓园。白园里有"白池""听伊亭"，环境清幽，正好让我们的行程从震撼收束到平静。

最后提醒一句：石窟区内全程步行、台阶较多，请穿舒适的鞋；石刻文物严禁触摸、刻画，拍照请勿使用闪光灯。

**【讲解要点提示】**

- 必讲：493年始凿与400余年营造史；奉先寺卢舍那大佛；2000年入遗。
- 数据锚点：2345个窟龛、10万余尊造像、2800余品题记、17.14米、1.9米、672年、宾阳中洞用工80余万。
- 常见误区：大佛"以武则天为原型"只是相传说法，须注明；龙门石窟保护范围远大于游客常走的西山一段，香山寺、白园常被漏掉。
- 互动/提问设计：请游客在奉先寺前观察大佛眼睛在不同光线下"睁"与"闭"的变化；问"为什么叫卢舍那"。

### 3. 焦作云台山—神农山—青天河风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 焦作市修武县、沁阳市、博爱县 |
| 类型 | 山岳峰林 · 地质地貌 · 水域湖泊 |
| 评定年份 | 2007 |
| 建议游览时长 | 云台山 1.5-2 天；神农山、青天河各 1 天 |

**【景区简介】**

云台山—神农山—青天河风景区横跨焦作市修武县、沁阳市与博爱县，总面积约556平方公里，是太行山南麓规模最大的山岳峡谷型旅游区。云台山以红石峡丹崖碧水的峡谷地貌著称，主峰茱萸峰海拔1308米，园内分布潭瀑峡、泉瀑峡、猕猴谷、子房湖、叠彩洞、万善寺、百家岩等景点，2004年作为"云台山世界地质公园"列入世界地质公园名录。神农山相传为炎帝神农氏辨五谷、尝百草、设坛祭天之地，紫金顶海拔1028米，白松岭一带是国家级猕猴自然保护区。青天河由大泉湖、靳家岭、月山寺等片区组成，素有"北方三峡"之誉。

**【导游词核心稿】**

各位朋友，欢迎来到焦作。我们这片景区有点特别——它不是一座山，而是三座山打包成的一个国家5A级旅游区，总面积约556平方公里，横跨修武、沁阳、博爱三县市。

先讲云台山。它最有名的是红石峡。请大家注意两侧的崖壁：紫红色的石英砂岩，一层层纹路清晰，像一本摊开的地质教科书。峡谷最窄处只容两人错身，抬头只见一线天，脚下是碧潭深流，夏天走进来凉意扑面，人称"盆景峡谷"。云台山主峰茱萸峰海拔1308米，唐代诗人王维那句"遥知兄弟登高处，遍插茱萸少一人"，写的就是这种登高的习俗。云台天瀑落差约314米，是亚洲落差最大的瀑布之一，但它属于季节性瀑布，雨季才见白练垂空，能不能遇上，要看运气。

再说神农山。相传炎帝神农氏曾在这一带辨五谷、尝百草、设坛祭天，山因此得名。主峰紫金顶海拔1028米，山脊上的白松岭生长着成片的白皮松，也是太行猕猴的重要栖息地，运气好的话，能在路边遇见猴群。

最后是青天河。这里的核心是全长十余里的大泉湖，两岸山势雄奇、水面开阔，素有"北方三峡"的美称；秋天的靳家岭，漫山红叶，是中原著名的红叶观赏地。

三片区之间距离不近，建议按两天以上安排行程。山区天气多变、峡谷湿滑，请务必穿防滑鞋，带一件薄外套。

**【讲解要点提示】**

- 必讲：三片区（云台山/神农山/青天河）的空间关系；红石峡地质成因；云台山2004年世界地质公园身份。
- 数据锚点：总面积约556平方公里、茱萸峰1308米、紫金顶1028米、云台天瀑落差约314米、2004年。
- 常见误区：云台天瀑为季节性瀑布，非全年可见；神农山在沁阳市、青天河在博爱县，与云台山并不相邻，别安排在同一天。
- 互动/提问设计：在红石峡请游客摸一摸岩壁，判断岩石颗粒粗细，猜一猜它形成的环境；在猕猴谷提醒"不投喂、不挑逗"。

### 4. 安阳殷墟景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 安阳市殷都区 |
| 类型 | 遗址考古 · 博物馆场馆 · 世界文化遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

殷墟位于安阳市殷都区洹河两岸，是中国历史上第一个有文献可考、并经甲骨文与考古发掘所证实的商代晚期都城遗址，保护范围约36平方公里。自商王盘庚迁殷至商王朝灭亡，这里历经8代12王。遗址由宫殿宗庙区、王陵区、洹北商城、后冈遗址及众多族邑聚落构成，出土甲骨约15万片、青铜器与玉器数以万计，其中后母戊鼎（又称司母戊鼎）重832.84公斤，是现存最重的古代青铜礼器。殷墟与甲骨文的发现，把中国有文字可考的信史上推到商代，2006年被列入《世界遗产名录》，被誉为"中国考古圣地"。

**【导游词核心稿】**

朋友们，眼前这片看似平静的田野，是中国考古学的圣地——殷墟。什么叫"墟"？就是旧都的废墟。三千多年前，商王盘庚把都城迁到这里，此后8代12王，一直住到商朝灭亡。

殷墟为什么这么重要？因为它是中国第一个既能从古书里查到、又被地下的甲骨文和夯土基址证实的都城。换句话说，中国的"信史"，从这里才算真正起步。

先看宫殿宗庙区。这里发现了50多座建筑基址，当年的宫殿就建在夯土台基之上，柱洞、门道、台阶的痕迹都还在。1976年，考古工作者在这里发掘了商王武丁配偶妇好的墓葬，出土随葬品1928件，包括468件青铜器和755件玉器，墓主人身份因此一目了然。

再看甲骨。殷墟出土的甲骨大约15万片，其中最著名的是1936年发现的第127号甲骨坑，一个坑里就出了17096片，像一座地下的档案库。据史料记载，1899年，金石学家王懿荣在药材"龙骨"上辨认出刻痕，甲骨文才为世人所知。

最后说说后母戊鼎。它1939年出土于武官村，重达832.84公斤，是目前已知最重的古代青铜礼器。器腹内壁铸着"后母戊"三个字，是商王为祭祀母亲所铸。

参观中请大家走栈道、不下探方，文物遗存极其脆弱，任何一点触碰都是不可逆的损伤。

**【讲解要点提示】**

- 必讲：8代12王、盘庚迁殷；妇好墓；甲骨与127号坑；2006年入遗。
- 数据锚点：保护范围约36平方公里、1928件随葬品、17096片甲骨、832.84公斤、1899年王懿荣、2006年。
- 常见误区："司母戊鼎"与"后母戊鼎"是同一件器物的两种释读，讲解时须说明；殷墟遗址现场多为基址与复原展示，主要实物陈列在殷墟博物馆内。
- 互动/提问设计：请游客辨认几个简单的甲骨文字（日、月、人、牛）；问"为什么商代人要在龟甲上刻字"。

### 5. 洛阳嵩县白云山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 洛阳市嵩县 |
| 类型 | 山岳峰林 · 森林草原 |
| 评定年份 | 2011 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

洛阳白云山景区位于河南省洛阳市嵩县南部伏牛山腹地的原始林区，总面积约168平方公里，地处长江、黄河、淮河三大流域的分水岭地带。景区森林覆盖率达98.5%以上，海拔1500米以上的山峰有37座，主峰玉皇顶海拔2216米，为中原地区的极高峰之一，是观日出、赏云海的绝佳去处。核心片区包括白云峰、玉皇顶、九龙瀑布、原始森林与白云湖等，其中九龙瀑布落差逾百米，气势磅礴。区内保存着完整的原始次生林与丰富的珍稀动植物资源，夏季气温明显低于周边城市，是中原著名的避暑与森林康养目的地。

**【导游词核心稿】**

各位朋友，我们现在进入的是伏牛山腹地——洛阳白云山。这里总面积约168平方公里，森林覆盖率98.5%以上，说白了，放眼望去除了树，还是树，所以人称"中原山水大观""天然氧吧"。

白云山最大的本钱是海拔。景区内海拔1500米以上的山峰有37座，主峰玉皇顶海拔2216米。也正因为山高，这里正好卡在长江、黄河、淮河三大流域的分水岭上——站在这里，您脚下的一条小溪，可能流进黄河，也可能最终汇入长江。

我们的行程大致三站。第一站玉皇顶。登顶要爬一段陡峭的台阶，但站上观景台，云海在脚下翻涌，运气好时还能看见日出时的"云海佛光"。第二站九龙瀑布。水流从百米高的崖顶跌下，被岩壁分成九股，如九条白龙腾空，水声在谷中回荡不止。第三站原始森林。这里的林子里古木参天、藤蔓缠绕，空气里的负氧离子含量极高，请大家多深呼吸几次，把城市里的浊气换一换。

白云山的四季各有讲究：春天高山杜鹃，夏天避暑戏水，秋天层林尽染，冬天则有雾凇冰挂。它与栾川的老君山同属伏牛山系，但分属嵩县与栾川县，两地相距约50公里（山区车程约1小时），请不要混为一谈。

最后提醒：山区海拔落差大，早晚温差明显，即便盛夏也建议带一件外套；观景台临崖，拍照请勿越栏。

**【讲解要点提示】**

- 必讲：伏牛山腹地地理位置；玉皇顶与云海日出；九龙瀑布。

### 6. 开封清明上河园景区

- 必讲：《清明上河图》张择端与5.28米×0.248米；虹桥叠梁拱结构；1998年建园、2011年评5A。
- 数据锚点：占地约600亩、水域180亩、画中人物逾800个、1998年开放、2011年。

- 互动/提问设计：请游客在虹桥上找一找《清明上河图》原画里的对应场景；问"画中那艘船为什么要放倒桅杆"。

朋友们，欢迎来到栾川。老君山海拔2217米，是伏牛山的主峰之一，也是中原地区最有名的道教名山。

### 9. 洛阳新安龙潭大峡谷景区

**【景区简介】**

龙潭大峡谷位于洛阳市新安县石井镇，总面积约19平方公里，由龙潭峡、黛眉山、青要山三大片区组成，是黛眉山世界地质公园的核心园区。峡谷以长达12公里的红岩嶂谷地貌为主体，紫红色石英砂岩经12亿年的地质沉积与约260万年的水流切割旋蚀，形成高峡瓮谷、隘谷、悬谷等典型地质遗迹，被专家称为"中国嶂谷第一峡"。谷内集中了六大自然谜团、七大幽潭瀑布与八大自然奇观，栈道沿崖壁蜿蜒穿行，是集地质探秘、峡谷观光、生态休闲于一体的风景名胜区。2013年评定为国家5A级旅游景区。

**【导游词核心稿】

各位朋友，今天我们要走的，是一条"被水切开的路"。

龙潭大峡谷全长12公里，两侧是紫红色的石英砂岩。这些岩石形成于大约12亿年前的滨海环境，一层层沉积下来；随后又经历了约260万年的水流切割与旋蚀，硬生生被冲出今天这道深谷。地质学家给它起了个名字——"嶂谷"，意思是谷壁直立、形如屏障的峡谷，而龙潭大峡谷被公认为"中国嶂谷第一峡"。

进谷之后，请大家留意几个地方。第一是"水往高处流"：一段溪流看上去在往坡上淌，很多人以为是奇观，其实这是周围地形造成的视觉错觉，是经典的自然谜团之一。第二是"佛光岩""天碑"这类崖壁：岩层纹理、节理裂隙清晰可辨，像天然的教科书插图。第三是谷中的黑龙潭、青龙潭、飞龙潭等幽潭，水色碧绿，深浅莫测。

峡谷里最舒服的一段是沿崖壁修建的栈道，一边是峭壁，一边是深潭，凉风习习。走到"一线天"时，两壁几乎贴合，抬头只见一线天空——那一刻最能体会什么叫"高峡"。

最后提醒：谷内栈道湿滑，请勿离开栈道进入河道；雨季峡谷可能临时封闭，出行前务必核实景区开放情况。

**【讲解要点提示】**

- 必讲：12亿年沉积与260万年切割的成因；"中国嶂谷第一峡"；六大谜团与八大奇观。
- 数据锚点：总面积约19平方公里、峡谷长12公里、12亿年、260万年、2013年评5A。
- 常见误区："水往高处流"是视觉错觉，不是违背重力的真实现象；龙潭大峡谷属黛眉山世界地质公园，与"黛眉山片区"是同一园区的不同部分。
- 互动/提问设计：请游客在崖壁前观察岩层交错层理，判断古水流方向；在"水往高处流"处先让游客自己判断，再揭晓答案。

再说老界岭。这里是伏牛山主峰区，主峰犄角尖海拔2212.5米。请大家记住一个数：它是中国南北气候的分界线，也是长江流域和黄河流域的分水岭。山北的水流进黄河，山南的水流进长江，一步跨两江，就是这个意思。因为山高林密，夏季特别凉爽，是中原著名的避暑地；沿着山脊走，能看到明显的植被垂直带谱——山下是阔叶林，往上变成针阔混交林，再往上是草甸。

嵖岈山还有"六峰山""北山"等片区，时间充裕的话可以一并游览。

### 12. 安阳林州红旗渠—太行大峡谷旅游景区

**【景区简介】**

红旗渠·太行大峡谷旅游景区位于河南省安阳市林州市，总面积约235平方公里，由红旗渠红色教育景区与太行大峡谷自然景区两大板块组成。红旗渠是20世纪60年代林县人民为解决严重缺水问题，在太行山腰开凿的引漳入林水利工程，1960年2月动工、1969年7月竣工，削平山头1250座、凿通隧洞211个、架设渡槽151座，总干渠长70.6公里，被誉为"人工天河"与"世界第八大奇迹"。太行大峡谷境内断崖高起、群峰峥嵘、台壁交错、流瀑四挂，是"北雄风光"的典型代表，核心景点有桃花谷、太行天路、王相岩、仙霞谷。2016年两景区联合评定为国家5A级旅游景区。

朋友们，前面这道挂在半山腰的水渠，就是红旗渠——一条完全靠人力凿出来的"人工天河"。

先说它为什么非修不可。林县地处太行山东麓，山高土薄，历史上十年九旱，老百姓为了吃水要走几十里山路。1960年2月，工程动工；1969年7月，主体竣工。整整十年，林县人民削平了1250座山头，凿通了211个隧洞，架设了151座渡槽，硬是把浊漳河水引了进来，总干渠长70.6公里。因此它被称作"世界第八大奇迹"，也孕育出"自力更生、艰苦创业、团结协作、无私奉献"的红旗渠精神。

我们的第一站是青年洞。它是总干渠的咽喉工程，长616米，横穿坚硬的石英砂岩。据记载，当年由300多名青年组成的突击队，用一年多的时间把它凿通，洞因此得名。站在洞口，看渠水从脚下流进太行深处，那种震撼难以言表。

第二站是太行大峡谷。桃花谷里潭瀑相连、溪水常年不断；王相岩相传是商王武丁与奴隶出身的宰相傅说相遇的地方，"王相"二字由此而来；太行天路沿山脊盘旋，是俯瞰峡谷全景的最佳位置。

参观红旗渠，请大家保持庄重；峡谷区台阶多、温差大，请穿防滑鞋、带外套。

**【讲解要点提示】**

- 必讲：1960—1969年的修建史与"人工天河"；青年洞；红旗渠精神。
- 数据锚点：总面积约235平方公里、1250座山头、211个隧洞、151座渡槽、总干渠70.6公里、青年洞616米、2016年。
- 常见误区：红旗渠是引漳入林的水利工程，不是天然河流；太行大峡谷与红旗渠分属两个板块，相距数十公里。
- 互动/提问设计：请游客估算当时没有大型机械，如何把数百万方石料运走；在青年洞前问"为什么要选在半山腰开渠"。

**【景区简介】**

芒砀山汉文化旅游景区位于豫、鲁、苏、皖四省结合部的河南省永城市芒山镇，总面积约14平方公里，由芒砀山主峰区、汉梁王陵景区、刘邦斩蛇处、陈胜园景区、夫子崖等片区组成。芒砀山是豫东平原上唯一的山群，以西汉梁国王陵墓群闻名：梁孝王刘武及其王后的陵墓是开凿于山体内部的大型崖洞墓，出土《四神云气图》壁画长5.14米、宽3.27米，年代早于敦煌壁画，被誉为"敦煌之前的敦煌"。景区另有刘邦斩蛇起义碑亭、陈胜墓与相传孔子避雨的夫子崖等遗迹，被称为"汉兴之地"。2017年评定为国家5A级旅游景区。

- 常见误区：芒砀山在商丘永城，不在芒山市——"芒山"是镇名；景区是"汉文化"主题，与三国无关。
- 互动/提问设计：请游客辨认《四神云气图》里的四神方位；问"为什么汉代王陵要开凿在山体里"。

### 15. 信阳鸡公山景区

**【景区简介】**

鸡公山景区位于河南省信阳市浉河区，地处大别山西端，南襟湖北，总面积达287平方公里。主峰鸡公头又名报晓峰，形似一只引颈高啼的雄鸡，山因此得名，海拔约768米。近代以来这里逐渐发展为避暑胜地，至民国时期形成由23个国家、近500栋风格各异的别墅组成的建筑群，被誉为"万国建筑博览馆"。鸡公山夏季平均气温约23℃，是中国四大避暑胜地之一。佛光、云海、雾凇、雨凇、霞光、异国花草、奇峰怪石、瀑布流泉并称鸡公山"八大自然景观"。2022年评定为国家5A级旅游景区。

各位朋友，眼前这座山，从侧面看像不像一只昂着头打鸣的公鸡？它叫鸡公山，主峰因此叫"报晓峰"，海拔约768米。别看它不高，名气却大——它是中国四大避暑胜地之一，与庐山、莫干山、北戴河并列。

为什么这么凉快？鸡公山地处大别山西端，南北气流在此交汇，植被茂密，夏季平均气温只有约23℃。所以一百多年前，人们就盯上了这块地方。

鸡公山最特别的，是它的别墅群。据史料记载，20世纪初，外籍人士陆续在此购地建屋，到民国年间，山上已有23个国家、近500栋风格各异的别墅——有欧式的尖顶、美式的廊柱、日式的挑檐，中国的工匠又把它们和本地石材结合起来，所以被称作"万国建筑博览馆"。其中"颐庐"最值得一提，它是直系军阀靳云鹗所建，四层洋楼，全部用本地花岗岩砌成，是当时中国人不甘示弱的"志气楼"。

至于"八大自然景观"——佛光、云海、雾凇、雨凇、霞光、异国花草、奇峰怪石、瀑布流泉，能不能一次看全，全凭运气。我们今天沿报晓峰、颐庐、美龄舞厅、长生谷一路走，把人文与山景各看一半。

提醒：山区多雨雾，台阶湿滑，请穿防滑鞋；老别墅内部参观请勿触碰木构件与壁炉。

**【讲解要点提示】**

- 必讲：报晓峰得名；23个国家近500栋别墅与"万国建筑博览馆"；中国四大避暑胜地之一。
- 数据锚点：总面积287平方公里、报晓峰约768米、夏季平均气温约23℃、近500栋别墅、2022年评5A。
- 常见误区：鸡公山是山岳避暑地与近代建筑群，不是宗教名山；"四大避暑胜地"是传统说法，非官方评级。
- 互动/提问设计：请游客在报晓峰下找"鸡冠"与"鸡嘴"；在颐庐前问"为什么当年要用本地石头建洋楼"。

太昊伏羲陵文化旅游区位于河南省周口市淮阳区，总面积约58平方公里，核心区由太昊伏羲陵庙、龙湖国家湿地公园与平粮台古城遗址三大片区组成。太昊陵是为祭祀"三皇之首"太昊伏羲氏而修建的大型陵庙，坐北朝南，是少见的集陵与庙为一体的大规模宫殿式古建筑群，占地875亩，1996年被国务院公布为第四批全国重点文物保护单位；"太昊伏羲祭典"已列入国家级非物质文化遗产名录。龙湖是国内面积较大的环城湖之一，平粮台城址则是距今4000余年的龙山文化古城，曾入选年度"全国十大考古新发现"。2024年景区评定为国家5A级旅游景区，实现周口市5A级景区零的突破。

**【导游词核心稿】

各位朋友，我们脚下这片土地，被称作"羲皇故都"。今天要拜谒的，是中华民族的人文始祖——太昊伏羲氏。

先说陵。太昊陵占地875亩，坐北朝南，从南往北依次是午朝门、道仪门、先天门、太极门、统天殿、显仁殿、寝殿，最后是伏羲的陵墓。这种"前庙后陵"的格局在中国古代陵庙中极为少见——既是一座庙，也是一座陵，规模宏大，中轴线层层递进，1996年被列为全国重点文物保护单位。

再说人。相传伏羲画八卦、教渔猎、定姓氏、制嫁娶，被尊为"三皇之首"。统天殿内供奉着伏羲的塑像，殿前有蓍草园——相传伏羲正是用这种草茎推演八卦。每年农历二月初二到三月初三，这里举办太昊陵庙会，也就是今天的伏羲文化旅游节，八方香客云集，是中原地区规模最大的民间庙会之一，伏羲祭典已被列入国家级非物质文化遗产名录。

第三站是龙湖。它是环绕淮阳老城的天然湖泊，水面开阔、荷香十里，夏季荷花节很有看头。最后一站平粮台古城遗址，距今4000多年，属龙山文化时期城址，是中国已发现年代较早、规划规整的城址之一。

参观陵庙请保持肃静，庙会期间人流极大，务必跟紧团队。

**【讲解要点提示】**

- 必讲：陵庙一体格局与875亩规模；伏羲画八卦的传说（须加"相传"）；平粮台城址4000余年。
- 数据锚点：总面积约58平方公里、陵庙占地875亩、1996年全国重点文物保护单位、2024年评5A。
- 常见误区：太昊陵是祭祀性陵庙，与淮阳城外的平粮台遗址分属不同片区；庙会期间景区人流与交通管制变化大，出行前务必核实。
- 互动/提问设计：请游客在蓍草园说说八卦有哪八个卦；问"为什么中国古代陵庙多坐北朝南"。

### 17. 新乡宝泉旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年12月评定） |
| 所在地 | 新乡市辉县市 |

| 评定年份 | 2024 |
| 建议游览时长 | 1-2 天（大峡谷、崖天下各一天） |

**【景区简介】**

宝泉旅游区位于河南省新乡市辉县市薄壁镇，总面积约110平方公里，由大峡谷与崖天下两大园区组成，洛伽寺索道与洞穴观光电梯南北分置，实现悬崖与峡谷上下连通、立体畅游。区内森林覆盖率达98%，平均海拔1150米，年平均气温约18℃。大峡谷以水景取胜，高峡平湖、潭瀑相连，见龙瀑、双龙瀑、玉女瀑、飞龙瀑、青苔瀑等十余处形态各异的瀑布组成"中华千瀑谷"，被誉为"中原小九寨""太行山水画廊"。崖天下以红岩赤壁与曲峡地貌为特色，设有丹崖天路、游龙湾、太行之心、悬崖蹦极、悬崖秋千、挂壁栈道等项目。2024年12月被文化和旅游部确定为国家5A级旅游景区。

**【导游词核心稿】

各位朋友，欢迎来到南太行最新的一块"国字号"招牌——宝泉旅游区。2024年12月，它与全国另外18家景区一同被文化和旅游部确定为国家5A级旅游景区，这是辉县的第二家5A，也让辉县成为河南首个"一县双5A"的县。

宝泉总面积约110平方公里，森林覆盖率98%，平均海拔1150米，年平均气温约18℃——一句话，凉快。它分成上下两园：下面是宝泉大峡谷，上面是崖天下，中间靠索道和洞穴观光电梯连起来。

先走大峡谷。这一路是水的主场：见龙瀑、双龙瀑、玉女瀑、飞龙瀑、青苔瀑，十来条瀑布形态各不相同，被称作"中华千瀑谷"。水色碧绿，潭潭相连，走在栈道上，水声一路伴行，夏天尤其舒服。

再上崖天下。这里是山的场面：万丈红绫、百里赤壁，丹崖天路沿崖壁蜿蜒，移步易景；俯瞰游龙湾，能看到太行山里少见的曲峡地貌；还有"太行之心"、驼峰奇观，以及悬崖秋千、悬崖蹦极、挂壁栈道这些惊险项目，胆子大的朋友可以试试。

大峡谷四季都能玩：春赏花、夏戏水、秋拾趣、冬玩雪。

提醒一句：高空体验项目有年龄与健康状况限制，请量力而行；上下两园靠索道连接，末班时间较早，请按导游通知的时间集合，避免错过返程。

**【讲解要点提示】**

- 必讲：2024年12月新晋5A；大峡谷与崖天下上下两园结构；"中华千瀑谷"。
- 数据锚点：总面积约110平方公里、森林覆盖率98%、平均海拔1150米、年均气温约18℃、2024年12月。
- 常见误区：宝泉与八里沟同在辉县，相距约25公里（车程半小时左右），但分属不同景区、分别售票，别混为一家；"中华千瀑谷"是品牌名称，不是正式的地质学名词。
- 互动/提问设计：在游龙湾请游客观察河道弯曲的形状，猜一猜曲峡是怎么形成的；在崖天下问"为什么这里的崖壁是红色的"。

## 三、待核实与补充事项

1. **底稿"待核实（第17家）"已核实确认**：为**新乡市宝泉旅游区**。文化和旅游部于2024年12月13日公示拟确定19家旅游景区为国家5A级旅游景区，名单中河南省为"新乡市宝泉旅游区"；2024年12月27日正式公告确定。宝泉与八里沟同处辉县市，辉县由此成为河南省首个拥有两家5A级景区的县（市）。本文件已按第17条撰写词条。
2. **八里沟5A评定年份存在两说**：底稿记为2019年，新乡市文化广电和旅游局2025年7月的政协提案答复中称"2020年八里沟景区成功创建5A级旅游景区"。本文件暂按底稿记2019年，**该年份待进一步核实**。
3. **4A名录为不完全收录**：河南省4A级景区实际269家（河南省人民政府门户网站"省情"页，2026-06），本索引仅收录113条，其中23条标注"待核实等级"，须在使用前核对最新等级公告；大量4A景区未收录，后续可持续补充。
4. **联合评定与范围变更**：河南省5A名单中有多处为多片区联合评定（云台山—神农山—青天河、老君山—鸡冠洞、伏牛山—老界岭—恐龙遗址园、红旗渠—太行大峡谷、尧山—中原大佛）。各片区之间距离较远，行程安排与"一家景区"的概念常有出入；部分片区的名称与范围近年亦有调整（如"西峡恐龙遗迹园—伏牛山—老界岭旅游区"的不同写法），讲解前请核对景区官方最新表述。
5. **未写入的易变信息**：所有词条的门票、开放时间、索道与景交车费用、演出场次、优惠政策均未写入正文，出行前请核实。部分景区（如太昊伏羲陵庙会期间、云台山雨季、鸡公山雾季）存在临时管控与封闭可能。
