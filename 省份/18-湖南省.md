## 一、5A级景区（精编词条）

### 1. 张家界市武陵源—天门山旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年首批评定） |
| 所在地 | 张家界市武陵源区（武陵源片区）／永定区（天门山片区） |
| 类型 | 地质地貌 · 山岳峰林 · 世界自然遗产（武陵源片区） |
| 评定年份 | 2007 |
| 建议游览时长 | 4-6 天（武陵源 3-4 天、天门山 1 天） |

> **讲解提示（必读）**：本景区是文化和旅游部统计口径中的一家5A级景区，但由**武陵源片区**与**天门山片区**两个相互独立的片区组成。武陵源片区在武陵源区（张家界国家森林公园、索溪峪、天子山、杨家界），天门山片区在永定区（市区南侧），两地相距约40公里，门票、验票口、游览动线、住宿体系全部独立，**绝对不能合并成"一天游完"**。讲解开场必须先向游客交代清楚这一点。

**【景区简介】**

武陵源—天门山旅游区是2007年首批评定的国家5A级旅游景区，由武陵源与天门山两大片区组成；其中武陵源片区于2007年5月评定，天门山片区于2011年9月作为扩展部分并入，两家合为官方名录中的同一家5A景区。武陵源片区包含中国第一个国家森林公园——张家界国家森林公园（1982年设立）、索溪峪、天子山、杨家界等，以3000余座石英砂岩峰柱构成的峰林峡谷地貌闻名于世，1992年被联合国教科文组织列入《世界自然遗产名录》。天门山片区位于永定区，主峰海拔1518.6米，以海拔1260余米处的天然穿山溶洞"天门洞"、全长7455米的高山客运索道、99道弯的"通天大道"与悬崖玻璃栈道著称，1999年世界特技飞行大奖赛穿越天门洞使其蜚声世界。

**【导游词核心稿】**

各位游客朋友，大家好！欢迎来到张家界。在开讲之前，我先给大家交个底：我们说的"武陵源—天门山"，听着是一个景区，其实是**两个片区、两张票、两套玩法**。武陵源在山里的武陵源区，天门山在张家界市区边上，两个地方差着约40公里。所以行程一定要分开排：武陵源至少三四天，天门山一整天。

先讲武陵源。它的石头是怎么来的？三亿八千万年前，这里是一片浅海，泥沙沉积成厚厚的石英砂岩。后来地壳抬升，岩石裂出纵横的缝，雨水顺着缝往下切，几百万年切出了3000多座石柱、石峰。1982年，这里成为中国第一个国家森林公园；1992年，被列入《世界自然遗产名录》。这是中国第一批以自然遗产身份入选的地方之一。

在武陵源，我推荐四个点：一是袁家界，那根垂直挺立的"乾坤柱"，是电影《阿凡达》中"哈利路亚山"的灵感来源之一；二是天子山，"峰林之王"，云雾起时群峰浮在云海上；三是金鞭溪，全长7.5公里，沿着溪谷走，抬头全是石峰；四是百龙天梯，垂直高度326米，两分钟把你从谷底送山顶。

再说天门山。它有三样东西世界闻名：第一，天门洞——海拔一千二百多米处的天然穿山洞，1999年世界特技飞行大奖赛，飞行员驾机从中穿过，全世界都看见了。第二，天门山索道，全长7455米，从市区一路爬升到山顶，落差上千米，是世界最长的高山客运索道之一。第三，通天大道——99道弯，10公里路从海拔200米盘到1300米。

最后提醒：武陵源景区面积很大，门票一般四天有效，务必留足时间；山区天气多变，请备雨衣。天门山索道旺季排队时间长，请错峰。祝大家在三千奇峰里，找到属于自己的那一座。

**【讲解要点提示】**
- 必讲：武陵源与天门山两个片区的独立关系（相距约40公里、分别售票）；石英砂岩峰林成因；天门洞与索道。
- 数据锚点：1992年入遗、1982年首个国家森林公园、3000余座石峰、百龙天梯326米、天门洞海拔1260余米、索道7455米、99道弯、天门山主峰1518.6米、金鞭溪7.5公里。
- 常见误区：①天门山不属于武陵源风景名胜区（两者的地貌与门票体系各自独立），但天门山是"张家界市武陵源—天门山旅游区"这一家国家5A级旅游景区的正式组成部分（2011年以扩展部分并入），讲解时须完整表述，不可只说"天门山不属于"；②"哈利路亚山"仅为灵感来源而非实地取景，讲解须说明；③武陵源景区内黄龙洞、宝峰湖为单独售票的4A景区，不含在大门票内。
- 互动/提问设计：请游客估算"一根石柱一年被雨水溶蚀掉多少"，再讲石英砂岩的形成年代与峰林的"生命周期"。

### 2. 衡阳市南岳衡山旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年首批评定） |
| 所在地 | 衡阳市南岳区 |
| 类型 | 宗教圣地 · 山岳峰林 |
| 评定年份 | 2007 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

南岳衡山旅游区位于衡阳市南岳区，为中国五岳之一，素有"五岳独秀""文明奥区""中华寿岳"之称。衡山绵延数百里，有大小山峰七十二座，主峰祝融峰海拔1300.2米。山下的南岳大庙始建于唐，现存建筑为清光绪八年（1882年）重建，占地约9.85万平方米，为江南规模最大的古建筑群之一，也是我国南方规模最大的宫殿式庙宇，九进院落沿中轴线层层展开，佛道两教共处一庙为其特征。山上有祝融殿、藏经殿、方广寺、磨镜台等胜迹，以及1943年建成的忠烈祠——我国大陆地区规模最大的抗日战争阵亡将士纪念陵园之一。2007年评为首批国家5A级。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到"五岳独秀"的南岳衡山。

五岳之中，衡山最南，也最秀。它不靠险峻取胜，靠的是"秀"——林深、云多、寺庙古。衡山有七十二峰，主峰祝融峰海拔1300.2米。祝融是传说中的火神，古人认为南方属火，所以把最高峰献给了他。

我们先看南岳大庙。这座庙占地约9.85万平方米，中轴线上九进院落，从棂星门一直排到后殿。它最特别的地方是"佛道共居"——东边是道观的八个宫观，西边是佛寺，中间是祭祀南岳圣帝的正殿。一座庙里，和尚道士各做各的法事，和平共处了几百年，这在全国都少见。现存建筑主体是清光绪八年、也就是1882年重建的。

上山之后，我推荐三处：一是祝融峰顶的祝融殿，石头建筑，铁瓦覆顶，为的是抗山顶的狂风暴雪；二是藏经殿，藏在密林深处，被称为"衡山四绝"之一；三是磨镜台。磨镜台有个著名的禅宗故事：相传唐代怀让禅师在这里拿一块砖头磨，问弟子"磨砖能成镜吗"，由此点化马祖道一——这个故事讲的是"坐禅未必成佛"。

还有一处必须去：忠烈祠。它建于1943年，是纪念抗日战争阵亡将士的大型陵园，仿南京中山陵形制，依山而上。站在"七七"纪念碑前，请各位默哀一分钟。

最后说"寿"。中国人祝寿说"寿比南山"，这个"南山"指的往往就是南岳衡山。山上的"寿"字石刻，随处可见。

提醒：祝融峰顶风大温低，请备外套；寺庙内请勿喧哗、勿随意燃香。愿大家福寿康宁，所愿皆成。

**【讲解要点提示】**
- 必讲：五岳独秀与"中华寿岳"；南岳大庙佛道共居；忠烈祠。
- 数据锚点：祝融峰1300.2米、七十二峰、大庙占地约9.85万平方米、1882年重建、1943年忠烈祠、2007年评5A。
- 常见误区：南岳区属衡阳市，与"衡山县"是两个不同行政区；"寿比南山"之"南山"指衡山属民间通行说法，讲解时用"相传/通常认为"。
- 互动/提问设计：问游客"庙里为什么和尚道士能住在一起"，再讲南岳佛道共存的历史渊源。

### 3. 湘潭市韶山旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 湘潭市韶山市 |
| 类型 | 红色旅游 · 博物馆场馆 |
| 评定年份 | 2011 |
| 建议游览时长 | 1 天 |

**【景区简介】**

韶山旅游区位于湘潭市韶山市，是毛泽东同志的故乡，2011年评为国家5A级。核心景点包括毛泽东同志故居、毛泽东同志纪念馆、毛泽东广场、滴水洞、韶峰与毛泽东纪念园。毛泽东同志故居为南方常见的"一担柴"式土木结构农舍，共13间半，1893年12月26日毛泽东诞生于此并度过少年时代。毛泽东同志纪念馆为国家一级博物馆、全国爱国主义教育示范基地。毛泽东广场上的毛泽东同志铜像于1993年12月揭幕，像高6米、基座高4.1米，总高10.1米。相传舜帝南巡至此演奏韶乐，韶山因此得名。韶山与宁乡花明楼、湘潭乌石并称"伟人故里金三角"。

**【导游词核心稿】**

各位游客，大家好！欢迎来到韶山——毛泽东同志的故乡。

先看这间房子。它是南方农村最常见的"一担柴"式格局：中间堂屋，两侧厢房，一共13间半——那"半间"是与邻居共用的堂屋。1893年12月26日，毛泽东就诞生在这里，在这里度过了童年和少年。门前有池塘，屋后有山林，他小时候在塘里游泳、在山上放牛。1925年，毛泽东回到韶山，在自家阁楼上创建了中共韶山支部。

第二站，毛泽东同志纪念馆。这里系统展示了毛泽东从韶山冲走向中国革命舞台的一生，馆藏文物丰富，是国家一级博物馆。讲解时请大家把重点放在"人"上：一个农民的儿子，怎么成为改变了中国的人。

第三站，毛泽东广场。1993年12月，为纪念毛泽东诞辰100周年，铜像在这里揭幕：像高6米，基座高4.1米，加起来10.1米——这个数字，您懂的。铜像面朝东南，背靠韶峰。每年12月26日，来自全国各地的人会在这里献花、鞠躬。

第四站，滴水洞。这是一条幽深的山谷，1966年毛泽东曾在此居住。因保密需要，当年这里不对外，如今是开放的参观点。

最后说说地名。相传舜帝南巡至此，演奏"韶乐"，于是此地得名韶山。山不在高，因一个人，成了亿万中国人心中的坐标。

提醒：韶山核心景区免费开放，但需实名预约、安检进入；故居内请勿触摸陈列物品、请保持肃静。愿这次韶山之行，让大家对"为人民服务"有更深的理解。

**【讲解要点提示】**
- 必讲：故居"一担柴"格局与13间半；1893年12月26日；铜像尺寸寓意；韶山得名传说。
- 数据锚点：1893年12月26日、13间半、铜像总高10.1米（像高6米、基座4.1米）、1993年12月揭幕、2011年评5A。
- 常见误区：韶山是湘潭市下辖的县级市，不在长沙；铜像高度是纪念性设计，不是毛泽东实际身高。
- 互动/提问设计：让游客猜"10.1米这个数字代表什么"，再引出10月1日。

### 4. 岳阳市岳阳楼—君山岛景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 岳阳市岳阳楼区（岳阳楼片区）／君山区（君山岛片区） |
| 类型 | 城市地标 · 古典园林 · 水域湖泊 |
| 评定年份 | 2011 |
| 建议游览时长 | 4-6 小时（含船游君山） |

> **讲解提示**：岳阳楼与君山岛为同一5A景区的两个片区，君山岛在洞庭湖中，须从岳阳楼码头或君山码头乘船前往，往返约需2-3小时，讲解开场须说明交通方式。

**【景区简介】**

岳阳楼—君山岛景区位于岳阳市，由岳阳楼片区与洞庭湖中的君山岛片区组成，2011年评为国家5A级。岳阳楼与黄鹤楼、滕王阁并称"江南三大名楼"，其前身相传为三国东吴鲁肃所建阅军楼。北宋庆历四年（1044年）滕子京谪守巴陵郡，次年重修岳阳楼，并请范仲淹作记，遂有千古名篇《岳阳楼记》。现存岳阳楼为清光绪六年（1880年）重建，三层四柱、飞檐盔顶，为纯木结构，"盔顶"做法在中国古代建筑中属孤例。周边有三醉亭、仙梅亭、怀甫亭、小乔墓、岳阳门。君山岛面积不足1平方公里，以湘妃竹（斑竹）、二妃墓、柳毅井与君山银针茶闻名。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到岳阳楼。中国有句话："洞庭天下水，岳阳天下楼。"

先说这座楼。它的前身，相传是三国时东吴大将鲁肃在这里修的阅军楼。真正让它名扬天下的，是北宋庆历四年、公元1044年——滕子京被贬到巴陵郡，第二年重修岳阳楼，并写信请好友范仲淹作记。请注意一个细节：**据史料记载，范仲淹写《岳阳楼记》时人在河南邓州，并没有到过岳阳楼**，他是凭滕子京寄去的一幅《洞庭晚秋图》和书信，写下了"衔远山，吞长江，浩浩汤汤，横无际涯"。一篇文章，让一座楼站了一千年。

请大家抬头看屋顶。岳阳楼最珍贵的地方，是它这个"盔顶"——像古代武士的头盔，四面坡顶、顶部攒尖，在中国古代建筑里几乎是孤例。全楼三层四柱，通高近20米，全用木料，不用一根铁钉承重。现存这座楼是清光绪六年、1880年重建的。

楼里最该背诵的，是那句"先天下之忧而忧，后天下之乐而乐"。范仲淹把它写进文章，后来成了中国士大夫的精神坐标。

楼下还有三醉亭、仙梅亭、怀甫亭，以及小乔墓与岳阳门古城门，都值得一看。

下午我们去君山岛。它在洞庭湖中，面积不到1平方公里，要坐船去。岛上有一种竹子叫斑竹，也叫湘妃竹——竹身布满泪痕似的斑点。相传舜帝南巡病逝，娥皇、女英二妃追到这里，泪洒竹上成斑。岛上还有柳毅井，相传是《柳毅传书》里柳毅下龙宫的入口。岛上产的君山银针，是中国名茶。

提醒：君山船票与班次随季节调整，出行前请核实；湖面风大，请穿好救生衣。愿"不以物喜，不以己悲"的心境，伴您走完这一程。

**【讲解要点提示】**
- 必讲：《岳阳楼记》的写作背景；盔顶建筑孤例；先忧后乐；湘妃竹传说。
- 数据锚点：1044年（庆历四年）重修、1880年重建、2011年评5A、君山岛面积不足1平方公里。
- 常见误区：范仲淹作记时未亲至岳阳楼；岳阳楼屡毁屡建，现存为清代建筑；"洞庭湖是中国第二大淡水湖"的说法随水文统计口径变化，讲解宜用"中国重要淡水湖之一"。
- 互动/提问设计：请游客齐诵"先天下之忧而忧，后天下之乐而乐"，再讲范仲淹的生平。

### 5. 长沙市岳麓山—橘子洲旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定；2016年摘牌、2017年复牌） |
| 所在地 | 长沙市岳麓区 |
| 类型 | 山岳峰林 · 城市地标 · 古典园林 |
| 评定年份 | 2012 |
| 建议游览时长 | 1 天 |

**【景区简介】**

岳麓山—橘子洲旅游区位于长沙市岳麓区及湘江江心的橘子洲，2012年评为国家5A级（2016年曾被摘牌，2017年复牌）。岳麓山海拔300.8米，集山、水、洲、城于一体。山下有创建于北宋开宝九年（976年）的岳麓书院，历经千年办学不辍，有"千年学府"之誉，1903年改制为新式学堂，1926年定名湖南大学；山中有取杜牧诗意的爱晚亭、始建于西晋泰始四年（268年）的麓山寺、云麓宫，以及黄兴、蔡锷等近代名人墓葬。橘子洲南北长约5公里，洲头立有毛泽东青年艺术雕塑，高32米、长83米、宽41米，2009年落成。

山上还安葬着黄兴、蔡锷等辛亥先驱。一座海拔只有300.8米的小山，埋着半部近代史，这就是岳麓山的分量。

### 7. 郴州市东江湖旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2015年评定） |
| 所在地 | 郴州市资兴市 |
| 类型 | 水域湖泊 · 山岳峰林 |
| 评定年份 | 2015 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

东江湖旅游区位于郴州市资兴市，以东江水库为主体，2015年评为国家5A级。东江湖水面面积约160平方公里，是湘江流域重要的水源涵养地与湖南省最大的人工湖泊之一；东江大坝为双曲薄壳拱坝，最大坝高157米，在同类型坝中曾居亚洲前列。景区最负盛名者为"雾漫小东江"——因大坝底层泄水与空气温差，小东江江面在每年4月至10月的清晨常起浓雾，渔翁撒网的剪影成为经典画面。其他主要景点有兜率岛溶洞、龙景峡谷、白廊环湖公路、天鹅山国家森林公园与黄草古镇，盛产东江鱼、东江果。

**【导游词核心稿】**

各位游客，大家好！欢迎来到东江湖。我先把最重要的一句提醒放在最前面：**想看雾，就得早起。**

东江湖是东江水库蓄起来的一片大水，水面约160平方公里。拦起这片水的，是东江大坝——双曲薄壳拱坝，最大坝高157米。当年建成时，这个坝型在亚洲是数一数二的。

为什么会有雾？原理很简单：大坝从水库底层放水，底层水温常年偏低，流进小东江后与温暖空气相遇，水汽凝结，就在江面上铺开一层白雾。所以雾不是天天有、时时有的——它集中在每年4月到10月，尤其是清晨五点半到八点之间。太阳一高，雾就散。所以看雾要早起，摄影的人管这叫"赶早"。

雾起来的时候，江上有渔翁划着小船撒网。那网一甩出去，在雾里散成一个圆，配上远山的轮廓，是东江湖最经典的一张照片。

看完雾，我们上兜率岛。岛上有座溶洞，钟乳石发育得很好，是喀斯特地貌的教科书。龙景峡谷则相反，是瀑布群和栈道，夏天走进去凉快得很。

再说说这湖水。东江湖是湘江流域重要的水源地，水质常年保持在优良水平——所以这里的鱼特别鲜，东江鱼是郴州的一张名片。

提醒：看雾务必住景区附近、凌晨出发；清晨江边气温低，请备厚外套；游船与景交车分段收费，出行前请核实线路与班次。愿这一江晨雾，给您留下最温柔的湖南记忆。

**【讲解要点提示】**
- 必讲：雾漫小东江的成因与最佳观赏时段；东江大坝；兜率岛与龙景峡谷。
- 数据锚点：水面约160平方公里、坝高157米、雾期4—10月、2015年评5A。
- 常见误区：雾只在清晨出现，正午看不到；东江湖（大水库）与小东江（大坝下游河段）不是同一处。
- 互动/提问设计：让游客猜"雾是怎么来的"，再解释底层低温泄水与温差凝结。

### 8. 邵阳市崀山景区

| 项目 | 内容 |

| 等级 | 5A（2016年评定） |

| 评定年份 | 2016 |
| 建议游览时长 | 2-3 天 |

**【景区简介】**

崀山景区位于邵阳市新宁县，是中国丹霞地貌的典型代表，2016年评为国家5A级。2010年8月，在巴西利亚召开的第34届世界遗产委员会会议上，"中国丹霞"被列入《世界自然遗产名录》，崀山为其六个组成部分之一（另五处为广东丹霞山、福建泰宁、江西龙虎山、浙江江郎山、贵州赤水）。景区由八角寨、辣椒峰、天一巷、夫夷江、紫霞峒、天生桥六大片区组成：八角寨主峰海拔818米，可俯瞰"鲸鱼闹海"的峰丛奇观；天一巷全长238.8米，两侧石壁高80—120米，最窄处仅0.33米，有"天下第一巷"之誉；辣椒峰高180余米。相传舜帝南巡至此，见山水奇异，赐一"崀"字。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到崀山。先看这个字——"崀"，山字头加一个良。相传舜帝南巡走到这里，见山奇水秀，就造了这个字赐给它，意思是"山之良者"。一个地方能得到一个专属的字，中国不多。

崀山是丹霞地貌。什么是丹霞？简单说，是红色砂砾岩在流水侵蚀和重力崩塌作用下，形成的顶平、身陡、麓缓的一种地貌，最典型的特征就是"赤壁丹崖"。2010年8月，"中国丹霞"在巴西利亚被列入《世界自然遗产名录》，崀山是六处之一。

今天我带大家看三样东西。

第一，八角寨。主峰海拔818米，登到顶上往下看，是一片峰丛的海洋——无数个圆圆的、红红的峰顶挤在一起，云雾在中间流动，像一群鲸鱼在海里游，所以叫"鲸鱼闹海"。这是崀山最震撼的画面。

第二，天一巷。它是两块巨石之间的一道缝，全长238.8米，两边的石壁高80到120米，最窄的地方只有0.33米——33厘米，胖一点的朋友要侧着身子过。走进去抬头，天只剩一条线，所以叫"天下第一巷"。

第三，辣椒峰。一根上粗下细的石柱，高180多米，形状活脱脱就是一只倒立的大辣椒，因形得名。旁边还有"骆驼峰""蜡烛峰"，也都靠一个"像"字。

夫夷江则可以漂流，从水上看丹霞，另有一番味道。

提醒：六大片区相距较远，请分日安排；天一巷通道狭窄潮湿，请注意脚下、勿拥挤；夏季石面反光强，请备防晒。愿这片红色山峦，让您记住中国丹霞的模样。

**【讲解要点提示】**
- 必讲："中国丹霞"世界遗产身份及六地组成；八角寨鲸鱼闹海；天一巷。
- 数据锚点：2010年8月入遗、八角寨818米、天一巷238.8米/最窄0.33米、辣椒峰高180余米、2016年评5A。
- 常见误区：崀山不是张家界，两省两地、地貌不同；"中国丹霞"为系列遗产，不要把六处混为一谈。
- 互动/提问设计：让游客猜"天一巷最窄处有多宽"，再公布0.33米。

### 9. 株洲市炎帝陵景区

| 评定年份 | 2019 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

炎帝陵景区位于株洲市炎陵县鹿原陂，是中华民族人文始祖炎帝神农氏的陵寝所在地，2019年评为国家5A级。据史料记载，炎帝陵自北宋乾德五年（967年）起建庙奉祀，历代修葺不绝；现存陵区沿中轴线布置午门、行礼亭、主殿、墓碑亭与陵墓，规模宏大，古木参天，洣水绕陵而过。"炎帝陵祭典"于2006年列入第一批国家级非物质文化遗产名录。炎陵县原名酃县，1994年因炎帝陵而更名为炎陵县。景区集祭祀谒祖、文化寻根、研学于一体，是海内外华人寻根问祖的重要场所。

**【导游词核心稿】**

各位游客，大家好！欢迎来到炎帝陵。站在这里，我们面对的是中华民族的"老祖宗"之一——炎帝神农氏。

炎帝为什么被尊为始祖？相传他做了三件大事：一是制耒耜、教民耕作，让中国人从打猎采集走向耕种；二是尝百草、辨药性，被尊为医药之祖；三是"日中为市"，让大家在正午交换物品，这是最早的集市。所以中国人自称"炎黄子孙"，炎帝排在第一位。

这座陵，据史料记载从北宋乾德五年、公元967年开始建庙奉祀，历代修葺，香火不断。我们现在走的这条中轴线，依次是午门、行礼亭、主殿、墓碑亭，最后是陵墓。请大家留意陵区里的古树——很多是几百年甚至上千年的老樟、老柏。

陵墓所在的这座山叫鹿原陂，洣水从陵前绕过，风水格局是"前有照、后有靠"。墓碑上是"炎帝神农氏之墓"几个字。

2006年，"炎帝陵祭典"被列入第一批国家级非物质文化遗产名录。每年清明、重阳，这里都要举行隆重的公祭，海内外华人聚集于此，向始祖行礼。

再说一个地名的故事：炎陵县原来叫酃县，1994年，为了突出炎帝陵这张文化名片，正式更名为"炎陵县"。一个县因一座陵而改名，这在湖南是独一份。

提醒：陵区为庄重的祭祀场所，请勿喧哗、勿踩踏祭坛；公祭期间人多，请提前核实开放安排。愿这次谒祖，让大家想起"我们从哪里来"。

**【讲解要点提示】**
- 必讲：炎帝神农氏的功绩传说；宋代建庙奉祀沿革；炎帝陵祭典非遗身份。
- 数据锚点：967年（北宋乾德五年）建庙、2006年首批国家级非遗、1994年酃县更名炎陵县、2019年评5A。
- 常见误区：除炎陵外，陕西宝鸡、山西高平等地亦有炎帝陵寝纪念地，学界对炎帝活动区域存在多说，讲解须客观；"陵"为纪念性陵寝，考古上无法确证具体葬地。
- 互动/提问设计：问"炎帝教了我们哪三件事"，再讲农耕、医药、集市。

| 建议游览时长 | 1 天 |

**【景区简介】**

桃花源旅游区位于常德市桃源县，是东晋诗人陶渊明《桃花源记》所描绘"世外桃源"的重要原型地之一，2020年评为国家5A级。景区由秦人村、桃花山、桃源山、五柳湖与桃花源古镇等片区组成。桃源山有桃川万寿宫，为道教洞天福地之一；桃花山有方竹亭、遇仙桥、秦人古洞等古迹；秦人村复原了"土地平旷，屋舍俨然""阡陌交通，鸡犬相闻"的田园景象。千百年来，桃花源一直是文人题咏的对象，历代碑刻诗文众多，也是"桃花源"文化研究与寻访的核心地。陶渊明约生于365年，《桃花源记》约作于421年前后。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到桃花源。今天我们要走进的，不是一座普通景区，而是中国人做了1600年的一个梦。

这个梦，来自陶渊明的一篇文章。《桃花源记》开篇就是这样一句："晋太元中，武陵人捕鱼为业。"——武陵，就是今天常德这一带。一个渔夫划着船，顺着溪水走，"忘路之远近"，忽然"忽逢桃花林，夹岸数百步，中无杂树"。他穿过一个山洞，"复行数十步，豁然开朗"，看见了一个与世隔绝的村庄：土地平旷，屋舍俨然，老人小孩都很快乐。问他们朝代，才知道"不知有汉，无论魏晋"。渔夫离开后再也找不到路，从此再没有人到过那里。

陶渊明写这篇文章，大约在公元421年前后，他本人约生于365年。那是个战乱不断的年代。他写的不是一个地名，而是一种愿望：人可以有不用打仗、不用交税、彼此和睦的日子。

现在我们走进秦人村。这里的田、屋、井、竹，都是按照《桃花源记》复原的，还保留了传统的耕作方式。请大家放慢脚步，看看那口井、那片田，想象一下1600年前那个渔夫看到的样子。

桃花山上有方竹亭——旁边那种竹子是方的，四棱分明，很稀奇。还有秦人古洞，相传就是渔夫"初极狭，才通人"钻进去的那个洞。

桃源山上的桃川万寿宫，是道教的洞天福地之一，历代香火很盛。

最后要说明一句：《桃花源记》是文学作品，它的原型地，常德、重庆酉阳等地各有主张，学界没有定论。我们来这里，为的是那份心境。

提醒：景区面积较大，建议乘坐景交车结合步行；春夏桃花花期人多，请错峰。愿大家在这里，找到自己的"豁然开朗"。

**【讲解要点提示】**
- 必讲：《桃花源记》内容与"豁然开朗""不知有汉"等名句；秦人村复原景象；道教洞天。
- 数据锚点：陶渊明约生于365年、《桃花源记》约作于421年、2020年评5A。
- 常见误区：文学作品原型地存在常德、酉阳等多说，须客观表述；秦人村为复原景观，不是考古遗址。
- 互动/提问设计：请游客背出"土地平旷，屋舍俨然"的下一句，再讲全文结构。

### 11. 湘西州矮寨·十八洞·德夯大峡谷景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2021年评定） |
| 所在地 | 湘西土家族苗族自治州吉首市（矮寨、德夯）／花垣县（十八洞村） |
| 类型 | 地质地貌 · 民族风情 · 红色旅游 |
| 评定年份 | 2021 |
| 建议游览时长 | 2 天（三片区分开） |

> **讲解提示**：矮寨（大桥与公路奇观）、德夯大峡谷在吉首市，十八洞村在花垣县，两地相距约60公里，须分别安排游览，讲解开场必须说明。

**【景区简介】**

本景区由三个片区组成，2021年评为国家5A级。矮寨片区位于吉首市，以矮寨大桥与"矮寨公路奇观"闻名：矮寨大桥为钢桁梁悬索桥，主跨1176米，2012年3月建成通车，桥面至谷底高差逾300米，创造了同类型桥梁的多项世界纪录；山下的湘川公路始建于1936年，6公里路段内有13道回头弯，被称为"矮寨公路奇观"。德夯大峡谷同为吉首市，"德夯"苗语意为"美丽的峡谷"，谷内有落差216米的流纱瀑布与苗寨。十八洞村位于花垣县，因村中有18个天然溶洞得名，2013年11月3日"精准扶贫"重要理念在此首次提出。

**【导游词核心稿】**

各位游客，大家好！欢迎来到湘西。先说明一下，我们这个景区由三块组成：矮寨、德夯大峡谷在吉首市，十八洞村在花垣县，相距约60公里，要分开走。

第一站，矮寨大桥。先给三个数字：主跨1176米，2012年3月通车，桥面到谷底高差超过300米。这座桥是钢桁梁悬索桥，架在两座大山之间，下面就是德夯大峡谷。当年施工难度极大，创造了同类型桥梁的多项世界纪录。站在观景平台上往下看，汽车在云里走。

而在大桥修通之前，人们要走下面的湘川公路。这条路修于1936年，抗战时期是通往大西南的命脉。它在6公里的路段里拐了13道回头弯，最陡的地方坡度极大，被称作"矮寨公路奇观"。抗战时，无数物资就是从这条"之"字路上运进内地的。

第二站，德夯大峡谷。"德夯"在苗语里的意思是"美丽的峡谷"。谷里有流纱瀑布，落差216米，水从崖顶飘下来，到半空就散成雾，像一缕轻纱，所以叫"流纱"。谷里还有苗寨，可以听到苗歌、看到苗鼓。

第三站，十八洞村。村里有18个天然溶洞，村因此得名。2013年11月3日，"精准扶贫"的重要理念在这里首次提出。八年之后，这个深山苗村整村脱贫，成了全国脱贫攻坚的样本。请大家留意村里的梨子、猕猴桃产业和苗绣工坊——这些都是真实的改变。

提醒：三个片区分属两县、相距较远，请勿安排在同半天；山区多雾多雨，请备防滑鞋与雨衣；村寨走访请尊重当地习俗，未经允许不要随意拍摄村民。愿大家看见桥、看见峡谷，也看见人。

**【讲解要点提示】**
- 必讲：矮寨大桥主跨与通车年份；矮寨公路奇观与1936年；十八洞村"精准扶贫"首倡地。
- 数据锚点：主跨1176米、2012年3月、桥面至谷底高差逾300米、公路6公里13道弯、1936年、流纱瀑布216米、2013年11月3日、2021年评5A。
- 常见误区：三片区分属吉首市与花垣县，不在一处；"矮寨大桥"与"矮寨公路"是新旧两代交通工程，不要混讲。
- 互动/提问设计：问"为什么要花这么大力气在山上架桥"，再讲湘川公路的历史与通行效率。

### 12. 湘西州凤凰古城旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年评定） |
| 所在地 | 湘西土家族苗族自治州凤凰县沱江镇 |
| 类型 | 古城古镇 · 民族风情 |
| 评定年份 | 2024 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

凤凰古城旅游区位于湘西土家族苗族自治州凤凰县沱江镇，2001年被列为国家历史文化名城，2024年评为国家5A级。古城依沱江而建，以吊脚楼、虹桥、东门城楼、古城墙、万名塔、万寿宫、沈从文故居、熊希龄故居、杨家祠堂等为主要看点。凤凰自明清以来即为湘西军事与商贸重镇，是苗族、土家族聚居区，境内还保存有始建于明代的南方长城（湘西边墙）遗存。作家沈从文（1902—1988）以《边城》等作品描写湘西风土，使凤凰成为中国文学地图上的重要坐标。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到凤凰古城。先说一句话：在中国，能被叫做"古城"的地方很多，但能同时拥有军事边墙、民族风情和一整部现代文学史的，只有凤凰。

先看水。沱江从古城中间穿过，江两边是一排排吊脚楼——一半在岸上，一半用木柱撑在水里。这是湘西山地民居最聪明的做法：平地少，就把房子挑到水上。傍晚时分，虹桥上的灯亮起来，水面倒影摇动，是凤凰最好看的一刻。

再看城。凤凰在明清两代是湘西的军事重镇，朝廷在这里设镇竿、驻重兵，为的是镇守苗疆。城外至今还留着一段明代修筑的"南方长城"——正式名称叫湘西边墙，始建于明嘉靖年间，全长约190公里，用来分隔与管控苗疆。这段墙不像北方长城那样高大，但它是真实的历史遗存。

第三看人。这里住着苗族、土家族。苗族的银饰、苗绣、苗鼓、赶秋节，都是活着的传统。"苗族赶秋"已被列入国家级非物质文化遗产名录。

第四看文。沈从文1902年出生在凤凰，他写的《边城》《湘西》，把这条江、这座城写进了中国现代文学。请注意：《边城》写的并不是凤凰古城，而是湘西边地小镇茶峒——即今湘西州花垣县边城镇，2005年由茶峒镇更名而来，地处湖南、重庆、贵州三省市交界（小说原文作"由四川过湖南去"，对岸洪安镇今属重庆市秀山县）。很多人搞混，讲解时要说清楚。

最后澄清一件事：湘西"赶尸"属于民间传说与旧时行当的说法，多见于文学作品和影视，不应当成真实的民俗活动来讲解。真正的湘西民俗，是苗歌、苗鼓和赶秋。

提醒：古城石板路湿滑，请穿防滑鞋；沱江边请勿翻越护栏；旺季人流密集，注意保管财物。愿大家在沱江的灯影里，遇见一个温柔的湘西。

**【讲解要点提示】**
- 必讲：沱江吊脚楼；南方长城（湘西边墙）；沈从文与《边城》；苗族民俗。
- 数据锚点：2001年列为国家历史文化名城、南方长城始建于明嘉靖年间全长约190公里、沈从文1902—1988、2024年评5A。
- 常见误区：《边城》描写的茶峒即今湘西州花垣县边城镇（2005年由茶峒镇更名），地处湘渝黔三省市交界，与凤凰古城并非同一处，不可混为一谈；"赶尸"属民间传说，不宜作为真实民俗讲解；古城核心区与"南方长城""奇梁洞"等景点分开售票。
- 互动/提问设计：问"吊脚楼为什么把柱子撑到水里"，再讲山地民居与防洪排涝的智慧。

- **凤凰古城旅游区**：2024年确定为国家5A级，具体公告批次与月份待与文化和旅游部公告原文复核。
- **岳麓山—橘子洲**：2012年评定，2016年被摘牌、2017年复牌，摘牌与复牌的正式文号待核实。
- **武陵源—天门山的片区关系**：文化和旅游部正式名录名称为"张家界市武陵源-天门山旅游区"。武陵源旅游区于2007年5月8日单独评定为5A，天门山景区于2011年9月6日以"扩展部分"并入同一家5A景区，自此合称现名。武陵源片区（武陵源区）与天门山片区（永定区）实际相距约40公里、分别售票，本文件已在词条开头加"讲解提示"专门说明。讲解时应说清楚"天门山不属于武陵源风景名胜区，但属于武陵源—天门山旅游区这一家5A"。
- **数据待复核**：矮寨大桥桥面至谷底高差（公开资料有300余米与350余米等说法，本文件采用"逾300米"）；东江湖总库容与蓄水量各版本数字不一，本文件仅采用"水面约160平方公里"与"坝高157米"；崀山天一巷（238.8米、最窄0.33米）、八角寨（818米）、辣椒峰（180余米）为景区常用口径；德夯流纱瀑布落差216米、南方长城全长约190公里均需以官方资料复核。
