### 1. 杭州西湖风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 杭州市西湖区 |
| 类型 | 水域湖泊 · 古典园林 · 世界文化遗产 |
| 评定年份 | 2007（首批） |
| 建议游览时长 | 4–6 小时 |

**【景区简介】**

杭州西湖风景区位于浙江省杭州市西部，三面云山、一面城垣，是中国最负盛名的城市湖泊风景名胜区。湖面面积约6.39平方公里，南北长约3.3公里、东西宽约2.8公里，苏堤、白堤横斜其间，将湖面分隔为外湖、里湖、西里湖、小南湖、岳湖五片水面。西湖自唐宋以来经一千余年持续营建，逐步形成以"西湖十景"为代表的题名景观传统，历代文人题咏不绝。2011年6月，"杭州西湖文化景观"被联合国教科文组织列入《世界遗产名录》，成为中国第41处世界遗产。景区内人文遗存密集，灵隐寺、雷峰塔、保俶塔、岳王庙、六和塔、三潭印月、白堤断桥等沿湖分布，另有中国茶叶博物馆、中国丝绸博物馆等专题场馆。

**【导游词核心稿】**

各位游客，大家好！欢迎来到"天下西湖三十六，就中最胜是杭州"的西湖。我们现在所在的这片水面，面积约6.39平方公里，说大不大，说小不小——绕湖一周大约15公里，步行一圈要走四五个小时，所以今天咱们择其精华而行。

西湖的美，美在"一湖两堤三岛"。苏堤是北宋元祐年间苏轼疏浚西湖、以淤泥筑成的长堤，全长近2.8公里，堤上六桥起伏，春日桃柳夹岸，这就是"苏堤春晓"。白堤则把孤山与城区连在一起，尽头那座断桥，因《白蛇传》中许仙与白娘子在此相会而家喻户晓——相传那是南宋年间的故事，说的是伞为媒、雨为凭的一段情缘，桥其实从未断过，名字来自冬日雪后"断桥残雪"的景致。

再看湖心那三座葫芦形小石塔，名叫三潭印月。三塔建于北宋，塔身中空、球面开五孔，中秋之夜点烛其中、糊以薄纸，月光、灯光、湖光交映，据说一轮明月能化出三十三个月亮，因此有"天上月一轮，湖中影成三"的说法。它还上了我们一元人民币纸币的背面，大家不妨掏出一张比对一下。

西湖不只有风月。北岸的岳王庙纪念的是南宋抗金名将岳飞，墓阙下有四个铁铸跪像；西岸的雷峰塔于2002年在原址上重建，新塔高71.7米，塔身用铜构件装饰，站在顶层可俯瞰全湖。2011年，西湖以"文化景观"身份入选世界遗产，世界遗产委员会给它的评语是：西湖是"天人合一"理想的杰出范例。

好了，眼前的湖光山色还请大家慢慢走、细细看。拍照时注意台阶湿滑，团队集合时间请大家记牢。祝大家在西湖有一段愉快的时光！

**【讲解要点提示】**
- 必讲：苏堤/白堤由来、断桥与白蛇传、三潭印月、2011年世界遗产身份。
- 数据锚点：湖面6.39平方公里；苏堤近2.8公里；雷峰塔重建后高71.7米；2011年6月列入《世界遗产名录》。
- 常见误区：断桥并非"桥断了"；西湖是世界"文化景观"而非自然遗产；雷峰塔是2002年重建的新塔，不是原塔。
- 互动/提问设计：请游客找出一元纸币背面的三潭印月，比对实景；请游客背诵一句咏西湖的古诗。

### 2. 温州乐清雁荡山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 温州市乐清市 |
| 类型 | 山岳峰林 · 地质地貌 · 世界地质公园 |
| 评定年份 | 2007（首批） |
| 建议游览时长 | 1.5–2 天 |

**【景区简介】**

雁荡山风景区位于浙江省温州市乐清市境内，部分延伸至台州温岭，主体属白垩纪流纹质火山岩地貌，是环太平洋火山带上一处保存完整的古火山地质遗迹。雁荡山因山顶有湖、芦苇丛生、秋雁宿之而得名，素有"海上名山、寰中绝胜"之誉。核心景区分为灵峰、灵岩、大龙湫、雁湖、显胜门、仙桥、羊角洞等片区，以"雁荡三绝"——灵峰、灵岩、大龙湫最为著名。大龙湫瀑布落差约197米，为中国落差最大的单体瀑布之一，随四季水量变化呈现不同形态。山中历代摩崖石刻与寺观遗存丰富，2005年经联合国教科文组织批准为世界地质公园。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到被誉为"海上名山、寰中绝胜"的雁荡山。先给大家打个底：雁荡山不是普通的山，它是一亿二千万年前白垩纪火山喷发留下的杰作——今天你看到的每一块流纹岩，都是当年炽热熔岩冷却后的纹路，那层层叠叠的条带，就是流动的岩浆被瞬间"定格"的样子。正因为这份独特，2005年联合国教科文组织把雁荡山列为世界地质公园。

雁荡山有"三绝"，今天咱们一一走过来。第一绝是灵峰。白天看灵峰，是两座相依的巨岩，叫"合掌峰"；可到了夜里，随着脚步移动、角度变换，同一块石头能变出雄鹰敛翅、夫妻相拥、婆婆拜观音等十余种形象。当地有句老话："灵峰一日景，夜景更销魂"，靠的就是这"移步换景"。

第二绝是灵岩，屏霞嶂高耸如墙，天柱峰、展旗峰一左一右对峙，两峰相距约200米，之间悬着一根钢丝绳——每天都有当地药农的后人表演"飞渡"，在高空翻跟头、撒红纸，相传这项技艺源自古时上山采石斛的采药人，已有上百年历史。

第三绝是大龙湫。这是一条落差约197米的单级瀑布，从连云嶂顶直泻潭中。有意思的是它"四季变形"：春夏水量大时如白龙飞舞，秋冬水少则化作一缕轻烟，飘到半空就散了。清代诗人袁枚写它"五丈以上尚是水，十丈以下全为烟"，说得极准。

雁荡山自南北朝起就有文人寻访，沈括在《梦溪笔谈》里就记录过这里的特殊地貌。现在请大家跟随我进入景区，山路湿滑、台阶较多，请穿好防滑鞋。祝大家看山不迷路、拍照不虚行！

**【讲解要点提示】**
- 必讲：白垩纪流纹质火山成因；雁荡三绝（灵峰、灵岩、大龙湫）；灵峰夜景的移步换景。
- 数据锚点：白垩纪距今约1.2亿年；大龙湫落差约197米；灵岩天柱峰与展旗峰间距约200米；2005年世界地质公园。
- 常见误区：雁荡山主体在乐清，不是一座孤立的"雁荡峰"；大龙湫水量季节性极强，枯水期可能只见细流。
- 互动/提问设计：在灵峰请游客各自猜"这块石头像什么"，比对不同角度的答案；在大龙湫请游客观察水汽雾化高度。

### 3. 舟山普陀山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 舟山市普陀区 |
| 类型 | 宗教圣地 · 山岳峰林 · 水域湖泊 |
| 评定年份 | 2007（首批） |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

普陀山风景区位于浙江省舟山市普陀区，是舟山群岛中的一个小岛，岛域面积约12.5平方公里，最高峰佛顶山海拔约291米。普陀山为中国佛教四大名山之一，自唐代起被尊为观世音菩萨应化道场，有"海天佛国""南海圣境"之称。全岛寺庵林立，以普济寺、法雨寺、慧济寺三大寺为核心，另有不肯去观音院、紫竹林、梵音洞、千步沙、百步沙等胜迹。岛东南端矗立的南海观音露天铜像，是普陀山的标志性景观。山中古木参天、奇石嶙峋，海蚀崖、沙滩与寺观建筑相互映衬，是集佛教文化、海岛风光于一体的朝圣与游览胜地。

**【导游词核心稿】**

各位游客，大家好！欢迎登上"海天佛国"普陀山。我们脚下这座小岛面积约12.5平方公里，海拔最高处是佛顶山，约291米——山不高，却是天下公认的观音道场。中国佛教四大名山各有分工：五台文殊、峨眉普贤、九华地藏，而普陀，供奉的是观世音菩萨。

第一站，我们去看南海观音。这尊露天铜像面朝大海，身高与基座合起来气势恢宏，是上世纪九十年代建成后普陀山的新地标。站在像下抬头仰望，背后是海、头顶是天，这种"面朝大海"的格局，正是观音信仰里"慈航普渡"的写照。

第二站，是三大寺。先说普济寺，它是全山最大的寺院，始建于北宋，主殿供奉的观音像两侧列着三十二应身，代表观音随缘化现的各种形象。法雨寺则藏在山坳里，屋脊上的九龙藻井是从南京明代宫殿拆运而来，极为珍贵。慧济寺在佛顶山顶，要爬1088级台阶上去，当地有"不上佛顶，等于没到普陀"的说法——不过体力不好的朋友也可以乘索道。

再给大家讲一段与普陀开山有关的传说。相传五代后梁年间，日本僧人慧锷从五台山请得一尊观音像，渡海归国时行至普陀洋面，忽起风浪、舟不能行，他便以为菩萨"不肯去"东瀛，于是就地建庵供奉，这就是"不肯去观音院"的由来。这个传说在《普陀山志》里有记载，也是普陀山成为观音道场的起点。

最后提醒各位：普陀山是宗教活动场所，进殿请轻声慢语、勿踏门槛、勿对佛像拍照；岛上山路多台阶，穿软底鞋更省力。祝大家此行平安、称心！

**【讲解要点提示】**
- 必讲：观音道场地位；三大寺（普济、法雨、慧济）；不肯去观音院传说。
- 数据锚点：岛域面积约12.5平方公里；佛顶山海拔约291米；慧济寺前1088级台阶。
- 常见误区：普陀山是行政上的"岛"而非"山"，与"普陀区"是两个层级的概念；慧济寺可乘索道替代登山。
- 互动/提问设计：请游客辨认殿堂内观音的三十二应身；在"不肯去观音院"请游客复述慧锷请像的故事。

### 4. 杭州淳安千岛湖风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 杭州市淳安县 |
| 类型 | 水域湖泊 · 森林草原 |
| 评定年份 | 2010 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

千岛湖风景区位于浙江省杭州市淳安县境内，是1959年新安江水电站建成蓄水后形成的大型人工湖，即新安江水库。湖区水域面积约573平方公里，蓄水量约178亿立方米，因水位抬高淹没了众多山峦，露出水面的山顶化作星罗棋布的岛屿，故得名"千岛湖"。湖区森林覆盖率高，水质长期保持优良，是中国著名的饮用水源地和优质淡水湖。主要游览区包括中心湖区、东南湖区，著名岛屿有梅峰岛、龙山岛、月光岛、渔乐岛等；湖底完好保存着始建于唐代的狮城、贺城两座千年古城，是极具价值的水下文化遗产。

**【导游词核心稿】**

各位游客，大家好！欢迎来到千岛湖。先问大家一个问题：这片湖是天然形成的，还是人工造出来的？答案是——人工。1959年，新安江水电站大坝合龙蓄水，江水上涨，把原本连绵的群山淹了大半，只留下一座座山顶露出水面，于是有了这1078座岛屿和"千岛湖"这个名字。

数据摆在这里：水域面积约573平方公里，相当于100个西湖；蓄水量约178亿立方米；最深处超过100米。这么大一盆水，靠的是上游流域的森林涵养，所以千岛湖的水一直以清著称，很多矿泉水品牌的水源就取自这一带。

上岛看什么？我推荐三处。第一是梅峰岛，"不上梅峰观群岛，不识千岛真面目"，登顶观景台可以俯瞰三百多个岛屿组成的天然"公"字形图案。第二是龙山岛，岛上有海瑞祠——明代清官海瑞曾任淳安知县，当地百姓立祠纪念他，这是淳安人世代相传的一段正气。第三是月光岛，由若干小岛以浮桥串联，夜游灯光别有意境。

再说一件很多人不知道的事：我们船下这汪清水里，沉睡着两座古城——狮城和贺城。据史料记载，狮城自唐代设县，城墙、牌坊、街巷格局完整，1959年蓄水时被整体淹没，因水深、水温低而保存较好。近年水下考古曾探明部分城墙与民居遗迹，因此千岛湖又有"水下古城博物馆"之称。

各位上船后请全程穿好救生衣，甲板湿滑请扶好栏杆，垃圾请带回船上。祝大家湖上顺风、满载而归！

**【讲解要点提示】**
- 必讲：1959年新安江水电站蓄水成因；1078座岛屿；梅峰观群岛；水下狮城与贺城。
- 数据锚点：1959年建成蓄水；水域约573平方公里；岛屿1078座；蓄水量约178亿立方米。
- 常见误区：千岛湖是人工湖而非天然湖；岛上景点需乘船，行程受天气与水位影响。
- 互动/提问设计：在梅峰观景台请游客数一数能看见多少座岛；请游客猜"千岛湖有多少个西湖大"。

### 5. 嘉兴桐乡乌镇古镇旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 嘉兴市桐乡市 |
| 类型 | 古城古镇 · 水域湖泊 |
| 评定年份 | 2010 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

乌镇古镇旅游区位于浙江省嘉兴市桐乡市，地处杭嘉湖平原腹地、京杭大运河南端，是典型的江南水乡古镇，建镇史可追溯至唐代，现存格局定型于明清。全镇以市河为轴，十字形水系将镇区分为东栅、西栅、南栅、北栅四块，至今保存大量明清民居、石桥、廊棚与水阁建筑。乌镇是中国现代文学巨匠茅盾的故乡，镇上保存有茅盾故居；同时也是木雕、蓝印花布、蚕丝织造等传统工艺的集聚地。乌镇自2013年起举办乌镇戏剧节，自2014年起成为世界互联网大会永久举办地，是国内保护与活化利用并重的古镇样板。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到"中国最后的枕水人家"——乌镇。大家先看脚下：一条市河穿镇而过，两岸是密密麻麻的木结构老屋，屋子的墙一半在水里、一半在岸上，这种建筑叫"水阁"，也叫"吊脚楼"，是乌镇最独特的符号。当地人世代枕河而居，推窗就是河，出门就是船。

乌镇有1300多年的建镇史。唐时这里已是江南重镇，明清时期因蚕桑和漕运而富甲一方。走在东栅、西栅的青石板路上，两边是染坊、酒坊、酱园、木雕馆——那高高挂起的蓝印花布，是用黄豆粉和石灰调成的防染浆手工刮印出来的，一套工序要七八道。

乌镇出过一个了不起的人：茅盾。他本名沈德鸿，是中国现代文学的重要作家，代表作《子夜》《春蚕》写的就是这片江南水乡。镇东栅的茅盾故居是他出生和少年读书的地方，屋里的书桌、油灯都按原样摆放，《春蚕》里描写的养蚕人家，原型就在这一带。

再看老街上那些石桥，桥下是水、桥上是廊——这种带顶的街叫"廊棚"，江南六大古镇里，西塘的廊棚最有名，乌镇的水阁最地道。夜里搭乘摇橹船在西栅水巷穿行，两岸灯笼倒映，是乌镇最值得留的一幕。

最后提醒：古镇街巷狭窄、桥面有台阶，请看管好老人小孩；夜游船班与戏剧节期间的演出安排变动较多，出行前请核实最新公告。祝大家在乌镇走得慢一点、看得细一点。

**【讲解要点提示】**
- 必讲：水阁/枕水人家；十字形水系与东栅西栅格局；茅盾故居与《春蚕》；蓝印花布等非遗。
- 数据锚点：建镇史1300余年；2013年首届乌镇戏剧节；2014年起为世界互联网大会永久举办地。
- 常见误区：乌镇的"东栅/西栅/南栅/北栅"是四片区域，其中南栅、北栅多为未开发的生活区。
- 互动/提问设计：请游客辨认水阁的承重木柱；请游客说一句茅盾作品的名字。

### 6. 宁波奉化溪口-滕头旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 宁波市奉化区 |
| 类型 | 古城古镇 · 宗教圣地 · 乡村田园 |
| 评定年份 | 2010 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

溪口-滕头旅游景区位于浙江省宁波市奉化区，由溪口镇与滕头村两大片区联合组成，2010年联合创建为国家5A级旅游景区。溪口是蒋介石、蒋经国父子的故里，镇上保存有丰镐房、玉泰盐铺、文昌阁、小洋房、蒋母墓道等近代史迹，其中蒋氏故居为全国重点文物保护单位。溪口镇西侧的雪窦山为浙东名山，山中有千年古刹雪窦寺、千丈岩瀑布与妙高台，历史上与佛教弥勒信仰关系密切。滕头村则以生态农业和美丽乡村建设闻名，曾获联合国"全球500佳"环境奖，是国内外知名的社会主义新农村样板。

**【导游词核心稿】**

各位游客，大家好！欢迎来到宁波奉化溪口-滕头。我们这个景区有点特别：一边是近代风云人物的故里，一边是生态乡村的样板，两种气质凑在同一张门票里。

先说溪口。溪口镇依剡溪而建，三面环山，明清以来就是浙东重镇。镇上的蒋氏故居群保存得相当完整：丰镐房是蒋介石出生和居住的老宅，玉泰盐铺是他祖父开的盐店，文昌阁是他回乡时常住之处，小洋房则带着明显的西洋风格。蒋母墓道在镇北的鱼鳞岙，沿石阶上行数百级，沿途有几处亭榭可供歇脚。讲解这段历史时我们会坚持一个原则：如实陈述、不作评判，让建筑自己说话。

再说雪窦山。它就在溪口镇西北，自古有"四明第一山"之称。山中的雪窦寺创建于晋代、兴盛于宋代，是佛教界公认的弥勒道场之一；寺后千丈岩瀑布从崖壁飞泻而下，崖顶的妙高台地势平坦开阔，可俯瞰群山。徐霞客曾游历此山并在游记中留下记载。

最后去看看滕头村。这个村子在上世纪九十年代就以生态农业起家，立体种植、立体养殖，把村居、果园、蔬菜大棚规划在一起，1993年前后获得联合国环境规划署授予的"全球500佳"称号，后来又多次亮相国内外博览会的乡村展馆。今天的滕头，既是景区，也是仍然在运转的村庄。

提醒各位：参观名人故居时请保持肃静，室内多不允许拍照；雪窦山山路弯多，晕车的朋友请提前做好准备。祝大家此行既有历史的厚度，也有田园的温度。

**【讲解要点提示】**
- 必讲：蒋氏故居群（丰镐房、玉泰盐铺、文昌阁、蒋母墓道）；雪窦寺与千丈岩；滕头村的生态乡村模式。
- 数据锚点：2010年溪口与滕头联合创5A；滕头村获联合国"全球500佳"；蒋氏故居为全国重点文物保护单位。
- 常见误区：溪口-滕头是一个5A景区下的两个片区，不在同一处，需分别安排时间；雪窦山与溪口镇之间有段车程。
- 互动/提问设计：请游客观察丰镐房门楣与江南普通民居的差别；在滕头请游客猜"立体农业"是什么。

### 7. 金华东阳横店影视城景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 金华市东阳市 |
| 类型 | 主题乐园 · 城市地标 |
| 评定年份 | 2010 |
| 建议游览时长 | 2–3 天 |

**【景区简介】**

横店影视城景区位于浙江省金华市东阳市横店镇，是国内规模最大的影视拍摄基地群，有"中国好莱坞"之称。基地自1996年为拍摄电影《鸦片战争》兴建广州街起步，此后陆续建成秦王宫、清明上河图、明清宫苑、梦幻谷、圆明新园、广州街·香港街等数十个跨越不同历史时期的实景拍摄基地与主题园区。横店同时配套有完整的剧组服务体系与演艺项目，日常有大量剧组驻场拍摄，游客可观赏《梦幻太极》《暴雨山洪》等大型实景演艺，并参与影视体验项目。2010年，横店影视城被评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到"中国好莱坞"——横店影视城。先给大家讲个起点故事：1996年，谢晋导演要拍《鸦片战争》，需要一条十九世纪的广州街，当地就在荒坡上按原样把它建了出来。片子拍完，房子留了下来，就这样一发不可收拾，慢慢长成了今天这片跨越几千年的"实景片场"。

横店最大的乐趣，是"一天穿越几千年"。早上去秦王宫，那是为电影《荆轲刺秦王》量身建造的，秦咸阳宫的复道、阙楼、四海归一殿都按秦汉规制复原，站在99级台阶下往上看，压迫感极强；中午转到清明上河图景区，参照北宋画家张择端的名作布局，虹桥、汴河、市井街铺一一再现，走在里面就是一幅活的宋画；下午进明清宫苑，按北京故宫的形制营建，中轴线上的太和殿、乾清门一个不落。

要说横店和别处最大的不同，是"这里是活的片场"。景区里常年有多个剧组同时开工，运气好的话您能隔着警戒线看到真实的拍摄现场——所以请务必留意现场的通告牌，不要跨越警戒、不要开闪光灯，这是行规，也是对剧组的尊重。

晚上，我推荐两场演出。《梦幻太极》以声光电与真人表演结合讲太极文化；《暴雨山洪》则用真实的洪水倾泻再造灾难场景，场面相当震撼。这两场是横店最叫座的招牌。

最后提醒：横店各园区之间距离较远，靠景区巴士串联，请提前规划好路线；演出场次随季节调整，出行前请核实当日排期。祝大家在横店"入戏愉快"！

**【讲解要点提示】**
- 必讲：1996年《鸦片战争》广州街的起点故事；秦王宫、清明上河图、明清宫苑三大园区；横店是"活的片场"。
- 数据锚点：1996年建广州街；2010年创建5A；数十个大型实景拍摄基地。
- 常见误区：横店是众多独立园区的集群，不是"一个门进去逛完"的单一景区；看到剧组拍摄不等于可以随意靠近。
- 互动/提问设计：请游客辨认明清宫苑与北京故宫的异同；请游客猜一部在横店拍摄过的影视剧。

### 8. 嘉兴南湖旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 嘉兴市南湖区 |
| 类型 | 红色旅游 · 水域湖泊 · 古典园林 |
| 评定年份 | 2011 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

嘉兴南湖旅游区位于浙江省嘉兴市南湖区，是浙江三大名湖之一（与杭州西湖、绍兴东湖并称）。南湖因位于嘉兴城南而得名，湖中有湖心岛与小瀛洲，岛上烟雨楼始建于五代吴越时期、重建于明代，为江南名楼。南湖在中国革命史上地位特殊：1921年7月，中国共产党第一次全国代表大会由上海转移至南湖，在一艘游船上继续举行并闭幕，宣告中国共产党成立，这艘船后来被称为"红船"。景区以南湖革命纪念馆、红船、烟雨楼、会景园、揽秀园等为主要景点，是重要的革命纪念地与红色旅游目的地。

**【导游词核心稿】**

各位游客，大家好！欢迎来到嘉兴南湖。这片湖不大，却因为一件事被写进了中国近现代史的第一页。

先把时间拨回1921年7月。中国共产党第一次全国代表大会在上海举行，会议进行中因遭到法租界巡捕的干扰而被迫中断。代表们随后转移到嘉兴，在南湖的一艘游船上继续开会，通过了党的第一个纲领和决议，选举产生了中央领导机构，宣告中国共产党正式成立。这艘船，就是我们今天要去看的"红船"——它不是当年原物，而是1959年依照当事人回忆与当年船型仿制复原的纪念船，停泊在湖心岛东南岸。

上岛之后，最先看到的是烟雨楼。楼名取自唐代诗人杜牧"南朝四百八十寺，多少楼台烟雨中"的意境，始建于五代，明代重建于湖心岛，乾隆皇帝六下江南时曾多次登临。站在楼上望出去，湖面开阔，菱角与芦苇随季节变换，这就是"烟雨楼台"的由来。

湖东岸的南湖革命纪念馆新馆，1991年落成、2011年扩建重开，馆内系统陈列着从鸦片战争到中国共产党成立的史料，展厅里那句"开天辟地的大事变"，说的就是在这条小船上发生的事。参观时请留意序厅与尾厅的浮雕，脉络很清楚：从"探索"到"觉醒"，再到"缔造"。

提醒各位：纪念馆为庄严肃穆场所，请轻声慢语、脱帽肃立，馆内按照指示参观；登船与登岛需排队，请看管好随行老人与儿童。祝大家此行有所思、有所得。

**【讲解要点提示】**
- 必讲：1921年中共一大由上海转移至南湖闭幕；红船；烟雨楼；南湖革命纪念馆。
- 数据锚点：1921年7月；红船为1959年仿制复原；纪念馆2011年扩建重开。
- 常见误区：湖心岛上的红船是仿制复原的纪念船，不是1921年原物；南湖与"南湖红船"所在位置需乘船抵达。
- 互动/提问设计：请游客说出一大的召开年份；请游客观察烟雨楼"重檐歇山"的屋顶形制。

### 9. 杭州西溪湿地旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 杭州市西湖区、余杭区 |
| 类型 | 水域湖泊 · 森林草原 · 城市地标 |
| 评定年份 | 2012 |
| 建议游览时长 | 4–6 小时 |

**【景区简介】**

杭州西溪湿地旅游区位于浙江省杭州市西部，是国内首个国家湿地公园，2005年经国家林业局批准设立。西溪是一处典型的城市次生湿地，由河港、湖漾、沼泽、塘垛交织而成，水网密布，"一曲溪流一曲烟"是其最形象的写照。湿地内植被丰富，以芦苇、柿树、梅花、竹林为特色，栖息着大量鸟类与鱼类，素有"杭州之肾"之称，对调节城市气候与涵养水源作用显著。主要游览区包括福堤、绿堤、寿堤三堤，以及秋雪庵、深潭口、河渚街、洪园、高庄等景点；每年秋季举办的西溪火柿节与冬季的探梅活动最具人气。

**【导游词核心稿】**

各位游客，大家好！欢迎来到杭州西溪湿地。如果说西湖是杭州的脸面，那西溪就是杭州的肺——这个比喻不是我编的，是生态学上的实情：湿地能吸水、净水、调节小气候，所以西溪有个外号叫"杭州之肾"。

西溪的水，和西湖完全不一样。西湖是一汪开阔的湖面，西溪则是密密麻麻的水网：河港、湖漾、池塘、沼泽缠在一起，船行其间，常常是"前面没路了，一转弯又是一片水"。古人总结得好——"一曲溪流一曲烟"，说它弯多、水汽重。整个湿地的水域占了很大比重，坐电瓶船是最省力也最地道的玩法。

上岸看什么？三样东西最值得留意。第一是柿树。西溪的柿子有几百年的种植史，每到秋天，水边一树一树的红灯笼，景区会办火柿节。第二是芦苇和芦花。深秋时节，河渚一带芦花如雪，旧时"秋雪庵"的名字就是这么来的。第三是老房子。洪园、高庄这一片是明清江南园林与民居的遗存，白墙黑瓦，临水而筑。

还有一段人文旧事要讲：西溪自宋元以来就是文人隐居与雅集之地，历代诗词题咏不断；清代《西湖志》里也专门记过西溪的"梵隐"格局——庵堂、别业散落水间，读书人在这里读书、养性。电影《非诚勿扰》曾在此取景，让西溪一下子被全国观众认识。

提醒各位：湿地栈道湿滑，请勿翻越护栏、请勿投喂野生动物；春秋两季蚊虫较多，建议穿长袖。祝大家在西溪慢慢走、静静看。

**【讲解要点提示】**
- 必讲：国内首个国家湿地公园（2005年）；水网型次生湿地特征；柿树、芦苇、梅花三季景观。
- 数据锚点：2005年设立国家湿地公园；2012年创建5A；三堤（福堤、绿堤、寿堤）。
- 常见误区：西溪不是"一片湖"，而是水网湿地；西溪与西湖是两个独立景区，相距有相当距离。
- 互动/提问设计：请游客观察水面植物并说出三种；在洪园请游客指出江南园林"借景"的用法。

### 10. 绍兴鲁迅故里-沈园景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 绍兴市越城区 |
| 类型 | 古城古镇 · 博物馆场馆 · 古典园林 |
| 评定年份 | 2012 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

鲁迅故里-沈园景区位于浙江省绍兴市越城区鲁迅中路，由鲁迅故里与沈园两个片区组成。鲁迅故里包括鲁迅祖居（周家老台门）、鲁迅故居（周家新台门）、百草园、三味书屋、绍兴鲁迅纪念馆等，是鲁迅出生并度过少年时代的地方，为全国重点文物保护单位。鲁迅（1881—1936）原名周树人，是中国现代文学的奠基者之一。沈园位于鲁迅故里东侧，为宋代始建的江南古典园林，因南宋诗人陆游与前妻唐琬在此重逢并各题《钗头凤》而闻名，园内现存孤鹤亭、半壁亭、双桂堂、陆游纪念馆等，是绍兴"宋韵"文化的重要载体。

**【导游词核心稿】**

各位游客，大家好！欢迎来到绍兴鲁迅故里-沈园。绍兴这座城，两千五百年城址未变，三步一个典故；而我们要看的这两处，一个是新文学的起点，一个是八百年前的一段旧情。

先看鲁迅故里。鲁迅生于1881年，本名周树人，"鲁迅"是他1918年发表《狂人日记》时用的笔名。走进周家新台门，穿过堂屋，后面就是百草园——对，就是课本里那个"碧绿的菜畦，光滑的石井栏，高大的皂荚树"。鲁迅在《从百草园到三味书屋》里写到的泥墙根，今天还在原处。三味书屋在另一侧，是鲁迅少年时的私塾，屋角那张刻着"早"字的书桌，相传是他因迟到受先生批评后自己刻下以示警戒的——这个故事流传很广，但严格说属于后人追述，大家当作一段励志的佳话来听就好。

再往东走几步，就是沈园。沈园原为南宋沈姓富商的私家园林，八百多年来几度兴废，现存园林为上世纪八十年代以来依宋代格局修复。园子因一段故事而不朽：据史料记载与宋人笔记所述，南宋诗人陆游与表妹唐琬婚后被迫离异，多年后在沈园不期而遇，陆游在园壁题下《钗头凤·红酥手》，唐琬见后和词一首，不久郁郁而终。这两阕词一刚一柔，写尽"错、错、错"与"难、难、难"。今天园中的孤鹤亭、葫芦池、断云石，都是当年旧景的延续。

游览提醒：鲁迅故里为免费开放景区，凭票或预约入内；室内展馆请勿拍照、请勿触摸展品。祝大家在绍兴既读到文章，也读到人生。

**【讲解要点提示】**
- 必讲：百草园与三味书屋；"早"字书桌典故；陆游与唐琬的《钗头凤》。
- 数据锚点：鲁迅生卒年1881—1936；1918年发表《狂人日记》；沈园始建于南宋。
- 常见误区：沈园现存园林为现代修复，不是宋代原构；"早"字故事属后人追述，非鲁迅自述。
- 互动/提问设计：请游客背诵一句《从百草园到三味书屋》的开头；在沈园请游客读一遍《钗头凤》的上下片。

### 11. 衢州开化根宫佛国文化旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 衢州市开化县 |
| 类型 | 博物馆场馆 · 宗教圣地 · 古典园林 |
| 评定年份 | 2013 |
| 建议游览时长 | 3–5 小时 |

**【景区简介】**

根宫佛国文化旅游区位于浙江省衢州市开化县，地处浙皖赣三省交界、钱塘江源头，是全球唯一以根雕艺术为主题的国家5A级旅游景区。开化根雕有上千年传承史，与青田石雕、东阳木雕、黄杨木雕并称，被业内称为"浙江第四雕"。景区占地面积约3.03平方公里，分三期建设，包含福门祥光、云湖禅心、根宫佛塔等四十余个景点，陈列大型根雕艺术系列作品两万余件（套），被吉尼斯世界纪录官方认证为"全球最大的根雕博物馆"。核心作品包括大雄宝殿内高约9.9米、重四十余吨的释迦牟尼根雕，以及长达680米的五百罗汉长廊。景区于2013年9月创建为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到开化根宫佛国。先请大家想一个问题：树根——通常是被砍掉、被丢弃、被当柴烧的那一部分，能不能变成艺术？走进这里，答案就摆在眼前。

开化根雕有一千多年的传承，与青田石雕、东阳木雕、黄杨木雕并称，业内把它叫做"浙江第四雕"。这门手艺讲究一句话：三分人工，七分天成。什么意思？树根在水里、泥里埋了千百年，被腐蚀、被扭曲，本身就长出了奇形；匠人不硬改它，而是顺着它的走势，把"像什么"看出来、点出来。所以你看到的每一件根雕，既是人做的，也是天做的。

景区的规模值得先说清楚：占地约3.03平方公里，分三期，四十多个景点，陈列大型根雕作品两万余件（套）。2013年前后，这里被吉尼斯世界纪录认证为"全球最大的根雕博物馆"——这个称号，全世界只有它一家。

重点看三处。第一是大雄宝殿里的释迦牟尼根雕，高约9.9米、重四十余吨，据景区介绍被称为"天下根雕第一佛"，整尊佛像是依一整段巨型根材顺势雕出的。第二是五百罗汉长廊，长680米，五百尊罗汉神态各异，没有两尊是重复的，走完全程要二十来分钟。第三是"福门祥光"雕塑群和根宫佛塔，汉唐风格的建筑与江南园林的布局结合，建筑本身就值得细看。

提醒各位：馆内为室内展陈，请勿触摸作品、请勿使用闪光灯；部分作品体量巨大，拍照请退到安全线外。祝大家在根宫佛国，看见"化朽为奇"的力量。

**【讲解要点提示】**
- 必讲："三分人工、七分天成"的工艺理念；9.9米释迦牟尼根雕；680米五百罗汉长廊；吉尼斯认证。
- 数据锚点：占地约3.03平方公里；根雕作品两万余件（套）；佛雕高9.9米、重40余吨；长廊680米；2013年9月创5A。
- 常见误区：根宫佛国是根雕艺术主题景区，不是传统寺庙；展出的是艺术作品而非宗教造像供奉。
- 互动/提问设计：请游客在罗汉长廊找出"最像自己"的一尊；请游客猜一段树根埋了多少年。

### 12. 湖州南浔古镇景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 湖州市南浔区 |
| 类型 | 古城古镇 · 古典园林 |
| 评定年份 | 2015 |
| 建议游览时长 | 5–7 小时 |

**【景区简介】**

南浔古镇景区位于浙江省湖州市南浔区，地处太湖南岸、江浙交界，是江南六大古镇之一，南宋以来因蚕丝贸易而兴盛。明清时期南浔以"辑里湖丝"闻名天下，该丝曾在1851年伦敦首届世界博览会获奖，富商巨贾云集，留下小莲庄、嘉业堂藏书楼、张石铭旧宅、刘氏梯号（红房子）、百间楼等大批中西合璧建筑群。当地以"四象八牛七十二金黄狗"形容丝商家族的财富等级。南浔兼具江南水乡格局与近代西洋建筑风格，历史文化积淀深厚，2015年被评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到南浔。都说江南六大古镇各有脾气：周庄是"中国第一水乡"，乌镇最"枕水"，西塘的廊棚最长，而南浔——南浔是最"有钱"的那个。

南浔的富，富在蚕丝。明清时期，这里出产一种叫"辑里湖丝"的生丝，细、白、匀、韧，是丝中上品。据史料记载，1851年伦敦举办首届世界博览会，辑里湖丝参展并获奖，从此名扬海外。靠着这条丝，南浔出了一大批巨富。当地有个特别的说法，用动物体型给财富分级：家产千万两白银以上的叫"象"，五百万两以上的叫"牛"，一百万两以上的叫"金黄狗"——合起来就是"四象八牛七十二金黄狗"，听着像玩笑，其实是当年实打实的财富榜。

有钱就盖房。南浔的老宅子，最妙的在于"中西合璧"。外表是粉墙黛瓦、马头墙、砖雕门楼，一脚进门，后院可能就是一栋红砖拱券的西洋楼——刘氏梯号俗称"红房子"，就是典型。张石铭旧宅里还藏着一间法式舞厅，地砖和玻璃都是从欧洲运来的。

再说两处必看。一是小莲庄，为南浔"四象"之首刘镛家族的私家园林，以荷花池为中心，夏日荷花开满池，是江南园林的精品。二是嘉业堂藏书楼，与小莲庄一墙之隔，是近代规模最大的私家藏书楼之一，由刘承干建于上世纪初，鼎盛时藏书数十万卷。

提醒各位：古镇街巷沿河，桥多台阶多，请看护好老人与小孩；出行前请核实各景点开放与联票情况。祝大家在南浔读出江南的另一副面孔。

**【讲解要点提示】**
- 必讲：辑里湖丝与1851年世博会获奖；"四象八牛七十二金黄狗"财富等级；中西合璧建筑（刘氏梯号、张石铭旧宅）；小莲庄、嘉业堂。
- 数据锚点：2015年创建5A；1851年伦敦首届世博会；嘉业堂藏书楼建于上世纪初。
- 常见误区：南浔属湖州市南浔区，行政上是"区"不是"镇"；"红房子"等建筑是中西合璧，非纯西式。
- 互动/提问设计：请游客找出宅院中一处"西洋元素"；请游客猜"四象"指的是多少家。

### 13. 台州天台天台山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 台州市天台县 |
| 类型 | 宗教圣地 · 山岳峰林 · 水域湖泊 |
| 评定年份 | 2015 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

天台山景区位于浙江省台州市天台县，是中国佛教天台宗的发源地与道教南宗的祖庭，素有"佛宗道源、山水神秀"之誉。佛教方面，隋开皇十八年（598年）创建的国清寺为天台宗根本道场，日本、韩国天台宗奉其为祖庭；道教方面，桐柏宫为道教南宗祖庭。自然方面，天台山以石梁飞瀑、华顶归云、赤城栖霞、琼台夜月等景观著称，主峰华顶山海拔约1098米，山间有华顶国家森林公园与大片云锦杜鹃。明代旅行家徐霞客的《游天台山日记》为其游记的开篇之作。景区于2015年被评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到"佛宗道源、山水神秀"的天台山。天台山在中国文化史上的地位，用一句话概括：它是佛教天台宗的老家，也是道教南宗的老家——一座山同时是两大思想体系的祖庭，全国找不出第二处。

先说佛。国清寺始建于隋开皇十八年，也就是公元598年，是天台宗创始人智者大师的道场。天台宗是佛教传入中国后第一个真正意义上的本土宗派，主张"止观并重"，后来传入日本、朝鲜半岛，日本天台宗与日莲宗至今仍奉国清寺为祖庭，每年都有海外僧侣来此寻根。寺中最耐看的，是那株传为隋代所植的隋梅、王羲之题写的"鹅"字碑，以及大雄宝殿后的千年古樟。

再说道。桐柏宫在县城西北，是道教南宗祖庭，宋代张伯端（紫阳真人）在此著《悟真篇》，讲内丹修炼，对后世道教影响深远。

山水这边，天台山有两样招牌。一是石梁飞瀑：一条天然石梁横跨两崖，长约7米，瀑布从梁下穿洞而过，水石相激，声响如雷——这种"石梁横空、飞瀑穿梁"的组合，在国内极为罕见。二是华顶山，主峰海拔约1098米，山顶有华顶国家森林公园，每年五月前后，成片的云锦杜鹃盛开，树龄多在百年以上，被称作"华顶归云"。

还有一段文脉：明代徐霞客的《徐霞客游记》，开篇第一篇就是《游天台山日记》，写于1613年。换句话说，中国最伟大的旅行家，是从天台山开始他一生的行走的。

提醒各位：山区天气多变，请备雨具；石梁一带水雾大、石阶湿滑，务必扶好栏杆。祝大家在天台山既得山水，也得心静。

**【讲解要点提示】**
- 必讲：国清寺与天台宗；桐柏宫与道教南宗；石梁飞瀑；徐霞客游记开篇。
- 数据锚点：国清寺始建于隋开皇十八年（598年）；石梁长约7米；华顶山海拔约1098米；徐霞客1613年首游天台山。
- 常见误区：天台山在浙江天台县，与四川、湖北等地的"天台山"同名但不同山。
- 互动/提问设计：请游客在国清寺找出隋梅与"鹅"字碑；请游客说出一句《徐霞客游记》的名句。

### 14. 台州仙居神仙居景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 台州市仙居县 |
| 类型 | 山岳峰林 · 地质地貌 · 森林草原 |
| 评定年份 | 2015 |
| 建议游览时长 | 5–7 小时 |

**【景区简介】**

神仙居景区位于浙江省台州市仙居县，古称"韦羌山"，是一处以白垩纪流纹岩火山地貌为主体的山岳型景区，与雁荡山同属浙东南火山岩地貌带。景区以奇峰、绝壁、深谷、飞瀑、云海为特色，观音峰、如来像、将军岩等象形石惟妙惟肖，栈道与索道沿崖壁蜿蜒，形成了"人在画中行"的游览体验。景区植被茂密，森林覆盖率高，负氧离子含量丰富。近年来新建的如意桥、卧龙桥等网红景观桥梁，使神仙居成为浙东南热门打卡地。2015年，神仙居被评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到台州仙居的神仙居。先解释一下这个名字——相传这里是神仙居住的地方，所以叫"神仙居"。当然，这只是个美丽的说法，真正让它"像仙境"的，是地质。

这里和雁荡山是同一个家族：都是一亿多年前白垩纪火山喷发留下的流纹岩。岩浆冷却时收缩开裂，又被亿万年的雨水沿着裂缝往下切，就切出了今天这种"刀劈斧削"的绝壁和一根根拔地而起的石峰。神仙居的峰林有个特点：不是连绵的山脊，而是一根一根独立站着，彼此隔着深谷遥遥相望，云雾一来，峰顶浮在云上，看着就像真的有仙人住在上面。

第一处必看，是观音峰。这是一块高达百米的巨型岩柱，从特定角度看，轮廓酷似一尊双手合十的观音立像，眉眼、衣褶都能辨认出来。它完全是天然的，没有一丝人工雕凿——这也是神仙居最让人称奇的地方。

第二处，是栈道和桥。景区在悬崖上凿出环形栈道，走在上面，脚下是几百米的深谷，头顶是垂直的岩壁。近年新建的如意桥横跨两座山峰之间，桥面造型取"如意"的曲线，从空中俯瞰宛如一件玉如意悬在山谷之上。

第三处，是云海。雨后初晴的清晨，山谷里水汽升腾，往往能遇上一整片云海，峰顶只露出尖尖一角，这是神仙居最好的画面，也是最考验运气的一幕。

提醒各位：栈道狭窄、临崖无护栏处甚多，请勿拥挤、请勿攀爬岩体；山区天气多变，请备雨衣与防滑鞋。祝大家在神仙居走得稳、看得远。

**【讲解要点提示】**
- 必讲：白垩纪流纹岩火山地貌成因；观音峰等象形石；悬崖栈道与如意桥；云海景观。
- 数据锚点：白垩纪距今约一亿余年；观音峰高约百米；2015年创建5A。
- 常见误区：神仙居古称韦羌山，与李白诗中的"天姥山"并非同一山，不要混为一谈；栈道为单向环路，请勿逆行。

### 15. 嘉兴嘉善西塘古镇旅游景区

**【景区简介】**

西塘古镇旅游景区位于浙江省嘉兴市嘉善县，地处江浙沪交界，是江南六大古镇之一。西塘明代成镇，因水网纵横、家家临水而被称为"吴根越角"，意即吴越两国交界的边地。古镇以"桥多、弄多、廊棚多"三多著称：镇内河道纵横，明清石桥遍布；深宅大院之间夹着上百条狭窄的宅弄，最窄者不足一米；沿河搭建的带顶廊棚绵延成片，为江南古镇中规模最大者之一，可遮阳避雨。主要景点有烟雨长廊、石皮弄、种福堂、西园、纽扣博物馆、瓦当陈列馆等。2017年，西塘被评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到西塘。人们常说，江南六大古镇里，西塘是最"生活"的一个——因为它至今还住着人，还有人在河边洗菜、在廊棚下喝茶。

先说西塘的"三多"：桥多、弄多、廊棚多。

桥多，是因为水多。镇上河道纵横，明清留下的石桥一座接一座，桥不高，拱不大，恰恰是江南水乡最耐看的样子。

弄多，是指宅子与宅子之间那些窄窄的巷子。全镇有上百条，最长的几十米，最窄的——就是我们要去的石皮弄，宽度不足一米，两人对面走过要侧身。弄堂两边是高高的封火山墙，抬头只见一线天，这种布局既是为了防火，也是为了家族分区而居。

廊棚多，是西塘的头号招牌。所谓廊棚，就是沿河人家把屋檐伸出去，搭成一条带顶的长廊，下面既是自家门口，也是公共的过道。下雨天走在这里，从头到尾不用打伞。据地方记载，西塘廊棚的形成与沿河商铺为客人遮阳避雨有关，是几百年来慢慢连成片的。烟雨长廊沿河而建，是拍照最好的一段。

再看人文。西塘自明代成镇，因地处吴越交界，古称"吴根越角"。镇上的西园是明代江南园林的旧址，园中假山、水池、亭榭俱全；纽扣博物馆和瓦当陈列馆则把江南人家的日常物件收进来，展示的是另一种"小历史"。

提醒各位：古镇石板路雨天湿滑，请慢行；清晨与傍晚游客较少，是拍照最好的时段，出行前请核实开放安排。祝大家在西塘遇见"活着的水乡"。

**【讲解要点提示】**
- 必讲：西塘"三多"（桥多、弄多、廊棚多）；石皮弄的宽度；烟雨长廊；"吴根越角"的来历。
- 数据锚点：2017年创建5A；石皮弄不足一米宽；全镇上百条弄堂。
- 常见误区：西塘属嘉善县，是江南六大古镇之一，与周庄、同里、乌镇、南浔、甪直并列但风格不同。
- 互动/提问设计：请游客在石皮弄实测宽度；请游客找出沿河廊棚的"公""私"分界线。

- 互动/提问设计：请游客辨认"川"字三峰的排列；在廿八都请游客猜一种门楼的流派归属。

### 17. 宁波天一阁·月湖景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 宁波市海曙区 |
| 类型 | 古典园林 · 博物馆场馆 · 城市地标 |
| 评定年份 | 2018 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

天一阁·月湖景区位于浙江省宁波市海曙区，由天一阁博物馆与月湖两大片区组成。天一阁是中国现存最古老的私家藏书楼，由明代兵部右侍郎范钦始建于明嘉靖四十年（1561年）前后，取《易经》"天一生水，地六成之"之义命名，以水克火、护书平安。天一阁原有藏书七万余卷，以明代地方志、登科录等珍本最为著名；范氏家族立下"代不分书、书不出阁"等严苛族规，使藏书得以延续数百年。新中国成立后多次征集捐赠，现藏古籍三十万卷左右，为全国重点文物保护单位。月湖开凿于唐代、兴盛于宋代，湖中有"月湖十洲"之胜，周边是宁波历史文化核心区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到宁波天一阁。先看这个楼名——"天一"，出自《易经》的"天一生水，地六成之"。藏书楼最怕什么？火。所以范钦建楼时，取"天一生水"之意，用水来克火，连楼下的水池也是按这个思路设计的。

范钦是明代嘉靖年间的兵部右侍郎，一生嗜书如命。他在明嘉靖四十年，也就是1561年前后建起这座藏书楼，收藏最多时达七万余卷。天一阁最珍贵的部分是明代的地方志和登科录——这两类书在当时几乎没人专门搜集，而正是这批"冷门"典籍，让天一阁在后世学界地位极高。

但真正让天一阁活到今天的，不是楼，是规矩。范氏定下族规："代不分书，书不出阁"——书永远属于范氏全族，谁也不能私自卖掉、带走；阁门钥匙由各房共同掌管，要开阁，必须各房到齐。这套制度听着严苛，却让这座书楼在四百多年的风雨、战乱、虫蛀、火灾中挺了过来。今天我们能站在这里，靠的是一代代人的死守。

走到月湖这边，是另一番气象。月湖开凿于唐代，宋代最盛，湖中分出十个小岛，合称"月湖十洲"。宋代以来，这里是宁波的文化中心，书院、藏书楼、名人宅第环湖而建，王安石、史浩等人都在此留下足迹。今天的月湖是市民公园，也是宁波古城格局的见证。

提醒各位：天一阁是木质古建与纸质文物的重地，全园禁烟、馆内请勿拍照；参观时请轻声慢行，不要触碰展柜与雕版。祝大家在书楼里读出"守"的分量。

**【讲解要点提示】**
- 必讲："天一生水，地六成之"的命名与防火设计；范钦与七万余卷藏书；"代不分书、书不出阁"族规；月湖十洲。
- 数据锚点：明嘉靖四十年（1561年）始建；原藏书七万余卷；现藏古籍约三十万卷。
- 常见误区：天一阁是"私家藏书楼"，不是官府藏书机构；现藏古籍中相当部分是后来征集与捐赠所得。
- 互动/提问设计：请游客找出院内防火设计的水池；请游客说出一条自家"传家规矩"。

### 18. 丽水缙云仙都景区

| 项目 | 内容 |

**【景区简介】**

缙云仙都景区位于浙江省丽水市缙云县，地处括苍山北麓、好溪两岸，是一处以流纹岩峰林与溪流田园为主体的山水型景区。核心景观鼎湖峰为一柱擎天的巨型石柱，高约170.8米，状如破土春笋，有"天下第一笋""天下第一石笋"之誉。仙都与黄帝文化关系密切，相传轩辕黄帝曾在此炼丹并乘龙升天，"缙云"之名亦与此传说相关，鼎湖峰下的黄帝祠宇是历代祭祀黄帝的重要场所。景区另有倪翁洞摩崖石刻、芙蓉峡、朱潭山、小赤壁、婆媳岩等景点，山水与田园交织，长期为影视剧取景地。2019年，仙都被评为国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到缙云仙都。今天的主角，就在大家眼前——那根拔地而起、直指青天的石柱，叫鼎湖峰。它高约170.8米，底部周长数十米，通体是一整块流纹岩，中间几乎没有横缝，看上去就像一根刚从地里冒出来的春笋。古人称它"天下第一笋"。

这根石柱是怎么来的？和雁荡山、神仙居一样，是白垩纪火山活动的产物：岩浆喷出地表后冷却，形成厚厚的流纹岩层；后来地壳抬升，流水沿着垂直的裂隙往下切割，把周围较软的岩石都剥走了，只留下这一柱最坚硬的"芯"。

仙都还有一层更厚的文化外衣——黄帝。相传轩辕黄帝曾在此铸鼎炼丹，丹成之后乘龙升天，人们把炼丹处称作"鼎湖"，把这座山叫做"缙云山"，缙云这个县名也由此而来。鼎湖峰下的黄帝祠宇，历代屡有修葺，是南方祭祀黄帝的重要场所之一。需要说明的是，这属于上古传说与地方传统，年代无法考证，我们讲的时候会说"相传"。

再往前走是倪翁洞。洞口石壁上保留了大量历代摩崖石刻，从唐代到清代都有，是研究浙南人文的第一手材料。朱潭山则是摄影师最爱的角度——老农牵牛从石桥上走过，背景就是鼎湖峰与水中的倒影，这张照片几乎成了仙都的名片。

好溪在峰下蜿蜒，田园、竹林、村舍沿溪分布，这种"奇峰 + 田园"的组合，是仙都区别于其他山岳景区的地方。

提醒各位：鼎湖峰下溪边湿滑，请勿涉水；景区内景点分散，建议按导览图顺序游览。祝大家在仙都看峰、看水、也看人间烟火。

**【讲解要点提示】**
- 必讲：鼎湖峰（170.8米）与流纹岩成因；黄帝炼丹升天的传说与黄帝祠宇；倪翁洞摩崖石刻；朱潭山经典取景角度。
- 数据锚点：鼎湖峰高约170.8米；2019年创建5A。
- 常见误区：黄帝传说属上古传说，非信史，讲解应加"相传"；仙都的"仙"与自然奇观相关，不等于道教宫观群。
- 互动/提问设计：请游客在朱潭山找到最佳倒影机位；请游客辨认倪翁洞石刻中的年号。

### 19. 温州刘伯温故里景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 温州市文成县 |
| 类型 | 山岳峰林 · 水域湖泊 · 陵寝祠庙 |
| 评定年份 | 2020 |
| 建议游览时长 | 1 天 |

**【景区简介】**

刘伯温故里景区位于浙江省温州市文成县，总面积约4.81平方公里，由刘基庙与百丈漈两大核心片区构成，2020年12月29日被评为国家5A级旅游景区。刘基（1311—1375），字伯温，谥"文成"，是明朝开国功臣、杰出的政治家与文学家，文成县即因其谥号得名。刘基庙位于南田镇，为全国重点文物保护单位，是浙南现存具有较高研究价值的明代木构建筑群之一。百丈漈为阶梯型三级瀑布群，总落差约353米，其中一漈落差约207米，曾被认证为"中国单体落差最高的瀑布"。景区所在的百丈漈—飞云湖为国家级风景名胜区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到温州文成的刘伯温故里。先说一个有趣的巧合：这个县叫"文成"，正是因为刘伯温——他去世后被追谥"文成"，后人设县时便用了这个谥号作县名。一个县以一个人的谥号命名，全国都不多见。

刘基，字伯温，生于1311年，卒于1375年，是明朝开国的重要谋臣，辅佐朱元璋平定天下，民间有"三分天下诸葛亮，一统江山刘伯温"的说法。当然，这是后人的夸张——但他在军事谋略、天文历法、文学上的成就，都是有史料记载的实打实的本事。他的《郁离子》是一部寓言体政论集，今天读来仍有锋芒。

我们先到南田镇的刘基庙。这座庙始建于明代，是纪念刘基的专祠，为全国重点文物保护单位。庙内的木构梁架保留了明代做法，斗拱、月梁、藻井都很规整，是研究浙南木构建筑的重要实例。庙中碑刻与匾额历代累积，可以读出后人对这位"立德、立功、立言"三不朽人物的评价。

再去百丈漈。这是景区的另一半，也是最壮观的一半。百丈漈是一条阶梯式的三级瀑布群，总落差约353米；其中第一漈落差约207米，水从绝壁上直落深潭，响声如雷，水雾弥漫，曾获认证为"中国单体落差最高的瀑布"。有意思的是，百丈漈的"漈"字是浙南话里"瀑布"的意思，这个字本身就带着地方味儿。

提醒各位：瀑布区水汽大、石阶陡滑，请务必穿防滑鞋、走指定步道；雨后水量增大，请勿靠近潭边护栏以外的区域。祝大家在文成，既读懂一个人，也震撼于一挂水。

**【讲解要点提示】**
- 必讲：刘基生平与"文成"县名的由来；刘基庙的明代木构价值；百丈漈三级瀑布与207米一漈。
- 数据锚点：刘基生卒年1311—1375；景区总面积约4.81平方公里；百丈漈总落差约353米、一漈约207米；2020年12月29日创5A。
- 常见误区：景区由"刘基庙"与"百丈漈"两片组成，不在同一处；"三分天下诸葛亮，一统江山刘伯温"是民间夸张说法，非史实评价。
- 互动/提问设计：请游客说出刘伯温的字与谥号；请游客估算一漈207米相当于多少层楼高。

### 20. 台州府城文化旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 台州市临海市 |
| 类型 | 古城古镇 · 遗址考古 |
| 评定年份 | 2022 |
| 建议游览时长 | 5–7 小时 |

**【景区简介】**

台州府城文化旅游区位于浙江省台州市临海市，总面积约3.12平方公里，包括台州府城墙、紫阳古街、东湖、巾山等景区，2022年7月被评为国家5A级旅游景区，是浙江省第20家国家5A级旅游景区。唐武德四年（621年）始置台州，此后台州州、路、府治所均设于临海，临海素有"小邹鲁""文化之邦"之誉，1994年列为国家历史文化名城。台州府城墙始建于东晋、扩建于唐、定型于宋、完善于明清，全长6000余米、现存约4730米，兼具军事防御与防洪双重功能，2001年列为全国重点文物保护单位，2012年列入《中国世界文化遗产预备名单》。

**【导游词核心稿】**

各位游客，大家好！欢迎来到临海台州府城。很多人第一次来，站在城墙下会恍惚：这不是长城吗？不错，它有"江南长城"和"江南八达岭"两个外号，而且这两个外号不是白叫的——中国古建筑专家罗哲文先生曾说，台州府城墙是北方明长城的"师范"和"蓝本"。

为什么一座江南的府城城墙，会和北方的长城扯上关系？关键在一个人：戚继光。明代嘉靖年间，倭寇侵扰东南沿海，戚继光在台州一带抗倭，他在台州府城墙上创造性地修筑了双层空心敌台——既能驻兵，又能储藏武器，还能从内部射击。这种形制后来被他带到了北方，应用到蓟镇长城的修筑上。所以准确地说，这座江南城墙影响了北方长城。

城墙本身也了不起。它始建于东晋，北宋定型，明清多次修缮，全长6000余米、现存约4730米。更独特的是它能防洪——城墙沿着灵江修筑，朝江的一侧做成弧形"马面"，可以分流水势；城门还设有闸槽，涨水时落闸挡水。一座城墙兼作军事与水利两用，这在全国是罕见的。2001年它成为全国重点文物保护单位，2012年进入《中国世界文化遗产预备名单》。

下了城墙，走进紫阳古街。这条街呈南北走向，全长1080米，因道教南宗始祖、紫阳真人张伯端而得名，2012年被评为"中国历史文化名街"。街巷保持着北宋里坊制的方格网格局，两侧是明清建筑与老字号，是最能感受临海烟火气的地方。

城东的东湖开凿于北宋，由台州知州钱暄疏浚拓建而成，清代学者俞樾评价它"杭州有西湖，台州有东湖，东湖之胜，小西湖也"。城东南的巾山，山有双峰、一山四塔，是浙东"唐诗之路"的终点。

提醒各位：城墙登临段有连续台阶，请量力而行；出行前请核实各景点开放情况。祝大家在临海读懂一座活着的府城。

**【讲解要点提示】**
- 必讲：戚继光与双层空心敌台的创制；城墙防洪功能；紫阳街1080米与张伯端；东湖与巾山。
- 数据锚点：唐武德四年（621年）始置台州；城墙全长6000余米、现存约4730米；紫阳街1080米；2022年创5A。
- 常见误区：台州府城墙不是长城的一段，而是府城城墙，因其形制影响明长城而被称"江南长城"；台州与临海是市与县级市的关系，府治历史在临海。
- 互动/提问设计：请游客在城墙上找出"马面"（弧形防洪墩台）；请游客比较东湖与西湖的造园手法。

### 21. 丽水云和梯田景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 丽水市云和县 |
| 类型 | 乡村田园 · 山岳峰林 |
| 评定年份 | 2024 |
| 建议游览时长 | 1 天 |

**【景区简介】**

云和梯田景区位于浙江省丽水市云和县崇头镇，距县城约10公里。梯田初凿于唐初，兴盛于元、明两代，已有1000多年开发历史。景区总面积约8.02平方公里，海拔从200余米延伸至1400余米，垂直高差1200多米，梯田层级达700多层，横跨山地、丘陵、谷地三个地质景观带，是华东地区最大的梯田群，有"中国最美梯田"之称。景区集梯田、云海、山村、竹海、溪流、瀑布、雾凇等景观于一体，被列入中国重要农业文化遗产，并拥有国家湿地公园等称号。2024年2月6日，云和梯田正式晋升国家5A级旅游景区，成为全国首个梯田型5A级旅游景区，也是丽水市第2个、浙江省第21个5A级景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到云和梯田。先给大家三个数字，听完您就知道它了不起在哪儿：海拔从200多米一直铺到1400多米，垂直高差1200多米；梯田一共700多层；景区总面积8.02平方公里。这三个数字合起来，撑起了"华东最大梯田群"这块牌子。

梯田是怎么来的？云和这地方山多、地少、坡度陡，先民要种粮，只能在山坡上一层层开出来。据地方志记载，云和梯田最早开凿于唐初，到元明时期形成规模，至今已有一千多年。一千多年里，一代代人不断垒石、固埂、引水，才把这些"挂在山上的田"养到现在。

这里的田有个特点：因为山太陡，田块被切得很窄。当地有句老话叫"青蛙一跳过三丘"——田块小到青蛙一跳就能跨过三块。最大的田能插十几行秧，最小的只能插一两行。这不是笑话，是山区农耕最真实的写照。

什么时候来最好？四季各有说法：春天灌水，一层层田像镜子一样反着天光；夏天秧苗转绿，山风一吹，绿浪翻滚；秋天稻子熟了，整座山金黄一片；冬天遇上雾凇，田埂挂霜，又是另一番景致。而云和梯田最出名的，还是云海——雨后初晴的清晨，水汽从山谷里升上来，田和村子在云中时隐时现，这也是"云和"这个名字最贴切的画面。

最后提一句：2024年2月，云和梯田正式成为国家5A级旅游景区，它是全国第一个以"梯田"身份进入5A序列的景区。这不是终点，而是对一千年来守着这片田的人的致敬。

提醒各位：山区昼夜温差大、天气多变，请备雨具与外套；观景台与田埂湿滑，请勿踩踏田块。祝大家在云和遇见最好的云和最好的田。

**【讲解要点提示】**
- 必讲：唐初开凿、元明兴盛的千年开发史；700多层、1200多米垂直高差；"青蛙一跳过三丘"的田块特征；四季景观与云海。
- 数据锚点：总面积8.02平方公里；海拔200余米至1400余米；700多层；2024年2月6日晋升5A，为全国首个梯田型5A。
- 常见误区：云和梯田是"农业文化遗产与景观"而非自然荒野，村民仍在耕种，请勿踩踏田块。
- 互动/提问设计：请游客数一数眼前可见的田埂层数；请游客猜"青蛙一跳过三丘"说的是什么。

### 22. 金华双龙风景旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A |
| 所在地 | 金华市婺城区 |
| 类型 | 地质地貌 · 宗教圣地 · 山岳峰林 |
| 评定年份 | 2024 |
| 建议游览时长 | 1 天 |

**【景区简介】**

金华双龙风景旅游区位于浙江省金华市婺城区罗店镇，金华山南麓，距金华市区约8公里，是国家级风景名胜区。景区以喀斯特溶洞群与金华山山岳森林景观为主体，划分为双龙洞、黄大仙、大盘天、优游园、仙鹤妍、尖峰山等六大片区，形成"一谷两湖六洞十景"的游览格局，森林覆盖率约90%。核心的双龙洞因洞口悬有两个钟乳石龙头而得名，外洞面积约1200平方米、俗称"龙厅"，内洞约2000平方米，游客须仰卧小舟、擦崖逆水而入，为国内罕见的入洞方式。山中金华观、黄大仙祖宫与黄初平"叱石成羊"传说相关，为道教"三十六洞天"之一。2024年12月27日，景区被文化和旅游部确定为国家5A级旅游景区，为浙江省第22家。

**【导游词核心稿】**

各位游客，大家好！欢迎来到金华双龙。在进洞之前，我先考考大家：你们是怎么进山洞的？走？爬？坐电梯？在双龙洞，答案是——躺着进去。

双龙洞由外洞和内洞两部分组成。外洞面积约1200平方米，高大宽敞，当地人称它为"龙厅"，站得下上千人。可要进内洞，中间只隔着一条地下暗河，水面紧贴着岩壁，中间只有一条刚够一条小船过的小缝。怎么办？只能仰面躺在船底，船工用手拉着岩壁上的绳索，把船一点点拽过去。人的鼻尖离岩石不过几厘米，真正是"擦崖逆水而入"。古诗说得好："洞中有洞洞中泉，欲觅泉源卧小船"——这就是双龙洞最有名的一绝。

明代崇祯九年，也就是1636年，旅行家徐霞客来到这里，把外洞形容为"轩旷宏爽，如广厦高穹"。三百多年后，作家叶圣陶写下《记金华的双龙洞》，细致描写了"从后脑到肩背，到臀部，到脚跟，没有一处不贴着船底"那种又紧张又新鲜的感受。这篇文章后来入选小学语文教材，几代中国人都是通过它认识双龙洞的。

再说说这座山的文化。金华山是道教名山，双龙洞被列为道教"三十六洞天"之一。山上还有黄大仙祖宫——相传东晋时有位牧羊人黄初平，在此得道成仙，能把白石点化成羊，这就是"叱石成羊"的传说。这个传说在岭南一带影响极深，因此每年都有港澳及海外信众来此寻根。

近年来景区形成了"一谷两湖六洞十景"的新格局，除了双龙洞，冰壶洞内有溶洞瀑布，仙瀑洞内的瀑布落差达73米，落差之大在洞瀑中极为罕见。

提醒各位：洞内常年温度在18℃左右、湿度大、地面湿滑，请穿防滑鞋、备一件薄外套；洞内狭窄处请勿起身、请勿探头出船。祝大家在双龙洞体验一次"躺着旅行"。

**【讲解要点提示】**
- 必讲：卧船仰面入洞的独特方式；徐霞客1636年到访与叶圣陶《记金华的双龙洞》；黄大仙"叱石成羊"传说；道教三十六洞天。
- 数据锚点：外洞约1200平方米、内洞约2000平方米；仙瀑洞瀑布落差73米；森林覆盖率约90%；1636年徐霞客到访；2024年12月27日创5A。
- 常见误区：双龙洞的"双龙"指洞口钟乳石形似两个龙头，并非洞内有两条真龙；洞内温度低、与外部温差大。
- 互动/提问设计：请游客在洞口辨认两个钟乳石龙头；请游客说说卧船入洞时的感受。
