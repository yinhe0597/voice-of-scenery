### 1. 武汉市黄鹤楼公园

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年首批评定） |
| 所在地 | 武汉市武昌区 |
| 类型 | 城市地标 · 古典园林 |
| 评定年份 | 2007 |
| 建议游览时长 | 2-3 小时 |

**【景区简介】**

黄鹤楼公园位于武汉市武昌区蛇山西端，濒临长江，与岳阳楼、滕王阁并称"江南三大名楼"，素有"天下江山第一楼"之誉。黄鹤楼始建于三国吴黄武二年（公元223年），初为军事瞭望楼，此后历代屡毁屡建，明清两代重建即达七次。现存黄鹤楼于1985年6月落成，以清代"同治楼"为蓝本，为钢筋混凝土仿木结构，楼高51.4米，共五层，平面呈方形，覆黄色琉璃瓦，全楼计72根圆柱、60个翘角。公园内另有白云阁、岳飞广场、千禧钟、古铜顶、诗碑廊与崔颢题诗浮雕等景点，是武汉最具代表性的城市文化地标。

**【导游词核心稿】**

各位游客朋友，大家好！欢迎来到"天下江山第一楼"——黄鹤楼。站在这里，脚下是蛇山之巅，眼前是滚滚长江，身后是武汉三镇的现代天际线。我们脚下这座楼，历史上已经是第N次重建了。

先说"年纪"。黄鹤楼始建于公元223年，那一年是三国吴黄武二年，孙权在夏口筑城，黄鹤楼最初只是一座瞭望敌情的军事楼。1700多年里，它屡毁屡建，光明清两代就重建了七次。我们现在看到的这座楼，是1985年6月落成的，以清代同治年间的"同治楼"为蓝本，楼高51.4米，五层，全楼72根圆柱、60个翘角向上飞扬，像一群黄鹤振翅欲飞。

再说"诗"。唐代诗人崔颢登楼写下"昔人已乘黄鹤去，此地空余黄鹤楼"，据说李白登楼读到这首诗，感叹"眼前有景道不得，崔颢题诗在上头"。不过李白终究还是写了——他在黄鹤楼送孟浩然："孤帆远影碧空尽，唯见长江天际流"。武汉别称"江城"，正是来自李白"黄鹤楼中吹玉笛，江城五月落梅花"这一句。

登楼时请大家留意三层到五层的壁画。一层是"白云黄鹤"图，二层是唐宋名楼的诗赋，顶层可俯瞰长江与长江大桥，视野最佳。下山前，别忘了到岳飞广场看看——岳飞曾驻军鄂州，手书的《满江红》石刻就在这里。

最后提醒一句：黄鹤楼是国家级重点文物保护单位，请勿在楼内吸烟、刻画；登楼台阶较多，老人和小孩请慢行。愿大家在此"极目楚天舒"，带走一江风月。

**【讲解要点提示】**
- 必讲：223年始建与1985年重建的区别；"江南三大名楼"；崔颢诗与李白"江城"典故。
- 数据锚点：公元223年、1985年6月、楼高51.4米、72根圆柱、60个翘角、五层。
- 常见误区：现存楼不是三国原物；原楼旧址在黄鹄矶头，因1957年建长江大桥而移至蛇山现址，两者相距约1公里，不可说"原址原建"。
- 互动/提问设计：问游客"崔颢的诗里，黄鹤去了哪里？"再引出"昔人已乘黄鹤去"，顺势讲李白搁笔的传说。

### 2. 宜昌市三峡大坝—屈原故里文化旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（三峡大坝片区2007年评定；屈原故里片区2014年纳入，文旅部统计口径合并为一家） |
| 所在地 | 宜昌市夷陵区三斗坪镇（三峡大坝片区）／秭归县茅坪镇（屈原故里片区） |
| 类型 | 水域湖泊 · 工业遗产 · 遗址考古 |
| 评定年份 | 2007（合并口径） |
| 建议游览时长 | 5-6 小时（两片区分开游览） |

**【景区简介】**

本旅游区由宜昌市夷陵区的三峡大坝片区与秭归县的屈原故里片区组成，是文化与旅游部统计口径中的一家5A级景区，但两个片区相距约40公里，须分别安排行程。三峡大坝是当今世界规模最大的水利枢纽工程，1994年12月14日正式开工，2006年5月大坝全线建成。大坝为混凝土重力坝，坝顶高程185米，最大坝高181米，坝轴线全长2309米，安装32台70万千瓦机组及2台5万千瓦电源机组，总装机容量2250万千瓦。主要参观点有坛子岭、185观景平台、截流纪念园、三峡工程展览馆与双线五级船闸。屈原故里片区位于秭归凤凰山，以屈原祠、屈原故里牌坊为核心，是端午祭祀与屈原文化的重要场所。

**【导游词核心稿】**

各位朋友，欢迎来到三峡。今天我们看的，是中华民族治水史上最大的一项工程，也是一位两千多年前诗人故乡的山水。

先说工程。三峡大坝1994年12月14日开工，2006年5月全线建成，坝顶高程185米，最大坝高181米，坝轴线全长2309米。站在坛子岭上，您可以俯瞰整条大坝：中间是泄洪坝段，两侧是电站厂房，左岸是双向五级船闸——船过闸像爬楼梯，一级一级往上走，全程大约三四个小时。大坝装有32台70万千瓦的水轮发电机组，总装机容量2250万千瓦，一年的发电量足够照亮半个中国南方。

再看数字背后的意义。三峡工程最核心的功能是防洪：它把荆江河段的防洪标准从十年一遇提高到百年一遇。1998年那场大洪水，荆江两岸百万军民上堤抢险；而今天的汛期，长江中下游的人们可以安稳睡觉。

接下来我们到秭归，看屈原故里。屈原约生于公元前340年，是楚国的贵族、诗人，也是中国第一位有主名的伟大诗人。"路漫漫其修远兮，吾将上下而求索"，就出自他的《离骚》。相传他投汨罗江后，百姓划船打捞、投米入水以防鱼虾伤其身，这便是端午竞渡与包粽子习俗的由来。2009年，"端午节"被列入联合国教科文组织人类非物质文化遗产代表作名录。

最后提醒大家：大坝为军事管理区，须实名预约、安检进入，请勿携带无人机；两个片区不在一处，请留足时间。愿大家记住毛泽东那句词——"更立西江石壁，截断巫山云雨，高峡出平湖"。

**【讲解要点提示】**
- 必讲：三峡工程防洪、发电、航运三大功能；屈原与端午文化。
- 数据锚点：185米坝顶高程、181米最大坝高、2309米坝长、2250万千瓦装机、1994年开工、2006年建成。
- 常见误区：三峡大坝≠三峡人家，两者相距约30公里；游客不能走近坝体，只在指定观景平台参观。
- 互动/提问设计：请游客猜"船过大坝要爬几级台阶"，再解释双线五级船闸的原理。

### 3. 宜昌市三峡人家风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 宜昌市夷陵区三斗坪镇石牌村 |
| 类型 | 民族风情 · 水域湖泊 |
| 评定年份 | 2011 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

三峡人家风景区位于宜昌市夷陵区西陵峡腹地，紧邻三峡大坝与葛洲坝之间的西陵峡段，2011年评为国家5A级。景区以"一肩挑两坝、一江携两溪"的区位见长，龙进溪与杨家溪在此汇入长江，完整保留了峡江地区传统的生产生活方式。主要景观包括水上人家、溪边人家、山上人家、龙进溪、巴王宫与灯影石。沿江吊脚楼依山临水，古帆船、乌篷船停泊岸边，幺妹儿山歌、薅草锣鼓、哭嫁等民俗表演常年上演，"长江峡江号子"于2008年列入国家级非物质文化遗产名录。景区内还有1943年石牌保卫战遗址，是抗战时期拱卫重庆的重要门户。

**【导游词核心稿】**

各位游客，大家好！欢迎来到三峡人家。这里不是大坝，也不是峡谷漂流，而是一座活着的峡江民俗博物馆——人们在这里怎么生活，我们就怎么看。

景区的核心是一条龙进溪。溪水从峡谷深处流出，两岸峭壁夹峙，溪边有吊脚楼、有水车、有榨坊，还有幺妹儿在溪边浣纱、唱山歌。请大家留意溪上那几只小船——船头尖尖、形似豌豆角的，叫"豌豆角船"，是峡江特有的木船。

往上走，就到了"水上人家"。峡江人世代以水为生，男人驾船、拉纤，女人织网、晒鱼。峡江的船工在激流中齐声喊号子，一人领、众人和，这叫"长江峡江号子"，2008年列入国家级非物质文化遗产名录。当年没有机器动力，全靠这一嗓子一嗓子的劲儿，把船从滩险里拽出来。

再往高处是"山上人家"和巴王宫。相传古代巴人在此生息，巴人以虎为图腾，勇猛善战。说到勇猛，请大家记住一个年份——1943年。那年5月，中国军队在这里的石牌要塞与日军血战，守住了通往重庆的最后一道门户，史称"石牌保卫战"，被誉为"东方的斯大林格勒保卫战"。

最后，请大家抬头看江对岸的四块巨石。相传月光下它们的剪影像唐僧师徒四人，所以这一段叫"灯影峡"。

提醒：景区内台阶与栈道较多，雨天湿滑请穿防滑鞋；观看民俗表演时请勿拥挤。愿大家在峡江的山水与号子声里，读懂什么叫"靠水吃水"。

**【讲解要点提示】**
- 必讲：龙进溪峡江生活场景；峡江号子；1943年石牌保卫战。
- 数据锚点：2011年评5A、1943年5月石牌保卫战、2008年峡江号子入国家级非遗、三峡蓄水位175米。
- 常见误区：三峡人家不是三峡大坝景区；三峡蓄水至175米后水位抬升，古栈道多已淹没，现存部分为高处遗存。
- 互动/提问设计：让游客听一段号子录音，猜"哪一句是领唱"，再讲号子的指挥作用。

### 4. 十堰市武当山风景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 十堰市丹江口市 |
| 类型 | 宗教圣地 · 山岳峰林 · 世界文化遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 1.5-2 天 |

**【景区简介】**

武当山风景区位于十堰市丹江口市，是道教圣地与武当武术发源地，主峰天柱峰海拔1612米。武当山古建筑群始建于唐贞观年间，明永乐十年（1412年）明成祖朱棣役使军民工匠三十万大修武当，历时十余年，建成九宫九观、三十六庵堂、七十二岩庙的宏大格局，史称"北建故宫，南修武当"。1994年，武当山古建筑群被联合国教科文组织列入《世界遗产名录》。核心景观包括天柱峰顶的明代金殿、紫霄宫、南岩宫、太和宫、太子坡、遇真宫等。金殿建于明永乐十四年（1416年），为铜铸鎏金仿木结构殿宇，历经六百年风雨仍光灿如新。2006年，"武当武术"列入第一批国家级非物质文化遗产名录。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到"亘古无双胜境，天下第一仙山"——武当山。

武当山为什么这么有名？两个字：皇家。明永乐十年，也就是公元1412年，明成祖朱棣调集军民工匠三十万人，大修武当。工程历时十余年，建成了九宫九观、三十六庵堂、七十二岩庙。历史上有句话叫"北建故宫，南修武当"——北京紫禁城和武当山古建筑群，是同一个皇帝、同一批匠人体系下的两件大作品。1994年，武当山古建筑群被列入《世界遗产名录》。

我们的第一站是太子坡。请大家看那道红墙，它依山势起伏蜿蜒，像黄河九曲，所以叫"九曲黄河墙"；还有那座"一柱十二梁"——一根主柱上撑起十二根横梁，是古代木构建筑的绝活。

第二站紫霄宫，是武当山现存最完整的宫殿之一，重檐歇山顶，层层叠叠落在山台之上。殿内供奉真武大帝。相传真武大帝在此修真得道，武当山因此成为真武道场。

第三站也是最精彩的一站——登金顶。天柱峰海拔1612米，峰顶那座金殿，建于明永乐十四年，也就是1416年，通体铜铸鎏金，六百多年风吹雨打，依旧金光闪闪。站在这里俯瞰群峰，您会明白古人为什么把这里叫做"太和"。

最后说武术。武当武术2006年列入首批国家级非物质文化遗产名录。至于太极拳是不是张三丰所创，史学界一直有争议，我们讲解时说"相传"就好。

提醒：山上气候变化快，请备外套；古建筑内请勿焚香、触摸彩绘。祝大家"福寿康宁"。

**【讲解要点提示】**
- 必讲：明永乐大修与"北建故宫，南修武当"；金殿；武当武术。
- 数据锚点：1412年、1416年金殿、主峰海拔1612米、1994年世界遗产、2006年国家级非遗。
- 常见误区：武当山在十堰丹江口市，不在襄阳；"张三丰创太极拳"属传说，须用"相传"表述。
- 互动/提问设计：让游客在太子坡数"一柱十二梁"到底几根梁，再讲其力学原理。

### 5. 恩施州神农溪纤夫文化旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 恩施土家族苗族自治州巴东县 |
| 类型 | 水域湖泊 · 民族风情 |
| 评定年份 | 2011 |
| 建议游览时长 | 4-5 小时 |

**【景区简介】**

神农溪纤夫文化旅游区位于恩施土家族苗族自治州巴东县，是长江北岸的一条常流性溪流，发源于神农架南麓，在巴东西壤口汇入长江。景区以峡谷幽深、溪流湍急、植被原始为特色，漂流游览段全长约60公里，由龙昌峡、鹦鹉峡、绵竹峡、神农峡四个峡段依次组成，两岸可见古栈道遗迹、悬棺、燕子阡溶洞与成群的野生短尾猴。最具代表性的是被誉为"世界纤夫活化石"的神农溪纤夫：船工驾驶形似豌豆角的木船，在浅滩处下水拉纤，唱起高亢的峡江号子，保留了长江上游最原始的航运方式。景区融合土家歌舞与婚俗表演，2011年评为国家5A级。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到神农溪。今天我们要坐的不是游轮，而是一种两头尖尖、形如豌豆角的小木船——当地人叫它"豌豆角船"。

神农溪从神农架南麓发源，一路穿山而来，在巴东的西壤口汇入长江。我们漂流这一段，大约60公里，依次经过龙昌峡、鹦鹉峡、绵竹峡、神农峡。每个峡段脾气不同：龙昌峡雄、鹦鹉峡秀、绵竹峡奇、神农峡险。

请大家抬头看崖壁。那些悬在半空、历经千百年的木棺，就是悬棺。相传这是古代巴人的丧葬习俗——把逝者安放在越高越险的地方，越能接近天、护佑后人。至今考古界对它的放置方法仍有多种推测。

再看水里。神农溪最动人的，是人。三峡蓄水之前，这里滩多水急，船上行要靠纤夫——人在岸边或浅滩里弓着身子，肩勒纤绳，一步一挪地把船拽上去。他们喊的号子，就是"长江峡江号子"，2008年成为国家级非物质文化遗产。历史上纤夫在浅滩拉纤时常常赤身，是因为衣物浸湿后会磨伤皮肤，并不是什么猎奇。

三峡工程蓄水到175米之后，很多险滩沉到了水下，水流平缓了。今天我们看到的拉纤，是船工们为游客保留的技艺展示。请大家把它当成一门手艺、一段历史去看，而不只是一个表演。

最后一个提醒：溪上日照强、水面反光，请备好帽子、防晒和防滑鞋；船行中请勿站立、勿将手伸出船舷。愿这一溪碧水，给您留下最清凉的恩施记忆。

**【讲解要点提示】**
- 必讲：豌豆角木船漂流；四峡段；纤夫与峡江号子；悬棺。
- 数据锚点：漂流段约60公里、2011年评5A、2008年峡江号子入国家级非遗、三峡蓄水位175米。
- 常见误区：神农溪不是神农架景区；蓄水后水流平缓，拉纤为技艺展示；"裸纤"有其历史成因，讲解须庄重。
- 互动/提问设计：问"纤夫为什么不穿衣服拉纤"，再解释湿衣磨伤皮肤的史实。

### 6. 神农架生态旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 神农架林区 |
| 类型 | 森林草原 · 山岳峰林 · 世界自然遗产 |
| 评定年份 | 2012 |
| 建议游览时长 | 2-3 天 |

**【景区简介】**

神农架生态旅游区位于湖北省神农架林区，地处大巴山脉东段、秦岭与大巴山交接带，北倚房县、竹山县而近武当，是中国东部保存最完好的原始林区之一，森林覆盖率超过90%。1990年，神农架加入联合国教科文组织"人与生物圈"保护区网络；2013年获批世界地质公园；2016年7月，"湖北神农架"被列入《世界自然遗产名录》。景区由神农顶、大九湖、官门山、神农坛、天生桥、天燕六大片区组成，主峰神农顶海拔3106.2米，为"华中第一峰"。区内保存有川金丝猴、珙桐、红豆杉等珍稀动植物，也是中国"野人"传说流传最广的地区之一，2012年评为国家5A级。

**【导游词核心稿】**

各位游客，大家好！欢迎来到神农架——中国中部唯一一片完整的大面积原始森林。

先说三个"世界级"身份。1990年，神农架加入联合国教科文组织"人与生物圈"保护区网络；2013年，成为世界地质公园；2016年7月，"湖北神农架"被列入《世界自然遗产名录》。一个地方同时拥有这三顶帽子，在中国是头一个。

再看高度。我们的主峰神农顶，海拔3106.2米，是"华中第一峰"。华中六省，没有哪座山比它更高。因为海拔落差大，从山脚到山顶，您可以一天之内走过亚热带、温带、寒温带三种气候带，看到常绿阔叶林、针阔混交林、高山草甸依次铺开——这叫垂直带谱，是神农架最珍贵的自然教科书。

神农架的名字，来自于一个人。相传炎帝神农氏曾在此搭架采药、教民稼穑，"神农架"因此得名。神农坛那座巨大的牛首人身雕像，纪念的就是他。《神农本草经》虽非他所著，但"神农尝百草"的故事，早已刻进了中国人的文化记忆。

还有一件事不能不提——"野人"。从20世纪70年代起，神农架不断有人报告目击野人，科考队也多次进山。但至今没有获得任何一件可靠的实物证据。所以讲解时请这样说：这是流传最广的民间传说，也是神农架神秘感的一部分，但科学上尚未证实。

最后提醒：山区天气多变，即使盛夏早晚也只有十几度，请带外套；林区严禁野外用火，请勿离开栈道。祝大家在华中屋脊上，遇见最纯净的绿。

**【讲解要点提示】**
- 必讲：世界自然遗产身份；神农顶海拔；垂直气候带谱；神农尝百草传说。
- 数据锚点：3106.2米、森林覆盖率超90%、2016年7月入遗、2013年世界地质公园、1990年生物圈保护区。
- 常见误区：六大片区相距较远（大九湖距神农顶约50公里），不可安排在同一天走完；"野人"未经科学证实。
- 互动/提问设计：让游客在官门山猜"川金丝猴为什么叫'川'金丝猴"，再讲其分布与保护。

### 7. 宜昌市长阳清江画廊景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 宜昌市长阳土家族自治县 |
| 类型 | 水域湖泊 · 民族风情 |
| 评定年份 | 2013 |
| 建议游览时长 | 5-6 小时（含船游） |

**【景区简介】**

清江画廊景区位于宜昌市长阳土家族自治县，是清江中游因隔河岩水利枢纽蓄水而形成的高峡平湖景观带。清江为长江一级支流，古称"夷水"，全长423公里，流域面积1.67万平方公里，因水色清明、两岸山峦如画，素称"八百里清江美如画"。景区主要看点有倒影峡、仙人寨、天柱山与武落钟离山。武落钟离山被土家族尊为民族发祥地，相传巴人首领廪君在此"掷剑""浮舟"而称王；天柱山道观始建于明代，为武当派分支道场，有"中武当"之称。沿岸分布吊脚楼、山歌、南曲、撒叶儿嗬等土家民俗，2013年评为国家5A级。

**【导游词核心稿】**

各位朋友，大家好！欢迎登上清江画廊的游船。接下来的几个小时，我们不是走路看景，而是坐在船上看一幅八百里长的山水长卷。

先认识这条江。清江是长江的一级支流，古时候叫"夷水"，全长423公里，流域面积1.67万平方公里。它最动人的地方是水色——一年到头清亮见底，山影落在水里，船就像在画中游。因为隔河岩水利枢纽蓄水，这里形成了高峡平湖，水不急，山更静。

第一个看点，倒影峡。请大家都往窗外看：两岸山体几乎垂直插入水中，水面像镜子一样把山完整复制了一遍。船一过，倒影碎成一片碎金，风一停，又拼回一座山。这就是"画廊"两个字的由来。

第二个看点，武落钟离山。这里是土家族人心中的圣地。相传巴人的首领廪君诞生于此，他用"掷剑入穴"和"土船浮水"两件事，赢得了部众的拥戴，成为巴人的第一位君长。山上的白虎雕像，就是巴人崇拜的图腾——土家人至今把白虎视为祖先的化身。

第三个看点，天柱山。山顶有道观，始建于明代，属于武当派的一支，所以叫"中武当"。道观建在孤峰绝顶之上，云雾起时，像悬在空中。

讲到土家人，请大家记住一个词：撒叶儿嗬。这是土家族特有的丧葬歌舞，老人去世，人们围着跳、唱、击鼓，用最热烈的方式送别。它不是悲伤，是对生命的理解。

提醒：船行约两小时，请全程穿好救生衣，不要在甲板奔跑；山区紫外线强，请备防晒。愿清江的一江碧水，洗净您的疲惫。

**【讲解要点提示】**
- 必讲：清江水质与倒影峡；武落钟离山与廪君传说；土家民俗。
- 数据锚点：清江全长423公里、流域面积1.67万平方公里、2013年评5A。
- 常见误区：清江画廊不是"清江漂流"，以游船观光为主；"中武当"天柱山与武当山不是同一处。
- 互动/提问设计：请游客看倒影说"山在水里是正的还是倒的"，再讲平湖形成的原因。

武汉东湖生态旅游风景区位于武汉市武昌区东部，水域面积约33平方公里，是中国最大的城中湖，风景区总面积约88平方公里，2013年评为国家5A级。景区由听涛、磨山、落雁、吹笛、白马、喻家山六大片区组成，环湖建有全长百余公里的东湖绿道。磨山景区集中展示楚文化，建有楚城、楚市、楚天台与"惟楚有材"碑；落雁景区以湿地与鸟类栖息地见长；听涛景区有行吟阁、屈原纪念馆与寓言雕塑园。东湖梅园为全国四大梅园之一，收集梅花品种300余种；樱花园与武汉大学樱花齐名，是武汉最负盛名的赏花地之一。

各位游客，大家好！欢迎来到东湖。先给大家一个数字：东湖的水面有33平方公里，是杭州西湖的六倍多——它是中国最大的城中湖。

东湖由听涛、磨山、落雁、吹笛、白马、喻家山六大片区组成，环湖绿道总长百余公里，骑完一圈要一整天。今天我们重点走磨山和听涛。

磨山是楚文化的集中地。湖北是楚国八百年的核心地带，楚人"筚路蓝缕"，从一个小部落做到春秋五霸、战国七雄。山上的楚城、楚市、楚天台，都是按楚式建筑复原的。请大家记住一句话："惟楚有材"——这原本是楚国的自许，后来成了湖南岳麓书院的门联，再后来成了整个湖湘荆楚的文化自信。

最后提醒大家：东湖免费开放，但绿道骑行、游船、磨山部分景点需另行购票；节假日人流量极大，建议错峰。愿大家在百湖之市，遇见这一片最开阔的水。

**【讲解要点提示】**
- 必讲：中国最大城中湖；楚文化（磨山）；梅园与樱园。
- 数据锚点：水域33平方公里、总面积88平方公里、绿道百余公里、梅花品种300余种、2013年评5A。
- 常见误区：东湖六大片区之间距离较远，不要安排半天走完；"东湖樱花园"与"武汉大学樱花"是两个不同地点。
- 互动/提问设计：问"杭州西湖水面多大"，引出东湖是西湖六倍的比较。

各位朋友，大家好！欢迎来到木兰故里——武汉市黄陂区。我要先说明一件事：我们说的"木兰文化生态旅游区"，不是一个大门进去的景区，而是四个各具特色的景区共同组成的5A级大家庭：木兰山、木兰天池、木兰草原、木兰云雾山。它们相距几十公里，最好分开安排。

第四站，云雾山。每年四五月，山上野生杜鹃连片盛开，漫山红遍。

### 10. 恩施州恩施大峡谷景区

| 项目 | 内容 |

| 所在地 | 恩施土家族苗族自治州恩施市沐抚办事处 |
| 类型 | 地质地貌 · 山岳峰林 |
| 评定年份 | 2015 |

**【景区简介】**

恩施大峡谷景区位于恩施土家族苗族自治州恩施市沐抚办事处，是清江流域一段典型的喀斯特峡谷，2015年评为国家5A级。已开放的核心片区为七星寨与云龙地缝两处。七星寨沿绝壁修建栈道，串联一炷香、母子情深、大地山川、绝壁环峰等景观；其中"一炷香"是一根高约150米的喀斯特石柱，最细处直径不足4米，历经千万年风雨而不倒，被视为"镇谷之宝"。云龙地缝全长约3.6公里，最深逾百米，为典型的"地缝式"峡谷。景区集峰丛、绝壁、溶洞、暗河、瀑布于一体，被地质学界称为"喀斯特地形地貌天然博物馆"。

**【导游词核心稿】**

各位游客，大家好！欢迎来到恩施大峡谷。有人说，看过恩施大峡谷，就不用去美国科罗拉多了——这话当然夸张，但它说明一件事：这里的喀斯特地貌，是世界级的。

先说"怎么来的"。恩施地处云贵高原东延的武陵山区，这里厚厚的石灰岩层，被含有二氧化碳的雨水溶蚀了几千万年，于是有了峰丛、绝壁、溶洞、暗河和地缝。地质学家把这里叫做"喀斯特地形地貌天然博物馆"。

我们的第一站是七星寨。栈道修在千米绝壁之上，一边是崖，一边是天，脚下是深谷。栈道尽头的明星景点叫"一炷香"——一根高约150米的石柱，最细的地方直径不到4米，头顶还长着一棵小树。千万年的风吹雨打，它不倒。土家人说它是镇谷之宝，地质学家说它是溶蚀残余的奇迹，无论哪种说法，站在它面前，人都会觉得自己很小。

第二站是云龙地缝。地缝全长约3.6公里，最深的地方超过百米，最窄处只容一人侧身通过。抬头看，天只剩一条线；两侧崖壁上，瀑布从缝口飘下来，落到半空就散成了雾。

再说说人。这一带是土家族、苗族的聚居地。山高谷深，过去出趟门要翻几座山，所以土家人的山歌唱得格外悠长。

最后提醒大家：七星寨栈道台阶多、落差大，体能不佳者请量力，缆车与扶梯可分段选择；山区天气多变，请备雨衣和防滑鞋。愿这根"一炷香"，为您燃起对自然的敬畏。

**【讲解要点提示】**
- 必讲：喀斯特成因；一炷香；云龙地缝；绝壁栈道。
- 数据锚点：2015年评5A、一炷香高约150米最细处不足4米、地缝长约3.6公里最深逾百米。
- 常见误区：恩施大峡谷与恩施大清江、腾龙洞是不同景区；"东方科罗拉多"是宣传语，两地地貌成因不同。
- 互动/提问设计：让游客猜"一炷香最细处有多粗"，再讲溶蚀速率与石柱寿命。

**【景区简介】**

三国赤壁古战场景区位于咸宁市赤壁市赤壁镇，地处长江南岸，与江北的洪湖乌林隔江相望，2018年评为国家5A级。公元208年（东汉建安十三年），孙权、刘备联军在此以少胜多击败曹操，史称"赤壁之战"，奠定了魏、蜀、吴三分天下的格局。景区以三国文化为主题，核心遗存为临江绝壁上的摩崖石刻"赤壁"二字，现为全国重点文物保护单位。主要景点包括周瑜石雕像、拜风台（相传为诸葛亮祭风处）、凤雏庵（相传为庞统读书处）、翼江亭、望江亭、赤壁大战陈列馆与三国雕塑园，是集历史遗迹、江景与文化体验于一体的主题景区。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到三国赤壁。请记住这个年份：公元208年，东汉建安十三年。这一年冬天，一场大火改变了中国的走向。

当时曹操南下，号称八十万大军，实际约二十万；孙刘联军加起来只有五万左右。兵力悬殊那么大，为什么曹操输了？第一，北方士兵不习水战，把战船首尾相连，成了活靶子；第二，军中疫病流行；第三，也是最关键的——周瑜、黄盖用诈降计，借东南风火攻。一夜之间，"樯橹灰飞烟灭"。这一仗之后，曹操北归，孙权据江东，刘备取荆州益州，三国鼎立的格局就此成型。

请大家跟我到江边，看崖壁上这两个字——"赤壁"。这是摩崖石刻，现为全国重点文物保护单位。相传这两个字是周瑜在胜利之后亲笔所题，当然这只是相传，学界对它的年代还有不同判断。

再往里走，是拜风台。相传诸葛亮在这里设坛祭风，借来了那场要命的东南风。这个故事出自《三国演义》的演绎；正史《三国志》里只写"时风盛猛"，没写祭风。所以我们讲的时候要说：这是小说家的精彩笔墨。凤雏庵相传是庞统读书的地方，"凤雏"与"卧龙"并称，都是那个时代最聪明的人。

最后澄清一件事：宋代苏轼写《念奴娇·赤壁怀古》的地方，是黄州赤壁，也叫"文赤壁"；我们今天站的这里，是当年打仗的"武赤壁"。两个赤壁，一个出诗文，一个出战火。

提醒：江边风大，请注意保暖和安全，不要翻越护栏。愿大家在江声里，听见一千八百年前的金戈铁马。

**【讲解要点提示】**
- 必讲：208年赤壁之战与三国鼎立；摩崖石刻"赤壁"；文武赤壁之别。
- 数据锚点：公元208年（建安十三年）、2018年评5A、摩崖石刻为全国重点文物保护单位。
- 常见误区：苏轼所咏为黄州文赤壁，非此处；"借东风""祭风"出自《三国演义》，正史无载，须用"相传"。
- 互动/提问设计：问"曹操为什么输"，让游客从水战、疫病、火攻三方面回答。

### 12. 襄阳市古隆中景区

**【景区简介】**

襄阳古隆中景区位于襄阳市襄城区西约13公里处，是三国时期诸葛亮寓居躬耕之地，2019年评为国家5A级。据史料记载，诸葛亮于东汉建安二年（197年）至建安十二年（207年）在此隐居，刘备"三顾茅庐"与《隆中对》典故即发生于此。景区主要景点有三顾堂、草庐亭、武侯祠、卧龙深处、隆中书院、腾龙阁、古柏亭、抱膝亭，以及明嘉靖年间所立的"古隆中"石牌坊。隆中山峦环抱、林木葱郁，历代碑刻楹联众多，其中游俊所撰"两表酬三顾，一对足千秋"概括了诸葛亮一生的功业与文章。

**【导游词核心稿】**

各位游客，大家好！欢迎来到古隆中。这里是中国历史上最著名的一次"拜访"发生的地方。

先说时间。据史料记载，诸葛亮从建安二年、也就是公元197年起，在这里寓居躬耕，到建安十二年、公元207年离开，前后十年。他离开时27岁。那一年，刘备第三次来到隆中，见到了他。《三国志》里只有五个字："凡三往，乃见。"——去了三次，才见到人。这就是"三顾茅庐"的出处。

见面之后，诸葛亮拿出了一份战略方案：先取荆州，再取益州，联孙抗曹，待天下有变，两路北伐。这就是著名的《隆中对》。一个27岁的年轻人，在没有地图、没有情报系统的山沟里，把天下三分画了出来。

请大家看三顾堂前的这副对联："两表酬三顾，一对足千秋。"上联说，诸葛亮用前后《出师表》报答刘备的三顾之恩；下联说，一篇《隆中对》足以流传千秋。这句话，是对他一生最好的总结。

再往前是"古隆中"石牌坊，立于明嘉靖年间，四百多年了。牌坊后面是草庐亭——诸葛亮当年住的茅草房，当然早已不存，亭子是后人纪念性的建筑。武侯祠里供奉着诸葛亮，历代香火不断。

最后要跟大家说一句公道话。诸葛亮在《出师表》里写"臣本布衣，躬耕于南阳"，于是河南南阳与湖北襄阳为"躬耕地"争论了几百年。汉代隆中属南阳郡邓县，而今天的南阳市是另一处。学界至今两说并存，我们讲解时如实陈述即可，不必替古人吵架。

提醒：景区以山地步道为主，请穿舒适鞋；请勿触摸碑刻。愿这份"淡泊明志、宁静致远"，伴随您的旅程。

**【讲解要点提示】**
- 必讲：197—207年躬耕十年；三顾茅庐与《隆中对》；"两表酬三顾，一对足千秋"。
- 数据锚点：197年、207年、诸葛亮生卒181—234年、2019年评5A、明嘉靖石牌坊。
- 常见误区：躬耕地"襄阳说"与"南阳说"并存，须客观表述；草庐为纪念性建筑，非原物。
- 互动/提问设计：问"《隆中对》给刘备规划了几步棋"，再复述取荆州、取益州、联吴抗曹。

腾龙洞景区位于恩施土家族苗族自治州利川市，是中国已探明规模最大的洞穴系统之一，2020年评为国家5A级。洞口高74米、宽64米，已探明的洞穴总长度约59.8公里，由旱洞与水洞两部分组成。清江在洞前"卧龙吞江"处潜入地下，形成长达十余公里的伏流，是长江流域罕见的"吞江"奇观。旱洞内部高大开阔，分为多层，已开发游览段分布着规模巨大的石笋、石柱、石幔与"妖雾山"等景观。景区在洞口大厅常年上演土家风情歌舞《夷水丽川》与激光秀，并把《龙船调》、肉连响等当地非遗项目融入游览动线。

进洞之后，请注意温度。洞里常年恒温，跟外面差着十几度，夏天进去像开了空调，冬天进去反而暖和。所以哪怕三伏天来，也请带件外套。

洞里的看点，一是"大"——大厅高达上百米，能装下整个体育场；二是"奇"——石笋、石柱、石幔、石瀑布，都是滴水几万年、几十万年一点点长出来的。请大家一定记住：钟乳石一折断，可能几百年的生长就毁了，所以只看不摸。

提醒：洞内路面湿滑、光线较暗，请扶好栏杆；请勿使用闪光灯拍摄钟乳石。愿这座地下宫殿，让您见识什么叫"鬼斧神工"。

**【讲解要点提示】**
- 必讲：洞口尺寸与洞穴长度；"卧龙吞江"伏流；钟乳石保护；土家歌舞。
- 数据锚点：洞口高74米、宽64米、已探明长度约59.8公里、2020年评5A。
- 常见误区：腾龙洞与恩施大峡谷相距约100公里，不在一处；洞内钟乳石不可触摸。
- 互动/提问设计：让游客估算"洞口能装下几层楼"，再给出74米的答案。

各位游客，大家好！欢迎来到三峡大瀑布。今天我们要做的，不是站在远处看瀑布，而是——走进瀑布里面去。

它还有一个名字，叫白果树瀑布。相传崖顶上曾经有一棵千年古银杏，当地人把银杏叫"白果树"，瀑布因此得名。

现在说最特别的——穿瀑。瀑布背后凿了一条一百多米长的通道，我们穿上雨衣、套上鞋套，从瀑布内侧走过去。走到中间，请抬头：头顶就是整幅水帘，水从你面前砸下去，风把水雾卷到你脸上，耳边的轰鸣盖过一切说话声。那一刻你会明白，为什么古人说"疑是银河落九天"。

最后三个提醒：穿瀑必须穿雨衣、鞋套，电子设备请做好防水；栈道湿滑，请勿奔跑；雷雨天景区可能临时关闭穿瀑项目，出行前请核实。愿这一身水雾，成为您宜昌之行最痛快的记忆。

**【讲解要点提示】**
- 必讲：瀑布高102米宽约80米；穿瀑体验；白果树名称由来。

**【景区简介】**

明显陵文化旅游景区位于荆门市钟祥市城东北郊，总面积3.18平方公里，2024年2月被文化和旅游部确定为国家5A级。核心资源为明显陵，是明世宗嘉靖皇帝生父兴献王朱祐杬与生母蒋氏的合葬陵寝，始建于明正德十四年（1519年），前后营建四十余年，2000年11月30日作为"明清皇家陵寝"的代表列入《世界遗产名录》，是明代帝陵中单体规模较大、保存较完整的一处。陵区有"一陵两冢"的双茔城、九曲御河、外罗城、明楼等独特规制，在中国陵寝制度研究中价值极高。景区另含莫愁湖国家湿地公园、明文化展示馆与荆楚民俗村莫愁村。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到明显陵。先说一个有意思的事实：这座陵墓的主人，一辈子没当过皇帝。

他叫朱祐杬，是明宪宗的儿子，封地在湖北安陆（今钟祥），爵位兴献王。他去世于1519年，按王的规格下葬。可两年后，他的儿子朱厚熜被从湖北接到北京当皇帝，就是嘉靖帝。嘉靖帝为了给父母争名分，跟大臣们斗了整整十几年，史称"大礼议"。最后他赢了——追尊父亲为皇帝，把王陵扩建成了帝陵。这就是我们今天看到的明显陵，始建于明正德十四年，前后营建四十多年。

请大家留意陵区里最特别的一处："一陵两冢"。别的帝陵是一座坟头，这里有两座——前面是朱祐杬原来的王墓，后面是后来按帝陵规格新建的宝顶，两座之间用土堤连起来，像一条龙脉。这是中国帝陵中绝无仅有的形制。

再看那条弯弯曲曲的水，叫九曲御河。它不只是排水沟，更是风水上的"玉带缠腰"。陵区外围还有一圈外罗城，把整个陵寝环抱起来。

2000年11月30日，明显陵作为"明清皇家陵寝"的代表，被列入《世界遗产名录》。2024年2月，它所在的景区又拿到了5A。一座六百年前的陵寝，今天成了世界级的文化名片。

走出陵区，我们还可以去莫愁湖和莫愁村。相传莫愁湖因楚国歌舞艺术家莫愁女在此生长而得名。莫愁村是依托明显陵建起来的荆楚民俗村，青砖黛瓦，可以吃、可以逛。

提醒：陵区为文物保护单位，请勿攀爬宝顶、触摸石刻；出行前请核实开放时间。愿这段"大礼议"的风云，给您留下对明代礼制的新认识。

**【讲解要点提示】**
- 必讲：陵主朱祐杬被追尊为帝的"大礼议"背景；"一陵两冢"；世界遗产身份。
- 数据锚点：景区总面积3.18平方公里、始建于1519年、2000年11月30日入遗、2024年2月评5A。
- 常见误区：明显陵不在北京明十三陵之列；陵主生前未登基，是嘉靖追尊。
- 互动/提问设计：问"为什么一座陵会有两个坟头"，再讲王改帝陵的扩建过程。

### 16. 黄冈市麻城龟峰山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年12月确定） |
| 所在地 | 黄冈市麻城市 |
| 类型 | 山岳峰林 · 森林草原 |
| 评定年份 | 2024 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**

麻城龟峰山景区位于黄冈市麻城市东部，地处大别山中段南麓，距武汉市区约113公里，2024年12月被文化和旅游部确定为国家5A级，是湖北省第16家国家5A级旅游景区，也是黄冈市首家、鄂东地区首家。山体由龟首、龟背、龟尾等九座山峰组成，远望如一只昂首吞日的神龟，因而得名。景区拥有连片面积达10万亩的古杜鹃群落，其面积、年代、密度与花色在国内罕见，每年四五月盛开时形成"北纬30度最美红飘带"的景观；森林覆盖率达95%，为国家级生态旅游示范区、大别山世界地质公园核心园区。景区建有1288观光塔、国际运动龟谷等现代旅游项目。

**【导游词核心稿】**

各位游客，大家好！欢迎来到麻城龟峰山。请先看远处的山脊——那不是普通的山，那是一只乌龟：高高地昂着头，背甲隆起，尾巴拖在后面，朝着太阳。它由龟首、龟背、龟尾等九座山峰组成，所以叫龟峰山。

但龟峰山真正让人震撼的，不是形状，是花。每年四五月，山上的杜鹃一起开，连片面积达到十万亩。十万亩是什么概念？约等于六十多个西湖那么大，全部染成红色。更稀奇的是，这里的杜鹃是"古杜鹃"——很多树龄在百年以上，长得比人还高，一棵树能开几千朵花。它的面积、年代、密度、花色，在国内都算得上罕见，所以人们说，这是"北纬30度最美红飘带"。

再说绿。龟峰山森林覆盖率达到95%，是大别山世界地质公园的核心园区。走在栈道上，空气里全是负氧离子，夏天山下三十几度，山上还得加件外套。

这一带还是大别山革命老区。2015年，国务院批复《大别山革命老区振兴发展规划》，麻城被列为大别山七大区域性中心城市之一。2024年12月，龟峰山成功创建5A，成为湖北省第16家5A景区，也填补了大别山革命老区5A级景区的空白——这块牌子，对老区来说分量很重。

山顶还有一座"1288"观光塔，取龟峰山最高处的海拔意象，登上去可以俯瞰整片杜鹃花海。

提醒：杜鹃花期集中在四月中下旬至五月上旬，非花期景观以山林为主，出行前请核实花期与开放安排；山区温差大，请备外套。愿这一山杜鹃，染红您的春天。

**【讲解要点提示】**
- 必讲：龟形山体九峰；十万亩古杜鹃；大别山革命老区5A突破。
- 数据锚点：古杜鹃连片10万亩、森林覆盖率95%、距武汉113公里、2024年12月评5A。
- 常见误区：杜鹃花期短暂，非花期游客预期需提前说明；江西弋阳有同名"龟峰"（同为5A、丹霞地貌），与本景区相距数百公里、地貌成因完全不同，讲到龟峰山时须点明在湖北麻城。
- 互动/提问设计：让游客找"龟头在哪儿"，再讲九峰组成与命名由来。
