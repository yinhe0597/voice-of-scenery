### 1. 天津古文化街旅游区（津门故里）

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 天津市南开区鼓楼街古文化街 |

| 评定年份 | 2007 |
| 建议游览时长 | 2-3 小时 |

**【景区简介】**（约240字）

天津古文化街旅游区（津门故里）位于天津市南开区，地处海河西岸、老城厢东北角，是天津城市发祥地之一。街区南北全长687米，宽约5米，1986年元旦建成开放，沿街铺面为仿清民间小式建筑，集中经营杨柳青年画、泥人张彩塑、风筝魏、刻砖刘等天津传统手工艺品及风味小吃。街中段坐落着敕建天后宫，始建于元泰定三年（1326年），是天津市区现存最古老的建筑群之一，与福建湄洲妈祖庙、台湾北港朝天宫并称中国三大妈祖庙。天后宫前即为历史上南运河、北运河与海河交汇的三岔河口，为天津漕运与城市兴起之地。2007年，古文化街旅游区被评定为国家5A级旅游景区。

**【导游词核心稿】**（约570字）

各位游客朋友们，大家好！欢迎来到天津古文化街。这里有个更响亮的招牌——"津门故里"。什么意思？就是说，这里是天津这座城市的"老家"。

为什么这么说？请大家跟我往前走。这条街南北全长687米，两边是清一色的仿清民间小式建筑，青砖灰瓦、飞檐斗拱。上世纪80年代，天津在城市改造中把这条老街整体修整，1986年元旦正式开放。

但真正让这条街"有资格"叫"故里"的，是眼前这座庙——天后宫，天津人管它叫"娘娘宫"。它始建于元泰定三年，也就是1326年，到今天快七百年了。它是天津市区现存最古老的建筑群之一。庙里供奉的是妈祖，也就是护佑航海、漕运的"天后"。它与福建湄洲妈祖庙、台湾北港朝天宫，并称为中国三大妈祖庙。

各位想一想：为什么一座妈祖庙，会出现在北方？答案就在庙前不远的地方——那里是南运河、北运河与海河交汇的"三岔河口"。元代起，南粮北运的漕船一路北上，终点就是这里。船工、纤夫、商人在此聚集，先是建了庙，后来才有了镇，再后来才有了天津城。所以天津有句老话："先有天后宫，后有天津卫。"

沿着街走，各位会看到天津的三样绝活：杨柳青年画，色彩浓艳、题材吉祥，是中国四大年画之一；泥人张彩塑，一团泥在手里三两下就成了活灵活现的人物，据说创始人张明山能在戏台下袖中塑像，惟妙惟肖；还有"风筝魏"的风筝，扎得轻、放得稳。这些都是国家级非物质文化遗产。

逛完整条街、参观天后宫约需2小时。出行前请核实街区与天后宫的开放时间、节假日活动安排。祝各位在"津门故里"，尝到天津的烟火气，也读懂这座城市从码头长成的故事。

**【讲解要点提示】**
- 必讲：古文化街长度与1986年建成、天后宫1326年始建、"先有天后宫，后有天津卫"、三岔河口与漕运、天津三绝手工艺
- 数据锚点：街区全长687米；天后宫始建于元泰定三年（1326年）；1986年元旦建成开放；中国三大妈祖庙之一
- 常见误区：①天后宫中的"天后"即妈祖，不是"送子娘娘"之外的其他神祇；②"津门故里"是街区品牌名，不是一条街的正式地名；③古文化街建筑为1980年代仿清风格的整修成果，并非原样明清老街
- 互动/提问设计：请游客猜一猜，为什么北方内陆的天津会建起一座妈祖庙？（答案：因三岔河口是漕运终点，船民信奉妈祖护航）

### 2. 盘山风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 天津市蓟州区官庄镇莲花岭村 |
| 类型 | 山岳峰林 · 宗教圣地 |
| 评定年份 | 2007 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**（约245字）

盘山风景名胜区位于天津市蓟州区西北，属燕山山脉南麓，总面积约106平方公里，主峰挂月峰海拔864.4米，为京东地区著名山岳风景区，历史上被誉为"京东第一山"。盘山以"三盘暮雨"的独特景观著称——上盘松胜，虬曲苍劲；中盘石胜，怪石嵯峨；下盘水胜，泉流淙淙。另有"五峰"（挂月峰、紫盖峰、自来峰、九华峰、舞剑峰）、"八石"等天然胜景。盘山佛教文化悠久，自唐代始建寺庵，明清最盛，有天成寺、万松寺、云罩寺、少林寺（北少林）等古刹遗迹，以及定光佛舍利塔等遗存。清乾隆皇帝曾多次登临盘山，留有"早知有盘山，何必下江南"的著名诗句与大量题咏。2007年，盘山被评定为国家5A级旅游景区。

**【导游词核心稿】**（约580字）

各位游客朋友们，大家好！欢迎来到盘山。盘山在天津蓟州，属燕山山脉，主峰挂月峰海拔864.4米。别看这个高度在名山里不算突出，古人却给了它一个响当当的名号——"京东第一山"。

为什么？因为盘山有"三盘暮雨"的奇景：上盘看松，古松盘曲，虬枝横斜；中盘看石，巨石嵯峨，形貌各异；下盘看水，泉流淙淙，四季不竭。春夏之交，雨雾起时，松、石、泉一起隐入烟云，这就是"三盘暮雨"。除此之外，盘山还有五座主峰——挂月峰、紫盖峰、自来峰、九华峰、舞剑峰，名字一个个都透着仙气。

说到盘山，绕不开一位"超级粉丝"：乾隆皇帝。据史料记载，他一生到过盘山几十次，留下诗作上千首，还写下了那句流传最广的评语——"早知有盘山，何必下江南"。一句诗，让这座北方山岳从此有了江南的声誉。相传，乾隆当年还专门为盘山修了行宫"静寄山庄"，可见喜爱之深。

盘山也是一座佛教名山。自唐代起，山上寺庵林立，到明清时最为兴盛。我们现在经过的天成寺，是盘山规模最大的寺院之一，寺前有古树、有塔影，布局玲珑；再往上，万松寺、云罩寺依次隐入山林，云罩寺就在接近挂月峰的地方，取"云遮雾罩"之意。山顶还有定光佛舍利塔，登临远望，群峰尽收眼底。

盘山山高路长，索道与步道结合游览全程约需4到6小时，体力不足的游客可选择索道上下。出行前请核实开放时间、索道运营与山区天气，雨天路滑请特别注意安全。祝各位在盘山，看得见松、石、泉，也听得见那段皇家往事。

**【讲解要点提示】**
- 必讲："三盘暮雨"（上盘松、中盘石、下盘水）、五峰、乾隆皇帝与盘山、佛教古刹群
- 数据锚点：主峰挂月峰海拔864.4米；总面积约106平方公里；2007年评为5A；"五峰"之名
- 常见误区：①盘山不是"五台山""盘山道"等他处同名山地，是天津蓟州的京东第一山；②"早知有盘山，何必下江南"是乾隆的诗句评语，民间流传版本略有出入，讲解时应说明为相传／据史料记载；③盘山与清代"静寄山庄"行宫遗址相关，现存遗迹情况需以景区现场标识为准
- 互动/提问设计：请游客沿途观察，山上松树、石头、泉水有什么不同，判断自己走到了"上盘""中盘"还是"下盘"？
