### 1. 青城山—都江堰旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 成都市都江堰市 |
| 类型 | 古典园林 · 宗教圣地 · 遗址考古 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

青城山—都江堰旅游景区位于成都市都江堰市境内，由青城山与都江堰两大片区组成。都江堰是世界年代最久、唯一留存、以无坝引水为特征的大型水利工程，始建于秦昭王末年（约公元前256年），由蜀郡太守李冰率民众主持修建，以鱼嘴分水堤、飞沙堰溢洪道、宝瓶口引水口三大主体工程科学解决了分水、排沙、防洪与灌溉问题，两千余年来持续发挥效益。青城山为中国道教发源地之一，相传东汉顺帝年间（约公元143年）张陵在此结茅传道，山上有建福宫、天师洞、上清宫等宫观，素以"幽"著称。2000年，青城山—都江堰被联合国教科文组织列入《世界遗产名录》。

**【导游词核心稿】**

各位游客，大家好！欢迎来到青城山—都江堰。这两处景点一山一水，一幽一雄，2000年一起列入了《世界遗产名录》。

我们先看都江堰。请大家站在安澜索桥上，脚下这条江就是岷江。约公元前256年，秦昭王末年，蜀郡太守李冰率民众在这里修建了都江堰。它的伟大之处在于"无坝引水"——不筑高坝，只靠三个工程就把水治住了：鱼嘴把岷江分成内江和外江，四六分水；飞沙堰把多余的洪水和泥沙泄回外江；宝瓶口像一道闸门，控制进入成都平原的水量。

请注意一个数字：两千两百多年。世界上有不少古代水利工程，但绝大多数早已废弃，只有都江堰一直用到今天，灌溉面积超过一千万亩。这就是它被称为"活的水利博物馆"的原因。

下午我们去青城山。它是中国道教的发源地之一，相传东汉顺帝年间张陵在此创立五斗米道。青城山最大的特点是一个"幽"字——林木常青，四季幽深，所以叫"青城天下幽"。主要宫观有建福宫、天师洞和上清宫，其中天师洞相传就是张陵讲经处，现存殿宇多为清代重建。

朋友们，上午看人类改造自然的智慧，下午看人与自然相处的哲学，这就是青城山—都江堰的完整体验。山间石阶湿滑，请穿防滑鞋。

**【讲解要点提示】**

- 必讲：李冰与三大主体工程（鱼嘴、飞沙堰、宝瓶口）；"青城天下幽"；道教发源地。
- 数据锚点：约公元前256年始建，历时2200余年；2000年列入世界遗产；灌溉面积逾千万亩。
- 常见误区：都江堰不是"大坝"，没有拦河蓄水；青城山不是青城山"前山+后山"同一个入口，前山文化、后山风景，注意区分。
- 互动/提问设计：问游客"为什么两千年不淤塞"，引出飞沙堰的排沙原理。
- 出行前请核实：索道运行情况、二王庙与离堆公园开放状态。

### 2. 峨眉山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 乐山市峨眉山市 |
| 类型 | 宗教圣地 · 山岳峰林 · 森林草原 · 世界文化与自然双重遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 2 天 |

**【景区简介】**

峨眉山位于四川省乐山市峨眉山市境内，属邛崃山脉南段，屹立于四川盆地西南边缘。景区面积约623平方公里（核心游览区约154平方公里），主峰万佛顶海拔3099米，金顶海拔3079米，相对高差超过2600米，山势陡峻、气象万千。峨眉山是中国佛教四大名山之一，为普贤菩萨道场，据史料记载，佛教于公元一世纪传入峨眉山，现存报国寺、伏虎寺、万年寺、金顶华藏寺等寺庙20余座。山中植被垂直带谱完整，保存有珙桐、桫椤等珍稀植物。1996年，峨眉山—乐山大佛被联合国教科文组织列入《世界文化与自然双重遗产名录》，是国内少数几处双遗产之一。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到峨眉山。它是中国佛教四大名山之一，也是普贤菩萨的道场。

先说高度：金顶海拔3079米，万佛顶海拔3099米，而山脚只有四百多米，相对高差超过2600米。这个落差意味着什么？意味着你在一天之内，可以从亚热带走到寒温带，看五种不同的植被带。这也是1996年峨眉山和乐山大佛一起，被列入《世界文化与自然双重遗产名录》的原因——它同时满足了文化遗产和自然遗产两个标准。

佛教传入峨眉山，据史料记载始于公元一世纪。全山现有寺庙20余座，最重要的是山下的报国寺、半山的万年寺和金顶的华藏寺。万年寺里供着一尊普贤骑象铜像，铸造于北宋太平兴国五年（980年），高7.85米、重62吨，是峨眉山的镇山之宝。

金顶是这趟行程的高潮。站在3079米的观景台上，天气好时可以看到贡嘎山的雪峰，脚下是翻涌的云海。运气特别好时，还能看到"佛光"——其实就是阳光透过云雾，把自己的影子投在云幕上形成的彩色光环。

还有一点要提醒：峨眉山的猴子很有名，但它们不是宠物。请不要喂食、不要挑逗、不要拎塑料袋。

朋友们，峨眉山"一日有四季，十里不同天"，请带上雨具和厚外套。

**【讲解要点提示】**

- 必讲：普贤菩萨道场；1996年双遗产；万年寺普贤骑象铜像；金顶云海。
- 数据锚点：金顶3079米、万佛顶3099米；相对高差超2600米；铜像铸于980年、高7.85米、重62吨。
- 常见误区："佛光"是光学现象而非神迹，可科学解释；金顶四面十方普贤像是当代作品（2006年落成），不是文物。
- 互动/提问设计：问游客"峨眉山的猴子为什么不怕人"，引出生态教育与安全管理。
- 出行前请核实：金顶索道、冬季道路与防滑链要求。

### 3. 九寨沟旅游景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定） |
| 所在地 | 阿坝藏族羌族自治州九寨沟县 |
| 类型 | 水域湖泊 · 森林草原 · 山岳峰林 · 世界自然遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 1-2 天 |

**【景区简介】**

九寨沟位于四川省阿坝藏族羌族自治州九寨沟县境内，地处岷山山脉南段，因沟内有荷叶、盘亚等九个藏族村寨而得名。景区面积约720平方公里，游览区沿树正沟、日则沟、则查洼沟三条主沟呈"Y"形分布，总长约60公里。九寨沟以翠海、叠瀑、彩林、雪峰、藏情、蓝冰"六绝"著称，有大小海子100余个，是喀斯特钙华与高山冰川共同塑造的高寒岩溶地貌典型代表。1992年，九寨沟被联合国教科文组织列入《世界自然遗产名录》。2017年地震后景区经修复并调整开放，实行限量预约游览。

**【导游词核心稿】**

各位游客，大家好！欢迎来到九寨沟。有句话叫"黄山归来不看山，九寨归来不看水"，今天我们就要看看，这句话是不是夸张。

九寨沟名字的来历很朴素——沟里有九个藏族村寨。景区面积约720平方公里，三条主沟呈"Y"字形展开，总长约60公里，分别是树正沟、日则沟和则查洼沟。

九寨的水为什么这么蓝、这么绿？第一，水极干净，含沙量极低；第二，湖底有大量古代钙华沉积，像刷了一层白色颜料；第三，湖水中悬浮的碳酸钙微粒对短波光有散射作用，于是把蓝绿光"挑"了出来。这就是为什么五花海能在一片水里呈现鹅黄、墨绿、深蓝几种颜色。

再看瀑布。诺日朗瀑布宽约300米、落差约20米，是九寨沟的标志；珍珠滩瀑布则是《西游记》片尾唐僧师徒走过的那道水帘。

还有树正群海——几十个海子层层跌落，像一串绿色的阶梯；长海则是沟里最大、最深的湖，冬季会封冻成蓝冰。

这里还是藏族聚居区。扎如寺、树正寨都是了解安多藏族文化的窗口。1992年，九寨沟被列入《世界自然遗产名录》。

朋友们，景区实行区间车加步行的方式游览，请勿下栈道、请勿投喂、请勿用手触摸湖水——钙华一旦被破坏，几百年都恢复不过来。

**【讲解要点提示】**

- 必讲："六绝"；水的呈色原理；1992年世界自然遗产；栈道不外踩。
- 数据锚点：景区面积约720平方公里；三条沟总长约60公里；海子100余个；诺日朗瀑布宽约300米。
- 常见误区：九寨沟地震后部分景点（如火花海）恢复情况每年不同，讲解前请核实最新开放范围；不要承诺"四季都能看到全部景点"。
- 互动/提问设计：让游客在五花海边数一数能分辨出几种颜色。
- 出行前请核实：预约政策、限流人数与开放沟段。

### 4. 乐山大佛景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 乐山市市中区 |
| 类型 | 宗教圣地 · 遗址考古 · 世界文化与自然双重遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**

乐山大佛景区位于四川省乐山市市中区，地处大渡河、青衣江与岷江三江汇流之处。乐山大佛为弥勒佛坐像，依凌云山栖鸾峰临江崖壁凿造，通高71米，头高14.7米、头宽10米，肩宽28米，脚背宽约8.5米，可容百人并坐，是世界上现存最高的石刻弥勒佛坐像。大佛于唐玄宗开元元年（713年）由海通和尚发起开凿，因经费中断一度停工，后经章仇兼琼、韦皋先后续建，至唐德宗贞元十九年（803年）完工，历时约90年。大佛两侧崖壁上有唐代摩崖造像与题记，1996年，峨眉山—乐山大佛被联合国教科文组织列入《世界文化与自然双重遗产名录》。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到乐山大佛。我们眼前这尊佛像，是世界上现存最高的石刻弥勒佛坐像，也是唐代留给世界的一件超级工程。

先看数字：通高71米，头高14.7米，肩宽28米，光是脚背上就能坐一百多人。也就是说，它有二十多层楼那么高。

它的故事要从一位和尚讲起。据史料记载，唐玄宗开元元年，也就是公元713年，凌云寺的海通和尚见三江汇流处水患频发、船毁人亡，便发愿凿一尊大佛以镇水势。他四处化缘，甚至有"自抉其目"以示决心的传说。工程开工后因经费不足停工，后来剑南节度使章仇兼琼、韦皋先后捐资续建，直到唐德宗贞元十九年，也就是公元803年才最后完工，前后历时约90年，三代人接力。

大家注意大佛两侧的崖壁，上面还留着唐代的造像和题记。而大佛本身的设计也很科学：佛身内有隐蔽的排水系统，衣纹褶皱里藏着排水沟，让雨水不会直接冲刷佛面——这是它能保存一千二百多年的关键之一。

1996年，峨眉山和乐山大佛一起被列入《世界文化与自然双重遗产名录》。

朋友们，看大佛有两条路：一是沿九曲栈道走到佛脚，近距离感受它的体量；二是坐游船在江面远观全貌。两种方式建议都体验。栈道狭窄陡峭，请排队慢行。

**【讲解要点提示】**

- 必讲：海通和尚发愿；三代人接力90年；71米的高度与排水系统。
- 数据锚点：713年开凿、803年完工、历时约90年；通高71米；头高14.7米、肩宽28米。
- 常见误区：乐山大佛是弥勒佛（未来佛），不是释迦牟尼；佛教中弥勒为坐姿与常见的布袋和尚形象不同。
- 互动/提问设计：请游客估算大佛耳朵里能站几个人，再讲"耳长7米"的量级。
- 出行前请核实：九曲栈道是否因维修关闭、游船班次。

### 5. 黄龙风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2012年评定） |
| 所在地 | 阿坝藏族羌族自治州松潘县 |
| 类型 | 地质地貌 · 水域湖泊 · 世界自然遗产 |
| 评定年份 | 2012 |
| 建议游览时长 | 4-6 小时 |

**【景区简介】**

黄龙风景名胜区位于四川省阿坝藏族羌族自治州松潘县境内，地处岷山山脉主峰雪宝顶（海拔5588米）北麓，景区海拔在3000至3600米之间，面积约700平方公里。核心景观黄龙沟全长约3.6公里，是一条由碳酸钙沉积（钙华）形成的巨型"金色阶梯"，沟内分布彩池3400余个，以五彩池、争艳池、迎宾池及金沙铺地、洗身洞、黄龙寺等最为著名。黄龙是中国规模最大、保存最完整的高原钙华景观，1992年与九寨沟同期被联合国教科文组织列入《世界自然遗产名录》，同时也是世界人与生物圈保护区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到黄龙。如果说九寨沟看的是"海子"，那黄龙看的就是"池子"和"台地"——它是中国规模最大、保存最完整的高原钙华景观。

先讲背景。黄龙在松潘县，背后是岷山主峰雪宝顶，海拔5588米。我们今天走的这条黄龙沟，全长约3.6公里，海拔在3000米以上。请大家放慢脚步，注意高反。

这里最神奇的是"钙华"。通俗地说，就是水里溶解的碳酸钙，因为温度、压力和藻类作用，重新沉淀成固体，一层一层往下长，像黄色的梯田。整条沟因此被染成金黄色，从山顶看下去，像一条黄龙从雪山上飞下来——这就是"黄龙"名字的由来。

沟里有彩池3400多个。最上面的是五彩池，它也是黄龙的终点和最高潮：几百个小池层层叠叠，水色有蓝、绿、黄、褐，在阳光下像打翻的调色盘。

还有一处叫"金沙铺地"，是世界上最长的钙华滩流，水在金黄色的钙华坡面上薄薄地流过，闪闪发光。

1992年，黄龙和九寨沟一起被列入《世界自然遗产名录》。

朋友们，钙华非常脆弱，一分钟踩踏、几十年难恢复。请全程走在栈道上，也不要把手伸进水里。高原上行走请量力而行，备好氧气和保暖衣物。

**【讲解要点提示】**

- 必讲：钙华成因；五彩池；1992年世界自然遗产；高原生态保护。
- 数据锚点：雪宝顶海拔5588米；沟长约3.6公里；彩池3400余个；景区海拔3000—3600米。
- 常见误区：黄龙与九寨沟是两个景区，相距约100公里，一日游会非常赶；高反与天气风险不可低估。
- 互动/提问设计：请游客观察钙华的颜色，猜"黄色"来自什么（碳酸钙沉淀与藻类）。
- 出行前请核实：冬季（12月至次年3月）是否开放、索道运行情况。

### 6. 阆中古城景区

| 等级 | 5A（2013年评定） |
| 所在地 | 南充市阆中市 |
| 类型 | 古城古镇 |
| 评定年份 | 2013 |

**【景区简介】**

先交代地理。剑门关位于大剑山和小剑山之间，两山在这里断出一个缺口，古人把这个缺口当成了进出四川的门户。据史料记载，三国时期诸葛亮在此凿石开道、砌石建关，从此这里就成了蜀汉的北大门。

院子里有两个细节最打动人。一个是朱德少年时读的私塾"药铺垭"，他在这里读了几年书，后来又过继给伯父才得以继续求学；另一口是"朱德井"，相传是少年朱德带着家人挖的，解决了全家吃水的问题。从这两件事能看出他的性格：想读书、肯干活。

1909年，二十三岁的朱德离开家乡，远赴云南昆明，考入云南讲武堂。从此他从佃农之子，走到护国战争的战场，走到井冈山，走到开国大典的城楼上。

纪念馆里有一件重要文物——他母亲使用过的纺车。朱德在《回忆我的母亲》这篇文章里，写尽了对母亲的感情，那篇文章曾长期入选语文课本。

朋友们，这里很少有"宏大叙事"，更多是一口井、一间私塾、一架纺车。但正是这些细节，让你明白一个人的来路。参观时请保持肃静。

**【讲解要点提示】**

- 必讲：1886年12月1日诞生于佃农家庭；药铺垭私塾与朱德井；1909年离家求学。
- 数据锚点：1886年12月1日；1909年赴云南讲武堂；2016年获评5A。
- 常见误区：朱德故居与"诞生地"是两处不同点位（李家湾出生、后迁居马鞍场），讲解时应区分。
- 互动/提问设计：请游客回忆《回忆我的母亲》片段，引出家风与家国主题。
- 出行前请核实：纪念馆开放日与讲解预约。

### 12. 海螺沟景区

**【景区简介】**

海螺沟景区位于四川省甘孜藏族自治州泸定县磨西镇，地处青藏高原东南缘、贡嘎山东坡，是国家级重点风景名胜区与国家级自然保护区的重要组成部分。贡嘎山主峰海拔7556米，为横断山脉最高峰，有"蜀山之王"之称。海螺沟以低海拔现代冰川著称，冰川末端下伸至海拔约2850米的原始森林中，落差达数千米，是同纬度海拔最低、活动性最强的冰川之一。沟内大冰瀑布高约1080米、宽500至1100米，是中国已发现最大的冰瀑布。景区还拥有温泉、原始森林、红石滩等资源，磨西古镇是1935年红军长征"磨西会议"旧址所在地。

各位游客，大家好！欢迎来到海螺沟。我们要去看的，是一座可以走近的冰川。

海螺沟最特别的一点，是"低"。一般的冰川都在雪线以上、人迹罕至，可海螺沟的冰川末端一直伸到海拔约2850米的原始森林里。也就是说，你可以穿着外套、走在林间栈道上，抬头就看见几千米高处流下来的冰。这在国内是独一份。

最震撼的景观是大冰瀑布，高约1080米、宽500到1100米，是中国已发现最大的冰瀑布。它由冰川跌落陡崖形成，冰面布满裂隙，晴天时呈淡蓝色，非常壮观。

**【讲解要点提示】**

- 必讲：贡嘎山7556米；冰川末端海拔约2850米；大冰瀑布；磨西会议。
- 数据锚点：主峰7556米；大冰瀑布高约1080米、宽500—1100米；冰川末端海拔约2850米。
- 常见误区：海螺沟属泸定县，与稻城亚丁、四姑娘山相距甚远；"红石"是藻类而非矿物染色。
- 互动/提问设计：问游客"为什么冰川能长到森林里"，引出低纬度、高降雪量的补给条件。
- 出行前请核实：索道（四号营地）、冰川步道开放状态与雨季落石风险。

各位朋友，大家好！欢迎来到雅安碧峰峡。雅安是"雨城"，一年有两百多天在下雨，森林覆盖率接近七成，所以这里空气特别好，连熊猫都爱住。

### 14. 光雾山旅游景区

| 项目 | 内容 |
| --- | --- |

**【景区简介】**

光雾山旅游景区位于四川省巴中市南江县北部，地处米仓山腹地，与陕西省相邻，主峰海拔约2508米。景区以喀斯特地貌、原始森林和红叶景观著称，森林覆盖率超过97%，保存有水青冈、红豆杉、巴山水青冈等珍稀树种，其中国家二级保护植物巴山水青冈为世界罕见的原始群落。光雾山以秋季红叶最为著名，红叶面积大、持续时间长（一般10月中下旬至11月），被誉为"亚洲最长的天然红地毯"，已连续举办多届四川光雾山国际红叶节。光雾山—诺水河已获联合国教科文组织世界地质公园称号。景区2020年获评国家5A级旅游景区。

**【导游词核心稿】**

各位游客，大家好！欢迎来到光雾山。如果你在秋天来，接下来这两天你会看到中国最壮观的红叶。

光雾山在巴中市南江县，藏在米仓山里，主峰海拔约2508米，和陕西交界。它最硬的三张牌是：石头、树、红叶。

先看石头。这里是典型的喀斯特地貌，山峰被溶蚀成一丛丛的峰丛、石林，配上常年不散的云雾，所以叫"光雾"——大概就是"山色明丽、云雾缭绕"的意思。

再看树。光雾山森林覆盖率超过97%，其中最珍贵的是巴山水青冈，国家二级保护植物，在这里有成片的原始林，全世界都罕见。

但真正的主角是秋天。每年10月中下旬到11月，从山脚到山顶，水青冈、枫树、漆树次第变色，红、橙、黄、紫一层层铺开，一直铺到天边，被称作"亚洲最长的天然红地毯"。为什么能这么壮观？因为山体高差大，不同海拔的树叶变色时间错开，观赏期能持续一个多月。

除了红叶，春天的光雾山是杜鹃花海，夏天是避暑的天然氧吧，冬天有雾凇和冰雪。

朋友们，红叶季是旺季，住宿和车辆都要提前安排。山里早晚温差大，请带厚外套；拍摄时请不要为了取景离开栈道、踩踏林下植被。

**【讲解要点提示】**

- 必讲：亚洲最长天然红地毯；巴山水青冈原始林；喀斯特峰丛与云雾。
- 数据锚点：主峰海拔约2508米；森林覆盖率超97%；红叶期一般为10月中下旬至11月。
- 常见误区：红叶最佳期每年随气温浮动，可提前一周至十天，讲解时不要用固定日期承诺。
- 互动/提问设计：让游客按海拔由低到高判断哪一层先变色，引出垂直气候带知识。
- 出行前请核实：红叶节期间交通管制、索道与景交车安排。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到稻城亚丁。有人说这里是"蓝色星球上的最后一片净土"，也有人称它"最后的香格里拉"。

第二站是洛绒牛场，海拔约4150米。这是一片开阔的高山草甸，三座雪山在这里同时入画，也是亚丁最经典的取景点。

- 出行前请核实：景区每日限流与观光车首末班、高原天气与道路结冰情况。

各位游客，大家好！欢迎来到安仁古镇。这座小镇有个很特别的外号——"中国博物馆小镇"。

安仁有1400多年历史，但它真正出名，是因为两样东西：公馆和博物馆。

第一样是刘氏庄园。这是全国重点文物保护单位，占地7万多平方米，建筑面积2万余平方米。它由几座院落连成一片，有中西合璧的楼阁、有花园、有账房、有粮仓。最值得看的是大型泥塑群《收租院》，一百多个人物，用连续的场景讲述了旧中国租佃关系下农民的生活，是二十世纪中国非常有代表性的一组雕塑作品。

第二样是建川博物馆聚落。这里有抗战、民俗、红色年代等系列30多座专题博物馆，是国内规模最大的民营博物馆聚落之一。其中"抗战系列"收藏了大量实物与文献，分量很重。

除了这两处，镇上还有20多座老公馆，走在树人街、裕民街这些老街上，青砖、封火墙、雕花门楣，能看到民国时期川西小镇的样子。安仁还是民国风的"网红"打卡地，很多人会穿旗袍来拍照。

2022年，安仁古镇成为国家5A级景区，是成都第二家5A。

朋友们，博物馆多，一天看不完，建议上午刘氏庄园、下午选两三个建川的分馆。参观《收租院》时请保持庄重。

**【讲解要点提示】**

- 必讲：刘氏庄园与《收租院》；建川博物馆聚落；"中国博物馆小镇"称号。
- 数据锚点：建镇1400余年；刘氏庄园占地7万余平方米、建筑面积2万余平方米；老公馆20余座；博物馆30余座。
- 常见误区：安仁古镇与"安仁"同名地点（如湖南安仁县）无关；《收租院》是1965年创作的泥塑作品，讲解时应说明其时代背景。
- 互动/提问设计：请游客比较老公馆的中式与西式元素，讨论近代川西的建筑融合。
- 出行前请核实：博物馆分馆开放数量与联票、周一闭馆惯例。

### 17. 四姑娘山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年2月公告） |
| 所在地 | 阿坝藏族羌族自治州小金县 |
| 类型 | 山岳峰林 · 森林草原 · 世界自然遗产 |
| 评定年份 | 2024 |
| 建议游览时长 | 2-3 天 |

**【景区简介】**

四姑娘山景区位于四川省阿坝藏族羌族自治州小金县与汶川县交界处，属邛崃山脉中段，由四座毗连的雪峰组成，自北而南依次为：大峰海拔5025米、二峰5276米、三峰5355米、幺妹峰（四峰）6250米。幺妹峰为邛崃山脉最高峰，有"蜀山皇后"之称，与"蜀山之王"贡嘎山并称。景区由双桥沟、长坪沟、海子沟三条沟谷组成，其中双桥沟全长约34.8公里、长坪沟约29公里、海子沟约19公里。区内保存完整的垂直植被带谱与高山针叶林，是"四川大熊猫栖息地"世界自然遗产的重要组成部分。景区2024年2月被确定为国家5A级旅游景区。

**【导游词核心稿】**

各位朋友，大家好！欢迎来到四姑娘山。它是四川人的"户外学校"，也是登山者心中的圣地。

先认识四位"姑娘"。从北往南数：大姑娘峰海拔5025米，二姑娘峰5276米，三姑娘峰5355米，最小的四姑娘——幺妹峰反而最高，6250米。它是邛崃山脉的最高峰，被称为"蜀山皇后"，和7556米的"蜀山之王"贡嘎山遥相呼应。相传四位姑娘是为保护家园与恶魔搏斗而化作雪山，所以当地藏族同胞把幺妹峰视为神山。

景区有三条沟，玩法完全不同：

双桥沟全长约34.8公里，最轻松，全程可坐观光车，看的是雪峰、草甸、白杨林和人参果坪，适合第一次来的人。

长坪沟约29公里，是徒步者的天堂。沟内古木参天，栈道沿溪而上，走到木骡子可以看到四姑娘山的背面，这也是登大峰、二峰的起点。

海子沟约19公里，最原始，以高山湖泊（海子）为主，骑马或徒步，人少景深。

生态上，这里是"四川大熊猫栖息地"世界自然遗产的一部分，2006年列入《世界遗产名录》。

朋友们，四姑娘山海拔高，长坪沟、海子沟往返都需要一整天，请量力选择。高原紫外线强，请做好防晒和保暖，不要独自离队。

**【讲解要点提示】**

- 必讲：四座山峰名称与海拔；幺妹峰6250米与"蜀山皇后"；三条沟的不同玩法。
- 数据锚点：5025米、5276米、5355米、6250米；双桥沟34.8公里、长坪沟29公里、海子沟19公里；2024年2月获评。
- 常见误区：四姑娘山在小金县，与毕棚沟（理县）是相邻但不同的景区，背靠背穿越需要专业向导。
- 互动/提问设计：请游客猜"四姑娘"里谁最高，再公布"幺妹峰最高"这一反常识的答案。
- 出行前请核实：各沟观光车、冬季封沟与登山报备（登大峰二峰需办理手续并雇请向导）。

### 18. 天台山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年12月公告） |
| 所在地 | 成都市邛崃市 |
| 类型 | 山岳峰林 · 森林草原 · 地质地貌 · 世界自然遗产 |
| 评定年份 | 2024 |
| 建议游览时长 | 1 天 |

**【景区简介】**

天台山景区位于四川省成都市邛崃市境内，距成都市区约110公里，属邛崃山脉，为独特的箱状向斜山地，山体由低至高形成三级台地，呈现"一重天台一重天，重重天台上九天"的景观结构。景区总面积约29.1平方公里，主峰玉霄峰海拔1812米，森林覆盖率约95%，动植物种类丰富，是"四川大熊猫栖息地"世界自然遗产的组成部分，同时为国家重点风景名胜区、国家森林公园。景区以"山奇、石怪、水美、林幽、云媚、萤舞"六绝著称，其中萤火虫资源尤为突出，据调查区内分布以三叶虫萤为代表的20余种萤火虫，是全球八大萤火虫观赏地之一、亚洲规模最大的萤火虫观赏基地，观赏期一般为每年4月至10月。

**【导游词核心稿】**

各位游客，大家好！欢迎来到成都邛崃的天台山。它是2024年12月才正式确定的5A级景区，也是成都的第三家5A。

天台山有"六绝"，我们一路走一路对：山奇、石怪、水美、林幽、云媚、萤舞。

先说"山奇"。天台山属于箱状向斜山地，从低到高形成三级台地，一层一层往上叠，古人形容为"一重天台一重天，重重天台上九天"。景区总面积约29.1平方公里，主峰玉霄峰海拔1812米。

再说"石怪"。这里的岩石在地质历史上经历复杂构造运动，形成山崖、峡谷、溶洞和大量奇石，花石林、神蜂窟、倒靴石、天梭石都是代表，因此有"九十里长河八百川，九千颗怪石两千峰"的说法。

"水美"是天台山的另一张王牌。金龙河从海拔1812米的玉霄峰一路蜿蜒而下，形成长滩、瀑布、叠溪和海子，当地有句话："九寨归来不看水，天台归来不玩水"。

"林幽"和"云媚"不用说——森林覆盖率约95%，负氧离子含量极高，雨后云雾起于山巅，是成都周边最好的洗肺去处之一。

最后是"萤舞"。据调查，天台山有以三叶虫萤为代表的20多种萤火虫，是全球八大萤火虫观赏地之一，也是亚洲最大的萤火虫观赏基地，每年4月到10月，从肖家湾到正天台，入夜后林间星河流动，非常震撼。

朋友们，看萤火虫请不要用强光手电、不要捕捉，也不要喷洒驱蚊液。白天登山请穿防滑鞋。

**【讲解要点提示】**

- 必讲：三级台地与"六绝"；萤火虫观赏地；世界自然遗产身份。
- 数据锚点：总面积约29.1平方公里；主峰玉霄峰海拔1812米；森林覆盖率约95%；20余种萤火虫；2024年12月获评。
- 常见误区：萤火虫观赏需夜宿山上且受天气影响，白天到访的团队无法看到，须提前说明。
- 互动/提问设计：请游客猜三级台地是怎么形成的，引出向斜构造。
- 出行前请核实：萤火虫最佳观赏期与夜间入园安排、肖家湾—正天台景交车。

## 三、待核实与补充事项

1. **四川第17、18家5A已确认**：底稿"17-18 待核实"经联网核对为**雅安市碧峰峡旅游景区**（文化和旅游部2020年1月7日公告，22家名单第18项，为四川省第13家）与**成都市天台山景区**（文化和旅游部2024年12月26日公告，19家名单第14项，位于邛崃市）。两处均已撰写词条。
2. **四姑娘山评定年份**：底稿标注"2024（待核实）"。经核对文化和旅游部2024年2月6日公告（21家名单第18项），确认为**2024年2月**，判断成立。
3. **黄龙评定年份**：底稿标注"年份待核实"。现有资料显示为**2012年1月**（2012年1月9日公布批次），本文件按2012年处理。若以评定工作完成年度计，个别资料可能记为2011年，**建议后续与文旅部批次公告再次比对**。
4. **汶川特别旅游区与北川羌城旅游区的准确范围**：两者均为"5·12"地震灾后重建形成的复合型景区，各片区（映秀/水磨/三江、新县城/巴拿恰/吉娜羌寨/寻龙山）之间的联票与开放状态常有调整，**出行前请核实**。
5. **峨眉山—乐山大佛景区面积口径**：不同资料对峨眉山景区面积有"623平方公里""154平方公里（核心游览区）"等多种口径，本文件采用"约623平方公里（核心游览区约154平方公里）"，**具体以景区官方公告为准**。
6. **九寨沟景区面积与开放范围**：景区面积有"720平方公里"（风景名胜区）与"约62—65平方公里"（已开放游览区）等不同口径；2017年地震后开放沟段逐年调整，**讲解前必须核实当年开放范围**。
7. **4A名录**：本表为不完全收录，共108条。四川4A景区实际数量远多于本表，甘孜、阿坝、凉山三州及成都、乐山等地遗漏较多，后续应按市州分批补充。标注"待核实等级"的条目，其A级资质、当前等级与景区名称需以四川省文化和旅游厅最新公告为准。
8. **词条待补**：本文件18家5A均已撰写完整词条；4A部分全部为"待补词条"，后续可优先补写成都大熊猫繁育研究基地、三星堆博物馆、武侯祠、杜甫草堂、蜀南竹海、李庄古镇、泸沽湖、毕棚沟等高频景区。
