### 1. 拉萨市布达拉宫景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 西藏自治区拉萨市城关区北京中路宫前巷35号 |
| 类型 | 宗教圣地 · 古城古镇 · 世界文化遗产 |
| 评定年份 | 2013 |
| 建议游览时长 | 2.5-4 小时（含预约与登阶） |

**【景区简介】**（约250字）

布达拉宫坐落于西藏自治区拉萨市城关区玛布日山（红山）上，是世界上海拔最高、规模最大、保存最完整的古代宫堡式建筑群。宫殿始建于公元7世纪吐蕃赞普松赞干布时期，后毁于雷火与战乱；现存主体由五世达赖喇嘛于1645年起重建白宫，并于1690年至1693年由第司·桑结嘉措主持增建红宫，此后历代均有扩建。布达拉宫占地约36万平方米，主楼高117.19米，外观13层，分红宫与白宫两大部分：白宫为达赖喇嘛的冬宫与政务场所，红宫供奉历代达赖喇嘛灵塔并设有众多佛殿。宫内保存有大量壁画、唐卡、雕塑与经卷，五世达赖喇嘛灵塔为宫内规模最大的一座，耗用大量黄金与珠宝。1994年，布达拉宫列入《世界遗产名录》，后大昭寺（2000年）、罗布林卡（2001年）作为扩展项目纳入。2013年，布达拉宫景区被评定为国家5A级旅游景区。

**【导游词核心稿】**（约580字）

各位游客朋友们，大家好！欢迎来到拉萨布达拉宫。

请各位先停一下，抬头看。这座宫殿建在玛布日山上，从山脚一直砌到山顶，占地约36万平方米，主楼高117.19米，外观13层。它是世界上海拔最高、规模最大、保存最完整的古代宫堡建筑群。第五套人民币50元的背面图案，就是它。

布达拉宫的历史，要分两段说。第一段在公元7世纪：吐蕃赞普松赞干布统一高原、定都拉萨，在红山上修建宫室，那是布达拉宫最早的模样。后来宫殿毁于雷火与战乱。第二段在17世纪：1645年，五世达赖喇嘛开始重建白宫；1690年到1693年，又增建了红宫。我们今天看到的样子，主要是这三百多年里长成的。

进宫之后请各位留意两个字：红与白。白宫，是达赖喇嘛的冬宫，也是处理政务的地方，墙体刷白；红宫，是供奉历代达赖喇嘛灵塔和佛殿的地方，墙体涂红。红白两色各司其职，这是布达拉宫最基本的格局。

红宫里最震撼的，是灵塔。历代达赖喇嘛的灵塔殿中，五世达赖喇嘛那一座规模最大、最华丽，据史料记载耗用黄金约11万两，并镶嵌大量珠宝。灵塔不是墓，是藏传佛教塔葬仪轨的产物，供奉的是经过处理的法体与舍利。请各位在这里放轻脚步、压低声音——对信众来说，这是他们一生中最重要的朝拜地之一。

宫内还藏有大量壁画与唐卡，内容涵盖历史事件、宗教故事与世俗生活，被称为"用绘画写成的西藏历史"。

1994年，布达拉宫列入《世界遗产名录》；2013年，被评为国家5A级旅游景区。

高原地区请缓步慢行，逐级休息。宫内禁止拍照，请勿触摸壁画与塑像。出行前请务必核实预约规定与当日开放安排。

**【讲解要点提示】**
- 必讲：海拔最高的古代宫堡建筑群；7世纪松赞干布始建、1645年重建白宫、1690—1693年建红宫；白宫与红宫的功能区分；五世达赖喇嘛灵塔；1994年世界文化遗产
- 数据锚点：占地约36万平方米；主楼高117.19米、外观13层；1645年；1690—1693年；1994年申遗；2013年评5A
- 常见误区：①现存布达拉宫主体为17世纪重建，7世纪原建筑仅存少量遗迹（如法王洞），不可说"唐代宫殿原样保存至今"；②灵塔是藏传佛教塔葬仪轨的宗教建筑，讲解须庄重客观，不可简化为"坟墓"；③世界遗产正式名称为"布达拉宫历史建筑群"，包含大昭寺与罗布林卡扩展项
- 互动/提问设计：请游客分辨红宫与白宫的墙体颜色，猜一猜各自的功能是什么

### 2. 拉萨市大昭寺景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2013年评定） |
| 所在地 | 西藏自治区拉萨市城关区八廓街 |
| 类型 | 宗教圣地 · 世界文化遗产 |
| 评定年份 | 2013 |
| 建议游览时长 | 2-3 小时 |

**【景区简介】**（约245字）

大昭寺位于西藏自治区拉萨市城关区八廓街中心，始建于公元7世纪吐蕃松赞干布时期，是西藏现存最辉煌的吐蕃时期建筑，也是西藏现存最早的土木结构建筑之一，开创了藏式平川式寺庙的布局规式。寺内主殿供奉释迦牟尼十二岁等身像（藏语称"觉卧仁波切"），据史料记载，该像由文成公主入藏时携入，是藏传佛教信众心中最为殊胜的佛像之一，因而大昭寺在藏传佛教各教派中均享有崇高地位。寺内保存有大量吐蕃时期的木构构件、壁画、雕塑，四层主殿顶部覆有金顶。寺前矗立着立于唐长庆三年（823年）的"唐蕃会盟碑"（长庆会盟碑），碑文以汉藏两种文字镌刻，记述唐蕃"和同为一家"的盟约，是汉藏关系史的重要实物见证。寺外八廓街为传统转经道。2000年，大昭寺作为布达拉宫扩展项目列入《世界遗产名录》；2013年，大昭寺景区被评定为国家5A级旅游景区。

**【导游词核心稿】**（约570字）

各位游客朋友们，大家好！欢迎来到拉萨大昭寺。

在拉萨有一句话："先有大昭寺，后有拉萨城。"这座寺，比这座城还要早。

大昭寺始建于公元7世纪，松赞干布时期，距今1300多年。它是西藏现存最辉煌的吐蕃时期建筑，也是西藏最早的土木结构建筑之一。更要紧的是它的格局——它是藏式平川式寺庙布局的开山之作。什么叫平川式？就是不像后来的有些寺院那样依山而建、层层叠上，而是在平地上按中轴对称铺开院落。后世的藏传佛教寺院，很多都学它。

大昭寺真正的核心，在大殿深处——那尊释迦牟尼十二岁等身像，藏语叫"觉卧仁波切"。据史料记载，这尊像是文成公主入藏时带进来的。对藏传佛教信众而言，见到这尊像，是一生中最重要的事之一。所以各位会在殿外、在八廓街上，看到从青海、四川、甘肃远道而来、一步一叩头到拉萨的信众。请各位尊重他们的信仰，不围观、不打扰、不挡在叩拜的通道上。

出寺之前，请各位看寺前这通碑——唐蕃会盟碑，也叫长庆会盟碑。它立于唐长庆三年，也就是公元823年，碑上用汉文和藏文两种文字刻着同样的盟约内容，其中有"商议社稷如一""和同为一家"这样的表述。一千二百年前，汉藏两家把盟誓刻在石头上，立在最重要的寺院门前。它站在那里，本身就是一段历史。

寺外这条环形街道，叫八廓街，是传统的转经道，也是拉萨最古老的街区。

2000年，大昭寺作为布达拉宫的扩展项目列入《世界遗产名录》；2013年，被评为国家5A级旅游景区。殿内通常禁止拍照，请勿触摸佛像与壁画。出行前请核实预约与开放时段。

**【讲解要点提示】**
- 必讲：7世纪始建、西藏最早土木结构建筑之一、平川式寺庙布局开创者；释迦牟尼十二岁等身像与文成公主；823年唐蕃会盟碑；八廓街转经道；2000年扩展列入世界遗产
- 数据锚点：1300多年历史；823年；七世纪始建；2000年申遗；2013年评5A
- 常见误区：①大昭寺供奉的是十二岁等身像，八岁等身像原在小昭寺，讲解时勿混淆；②大昭寺是世界遗产"布达拉宫历史建筑群"的扩展项（2000年），不是独立申报项目；③转经与叩拜是信众的宗教实践，讲解须客观尊重，严禁猎奇式描述或调侃
- 互动/提问设计：请游客在寺前的唐蕃会盟碑上找一找，能否同时辨认出汉文和藏文两种文字

### 3. 林芝市巴松措景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2017年评定） |
| 所在地 | 西藏自治区林芝市工布江达县错高乡 |
| 类型 | 水域湖泊 · 宗教圣地 |
| 评定年份 | 2017 |
| 建议游览时长 | 3-4 小时 |

**【景区简介】**（约240字）

巴松措景区位于西藏自治区林芝市工布江达县错高乡，藏语意为"绿色的水"，又名措高湖，是一处高山冰川堰塞湖，湖面海拔约3480米，湖面面积约26平方公里。湖水由雪山融水与降水补给，因水深、含沙量低且富含矿物质，在晴日呈现碧绿至蓝绿色，四周群山环抱，雪峰、原始森林与湖面相互映衬，被称为镶嵌于高山峡谷中的一块碧玉。湖心岛（扎西岛）上建有措宗寺，是一座藏传佛教宁玛派小寺，为当地信众重要的礼佛场所。环湖及周边区域植被茂密，以冷杉、云杉为主的高山暗针叶林保存完好，分布有多种珍稀动植物，被视为重要的生物基因库。景区还包含雪山、瀑布、原始森林与工布藏族村落等景观。2017年，巴松措景区被评定为国家5A级旅游景区。

**【导游词核心稿】**（约550字）

各位游客朋友们，大家好！欢迎来到林芝巴松措。

"巴松措"是藏语，意思是"绿色的水"。各位一会儿站到湖边，就会明白这个名字起得有多准确。

先说几个数字：湖面海拔约3480米，湖面面积约26平方公里。它是一处冰川堰塞湖——很久以前，冰川携带的泥沙石块把河谷堵住，水越积越多，就积成了这片湖。

为什么水是绿的？主要有三个原因：一是水很深，二是泥沙极少，三是水里溶解了岩石带来的矿物质。阳光照进水里，红光、黄光先被吸收掉，剩下的蓝绿光散射出来，于是这片湖就像一整块碧玉，嵌在雪峰和森林之间。

请各位看湖中心那个小岛——扎西岛。岛上有一座小小的措宗寺，是一座藏传佛教宁玛派寺院。别看它不大，对周边的信众来说很重要。湖在藏地被称为"圣湖"，当地百姓世代有绕湖祈福的传统。各位如果有兴趣，可以按顺时针方向沿湖走一段，但请尊重当地习俗，不在湖中洗涮、不向湖里丢弃任何东西。

再看四周的山和树。巴松措这一带，冷杉、云杉组成的原始暗针叶林保存得非常完整，林子里苔藓厚、松萝长，物种资源丰富，被看作一座天然的基因库。林芝素有"西藏江南"之称，就是因为这一带的森林和水量，在整个青藏高原上都少见。

今天这一片山水，属于工布藏族的家园。当地百姓世代在此放牧、耕作，与这片湖相处了千百年。

2017年，巴松措被评为国家5A级旅游景区。高原紫外线强、昼夜温差大，请各位做好防晒与保暖。游览约3到4小时，出行前请核实景区开放安排。

**【讲解要点提示】**
- 必讲：藏语意为"绿色的水"；湖面海拔约3480米、面积约26平方公里；冰川堰塞湖成因；湖水呈绿色的成因；湖心岛措宗寺（宁玛派）；"圣湖"信仰与绕湖习俗
- 数据锚点：3480米；约26平方公里；2017年评5A
- 常见误区：①巴松措是藏传佛教信众心中的圣湖，讲解须庄重，不得猎奇或戏谑，尤其涉及到民间求子之类的说法时应客观转述；②措宗寺为宁玛派寺院，勿与其他教派混淆；③湖水为饮用水源与宗教圣境，严禁下水、洗涤或丢弃物品
- 互动/提问设计：请游客在不同天气、不同角度观察湖水颜色变化，想一想水色为什么会变？（引出光线角度、水深与悬浮物的影响）

### 4. 日喀则市扎什伦布寺景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2017年评定） |
| 所在地 | 西藏自治区日喀则市桑珠孜区几吉朗卡路1号 |
| 类型 | 宗教圣地 |
| 评定年份 | 2017 |
| 建议游览时长 | 2.5-3.5 小时 |

**【景区简介】**（约250字）

扎什伦布寺位于西藏自治区日喀则市桑珠孜区尼色日山下，藏语意为"吉祥须弥寺"，由藏传佛教格鲁派创始人宗喀巴的弟子、后被追认为一世达赖喇嘛的根敦珠巴于明正统十二年（1447年）创建，此后经四世班禅罗桑却吉坚赞等大规模扩建，自四世班禅起成为历代班禅额尔德尼的驻锡地。寺院占地面积约15万平方米，四周宫墙沿山势蜿蜒3000多米，有经堂57间、房屋3600间。它与拉萨甘丹寺、哲蚌寺、色拉寺并称格鲁派"四大寺"，又与青海塔尔寺、甘肃拉卜楞寺并列为格鲁派"六大寺"。主要建筑包括措钦大殿（可容2000余人诵经）、强巴佛殿、汉佛堂（甲纳拉康）与历代班禅灵塔殿。强巴佛殿建于1914年，由九世班禅确吉尼玛主持，殿内供奉鎏金铜弥勒（强巴）坐像，总高26.2米。1961年，扎什伦布寺被列为第一批全国重点文物保护单位；2017年，被评定为国家5A级旅游景区。

**【导游词核心稿】**（约580字）

各位游客朋友们，大家好！欢迎来到日喀则扎什伦布寺。

请各位先记住这座寺的位置：它背靠尼色日山，坐北朝南，殿宇顺着山坡一层层向上排布，疏密有致，看得出整体规划的功夫。"扎什伦布"是藏语，意为"吉祥须弥寺"。

它的创建者，是格鲁派创始人宗喀巴的弟子根敦珠巴。明正统十二年，也就是1447年，他在这里建起了最初的寺院。后来四世班禅罗桑却吉坚赞主持了最大规模的一次扩建。从四世班禅开始，这里成为历代班禅额尔德尼的驻锡地，直到今天。

在藏传佛教格鲁派的谱系里，扎什伦布寺的地位极高：它与拉萨的甘丹寺、哲蚌寺、色拉寺合称"四大寺"，又与青海塔尔寺、甘肃拉卜楞寺并列为"六大寺"。各位在别的藏区听过的寺院，多半就在这几个名字里。

今天有几处必看。第一处是强巴佛殿。它建于1914年，由九世班禅确吉尼玛主持修建。殿里供奉着一尊鎏金铜弥勒——也就是强巴佛——坐像，总高26.2米。据记载，铸造它用了黄铜23万多斤、黄金6700两，是世界上最大的室内铜佛坐像之一。各位站到佛脚下抬头看，会真切感受到什么叫"仰望"。

第二处是灵塔殿。寺里有历代班禅的灵塔，其中四世班禅灵塔建于1666年，五至九世班禅合葬灵塔"扎什南捷"、十世班禅灵塔"释颂南捷"则分别为20世纪80年代和90年代建成。灵塔是藏传佛教塔葬仪轨的重要建筑，请各位保持庄重。

第三处是汉佛堂，藏语叫"甲纳拉康"，建于七世班禅时期，堂内陈列着清代皇帝赠送给历世班禅的礼品。这些文物，是西藏地方与历代中央政府关系的重要历史见证。

1961年，扎什伦布寺被列为第一批全国重点文物保护单位；2017年，被评为国家5A级旅游景区。寺内禁止拍照区域请勿拍摄，进入殿堂请脱帽、不大声喧哗。

**【讲解要点提示】**

**【景区简介】**（约250字）

雅鲁藏布大峡谷景区位于西藏自治区林芝市米林市派镇，地处雅鲁藏布江下游。峡谷全长504.6公里，最深处达6009米，被公认为世界上长度最长、深度最深的大峡谷。雅鲁藏布江在此绕南迦巴瓦峰形成巨大的马蹄形拐弯，峡谷两侧山体从海拔7782米的南迦巴瓦峰直降到谷底，垂直高差极大，形成从高山冰雪带到热带季雨林带的完整垂直自然带谱，被誉为"山地生物资源基因宝库"与"世界地质博物馆"。峡谷同时是印度洋暖湿气流进入青藏高原的重要水汽通道，造就了林芝一带湿润温暖的独特气候。景区主要景观包括南迦巴瓦峰、大峡谷亲水台、直白村、索松村、千年古桑树及大拐弯等，区域内还散居着工布藏族、门巴族、珞巴族等民族村落。该景区2010年被评为国家4A级旅游景区，2020年11月授牌为国家5A级旅游景区。

**【导游词核心稿】**（约580字）

各位游客朋友们，大家好！欢迎来到林芝雅鲁藏布大峡谷。

这里有两个数字，值得各位记一辈子：峡谷全长504.6公里，最深处6009米。它是世界上最长、最深的大峡谷。把喜马拉雅山整个放进去，也填不满它。

先说它怎么来的。雅鲁藏布江从喜马拉雅山脉和冈底斯山脉之间一路东流，到了这一带，地壳抬升得厉害，江水就拼了命往下切。切了几百万年，切出了这条深达6009米的裂缝。

再看一个奇观：就在这一段，江水绕着一座山峰转了一个巨大的马蹄形弯——大拐弯。那座山，就是南迦巴瓦峰，海拔7782米，是喜马拉雅山脉东端的最高峰。从7782米的雪峰顶，到谷底的热带季雨林，直线距离之内落差超过5000米。所以有人说，站在这里，你一眼能看到"从赤道到极地"的全部风景：山顶是永久积雪，往下是高山灌丛、针叶林、针阔混交林、常绿阔叶林，再到谷底的季雨林。这在全世界都极为罕见。

还有一件更重要的事。这条峡谷，是印度洋暖湿气流进入青藏高原的"水汽通道"。孟加拉湾的湿润空气顺着峡谷往北灌，一路送进高原腹地，才有了林芝这片森林茂密、雨量充沛的土地，人们才叫它"西藏江南"。

谷里还生活着工布藏族、门巴族、珞巴族等民族的乡亲，他们在这样的环境里世代耕作、放牧，形成了独特的山地文化。请各位尊重当地生活习俗，不擅自进入村寨和农田。

请各位注意：南迦巴瓦峰常年云雾缭绕，能不能看见全貌要看缘分，我不会向各位承诺一定能看到。

大峡谷2010年被评为国家4A级景区，2020年11月正式授牌为国家5A级旅游景区。出行前请核实观光车线路与天气情况。

**【讲解要点提示】**
- 必讲：全长504.6公里、最深6009米，世界最长最深峡谷；南迦巴瓦峰7782米与马蹄形大拐弯；完整垂直自然带谱；水汽通道作用；2020年11月授牌5A
- 数据锚点：504.6公里；6009米；7782米；2010年4A；2020年评5A
- 常见误区：①南迦巴瓦峰常见云雾遮蔽，"十人九不遇"，不可向游客承诺一定能看到；②峡谷的"最深6009米"为相对深度测量值，讲解时说明其为公开数据；③门巴族、珞巴族等民族文化讲解须客观尊重，避免猎奇式表述
- 互动/提问设计：请游客观察从谷底到山顶植被的变化，数一数能看到几个不同颜色的植被带
