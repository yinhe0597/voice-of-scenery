## 一、5A级景区（精编词条）

### 1. 嘉峪关文物景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 嘉峪关市峪泉镇 |
| 类型 | 古城古镇 · 遗址考古 · 世界文化遗产 |
| 评定年份 | 2007 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

嘉峪关文物景区位于嘉峪关市西南，核心为嘉峪关关城。嘉峪关始建于明洪武五年（1372年），是明长城西端的起点，也是明代九边重镇中规模最大、保存最完整的军事防御关隘，有"天下第一雄关"之称。关城由内城、外城、罗城、瓮城、城壕组成，内城周长 640 米、总面积约 3.35 万平方米，城墙高约 10.7 米，四面设敌楼、角楼、箭楼，形成"两翼、三城、五里一燧"的完整防御体系。关城周边还分布有长城第一墩（讨赖河墩）、悬壁长城、黑山石刻等遗迹。1961 年，嘉峪关被列为第一批全国重点文物保护单位；1987 年，长城被联合国教科文组织列入《世界遗产名录》，嘉峪关是其中的重要组成部分。

**【导游词核心稿】**

各位游客，欢迎来到嘉峪关。这里是明长城的最西端，也是古人所说的"河西第一隘口"。

先看这座关城的来历。明洪武五年，也就是 1372 年，征西将军冯胜在河西走廊最窄的地方选址建关——南边是祁连山的雪峰，北边是黑山，中间只留一条十几公里宽的通道，把关城建在这里，就等于把河西走廊的喉咙攥在手里。此后一百多年不断增修，才有了今天看到的规模。

第二看"城中之城"。嘉峪关不是一道墙，而是一整套防御系统：外面是罗城，中间是外城，最里面才是内城。内城周长 640 米，城墙高约 10.7 米，四面有敌楼、角楼、箭楼；城外还有瓮城——敌人万一冲进来，进了瓮城就是四面受敌，古人叫"瓮中捉鳖"。整个关城总面积 3 万多平方米，是明代九边重镇里保存最完整的一座。

第三看"巧"。关城西侧有一块"定城砖"的传说：相传当年工匠易开占精确算出了用砖数量，完工后只多出一块砖，这块砖就被放在西瓮城门楼的后檐台上，成了"定城砖"。这是民间传说，讲解时请说明"相传"。真正让人佩服的，是这里不用一钉一铆的夯土与包砖工艺，六百多年过去依然挺立。

清代林则徐被贬新疆途中经过嘉峪关，写下"严关百尺界天西，万里征人驻马蹄"的诗句，说的就是这座关的雄浑。

最后提醒：关城内外日晒强烈、风沙大，请备帽子、墨镜和水；墙体为文物，请勿攀爬、刻画。长城第一墩与悬壁长城距离关城较远，需乘车前往，请提前安排。

**【讲解要点提示】**
- 必讲：1372 年始建、明长城西端起点；内城周长 640 米、墙高 10.7 米；1961 年全国重点文保、1987 年长城世界遗产。
- 数据锚点：1372 年；640 米；10.7 米；约 3.35 万平方米；1987 年世界遗产。
- 常见误区：嘉峪关不是"长城的终点"，明长城向东一直延伸到辽东；"天下第一雄关"是赞誉性称号，非官方定名。
- 互动/提问设计：为什么关城要修"瓮城"？古人是怎么在没有水泥的年代把墙砌得这么结实的？

### 2. 平凉崆峒山风景名胜区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2007年评定，首批） |
| 所在地 | 平凉市崆峒区 |
| 类型 | 山岳峰林 · 宗教圣地 |
| 评定年份 | 2007 |
| 建议游览时长 | 5–7 小时 |

**【景区简介】**

崆峒山位于平凉市崆峒区西部，属六盘山支脉，主峰海拔约 2123 米，是古丝绸之路西出长安后的第一座名山，有"西来第一山""道源圣地"之誉。山体以丹霞地貌与石灰岩峰林为主，森林覆盖率超过 90%，兼具北雄南秀之姿。崆峒山自秦汉即为道教圣地，相传黄帝曾在此问道于广成子，历代在此修建道观，现存皇城、雷声峰、凌空塔、问道宫等建筑群，是道教全真派的重要活动场所，民间亦有"崆峒武术"流传。1994 年，崆峒山被列为国家重点风景名胜区，2007 年评为首批国家 5A 级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到崆峒山。这座山有两个标签：一个是"道源"，一个是"奇险"。

先说"道源"。崆峒山自古就是道教名山。相传，轩辕黄帝曾专程来到这里，向隐居于此的广成子请教治国与养生之道，这就是著名的"黄帝问道"典故。《庄子》里记载了这个故事，后世把崆峒山尊为道教的发源地之一，称它"道源圣地"。当然，这是记载于古籍的传说性典故，讲解时我们说"相传""据《庄子》记载"。山上至今有问道宫、皇城、雷声峰等宫观建筑，依山就势，一层层贴在崖壁上。

再看"奇险"。崆峒山主峰海拔约 2123 米，山体是丹霞地貌与石灰岩峰林的混合体，峰顶平缓、四壁陡峭，很像南方的丹霞山，却又长在西北的黄土高原边缘，所以古人说它"兼北雄南秀"。森林覆盖率超过 90%，走在林子里，夏天格外凉爽。

第三看"塔"。山顶有座凌空塔，是一座明代砖塔，建在险峻的峰顶平台之上，几百年来风吹雨打不倒，是崆峒山的标志。

崆峒武术是流传于当地的传统武术流派，在民间影响很大，金庸武侠小说里也写到过崆峒派。需要说明：武侠小说中的门派描写属于文学创作，与现实中的崆峒武术传统不是一回事，讲解时要把两者分开。

最后提醒：登山有索道与步行道两种选择，全程徒步约需 4—5 小时；山上道观为宗教活动场所，请尊重道教的礼仪与禁忌，未经允许不要拍摄殿内神像与宗教仪式。

**【讲解要点提示】**
- 必讲：主峰海拔约 2123 米；黄帝问道广成子的典故及"相传"标注；皇城、雷声峰、凌空塔。
- 数据锚点：2123 米；森林覆盖率 90% 以上；1994 年国家重点风景名胜区；2007 年首批 5A。
- 常见误区：不要把崆峒武术等同于武侠小说里的"崆峒派"；崆峒山是道教名山，也有佛教寺院共存，讲解宜客观描述。
- 互动/提问设计：《庄子》里广成子给黄帝的答案是什么？为什么古人喜欢把道观修在山顶？

### 3. 天水麦积山景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2011年评定） |
| 所在地 | 天水市麦积区麦积镇 |
| 类型 | 宗教圣地 · 遗址考古 · 世界文化遗产 |
| 评定年份 | 2011 |
| 建议游览时长 | 4–5 小时 |

**【景区简介】**

麦积山位于天水市麦积区东南，是小陇山中的一座孤峰，因山形酷似农家麦垛而得名。麦积山石窟始凿于十六国后秦时期（约公元 4 世纪末至 5 世纪初），历经北魏、西魏、北周、隋、唐、宋、元、明、清历代开凿重修，现存窟龛 221 个，各类造像 1 万余身，壁画近 1000 平方米，是中国四大石窟之一。石窟开凿在高约 142 米的崖面上，栈道凌空盘旋，最高处距地面 80 余米，以精美的泥塑著称，被誉为"东方雕塑陈列馆"。1961 年，麦积山石窟被列为第一批全国重点文物保护单位；2014 年作为"丝绸之路：长安—天山廊道的路网"遗产点列入《世界遗产名录》。

**【导游词核心稿】**

各位游客，欢迎来到麦积山。请您先抬头——眼前这座山像什么？像不像乡下场上堆起的麦垛？"麦积"这个名字，就是这么来的。

第一看"险"。石窟全部开凿在这面高约 142 米的崖壁上，最高的洞窟距地面 80 多米。当年工匠们先在崖面上凿出桩孔，架起木栈道，再一层层往上开窟。今天我们走的凌空栈道，就是沿着当年的路线修的，脚下悬空，请扶好栏杆、不要拥挤。

第二看"塑"。麦积山最了不得的是泥塑。因为这里的砂砾岩不适合精雕细刻，工匠就改用"石胎泥塑"——先凿出粗胎，再敷泥塑形、彩绘。现存窟龛 221 个，造像 1 万多身，壁画近 1000 平方米。北魏的造像清瘦俊逸、衣纹如水；西魏的菩萨面带微笑，被后人称作"东方的微笑"；北周、唐代的造像则更加丰润饱满。

第三看"时间"。这座石窟从十六国后秦开始凿，一直延续到清代，前后一千五百多年，几乎每个朝代都在这里留下了作品，堪称一部立体的中国雕塑编年史。

1961 年它成为第一批全国重点文物保护单位，2014 年又作为丝绸之路的一处遗产点列入《世界遗产名录》。

提醒：洞窟内光线昏暗且空间狭小，请勿使用闪光灯、勿触摸塑像与壁画；部分特窟需另行预约。栈道为单行线，请勿逆行。山顶与山下温差较大，请带一件外套。

**【讲解要点提示】**
- 必讲：始凿于后秦、延续至清；窟龛 221 个、造像万余身；"东方雕塑陈列馆"；2014 年世界遗产。
- 数据锚点：崖面高约 142 米；221 个窟龛；造像 1 万余身、壁画近 1000 平方米；2014 年申遗成功。
- 常见误区：麦积山石窟以"泥塑"见长，不是以"石雕"见长，与云冈、龙门区别明显；洞窟编号不是游览顺序。
- 互动/提问设计：为什么这里的佛像多用泥塑而不是石雕？"东方的微笑"指的是哪一尊？

### 4. 敦煌鸣沙山·月牙泉景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2015年评定） |
| 所在地 | 酒泉市敦煌市月牙泉镇 |
| 类型 | 沙漠戈壁 · 水域湖泊 |
| 评定年份 | 2015 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

鸣沙山·月牙泉景区位于敦煌市城南，是敦煌世界地质公园的核心园区之一。鸣沙山东西绵延约 40 公里、南北宽约 20 公里，由连绵的沙垄组成，因风起或人马沿沙面下滑时沙粒摩擦发出声响而得名，古人称"沙岭晴鸣"。月牙泉处于沙山环抱之中，形似新月，南北长约 150 米、东西宽约 50 米，是沙漠中罕见的天然淡水泉。沙山与清泉共处、"沙不掩泉、泉不涸竭"的景观在中国乃至世界均属少见。20 世纪后期月牙泉水位一度下降，此后通过地下水回灌等生态保护措施维持水位，成为沙漠遗产地保护的代表性案例。景区为国家重点风景名胜区。

**【导游词核心稿】**

各位朋友，欢迎来到鸣沙山·月牙泉。这一站的核心是两个字：共生。

第一看"沙"。鸣沙山东西长约 40 公里、南北宽约 20 公里，全是一层层沙垄堆起来的。为什么叫"鸣沙"？风一起，或者大家顺着沙坡往下滑的时候，沙粒相互摩擦，会发出嗡嗡的声音，像远处的鼓声。这是真实存在的物理现象，您在滑沙时可以留意听一听。

第二看"泉"。月牙泉就在沙山的环抱之中，形如新月，南北长约 150 米、东西宽约 50 米。它最特别的地方是：被沙山四面围住，却千百年没有被沙埋掉。古人惊叹"沙不掩泉、泉不涸竭"。这里要如实说明：20 世纪后期，受地下水开采、上游来水变化等影响，月牙泉水位曾明显下降、水面缩小；后来通过地下水回灌等生态补水措施，水位才得以维持。所以讲解时不要把它讲成"永不枯竭的奇迹"，而要说"这是自然奇观加科学保护的结果"——这更能体现我们对自然遗产的态度。

第三看"事"。敦煌是丝绸之路上的重镇，月牙泉边的建筑群历代屡有兴废，现存多为近年修缮。古人在这里祈雨、庙会，留下不少民俗记忆。

建议安排：清晨或傍晚进园，避开中午高温；滑沙、骑骆驼、沙漠摩托等项目各有收费与年龄限制，出行前请核实。

最后提醒：沙漠地区日照极强、昼夜温差大，请备足水、帽子、墨镜和防沙头巾；请走指定栈道，不要单独深入沙山腹地。

**【讲解要点提示】**
- 必讲：鸣沙成因；月牙泉规模（长约 150 米、宽约 50 米）；"沙泉共生"景观与生态补水保护。
- 数据锚点：鸣沙山东西约 40 公里、南北约 20 公里；月牙泉约 150 米 × 50 米；2015 年评为 5A。
- 常见误区：月牙泉如今的水位依靠人工补水维持，不宜讲成"天然永不干涸"；鸣沙山与莫高窟是两个不同景区，相距约 25 公里。
- 互动/提问设计：沙子为什么会"唱歌"？为什么泉水不会被沙埋掉？

### 5. 张掖七彩丹霞景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2019年评定） |
| 所在地 | 张掖市临泽县（部分跨肃南裕固族自治县） |
| 类型 | 地质地貌 · 山岳峰林 |
| 评定年份 | 2019 |
| 建议游览时长 | 3–4 小时 |

**【景区简介】**

张掖七彩丹霞景区位于张掖市临泽县倪家营镇一带，地处祁连山北麓，是中国北方干旱区典型的丹霞地貌与彩色丘陵复合景观区。张掖丹霞地貌总面积约 510 平方公里，其中核心游览区集中在临泽县，设有四座观景台。这里的岩层形成于约 1 亿年前的白垩纪，由红色砂砾岩、泥岩与含铁、含钙的杂色岩层交替沉积，后期的构造抬升与流水、风力侵蚀，雕出层层叠叠的彩色条带。2005 年，张掖丹霞被《中国国家地理》杂志评选为"中国最美的七大丹霞"之一；现为国家地质公园，2019 年评为国家 5A 级旅游景区。

**【导游词核心稿】**

各位游客，欢迎来到张掖七彩丹霞。这里的山不是绿的，也不是灰的，是彩色的。

第一看"色"。这些岩层主要是白垩纪形成的，大约在 1 亿年前，那时候这里还是一片内陆湖盆，气候时干时湿。气候干燥时，铁质被氧化，沉积物就变成红色、紫红色；气候湿润时，还原环境下又生成灰绿、灰白色的夹层。一红一绿反复交替，像千层蛋糕一样叠了几百米厚。后来地壳抬升、湖水退去，风和水再慢慢雕，才把这些彩色条带剖开给我们看。

第二看"形"。丹霞地貌的特点是"顶平、身陡、麓缓"，配上彩色丘陵，就形成了一片片圆润的彩色山丘。景区内设有四座观景台，每座看到的画面都不一样：一号台视野最开阔，四号台的色彩最浓艳，也是看日落的最佳位置。

第三看"时"。同一座山，早上、正午、傍晚的颜色完全不同。中午光线平，颜色偏淡；日出和日落时斜光一打，红色和黄色会被彻底点燃。所以摄影的朋友，请把最好的时间留给清晨和黄昏。

2005 年，《中国国家地理》把张掖丹霞列入"中国最美的七大丹霞"，此后这里成了西北最热门的地质景观之一。2019 年评为国家 5A 级景区。

提醒：这些彩色岩层极其脆弱，踩上去几十年都恢复不了，请务必在栈道和观景台内活动，不要翻越护栏、不要踩踏地貌；景区没有遮阴处，请带水、帽子和防晒用品。

**【讲解要点提示】**
- 必讲：白垩纪沉积与氧化还原成色原理；丹霞地貌"顶平身陡麓缓"特征；四座观景台的差异。
- 数据锚点：张掖丹霞总面积约 510 平方公里；岩层形成于约 1 亿年前；2005 年入选"中国最美七大丹霞"；2019 年评为 5A。
- 常见误区：不要把"丹霞"与"彩色丘陵"混为一谈，本景区是两者复合；地貌不可再生，严禁踩踏。

### 6. 临夏炳灵寺世界文化遗产旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2020年评定） |
| 所在地 | 临夏回族自治州永靖县 |
| 类型 | 宗教圣地 · 地质地貌 · 世界文化遗产 |
| 评定年份 | 2020 |
| 建议游览时长 | 4–6 小时 |

**【景区简介】**

炳灵寺世界文化遗产旅游区位于临夏回族自治州永靖县，由炳灵寺石窟、炳灵石林与刘家峡库区水域三部分组成。炳灵寺石窟开凿于黄河岸边的红砂岩崖壁上，始凿于西秦时期，第 169 窟存有西秦建弘元年（420年）的墨书题记，是中国石窟中年代明确的最早纪年题记之一，为研究中国石窟年代提供了关键标尺。现存窟龛 216 个，各类造像近 800 尊，壁画约 1000 平方米；其中第 171 窟的唐代弥勒大佛高约 27 米，为景区标志性造像。"炳灵"为藏语译音，意为"十万弥勒佛洲"，反映出该地藏传佛教传承的深厚背景。2014 年，炳灵寺石窟作为"丝绸之路：长安—天山廊道的路网"遗产点列入《世界遗产名录》。

**【导游词核心稿】**

各位游客，欢迎来到炳灵寺。这里藏在黄河三峡的峡谷里，需要乘船进入——光是这段水路，就已经是一次旅行。

第一看"早"。炳灵寺石窟最珍贵的，是第 169 窟里的那方墨书题记：西秦建弘元年，也就是公元 420 年。它为什么重要？因为中国早期石窟大多年代不明，而这一处有明确的纪年，就像一把标尺，帮考古学家校准了其他石窟的年代。所以学界称它是中国石窟断代的关键证据之一。

第二看"佛"。石窟现存窟龛 216 个，造像近 800 尊，壁画约 1000 平方米。最震撼的是第 171 窟的唐代弥勒大佛，高约 27 米，依崖而凿，站在佛脚下抬头仰望，人显得格外渺小。

第三看"名"。"炳灵"是藏语的音译，意思是"十万弥勒佛洲"。这个名字本身就说明，这里长期是藏传佛教的重要道场，后来又与汉传佛教、当地多民族信仰交融，形成了独特的文化面貌。临夏一带是多民族聚居区，回、汉、藏、东乡、保安、撒拉等民族世代相处，讲解时请客观尊重各民族的风俗与宗教信仰。

上岸之后，还可以看炳灵石林——一片丹霞峰林立在黄河岸边，红岩碧水，与石窟相映。

提醒：前往石窟需乘船，班次受季节、水位和天气影响较大，出行前务必核实；石窟栈道狭窄陡峭，请量力而行；洞窟内禁止拍摄与使用闪光灯，请勿触摸造像与壁画。

**【讲解要点提示】**
- 必讲：第 169 窟西秦建弘元年（420年）题记的断代价值；第 171 窟唐代大佛约 27 米；2014 年世界遗产身份。
- 数据锚点：420 年；窟龛 216 个、造像近 800 尊、壁画约 1000 平方米；大佛约 27 米；2020 年评为 5A。
- 常见误区：不要说"炳灵寺始于唐代"，其始凿年代在西秦（十六国时期）；"炳灵"为藏语音译，不是汉语地名。
- 互动/提问设计：为什么有明确纪年的石窟这么重要？藏语地名"炳灵"说明了什么？

### 7. 陇南官鹅沟景区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2022年评定） |
| 所在地 | 陇南市宕昌县城南 |
| 类型 | 山岳峰林 · 水域湖泊 · 森林草原 |
| 评定年份 | 2022 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

官鹅沟位于陇南市宕昌县城南，地处青藏高原东部边缘与西秦岭的交汇地带，由官珠沟、鹅嫚沟两条主沟及多条支沟组成，是一处以峡谷、瀑布、湖潭和原始森林为主体的复合型生态景区。谷内峰峦叠嶂，发育有大小瀑布数十处，湖潭（当地称"海子"）星罗棋布，森林覆盖率高，保存有较完整的山地植被垂直带谱，有"陇上小九寨"之誉。所在的宕昌县为多民族聚居区，沟内保留有藏族村寨与传统民俗。官鹅沟现为国家森林公园，2022 年被确定为国家 5A 级旅游景区。

**【导游词核心稿】**

各位朋友，欢迎来到官鹅沟。这里在甘肃的最南边，地理上已经算得上"南方的北方、北方的南方"。

第一看"水"。官鹅沟由官珠沟和鹅嫚沟两条主沟组成，沟里几乎步步有水：溪流、跌水、瀑布、深潭连成串，当地人把那些幽绿的深水潭叫"海子"。夏天水量大，瀑布一个接一个；秋天水清林黄，是摄影最好的季节。

第二看"绿"。这里地处青藏高原边缘和西秦岭的交汇带，山高谷深，植被保存得非常好，从山脚的阔叶林一直往上过渡到针叶林和高山草甸。因为空气湿润、植被茂密，走进沟里就像进了天然空调房，所以人称"陇上小九寨"。

第三看"人"。宕昌是汉、藏、回等多民族共同生活的地方，沟里还保留着藏族村寨。当地的传统民居、服饰、歌舞和节庆，都是长期适应这片山地环境形成的文化。讲解时请本着尊重的态度客观介绍，不要猎奇式地描述，也不要随意评价信仰与习俗。

需要说明：官鹅沟的生态非常脆弱，谷内栈道是唯一的行走路径，请勿下水、采摘或离开栈道。

提醒：景区面积大，两条沟完整走完需要一整天，建议住一晚；山区天气多变，随时可能下雨，请带雨具和防滑鞋。观光车与索道的运营安排随季节调整，出行前请核实。

**【讲解要点提示】**
- 必讲：官珠沟、鹅嫚沟两沟格局；瀑布群与"海子"；森林与垂直植被带。
- 数据锚点：由官珠沟、鹅嫚沟等沟谷组成；2022 年评为 5A；国家森林公园。
- 常见误区：不要把"陇上小九寨"理解成官鹅沟的正式定位，它只是赞誉性说法；景区不同沟谷之间距离较远，需分别安排时间。
- 互动/提问设计：为什么这里的高山湖泊叫"海子"？山地植被为什么会一层层变化？

### 8. 甘南冶力关旅游区

| 项目 | 内容 |
| --- | --- |
| 等级 | 5A（2024年评定） |
| 所在地 | 甘南藏族自治州临潭县冶力关镇 |
| 类型 | 山岳峰林 · 水域湖泊 · 森林草原 |
| 评定年份 | 2024 |
| 建议游览时长 | 1–2 天 |

**【景区简介】**

冶力关旅游区位于甘南藏族自治州临潭县，地处青藏高原东北边缘向黄土高原过渡的地带，海拔约 2200—3900 米，是以高原湖泊、赤壁丹崖、原始森林与草原牧场为主体的生态文化景区。核心景观包括高山淡水湖冶海（俗称常爷池）、赤壁幽谷、莲花山、亲昵沟、镇关雄柱等。冶海为高山堰塞湖，冬季湖面冰层形成独特纹理，旧有"冶海冰图"之说；莲花山主峰海拔约 3578 米，是甘南地区重要的神山之一，山下的莲花山"花儿"民歌活动为中国国家级非物质文化遗产。甘南为藏、汉、回、土等多民族聚居区，当地民俗与信仰传统深厚。冶力关现为国家森林公园，2024 年被确定为国家 5A 级旅游景区。

**【导游词核心稿】**

各位游客，欢迎来到甘南冶力关。这里是青藏高原伸向黄土高原的一只脚，海拔 2200 米到 3900 米，一天之内可以经历几种风景。

第一看"湖"。冶海是景区的核心，一个高山淡水湖，湖面海拔约 2600 米，四周被森林和草甸包围。冬天湖水结冰，冰面上会裂出各种纹路，古人把这些纹路看作某种征兆，称之为"冶海冰图"。这是一种民间的观察与想象，学理上是冰层应力变化的结果，讲解时可以说清两者的区别。

第二看"赤壁"。赤壁幽谷是一段红色的砂砾岩峡谷，岩壁垂直、色泽赭红，和绿色的森林形成强烈对比，是拍照的好地方。

第三看"山"。莲花山主峰海拔约 3578 米，山形如莲瓣层层舒展。在当地藏族、汉族群众的传统观念里，它是重要的神山，民间有朝山的习俗；山下每年还有"花儿会"——这是流传于甘青宁一带的一种山歌演唱活动，已被列入中国国家级非物质文化遗产名录。这些信仰与民俗，是当地群众长期生活经验的积累，讲解请保持尊重与客观，不要调侃、不要猎奇，也不要擅自解读宗教仪式的含义。

提醒：甘南平均海拔较高，初到这里请勿剧烈运动、注意保暖、多喝水；尊重当地风俗，进入寺院请脱帽、不喧哗，拍摄人物前请先征得同意；山区天气变化快，行程请留出弹性。

**【讲解要点提示】**
- 必讲：冶海高山湖；赤壁幽谷；莲花山与"花儿会"非遗。
- 数据锚点：景区海拔约 2200—3900 米；莲花山主峰约 3578 米；冶海湖面海拔约 2600 米；2024 年评为 5A。
- 常见误区：不要把"神山""朝山"当成旅游景点项目来推销，它们是当地群众的信仰实践；"冶海冰图"宜解释为冰面自然纹理的民间解读。
- 互动/提问设计：高山湖是怎么形成的？为什么甘南的"花儿"要用方言唱？
